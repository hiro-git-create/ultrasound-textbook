# 乳腺の解剖と JABTS カテゴリー判定基準（乳癌鑑別アルゴリズム）

乳腺超音波検査は、若年者や高濃度乳房（Dense Breast）を含むすべての女性において、**乳癌（浸潤性乳管がん・非浸潤性乳管がん）と良性腫瘤（線維腺腫・嚢胞）を高精度に鑑別**するための標準的画像診断です。

---

## 1. JABTS 乳房超音波 カテゴリー 1 〜 5 判定基準

| カテゴリー (Category) | 臨床的意義 (JABTS) | 該当する代表的超音波所見 | 判定・推奨アクション |
| :---: | :--- | :--- | :--- |
| **カテゴリー 1** | **異常なし (Negative)** | 正常乳腺組織のみ。腫瘤や局所的変化なし。 | 定期検診継続 |
| **カテゴリー 2** | **良性病変 (Benign)** | 単純嚢胞、典型的な線維腺腫（平滑・横長・等回音）、乳腺症。 | 精査不要 (次回検診) |
| **カテゴリー 3** | **良性悪性鑑別困難<br>(おそらく良性 / 悪性率 < 2%)** | 形状整だが境界一部不鮮明、あるいは非浸潤癌を否定できない低エコー域。 | **要精査 (6ヶ月後フォロー / 組織診)** |
| **カテゴリー 4** | **悪性疑い (Suspicious / 悪性率 2-95%)** | 不整形腫瘤、境界部断微細像 (Halo / Spiculation)、微細点状石灰化集簇。 | **要精密検査 (針生検 CNB / 組織診)** |
| **カテゴリー 5** | **悪性極めて濃厚 (Malignant / 悪性率 > 95%)** | 浸潤傾向が明白な高度不整形、縦横比 $>1$、後方エコー著明減衰、胸筋浸潤。 | **悪性確定診断・手術/化学療法** |

---

## 2. 腫瘤性病変の悪性・良性エコー所見比較 (JABTS)

```
【良性腫瘤 (線維腺腫)】          【悪性腫瘤 (浸潤性乳管癌)】
      ┌──────┐                    ／＼／＼  (不整形・鋸歯状)
      │ 楕円 │ 縦横比 < 1       (   癌   ) 縦横比 > 1 (縦長)
      └──────┘                    ＼／＼／  Halo・Spiculation (棘状突出)
   後方エコー増強                  後方エコー減衰 (音響陰影)
```

- **境界部断微細像 (Border characteristics)**:
  - **Halo (ハロー)**: 腫瘤周囲の帯状の低〜高エコー縁。厚く不均一な Halo は悪性所見。
  - **Spiculation (スピキュラ)**: 腫瘤から周囲乳腺組織へ放射状に伸びる棘状・針状突出像（浸潤癌の決定的所見）。
