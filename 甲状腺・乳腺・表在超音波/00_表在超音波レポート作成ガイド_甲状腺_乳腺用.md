# 表在超音波標準レポートテンプレート ＆ 作成ガイド (甲状腺・乳腺・表在用)

本ページは、**甲状腺超音波**、**乳腺超音波 (JABTS カテゴリー対応)**、および**皮下・唾液腺・リンパ節**の電子カルテ用コピペ可能標準レポートテンプレートです。

================================================================================
【患者基本情報】
ID: [           ] 氏名: [           ] 年齢: [   ]歳 性別: [男/女]

【1. 甲状腺実質 ＆ サイズ】
・右葉: [    ] x [    ] x [    ] mm  /  左葉: [    ] x [    ] x [    ] mm  /  峡部厚: [    ] mm
・実質エコー: [ 均一・正常 / 粗雑・不均一 ( 橋本病疑い ) / びまん性腫大・Inferno血流 ( バセドウ病疑い ) ]

【2. 結節性病変 (Nodule)】
・結節の有無: [ なし / あり ( [右葉 / 左葉 / 峡部] [上極 / 中部 / 下極] ) ]
  - サイズ    : [      ] x [      ] x [      ] mm ( 縦横比: [ >1.0 / <1.0 ] )
  - 形状・境界: [ 円形・平滑 / 不整・微細分葉状・Spiculation (悪性疑い) ]
  - 内部エコー: [ 嚢胞性 / 等回音 / 著明低回音 (前頸筋以下) / 充実性 ]
  - 石灰化    : [ なし / 砂粒状微細石灰化(≤1mm: 乳頭癌疑い) / 粗大石灰化 / 殻状 ]
  - 血流      : [ 辺縁優位 / 内部豊富 / 乏しい ]

--------------------------------------------------------------------------------
【総合診断インプレッション】
