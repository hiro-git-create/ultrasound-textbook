# 臨床・病理 乳癌取扱い規約 ＆ 病理ガイドライン完全まとめ

> [!NOTE] 概要
> 本ドキュメントは、日本乳癌学会編『臨床・病理 乳癌取扱い規約』および国際標準（UICC/AJCC 第8版、WHO分類）に完全準拠した臨床・病理・超音波診断の統合リファレンスです。
> 超音波検査による腫瘍計測・進展度評価から、病理組織型・バイオマーカー・サブタイプ判定、術前化学療法（NAC）効果判定までを網羅しています。

---

## 1. TNM分類と病期分類（Clinical & Pathological Staging）

乳がんの病期判定は、**臨床分類（cTNM）**と**病理分類（pTNM）**に明確に区別されます。超音波検査は特にcTおよびcNの決定において中心的な役割を果たします。

```
                     ┌─── T因子（原発巣の浸潤径・胸壁/皮膚浸潤）
【乳癌病期 (Stage)】 ──┼─── N因子（所属リンパ節転移：個数・部位・固定）
                     └─── M因子（遠隔転移の有無）
```

---

### (1) T因子（原発腫瘍の大きさ・浸潤度）
超音波・病理診断ともに**「浸潤部分の最大径（Invasive size）」**で評価します（非浸潤成分［DCIS成分］は長径に含めない）。

| T分類 | 定義 | 超音波検査・臨床所見のポイント |
| :--- | :--- | :--- |
| **TX** | 原発腫瘍の評価が不可能 | — |
| **T0** | 原発腫瘍を認めない | — |
| **Tis** | **非浸潤癌 (In situ carcinoma)** | **DCIS**、小葉上皮内癌（LCIS）、パジェット病（腫瘤を伴わないもの） |
| **T1** | **浸潤径 $\le 2.0\text{ cm}$** | 最も早期の浸潤癌ステージ |
| ├ **T1mic** | 微小浸潤（$\le 0.1\text{ cm} = 1\text{ mm}$） | 浸潤巣が $1\text{ mm}$ 以下の極小病変 |
| ├ **T1a** | $0.1\text{ cm} < \text{浸潤径} \le 0.5\text{ cm}$ | $1\text{ mm}$ 超 $5\text{ mm}$ 以下 |
| ├ **T1b** | $0.5\text{ cm} < \text{浸潤径} \le 1.0\text{ cm}$ | $5\text{ mm}$ 超 $10\text{ mm}$ 以下 |
| └ **T1c** | $1.0\text{ cm} < \text{浸潤径} \le 2.0\text{ cm}$ | $10\text{ mm}$ 超 $20\text{ mm}$ 以下 |
| **T2** | **$2.0\text{ cm} < \text{浸潤径} \le 5.0\text{ cm}$** | $2\text{ cm}$ 超 $5\text{ cm}$ 以下の浸潤癌 |
| **T3** | **浸潤径 $> 5.0\text{ cm}$** | $5\text{ cm}$ 超の巨大浸潤癌 |
| **T4** | **胸壁固定または皮膚浸潤を伴うもの**（大きさ不問） | — |
| ├ **T4a** | 胸壁（肋骨、肋間筋、前鋸筋）への浸潤・固定 | 大胸筋浸潤のみではT4とならない点に注意 |
| ├ **T4b** | 皮膚の浮腫（peau d'orange: 橙皮状皮膚）、皮膚潰瘍、同側乳房皮膚結節 | — |
| ├ **T4c** | T4a と T4b の両方を認めるもの | — |
| └ **T4d** | **炎症性乳癌 (Inflammatory carcinoma)** | びまん性の皮膚発赤・浮腫・熱感（急激な進行） |

> [!WARNING] 超音波計測時の重要注意点
> - 乳腺エコーで計測する際、**「浸潤癌疑い部分の最大長径」**と**「乳管内進展部（広がり）を含めた全体長径」**の両方を記録することが推奨されます。
> - T分類の基準となるのは**浸潤径**です。

### (2) N因子（所属リンパ節転移）

#### 臨床的N分類 (cN)
| cN分類 | 定義 | 超音波・触診所見 |
| :--- | :--- | :--- |
| **cN0** | 所属リンパ節転移なし | エコーでリンパ門保持、皮質菲薄（$< 2.5\sim 3\text{ mm}$） |
| **cN1** | 可動性の同側腋窩リンパ節（Level I, II）転移 | 皮質肥厚、リンパ門消失、球状化、血流増多 |
| **cN2** | 固定/癒合した同側腋窩リンパ節、または内胸リンパ節転移 | — |
| ├ **cN2a** | 互いに固定または周囲組織に固定した同側腋窩リンパ節転移 | リンパ節同士の癒合塊（matted nodes） |
| └ **cN2b** | 腋窩転移を伴わない臨床的同側内胸リンパ節転移 | 胸骨傍のリンパ節腫大 |
| **cN3** | 進行した領域リンパ節転移 | — |
| ├ **cN3a** | 同側**鎖骨下リンパ節**（Level III）転移 | 鎖骨下窩・小胸筋内側の腫大リンパ節 |
| ├ **cN3b** | 同側**内胸リンパ節転移** ＋ **腋窩リンパ節転移**の併発 | — |
| └ **cN3c** | 同側**鎖骨上リンパ節**転移 | 鎖骨上窩リンパ節（所属リンパ節として扱う） |

#### 病理学的N分類 (pN) - 郭清・生検後
- **pN0**: 転移なし
  - **pN0(i+)**: 孤立性腫瘍細胞（ITC: Isolated Tumor Cells, $\le 0.2\text{ mm}$ または 200細胞以下）
  - **pN0(mol+)**: RT-PCR等の分子生物学的陽性のみ
- **pN1**: 1〜3個の所属リンパ節転移
  - **pN1mi**: 微小転移（Micrometastasis: $0.2\text{ mm} < \text{転移巣} \le 2.0\text{ mm}$）
  - **pN1a**: 1〜3個の腋窩リンパ節転移（少なくとも1個は $> 2.0\text{ mm}$）
  - **pN1b**: 内胸リンパ節微小転移（センチネル生検検出）
  - **pN1c**: pN1a ＋ pN1b
- **pN2**: 4〜9個の腋窩リンパ節転移（pN2a）、または臨床的内胸リンパ節転移（pN2b）
- **pN3**: 10個以上の腋窩転移、鎖骨下リンパ節転移（pN3a）、内胸＋腋窩（pN3b）、鎖骨上リンパ節転移（pN3c）

---

### (3) M因子（遠隔転移）
- **cM0 / pM0**: 遠隔転移なし
- **cM1 / pM1**: 遠隔転移あり（骨、肺、肝、脳、遠隔リンパ節など）

---

### (4) 解剖学的病期分類 (Anatomic Stage Groups)

| Stage | T | N | M | 臨床的要約 |
| :---: | :---: | :---: | :---: | :--- |
| **Stage 0** | **Tis** | **N0** | **M0** | 非浸潤癌（DCIS等） |
| **Stage IA** | T1 | N0 | M0 | $2\text{ cm}$ 以下の浸潤癌・転移なし |
| **Stage IB** | T0〜T1 | **N1mi** | M0 | 原発巣微小または $2\text{ cm}$ 以下 ＋ 微小転移 |
| **Stage IIA** | T0〜T1<br>T2 | **N1**<br>N0 | M0<br>M0 | $2\text{ cm}$ 以下＋腋窩転移(1-3個)<br>または $2\sim 5\text{ cm}$＋転移なし |
| **Stage IIB** | T2<br>T3 | **N1**<br>N0 | M0<br>M0 | $2\sim 5\text{ cm}$＋腋窩転移(1-3個)<br>または $5\text{ cm}$ 超＋転移なし |
| **Stage IIIA** | T0〜T2<br>T3 | **N2**<br>N1〜N2 | M0<br>M0 | 腋窩転移4-9個/固定<br>または $5\text{ cm}$ 超＋リンパ節転移あり |
| **Stage IIIB** | **T4** | N0〜N2 | M0 | 胸壁固定・皮膚潰瘍・炎症性乳癌 |
| **Stage IIIC** | 任意のT | **N3** | M0 | 鎖骨下・鎖骨上・内胸転移 |
| **Stage IV** | 任意のT | 任意のN | **M1** | **遠隔転移あり** |

## 2. 病理組織学的分類（WHO / 日本乳癌学会）

```
【病理組織分類】
├── 1. 上皮性悪性腫瘍
│   ├── (1) 非浸潤癌 (Non-invasive carcinoma)
│   │   ├── 非浸潤性乳管癌 (DCIS)
│   │   └── パジェット病 (Paget disease of the nipple)
│   └── (2) 浸潤癌 (Invasive carcinoma)
│       ├── 浸潤性乳管癌（非特殊型: Invasive carcinoma of NST / IDC）
│       └── 特殊型 (Special types)
│           ├── 浸潤性小葉癌 (Invasive lobular carcinoma: ILC)
│           ├── 粘液癌 (Mucinous carcinoma)
│           ├── 管状癌 (Tubular carcinoma)
│           ├── 髄様様・TILs高値型癌
│           ├── アポクリン癌 (Apocrine carcinoma)
│           └── 化生癌 (Metaplastic carcinoma)
└── 2. 非上皮性・境界病変
    ├── 葉状腫瘍 (Phyllodes tumor)［良性 / 境界悪性 / 悪性］
    └── 血管肉腫等
```

### (1) 組織異型度グレード（Nottingham Histological Grade）
浸潤性乳管癌（NST）の悪性度を3項目の合計点（3〜9点）で評価します：

| 評価項目 | 1点 | 2点 | 3点 |
| :--- | :--- | :--- | :--- |
| **1. 腺管形成度** | 豊富（$> 75\%$） | 中等度（$10\sim 75\%$） | 乏しい（$< 10\%$） |
| **2. 核異型度** | 小型・均一 | 中等度 | 高度（大小不同・多形性・大型核小体） |
| **3. 核分裂像数 (/10 HPF)** | 少数（$0\sim 5$個） | 中等度（$6\sim 10$個） | 多数（$\ge 11$個） |

- **Grade 1 (Low grade)**: 3〜5点（高分化型）
- **Grade 2 (Intermediate grade)**: 6〜7点（中分化型）
- **Grade 3 (High grade)**: 8〜9点（低分化型・悪性度高）

## 3. バイオマーカー判定基準とサブタイプ分類

```
                               ┌─── HER2陰性 ─── Ki-67低 ──► ルミナルA型 (Luminal A)
        ┌─── ER/PgR陽性 ───────┤
        │                      └─── HER2陽性 / Ki-67高 ─────► ルミナルB型 (Luminal B)
乳がん ──┤
        │                      ┌─── HER2陽性 ──────────────► HER2過剰発現型 (HER2-enriched)
        └─── ER/PgR陰性 ───────┤
                               └─── HER2陰性 ──────────────► トリプルネガティブ (TNBC)
```

### (1) ホルモン受容体（ER / PgR）判定
- **陽性判定基準**: 免疫染色（IHC）で腫瘍細胞核の **$\ge 1\%$** に陽性所見を認めるもの。
- **J-Score / Allred Score**: 染色強度と陽性細胞比率の合計スコアで定量化。

### (2) HER2 判定基準（ASCO/CAP & 日本乳癌学会 ガイドライン）
- **IHC 0**: 染色なし、または $< 10\%$ の不完全・微弱な細胞膜染色（**陰性**）
- **IHC 1+**: $> 10\%$ の不完全・淡い細胞膜染色（**陰性**）
- **IHC 2+**: $> 10\%$ の中等度〜強度の不完全/完全な細胞膜染色（**判定保留 ➔ FISH/DISH検査へ**）
- **IHC 3+**: $> 10\%$ の均一で強い完全な細胞膜染色（**陽性**）
- **FISH/DISH法**: $HER2/\text{CEP17 比} \ge 2.0$ かつ $HER2\text{コピー数} \ge 4.0$ で陽性判定。

> [!TIP] 最新トピック：HER2-low の概念
> - 従来のHER2陰性群のうち、**IHC 1+** または **IHC 2+ かつ FISH陰性** の症例は **「HER2-low」** と定義され、抗体薬物複合体（ADC: トラスツズマブ デルクステカン [T-DXd] 等）の有効な適応対象となります。

### (3) Ki-67 標識率 (Labeling Index)
- 腫瘍の細胞増殖能を評価（ホットスポット法または平均法で測定）。
- 一般に **$< 14\sim 20\%$ で低値（Luminal Aの指標）**、**$\ge 20\%$ で高値（Luminal Bの指標）**。

### (4) 臨床サブタイプと標準治療一覧

| サブタイプ | ER/PgR | HER2 | Ki-67 | 主な全身治療（薬物療法） |
| :--- | :---: | :---: | :---: | :--- |
| **ルミナルA型** | 陽性 | 陰性 | 低値 | **内分泌療法（ホルモン療法）単独** |
| **ルミナルB型 (HER2-)** | 陽性 | 陰性 | 高値 | **内分泌療法 ＋ 化学療法**（再発リスクに応じて検討） |
| **ルミナルB型 (HER2+)** | 陽性 | **陽性** | 不問 | **抗HER2薬（トラスツズマブ等） ＋ 化学療法 ＋ 内分泌療法** |
| **HER2過剰発現型** | 陰性 | **陽性** | 不問 | **抗HER2薬 ＋ 化学療法** |
| **トリプルネガティブ (TNBC)** | 陰性 | 陰性 | 不問（高値） | **化学療法 ＋ 免疫チェックポイント阻害薬**（PD-L1陽性時）/ PARP阻害薬（BRCA変異陽性時） |

## 4. 手術切除断端評価と病理組織学的治療効果判定

### (1) 切除断端評価 (Surgical Margin)
- **浸潤癌 (Invasive Carcinoma)**:
  - **断端陰性 (Negative)**: 切除断端のインク塗布面に浸潤癌細胞が露出していない（**"No ink on tumor"**）。
  - **断端陽性 (Positive)**: 断端に直接癌細胞が露出（追加切除または放射線追加の検討）。
- **非浸潤性乳管癌 (DCIS)**:
  - 断端から病変までの距離（Clearance）が **$\ge 2\text{ mm}$** で断端陰性（良好）と判断。

---

### (2) 術前薬物療法（NAC）後の病理組織学的効果判定基準（日本乳癌学会）

| 治療効果グレード | 判定基準（組織所見） | 臨床的意義 |
| :--- | :--- | :--- |
| **Grade 0** | 腫瘍細胞に組織学的変化を認めない | 無効（治療抵抗性） |
| **Grade 1a** | ごく軽度の変化（変性細胞が全腫瘍細胞の **$1/3$ 未満**） | 軽微な効果 |
| **Grade 1b** | 軽度の変化（変性細胞が全腫瘍細胞の **$1/3 \sim 2/3$**） | 中等度の残存 |
| **Grade 2a** | 中等度〜高度の変化（残存する生存癌細胞が **$1/3$ 未満**） | 高度の効果 |
| **Grade 2b** | 極めて高度の変化（**ごくわずかな生存癌細胞**のみ残存） | 準完全奏効 |
| **Grade 3** | **すべての浸潤癌細胞が消失**（組織球集簇・肉芽・線維化組織に置換） | **pCR (Pathological Complete Response)**<br>予後極めて良好 |

## 5. 超音波検査レポートへの反映・連携のポイント

1. **腫瘍局在（Quadrant / クロックポジション・乳頭からの距離）**
   - 例：`Rt. C領域 (10時方向), 乳頭から 25mm`
2. **大きさの記載（3軸径）**
   - `長径 × 短径 × 厚さ (mm)`（例: `18.5 × 14.2 × 12.0 mm`）
   - 広がり（乳管内伸長・サテライト病変）がある場合は浸潤部と全体径を併記。
3. **周囲組織進展**
   - 前境界線断裂、クーパー靭帯牽引、大胸筋筋膜・筋層への浸潤有無（T4a評価）。
4. **リンパ節評価（Level I / II / III / 鎖骨上 / 内胸）**
   - 最大短径、皮質厚（$> 3\text{ mm}$）、リンパ門消失、血流パターンの有無を明記。
