# 整形外科・運動器超音波標準レポートテンプレート ＆ 作成ガイド (MSK)

本ページは、**肩関節（腱板断裂）**、**肘・手関節（テニス肘・手根管症候群）**、および**下肢（肉離れ・アキレス腱断裂）**の電子カルテ用コピペ可能標準レポートテンプレートです。

---

## 📋 1. 肩関節超音波検査 レポート入力テンプレート

```text
================================================================================
                    肩関節超音波検査報告書 (Shoulder US Report)
================================================================================
【患者基本情報】
ID: [           ] 氏名: [           ] 年齢: [   ]歳 性別: [男/女]  部位: [ 右肩 / 左肩 ]
主訴: [ 夜間痛 / 挙上困難 / インピンジメント症状 / 外傷後 ]

【1. 棘上筋腱 (SST: Supraspinatus Tendon)】
・腱板断裂: [ なし (正常・腱肥厚なし) / 不完全断裂 (滑液包側 / 関節面側) / 完全断裂 (Full-thickness) ]
  - 断裂幅 (Gap) : 左右幅 [      ] mm  x  前後幅 [      ] mm
  - 軟骨露出 (Cartilage sign): [ なし / あり (大結節骨頭軟骨が直視) ]
  - 骨皮質不整 (Cortex irregularity): [ なし / あり ]

【2. 上腕二頭筋長頭腱 (LHB) ＆ 肩峰下滑液包 (SAB)】
・LHB: [ 正常 (結節間溝内に保持) / 脱臼・亜脱臼 / 腱鞘滑膜炎 (液体貯留 [   ] mm) / 断裂 ]
・SAB (肩峰下滑液包): [ 正常 / 滑液包炎・肥厚あり ( 厚さ: [      ] mm ≥ 2.0mm ) ]

--------------------------------------------------------------------------------
【総合診断インプレッション】
1. [ 右/左 ] 棘上筋腱 (SST) に [ 完全断裂 (断裂Gap:  mm) / 滑液包側不完全断裂 / 腱板炎 ] を認めます。
2. [ SAB肥厚 / LHB腱鞘炎 ] を合併しています。
================================================================================
```
