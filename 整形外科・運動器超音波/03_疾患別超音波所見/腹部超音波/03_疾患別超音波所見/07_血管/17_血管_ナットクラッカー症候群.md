# ナットクラッカー症候群 (Nutcracker Syndrome) 超詳細診断プロトコル

> [!NOTE] 概要
> ナットクラッカー現象 (Nutcracker Phenomenon) / 症候群 (Nutcracker Syndrome) は、上腸間膜動脈 (Superior Mesenteric Artery: SMA) と腹部大動脈 (Abdominal Aorta: AO) のなす狭い角度（Aortomesenteric Angle）において、間を横走する**左腎静脈 (Left Renal Vein: LRV)** が「くるみ割り器 (Nutcracker)」のように解剖学的に絞扼・圧迫される病態です。無症候性の構造変化を「現象」、肉眼的/微視的血尿、左腰背部痛、精巣静脈瘤/骨盤うっ血症候群などの臨床症状を伴うものを「症候群」と定義します。

---

## 1. 解剖学的病態と血流動態の機構

### 1) 解剖学的関係 (Anatomical Triad)
上腹部正中横断像において、腹部大動脈 (AO) の前方かつ上腸間膜動脈 (SMA) の後方の間隙を左腎静脈 (LRV) が右方向へ向かって横走し、下大静脈 (IVC) へ流入します。

```text
       【 腹部大動脈 (AO) 】
                │
                ├── (SMA)  ← 前方からの鋭角分岐（脂肪織減少等で角度縮小）
                │    │
                │   [LRV]  ← ★ ここで強く押し潰される（圧迫部）
                │    │
  [末梢側LRV (左腎門部)] ───┘  ← 鬱血・高度拡張（静脈圧上昇）
```

### 2) 病態生理
- **LRV内圧の上昇**: 圧迫部での還流障害により、左腎静脈の末梢側（腎門部側）の内圧が持続的に上昇。
- **側副血行路の発達**: 逃げ場を失った高圧のLRV血流が、**左卵巣静脈 / 左精巣静脈**、**左上腰静脈**、**半奇静脈**へ逆流。
- **血尿の機構**: 左腎の腎盂・腎盂過度充血により、薄い腎微小静脈が破裂して尿路へ出血（無症候性肉眼的血尿の原因）。

## 3. カラードプラ・パルスドプラ所見の詳細

- **エイリアシング・ジェット流 (Jet Flow)**:
  - カラードプラにて、AoSMA間隙のLRV狭小化部位で鮮やかなモザイクパターン（高速血流）を認める。
- **左性腺静脈（左性腺静脈/左卵巣静脈）への逆流**:
  - 左腎門部から尾側に向かう左卵巣静脈/左精巣静脈の拡張（径 > 4～5 mm）と、息こみ（Valsalva手技）や立位で著明となる**向尾性逆流血流 (Retrograde Flow)**。

---

## 4. スキャン手順 (Step-by-Step Protocol)

1. **基本姿勢・前処置**:
   - 原則として空腹時検査。まずは仰臥位で検査を開始。
2. **描出断面（上腹部正中横断像）**:
   - 探触子を上腹部正中に当て、腹部大動脈とSMAの短軸像を同時に出せる断面を探索。
3. **LRVの全体像追跡**:
   - 左腎門部から大動脈前方を通過し、下大静脈 (IVC) 直前に至るLRVの全走行を長軸像で描出。
4. **Bモード径計測**:
   - **圧迫部径**: AoSMA間で最も狭小化している内腔の前後径（内内径）を計測。
   - **末梢部径**: 大動脈の左縁直外側で最も拡張しているLRV内腔の前後径を計測。
5. **ドプラ計測 (角度補正 θ ≤ 60°)**:
   - パルスドプラのサンプルボリュームを圧迫部（狭窄部）に配置し、最高血流速度 (PSV_narrow) を測定。
   - 同様に、末梢側拡張部にサンプルボリュームを移動し、PSV_hilar を測定。流速比を算出。
6. **立位・息こみ手技 (オプション)**:
   - 仰臥位で境界域の場合、被検者を**立位**にさせるか **Valsalva手技** を行わせる。重力・内圧変化によりAoSMA角度がさらに狭まり、流速比・径比がより顕著となるか観察する。

## 6. レポート記載例

```
【超音波所見】
左腎静脈 (LRV)：腹部大動脈 (AO) と上腸間膜動脈 (SMA) の前開角部にて著明な絞扼・圧迫を認める。
・圧迫部 LRV 径: 1.6 mm
・末梢部 LRV 径 (大動脈左縁): 9.2 mm
・径比 (末梢部/圧迫部): 5.75 (正常 < 3.0)

カラードプラ / パルスドプラ評価：
・圧迫部 (AoSMA間): モザイクパターンを伴う高速血流。PSV = 142 cm/s
・末梢部 (左腎門部): 血流うっ滞あり。PSV = 22 cm/s
・PSV 比 (圧迫部/末梢部): 6.45 (正常 < 3.0)
・側副血行路: 左性腺静脈の拡張 (4.8 mm) および向尾性逆流血流を認める。

左腎実質：形態・サイズ正常、水腎症や明確な腫瘤像なし。右腎正常。

【印象】
LRVの著明な夾雑・血流障害および性腺静脈への逆流を認める。
ナットクラッカー症候群 (Nutcracker Syndrome) の典型的超音波像。
臨床症状（血尿・左腰痛等）と併せて専門医でのフォローを推奨。
```
