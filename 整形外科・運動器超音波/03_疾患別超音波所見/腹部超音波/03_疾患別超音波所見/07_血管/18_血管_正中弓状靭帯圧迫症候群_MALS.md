# 正中弓状靭帯圧迫症候群 (Median Arcuate Ligament Syndrome: MALS) 超詳細診断プロトコル

> [!NOTE] 概要
> 正中弓状靭帯圧迫症候群 (Median Arcuate Ligament Syndrome: MALS / Dunbar Syndrome / Celiac Axis Compression Syndrome) は、横隔膜脚を構成する**正中弓状靭帯 (Median Arcuate Ligament: MAL)** により、**腹腔動脈 (Celiac Artery: CA)** 根部が頭側から持続的または呼吸性変化を伴って外因性に圧迫・夾雑され、食後上腹部痛、体動時腹痛、および減量を呈する血管圧縮疾患です。超音波検査は**呼吸位相による流速・形態変化**をリアルタイムに捉えられる決定的な第一選択検査です。

---

## 1. 解剖学的病態と呼吸動態のメカニズム

### 1) 解剖学的関係
上腹部正中縦断走査において、腹部大動脈 (AO) の前壁から最初に分岐する腹腔動脈 (CA) の根部領域を観察します。

```text
               【 腹部大動脈 (AO) 】
                         │
                         ├── (MAL)  ← 正中弓状靭帯（低エコー～中等度バンド）による頭側からの押し下げ圧迫
                         │    ＼
                         │     (CA) ← 呼気時に鋭角に屈曲・くびれ像 (Hook-like configuration)
```

### 2) 呼吸位相による動態機構 (Respiratory Dynamics)
- **安静呼気時 (Expiration)**:
  - 横隔膜が頭側へ上昇するに伴い、正中弓状靭帯 (MAL) が頭側へ引っ張られ、CA根部に対する下方・後方への圧迫強度が強まる。
  - CA根部は著しく屈曲・狭小化し、流速が急上昇（PSV > 200 cm/s）、エイリアシングが発生。
- **深吸気時 (Deep Inspiration)**:
  - 横隔膜が尾側へ降下するに伴い、MALも尾側へ移動し、CA根部に対する引きつれ・夾雑が解放される。
  - CAの屈曲が伸び、流速が劇的に正常化（PSV < 200 cm/s）する。

## 3. スキャン手順 (Step-by-Step Protocol)

1. **体位および前処置**:
   - 仰臥位。空腹時。探触子はコンベックス探触子（3.5～5.0 MHz）を使用。
2. **描出断面（上腹部正中縦断像）**:
   - 探触子を腹部正中に当て、腹部大動脈 (AO) の長軸像を描出。大動脈前壁から頭側へ分岐する腹腔動脈 (CA) およびその数mm末梢に分岐する上腸間膜動脈 (SMA) の起始部を同時に画面内に出す。
3. **Bモード呼気/吸気観察**:
   - 被検者に「息を軽く吐いて止めて（呼気保持）」と指示。CA根部が頭側から押し潰され、J字型またはフック状に下向きに屈曲する像 (Hook-like sign) を観察。
   - 被検者に「息を大きく吸って止めて（吸気保持）」と指示。屈曲が解消され、CAが直線状に伸びるかを確認。
4. **カラードプラ設定**:
   - カラーゲインを調整し、壁振動アーチファクトを抑える。呼気時にCA根部で鮮やかなエイリアシング（高速ジェット流）が出現し、吸気時に一転して単色化（正常流速）するか確認。
5. **パルスドプラ波形計測 (角度補正 θ ≤ 60° 必須)**:
   - **呼気時計測**: 呼気保持状態で、CA根部の最も狭小化・エイリアシングしている部位にサンプルボリュームを配置し、PSV_exp を計測。
   - **吸気時計測**: 深吸気保持状態とし、同一部位で PSV_insp を計測。
   - 呼気時PSV ÷ 吸気時PSV を計算。

## 5. レポート記載例

```
【超音波所見】
腹腔動脈 (CA) 起始部：
・Bモード像：
  - 安静呼気時：CA起始部頭側より正中弓状靭帯による強い押し下げを受け、J字型の急峻な屈曲（Hook-like deformity）を呈する。
  - 深吸気時：横隔膜降下に伴いCA根部の屈曲が速やかに解除され、走行が直線化する。

・パルスドプラ計測（角度補正 48°）：
  - 安静呼気時 PSV: 285 cm/s（強度のエイリアシングおよび後狭窄性乱流を伴う）
  - 深吸気時 PSV: 118 cm/s（流速の劇的な正常化）
  - 呼気 / 吸気 PSV 比: 2.41 ( > 2.0)

上腸間膜動脈 (SMA)：起始部径・流速ともに正常 (PSV = 110 cm/s)。動脈硬化性プラークなし。

【印象】
呼吸位相に完全に同調する腹腔動脈根部の可逆性夾雑および流速急変を認める。
正中弓状靭帯圧迫症候群 (MALS / Dunbar Syndrome) の典型的超音波所見。
臨床症状（食後上腹部痛等）との対比および血管造影/CTアンギオでの確認を推奨する。
```
