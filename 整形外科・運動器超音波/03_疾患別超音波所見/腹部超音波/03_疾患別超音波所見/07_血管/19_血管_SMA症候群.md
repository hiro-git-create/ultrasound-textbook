# 上腸間膜動脈症候群 (SMA Syndrome / Wilkie症候群) 超詳細診断プロトコル

> [!NOTE] 概要
> 上腸間膜動脈症候群 (Superior Mesenteric Artery Syndrome: SMA症候群 / Wilkie症候群 / 腸骨動脈角症候群) は、急激な体重減少、消瘦、長期ベッドサスペンション、脊椎矯正手術などを契機に、腹部大動脈 (AO) と上腸間膜動脈 (SMA) の間に存在する脂肪織クッション (Retroperitoneal Fat Pad) が減少・消失し、両血管が形成する狭い前開角において**十二指腸第3部 (水平部)** が前後からサンドイッチ状に物理的に嵌頓・圧迫される血管圧迫性消化管閉塞疾患です。

---

## 1. 圧迫解剖と血管関連疾患の比較

### 1) 解剖学的構造 (Nutcracker vs SMA症候群)
上腹部正中縦断走査において、大動脈前壁からSMAが鋭角に分岐する領域を観察します。

```text
       【 腹部大動脈 (AO) 】
                │
                ├── (SMA)  ← 分岐角の狭小化（角度 < 22°）
                │    │
                │   [十二指腸第3部 (水平部)]  ← ★ SMA症候群：ここで十二指腸が押し潰される！
                │    │
                │   [左腎静脈 (LRV)]          ← ★ ナットクラッカー症候群：ここで静脈が押し潰される！
```

> [!IMPORTANT] SMA血管系3大外因性圧迫疾患の明確な鑑別
> - **SMA症候群 (Wilkie症候群)**: SMAとAOの間で **十二指腸水平部** が圧迫され、食後上腹部膨満感・胆汁性嘔吐を来す。
> - **ナットクラッカー症候群**: SMAとAOの間で **左腎静脈 (LRV)** が圧迫され、血尿・左腰痛・性腺静脈瘤を来す。
> - **MALS (正中弓状靭帯圧迫)**: 正中弓状靭帯により **腹腔動脈 (CA)** が頭側から圧迫され、呼気時に流速が急上昇する。

## 3. リアルタイム機能サインと体位変換動態試験

### 1) To-and-fro 逆流運動 (To-and-fro Peristalsis)
- SMA直下の圧迫部位より口側の十二指腸水平部および胃が高度に拡張。
- 十二指腸壁が強力に収縮・蠕動するが、狭窄部を通過できず、液体・食査内容物が前後に往復 (To-and-fro) 揺れ動く特異的リアルタイムサイン。

### 2) 体位変換解除試験 (Positional Relief Test / Knee-Chest Test)
- **手技**:
  1. 仰臥位 (Supine) にて十二指腸の狭窄・拡張およびTo-and-fro運動を確認。
  2. 患者を**うつ伏せ (Prone)**、**左側臥位 (Left Lateral Decubitus)**、または**膝胸位 (Knee-Chest position)** へ体位変換させる。
- **陽性判定 (Positive Response)**:
  - 重力効果によりSMAが腹側（前方）へ垂れ下がり、AO-SMA間隙が拡大。
  - **十二指腸内に滞留していた食査・液体が一気に尾側（空腸）へ流出・開通**するリアルタイム動画を捕捉する。

---

## 4. スキャン手順 (Step-by-Step Protocol)

1. **基本体位・前処置**: 仰臥位。絶食下（または食後症状出現時）。コンベックス探触子。
2. **AO-SMA分岐角度の計測**:
   - 上腹部正中縦断走査にて、腹部大動脈 (AO) からSMAが分岐する起始部を描出。
   - 大動脈前壁の走行線と、SMA後壁の走行線がなす角度 (Angle) を計測。
3. **AO-SMA間隙距離の計測**:
   - SMAが最も大動脈に近接する位置（十二指腸水平部が通過する高さ）において、大動脈前縁からSMA後縁までの垂直距離 (Distance) を計測。
4. **十二指腸水平部の短軸・長軸観察**:
   - 上腹部正中横断走査に切り替え、大動脈・IVCの前に位置する十二指腸水平部を描出。
   - 血管間で押し潰されて扁平化した十二指腸壁と、その口側（右側）の拡張・液体貯留を確認。
5. **体位変換動態観察**:
   - 探触子を当てたまま患者を左側臥位または膝胸位に体位変換させ、AO-SMA間隙が拡大し、内腔内容物が開通・流出する様を観察。

## 6. レポート記載例

```
【超音波所見】
上腹部正中縦断走査：
・AO-SMA 分岐角度: 12°（著明に縮小、正常 38～65°）
・AO-SMA 間隙距離: 3.5 mm（著明に狭小化、正常 10～28 mm）

十二指腸・胃観察：
・十二指腸第3部（水平部）は大動脈-SMA間隙にて全周性に圧迫・狭小化。
・口側十二指腸（球部～第2部）および胃は高度に拡張（内径 36 mm）し、強力な往復蠕動 (To-and-fro movement) を認める。

体位変換試験：
・左側臥位および膝胸位への体位変換により、SMAが前方へ下垂してAO-SMA間隙が 11 mm に拡大。
・十二指腸内容物が一気に遠位空腸へ流出・開通するリアルタイム動態を確認。

【印象】
AO-SMA角度および距離の著明な縮小に伴う、十二指腸第3部の物理的圧迫所見。
体位変換での開通が確認され、上腸間膜動脈症候群 (SMA Syndrome / Wilkie症候群) に極めて矛盾しない。
栄養管理および臨床フォローを推奨する。
```
