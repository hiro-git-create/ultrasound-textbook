# 肩関節超音波検査（腱板断裂・棘上筋腱 SST ＆ 肩峰下滑液包炎 SAB 評価）

肩関節超音波は、五十肩（凍結肩）との鑑別、および**腱板断裂（Rotator Cuff Tear）の有無・完全断裂/不完全断裂の深さ・断裂幅（Gap）**をリアルタイムに評価するゴールドスタンダード検査です。

---

## 1. 棘上筋腱 (SST: Supraspinatus Tendon) の標準描出肢位 (Modified Crass 肢位)

- **肢位**: 患者の腕を背中（後ろポケット）へ回し、肩関節を内旋・伸展させる。
- **観察のポイント**:
  - 正常な棘上筋腱は、上腕骨頭大結節に付着する**均一な嘴状（Beak-like）の高エコー線維構造**を示す。

---

## 2. 腱板断裂 (Rotator Cuff Tear) の超音波診断基準

```
【正常な腱板 (SST)】            【完全断裂 (Full-thickness Tear)】
  肩峰下滑液包 (SAB)              肩峰下滑液包 (SAB) が直接骨頭へ落ち込む
 ┌────────────────┐              ───┐            ┌───
 │  棘上筋腱 SST  │                 │ 腱欠損 Gap │
 └────────────────┘                 └───┐    ┌───┘
 ━━━━━━━━━━━━━━━━ (大結節骨皮質)         ━━━━━━━━━━━━━━━━ (Cartilage sign: 軟骨裸出)
```

| 断裂タイプ | 超音波の核心的所見 | 臨床的意義 |
| :--- | :--- | :--- |
| **完全断裂 (Full-thickness Tear)** | **腱実質の全層欠損 (Gap)**。肩峰下滑液包 (SAB) が上腕骨頭に直に接する。<br>**軟骨境界面徴候 (Cartilage interface sign)** 陽性。 | 手術 (鏡視下腱板修復術 ARCR) 適応検討 |
| **滑液包側 不完全断裂 (Bursal-side)** | 腱の表層（SAB 側）に限局した低エコー欠損。 | 保存療法 (ヒアルロン酸/ステロイド注射) |
| **関節面側 不完全断裂 (Articular-side)** | 腱の深層（骨頭軟骨側）に限局した欠損。 | 保存療法・経過観察 |
| **肩峰下滑液包炎 (SAB 肥厚)** | **SAB 厚さ $\ge 2.0 \text{ mm}$** に肥厚、内部に滑液貯留 (Effusion)。 | 疼痛の原因 (インピンジメント) |
