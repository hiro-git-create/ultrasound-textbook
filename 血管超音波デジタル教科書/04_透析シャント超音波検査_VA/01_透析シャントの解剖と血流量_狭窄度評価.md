# 透析血管アクセス (シャントエコー) の評価（吻合部狭窄・血流量 FV・過剰血流判定）

本ページは、血液透析患者の命綱である**バスキュラーアクセス（AVF: 自己血管内シャント / AVG: 人工血管グラフト）**における**吻合部狭窄**、**シャント血流量 (FV: Flow Volume)**、**静脈高血圧・過剰血流（スティール・心不全）**の超音波評価基準（日本透析医学会 / JSS ガイドライン準拠）の解説です。

---

## 1. 透析シャントの種類と基本解剖

- **AVF (Arteriovenous Fistula: 自己血管内シャント)**:
  - 最多: 橈骨動脈 (RA) ─ 頭静脈 (CeV) 吻合（前腕手関節近傍）。
- **AVG (Arteriovenous Graft: 人工血管シャント)**:
  - 自己血管不良時に ePTFE 人工血管をループ/ストレート状に間置。

---

## 2. シャント血流量 (FV: Flow Volume mL/min) の算定

上腕動脈 (BA: Brachial Artery) またはシャント流出静脈の直線部にて、**時間平均流速 (TAMV)** と **血管内径 $d$ (cm)** から血流量を自動算出します。

$$\text{シャント血流量 FV (mL/min)} = \text{TAMV (cm/s)} \times \pi \times \left( \frac{\text{血管内径 } d (\text{cm})}{2} \right)^2 \times 60$$

| シャント血流量 (FV: mL/min) | 臨床評価 | 対策・推奨アクション |
| :---: | :--- | :--- |
| **$< 300 \sim 400 \text{ mL/min}$** | **低血流 (Underflow) / 狭窄疑い** | 透析困難・血栓閉塞リスク。VAIVT (PTA) 適応考慮。 |
| **$400 \sim 800 \text{ mL/min}$** | **至適血流 (Optimal Flow)** | 良好に維持。定期経過観察。 |
| **$800 \sim 1500 \text{ mL/min}$** | **高血流 (High Flow)** | 慎重観察。 |
| **$> 1500 \text{ mL/min}$** | **過剰血流 (Excessive Flow)** | **高拍出性心不全・シャントスチール症候群**のリスク。バンディング考慮。 |

---

## 3. 吻合部および流出路狭窄の判定基準 (JSS / 日本透析医学会)

狭窄好発部位は、**動静脈吻合部 (Anastomosis)**、**穿刺部 (Puncture site)**、および **鎖骨下静脈合流部 (Central vein)** です。

| 狭窄度評価 | 形態的評価 (Bモード/カラー) | ドプラ血流速度 (PSV / RI) |
| :--- | :--- | :--- |
| **有意狭窄なし** | 血管径 $\ge 2.5 \sim 3.0 \text{ mm}$ を保持 | 吻合部 PSV $< 200 \text{ cm/s}$ / 上腕動脈 RI $< 0.60$ |
| **有意狭窄 ($\ge 50\%$ 狭窄)** | 局所血管内径 $< 2.0 \text{ mm}$ に狭小化 | **狭窄部 PSV $\ge 300 \sim 400 \text{ cm/s}$ (または PSV比 $\ge 2.0 \sim 3.0$)** |
| **流入動脈高抵抗化** | 末梢閉塞・吻合部狭窄 | **上腕動脈 RI $\ge 0.65 \sim 0.70$ (拡張期血流の途絶)** |
