# IMT計測・プラーク性状評価と狭窄率（NASCET/ECST）算定

本ページでは、頸動脈超音波における動脈硬化の核心指標である**IMT（内膜中膜複合体厚）計測**、**プラークのエコー性状・潰瘍判定**、および脳梗塞リスクを判定する**狭窄率（NASCET / ECST基準）とPSV最高血流速度評価**を解説します。

---

## 1. 内膜中膜複合体厚 (IMT: Intima-Media Thickness) 計測

### 1) IMT の定義と基準値
- **IMT**: 血管内腔-内膜境界（第1境界線）から、中膜-外膜境界（第2境界線）までの厚さ。
- **正常値**: **$\le 1.0 \text{ mm}$**
- **プラークの定義**: **IMT $\ge 1.1 \text{ mm}$** に局所的に隆起・肥厚した領域。

### 2) 計測部位
- **Mean IMT (平均IMT)**: 総頸動脈 (CCA) 遠位壁10mm区間の平均厚。
- **Max IMT (最大IMT)**: 左右の CCA, 膨大部 (Bulb), ICA の全観察領域の中で**最も肥厚した最大の厚さ**。血管疾患リスク予測に最高感度。

---

## 2. プラークのエコー性状と危険度分類

プラークの内部エコー性状は、脳塞栓症（脳梗塞）の危険度評価において極めて重要です。

| プラーク性状 | エコー輝度・特徴 | 脳塞栓症リスク |
| :--- | :--- | :---: |
| **等〜高回音プラーク (Hard Plaque)** | 外膜と同等〜それ以上の高輝度。石灰化を伴う。 | 低リスク (安定) |
| **低回音プラーク (Soft Plaque)** | **血液腔よりわずかに明るい程度の暗い低輝度**。脂質・血栓主分。 | **高リスク (脆弱)** |
| **無回音/不均一プラーク (Vulnerable)** | 内部に低回音〜無回音領域が混在（斑状）。内出血・脂質コア。 | **極めて高リスク** |
| **潰瘍形成 (Ulcerated Plaque)** | **プラーク表層に 2 mm 以上の落ち込み・陥凹（窪み）**を認める。 | **最重症 (絶対的塞栓源)** |

> [!WARNING]
> **脆弱プラーク (Vulnerable Plaque)**
> 低回音で可動性（Mobile）を伴うプラークや、潰瘍形成例は、無症状であっても微小塞栓片が脳へ飛散し脳梗塞を引き起こす絶対的ハイリスク病変です。

---

## 3. 狭窄率算定 (NASCET 基準 vs ECST 基準)

内頸動脈 (ICA) 狭窄症の重症度は、**Bモード形態学的狭窄率**および**ドプラ最高血流速度 (ICA PSV)** を組み合わせて判定します。

### 1) NASCET 基準と ECST 基準の計算式

$$\text{NASCET 狭窄率 (\%)} = \left( 1 - \frac{\text{狭窄部最小内径 } A}{\text{狭窄より遠位の正常 ICA 内径 } D} \right) \times 100$$

$$\text{ECST 狭窄率 (\%)} = \left( 1 - \frac{\text{狭窄部最小内径 } A}{\text{狭窄部の本来の推定血管外径 } C} \right) \times 100$$

*(※ NASCET 70% 狭窄 $\approx$ ECST 80-85% 狭窄 に相当します。)*

### 2) ICA PSV (最高収縮期血流速度) による狭窄度分類 (度量衡)

| 狭窄度 (NASCET) | ICA PSV (最高血流速度) | ICA / CCA PSV 比 | 臨床的意義 |
| :---: | :---: | :---: | :--- |
| **正常 (Normal)** | $< 125 \text{ cm/s}$ | $< 2.0$ | 有意な狭窄なし |
| **< 50% 狭窄** | $< 125 \text{ cm/s}$ | $< 2.0$ | 軽度狭窄 |
| **50 〜 69% 狭窄** | **$125 \sim 230 \text{ cm/s}$** | **$2.0 \sim 4.0$** | **中等度狭窄** |
| **$\ge 70\%$ 狭窄** | **$> 230 \text{ cm/s}$** | **$> 4.0$** | **高度狭窄 (CEA/CAS 手術適応考慮)** |
| **閉塞 (Occlusion)** | **血流信号なし (0 cm/s)** | — | 完全閉塞 |
