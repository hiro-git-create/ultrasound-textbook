# 椎骨動脈 (VA) の超音波評価 ＆ 鎖骨下動脈盗血症候群 (Subclavian Steal) 判定

本ページは、**日本超音波検査学会 (JSS: Japanese Society of Sonographers)** の観察法ガイドラインに準拠した**椎骨動脈 (VA: Vertebral Artery)** の基本描出、血管径・左右差判定、および**鎖骨下動脈盗血症候群 (Subclavian Steal Syndrome: SSS) のドプラ波形 3 段階分類 (Pre-steal / To-and-fro / Reversed)** の詳細解説です。

---

## 1. 椎骨動脈 (VA) の解剖セグメントと描出手順

椎骨動脈 (VA) は鎖骨下動脈から分岐し、脳底動脈 (Basilar Artery) へ血流を供給する後方循環系の最重要血管です。

```
【椎骨動脈 (VA) の 4 大解剖セグメント】
 V1: 起始部 (鎖骨下動脈分岐部 〜 第6頸椎 C6 横突孔入口) ★動脈硬化・狭窄の好発部位
 V2: 横突孔走行部 (C6 〜 C2 横突孔内) ★通常エコー観察のメイン領域 (梯子状像)
 V3: アトラス部 (C2 〜 C1 〜 大後頭孔)
 V4: 脳内セグメント (硬膜貫通 〜 左右合流し脳底動脈へ)
```

### JSS 標準描出手順 (V2 セグメント)
1. **総頸動脈 (CCA) 長軸像** をまず描出する。
2. 探触子をわずかに外側かつ斜め後方へ平行移動（または傾斜）させる。
3. **頸椎横突起の音響陰影（梯子状の黒い影）**の合間を縦断走行する赤/青の血管信号（VA）を描出する（伴走する椎骨静脈 VV との識別が必要）。

---

## 2. 椎骨動脈 (VA) の正常パラメータ ＆ 異常判定

| 評価項目 | 正常基準値 (JSS) | 異常・病態判定 | 臨床的意義 |
| :--- | :---: | :--- | :--- |
| **血管径 (Diameter)** | **$3.0 \sim 4.0 \text{ mm}$** | $< 2.0 \text{ mm}$ ➔ **VA 低形成 (Hypoplasia)** | 左右径差 $> 1.0\text{mm}$ は頻見 (左優位多) |
| **最高血流速度 (PSV)** | **$30 \sim 60 \text{ cm/s}$** | $< 20 \text{ cm/s}$ ➔ 低流速 (近位/遠位病変) | 低抵抗波形 (脳血流供給) |
| **血流方向 (Flow Direction)** | **頭側への順行性** | 足側への**逆行性血流 (Reversed)** | **鎖骨下動脈高度狭窄・閉塞** |

---

## 3. 鎖骨下動脈盗血症候群 (Subclavian Steal Syndrome: SSS) のドプラ波形分類

同側の鎖骨下動脈（または無名動脈）近位部に高度狭窄・閉塞が存在すると、上肢への血流不足を補うために**対側VA ➔ 患側VA を経由して脳血流が足側（腕）へと奪われる（Steal現象）**が発生します。

```
【正常 VA 波形】       【Type 1: Latent (Pre-steal)】  【Type 2: Incomplete (To-and-fro)】 【Type 3: Complete (Reversed)】
   ▲ (順行波)             ▲   (収縮中・末期に)          ▲ (収縮期は逆流)                     ────────── (基線)
  / \                    / \  (落ち込み Notch)         ───┴─── (基線)                       \        /
 /   \____              /   \_/\____                     \   /  (拡張期は順行)                    \______/  (全時相逆行波)
```

### JSS 基準：Steal ドプラ波形の 3 段階分類

| ステージ分類 (JSS) | ドプラ波形の形態的特徴 | 病態重症度 |
| :--- | :--- | :---: |
| **Type 1: Latent Steal<br>(潜在型 / Pre-steal 波形)** | 順行性血流を保つが、**収縮期中〜末期に一時的な流速低下・落ち込み (Notch / Decreta)** を認める。 | 鎖骨下動脈<br>軽度〜中等度狭窄 |
| **Type 2: Incomplete Steal<br>(不完全型 / To-and-fro 波形)** | **収縮期は逆行（足側へ）し、拡張期は順行（頭側へ）する** 双方向波形を呈する。 | 鎖骨下動脈<br>高度狭窄 |
| **Type 3: Complete Steal<br>(完全型 / Reversed 波形)** | 収縮期・拡張期ともに**全時相で完全に逆行性血流（基線より下）**を呈する。 | 鎖骨下動脈<br>完全閉塞 |

---

## 4. 潜在性 Steal を暴く！上肢カフ加圧開放試験 (Cuff Inflation/Release Test)

Type 1 (Pre-steal) や疑わしい波形を認めた場合、**「上肢カフ加圧開放試験」**を行うことで病態を決定づけることができます。

### ■ 実施手順
1. 患側（盗血が疑われる側）の上腕に血圧計カフを巻く。
2. VA ドプラ波形を観察しながら、**収縮期血流より高い圧（約 200 mmHg）で 1 〜 2 分間加圧・脱血**する。
3. **カフをパッと急速解放（Release）**した瞬間の VA 波形変化を記録する。

### ■ 判定結果
- **陽性変化**: 急速開放に伴う上肢の反応性充血により、**Pre-steal 波形が不完全型 (To-and-fro) や完全逆流 (Reversed) へ著明に悪化**すれば、潜在性鎖骨下動脈盗血と確定！
