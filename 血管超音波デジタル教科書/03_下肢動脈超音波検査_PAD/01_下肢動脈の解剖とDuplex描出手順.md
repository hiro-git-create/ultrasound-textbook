# 下肢動脈の解剖と Duplex（デュプレックス）スキャン描出手順

下肢動脈超音波検査は、**末梢動脈疾患（PAD: Peripheral Artery Disease / ASO: 閉塞性動脈硬化症）**における動脈狭窄・閉塞部位の特定および血流低下の定量評価を行う非侵襲的検査です。

---

## 1. 下肢動脈の解剖学的走行

```
外腸骨動脈 (EIA)
 └─ 総大腿動脈 (CFA: Common Femoral A.)
     ├─ 大腿深動脈 (PFA)
     └─ 浅大腿動脈 (SFA: Superficial Femoral A.) ── (ハンター管を通る)
         └─ 膕動脈 (PA: Popliteal A.)
             ├─ 前脛骨動脈 (ATA) ──► 足背動脈 (DPA: Dorsalis Pedis A.)
             └─ 脛骨腓骨幹 (T-P trunk)
                 ├─ 後脛骨動脈 (PTA) ──► 内果後方
                 └─ 腓骨動脈 (PER)
```

---

## 2. Duplex スキャン（2D Bモード ＋ カラー ＋ パルスドプラ）の手順

### 1) ドプラ角度補正の重要性
下肢動脈の血流速度（PSV: 最高収縮期血流速度）を正確に計測するため、**ドプラ角度（Steering / Angle Correction）は必ず 60 度以下（できれば 45〜60 度）**に補正して計測します。

### 2) 主要血管の観察ステップ
1. **総大腿動脈 (CFA) 〜 分岐部**: 鼠径部でBモード縦断像を描出。CFA から 浅大腿動脈 (SFA) および 大腿深動脈 (PFA) の分岐部を観察。
2. **浅大腿動脈 (SFA)**: 大腿前内側を近位から順に遠位へスキャン。ハンター管（内収筋管）通過部は描出が難しいため、カラーゲインと深度を調整。
3. **膕動脈 (PA)**: 膝裏（膕窩）で描出。動脈瘤（Popliteal Aneurysm）の有無も確認。
4. **足背動脈 (DPA) / 後脛骨動脈 (PTA)**: 足関節レベルでの血流評価。重症下肢駆血（CLTI）の末梢開通性判断において必須の計測ポイント。
