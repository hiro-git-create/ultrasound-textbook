# 腹部大動脈瘤 (AAA) 超音波検査 ＆ EVAR 術後エンドリーク評価

本ページは、**腹部大動脈瘤 (AAA: Abdominal Aortic Aneurysm)** の早期発見、最大短軸外径計測法、およびステントグラフト内挿術（EVAR）後の**エンドリーク (Endoleak Type I 〜 V)** 超音波評価の解説です。

---

## 1. 腹部大動脈瘤 (AAA) の診断と計測基準

- **腹部大動脈瘤 (AAA) の定義**:
  - 腹部大動脈の**最大外径 $\ge 30 \text{ mm}$ (3.0 cm)**、または正常近位部径の 1.5 倍以上に拡大した状態。
- **JSS 正確な計測法**:
  - 血管長軸に対して**垂直な短軸断面にて「外膜 - 外膜 (Outer to Outer)」の最大外径**を計測する。
- **手術・血管内治療（EVAR/開腹）適応**:
  - 最大瘤径 **$\ge 50 \text{ mm}$ (女性は $\ge 45 \text{ mm}$)**、または **半年で 5 mm 以上の急速拡大**。

---

## 2. EVAR 術後エンドリーク (Endoleak) の 5 大分類

ステントグラフト（人工血管）の外側かつ瘤嚢（Aneurysm Sac）内に残存する異常血流（エンドリーク）をカラードプラで精査します。

```
【EVAR エンドリーク 5 大タイプ】
 Type I  : グラフトの近位部 (Ia) または遠位部 (Ib) の密着不全による漏出 ★破裂リスク大・要再手術
 Type II : 腰動脈や下腸間膜動脈 (IMA) からの逆流性血流 ★最多 (経過観察多)
 Type III: グラフト本体の断裂・パーツ接合部 (ジャンクション) からの漏出 ★超緊急
 Type IV : グラフト素材の網目（ポーロシティ）からの滲出 (術後早期・自然消退)
 Type V  : エンドテンション (明確な漏出はないが瘤径が拡大)
```

| エンドリーク型 | 漏出メカニズム | カラー/ドプラ所見 | 臨床緊急度 |
| :---: | :--- | :--- | :---: |
| **Type I (Ia / Ib)** | **グラフト固定部（ネック）の不全** | 拍動性の高流速動脈血流がグラフト端から流入 | **極めて高い (再治療)** |
| **Type II** | **側副枝（腰動脈/IMA）の逆流** | 瘤嚢辺縁部に低流速の双方向・逆流性血流 | 経過観察 (瘤拡大時治療) |
| **Type III** | **グラフト破損・接合部離断** | グラフト中央部から高流速ジェットの噴出 | **極めて高い (緊急治療)** |
