# 川崎病 心エコー計測法とDr対話カンファレンスマニュアル

---

## 1. 概要と本マニュアルの目的

川崎病（Kawasaki Disease: KD）における心臓超音波検査は、冠動脈病変（冠動脈瘤・拡張・狭窄・血栓）の早期検出、急性期治療（IVIGなど）の効果判定、および遠隔期予後管理において決定的な役割を果たします。
従来の実務では絶対径（mm）のみに依存した評価が行われがちでしたが、体格・年齢差の著しい小児領域においては**体表面積（BSA）で標準化したZスコア（Z-score）による評価**が国際的・国内的標準となっています。

本マニュアルは、臨床検査技師が質の高い高分解能画像を描出し、正確な冠動脈内径計測を行うための技術的プロトコルと、カンファレンスや病棟で小児科医（主治医）と建設的かつ的確に連携するための実践的対話トークスクリプトを網羅しています。

## 2. 冠動脈の標準計測断面と描出テクニック

### 2.1 超音波プローブの選定と装置セッティング

乳幼児・小児の冠動脈は管径1〜3mm程度と極めて細小であり、かつ高心拍下で激しく拍動します。正確な内膜同定には、空間分解能（特に軸方向分解能）と時間分解能の両立が不可欠です。

| 項目 | 推奨セッティング・運用基準 | 臨床的意義・留意点 |
| :--- | :--- | :--- |
| **プローブ選択** | ・新生児〜乳児（<10kg）：8〜12MHz 高周波セクタ / マイクロコンベックス<br>・幼児〜学童初期（10〜25kg）：6〜8MHz セクタ<br>・学童〜思春期（>25kg）：3〜5MHz セクタ | 可能な限り最高周波数のプローブを選択し、浅部フォーカスにより解像度を最大化する。 |
| **鎮静・安静保持** | ・トリクロホスナトリウム（トリクロール）経口投与、抱水クロラール座薬等<br>・哺乳直後の自然入眠、おしゃぶり・動画視聴の併用 | 体動や啼泣（頻脈・呼吸性変動）はフレームレート低下や拍動ブレを引き起こし、内径の過小/過大評価の主因となる。安全な鎮静モニタリング（SpO2・呼吸観察）を併行する。 |
| **フレームレート** | 60〜90 fps 以上を確保（ズーム・画角絞り込み） | 高心拍（120〜160 bpm）下でも拡張末期・収縮期の動態を明瞭に捉える。 |
| **ゲイン・ダイナミックレンジ** | ・2Dゲイン：過度な高ゲインを避け、ルーメン（無エコー）を保つ<br>・ダイナミックレンジ：45〜55dB（やや狭め） | 高ゲインは側方音束幅増大（ブルーミング効果）を招き、血管内腔を狭く誤認させる。ダイナミックレンジをやや落としてコントラストを強調する。 |
| **アコースティックズーム（RES）** | 対象血管（LMCA, LAD, RCA）にROIを絞りアコースティックズームを使用 | ピクセル補間ではなく走査線密度を高めた光学ズーム相当で、内膜境界のクリアランスを向上させる。 |
| **カラーフロードプラ** | ・速度レンジ（PRF）：20〜40 cm/s<br>・カラーゲイン：アーチファクトが出ない限界まで | 走行の追跡および微小瘤、局所血流シグナルの確認に有用。ただし2D計測時は必ずカラーオフとする。 |

### 2.2 主要標準断面とアプローチ法

```mermaid
flowchart TD
    subgraph "胸骨左縁アプローチ"
        A["\"胸骨左縁大動脈弁短軸像 (PSAX AV level")"] --> B["\"左冠動脈主幹部 (LMCA") の起始・分岐"]
        A --> C["\"左前下行枝 (LAD proximal")"]
        A --> D["\"回旋枝 (LCx proximal")"]
        A --> E["\"右冠動脈 (RCA segment 1: 起始部")"]
    end

    subgraph "変法・高位断面"
        F["\"高位胸骨左縁短軸像 (High PSAX") / 肋間を1腔上げる"] --> G["LMCA全長およびLAD-LCx分岐部明瞭化"]
        H["\"胸骨左縁長軸像 (PLAX") をやや右室流出路側へ傾斜"] --> I["RCA segment 1〜2の長軸像"]
    end

    subgraph "心尖部・胸骨下アプローチ"
        J["\"心尖部変法 (Modified A4C / A5C")"] --> K["LAD遠位部・心尖部回り込み"]
        L["\"肋骨下短軸・長軸像 (Subcostal view")"] --> M["\"RCA segment 2〜3 (屈曲部・後下行枝分岐")"]
    end
```

1. **胸骨左縁大動脈弁短軸像（PSAX at Aortic Valve level）**
   - 冠動脈エコーの基軸となる断面。大動脈弁レベル（メルセデス・ベンツサイン）を描出し、約4時方向から起始する左冠動脈主幹部（LMCA）と、約10〜11時方向から起始する右冠動脈（RCA）起始部を同一またはわずかなチルトで観察。
2. **高位胸骨左縁短軸像（High PSAX view: 肋間を1つ上げたアプローチ）**
   - LMCAが長く伸び、LADとLCxへの分岐部（Bifurcation）が鮮明に描出される。超音波ビームがLMCAの長軸に対してほぼ直交するため、前後壁の内膜エコーが最も明瞭となる。
3. **胸骨左縁変法・修正長軸像（Modified PLAX for RCA）**
   - 通常のPLAXからプローブを右室側・前壁側へ浅くチルトさせ、RCA近位部（segment 1）から右室前壁を走行するsegment 2を長軸に捉える。
4. **心尖部アプローチ（Modified Apical views）**
   - 心尖部4腔像・2腔像において前室間溝に沿ってフォーカスを当て、LADの中枢〜心尖部回り込み部を描出する。
5. **肋骨下アプローチ（Subcostal approach）**
   - 乳児で良好な音響窓が得られる。下大静脈・右房移行部から房室間溝を追跡し、RCA segment 2〜3（後下行枝：PDA分岐部）を観察する。

## 3. 冠動脈内径の計測ルールと評価指標

### 3.1 Inner-to-Inner（内膜内縁から内膜内縁）計測の原則

日本小児循環器学会（JSPCCS）および米国心臓協会（AHA）ガイドラインに準拠し、計測は厳格に**Inner-to-Inner（内腔面の内縁と対側内膜内縁）**で行います。

* **計測のタイミング**: 心電図同期下で**拡張末期（R波頂点、または大動脈弁閉鎖直後〜拡張中期）**の血管径が最大かつ安定するフレームでフリーズして計測。
* **外膜やPerivascular brightnessを含めない**: 冠動脈周囲の炎症に伴う高エコー（輝度亢進）を血管壁や内腔と混同しないよう注意する。
* **軸直交性の保持**: 血管の走行方向に対して完全に直角となるカーソル配置を行う。斜めに切ると内径が過大評価される。

```
       外膜（Adventitia）
  ───────────────────────────────
       中膜・内膜（Intima）
  ═══════════════════════════════  ← [内膜内縁 Inner margin]
            内腔（Lumen）          ↕ 内径計測カーソル（Inner-to-Inner）
  ═══════════════════════════════  ← [対側内膜内縁 Inner margin]
       中膜・内膜（Intima）
  ───────────────────────────────
       外膜（Adventitia）
```

### 3.2 形態・病変別の計測部位

1. **正常・均一走行部位**:
   - 起始部直後、または分岐後1〜2mmの安定した部分を計測。
2. **限局性冠動脈瘤（Saccular / Fusiform Aneurysm）**:
   - **最大径部位（Maximal internal diameter）**: 瘤の最も膨隆した部位の内縁間距離を必ず記録。
   - **近位部・遠位部の正常血管径（Reference diameter）**: 瘤直前および直後の非拡張部位の内径を測定し、局所拡大比（最大径 / 参照径）を算出する。
3. **びまん性拡張（Ectasia）**:
   - 最も拡張している部位の内径とともに、拡張病変の長軸方向の広がり（mm）を評価する。

### 3.3 冠動脈周囲の高エコー（Perivascular Brightness）と血栓観察

* **Perivascular Brightness（冠動脈周囲輝度亢進）**:
  - 発熱早期（発病3〜5日目）において、血管内腔の拡張（Zスコア上昇）に先行して冠動脈外膜周囲に菲薄な高輝度エコー帯（輝度亢進）が認められることがある。これは全層性血管炎に伴う浮腫・炎症細胞浸潤を反映した早期所見であり、見逃さずに記載する。
* **内腔輝度・血栓（Intraluminal Thrombus）の評価**:
  - 巨大冠動脈瘤内や屈曲部では血流鬱滞により自発エコーコントラスト（SEC / スモーク様エコー）や、壁在血栓・閉塞性血栓が生じやすい。
  - 低流速に合わせたカラードプラやパルスドプラ波形（順行性流速の著明な低下、逆流波）の確認を併用する。

## 4. 主要血管別の計測推奨ポイント

```mermaid
flowchart LR
    AO["\"大動脈基部 (Aortic Root")"] --> LMCA["\"左冠動脈主幹部 (LMCA")"]
    AO --> RCA1["\"右冠動脈 (RCA segment 1")"]
    LMCA --> LAD["\"左前下行枝 (LAD")"]
    LMCA --> LCx["\"回旋枝 (LCx")"]
    RCA1 --> RCA2["\"右冠動脈 (RCA segment 2")"]
    RCA2 --> RCA3["\"右冠動脈 (RCA segment 3")"]
```

| 血管名 | 観察・計測の推奨ポイント | 典型的な描出断面・注意点 |
| :--- | :--- | :--- |
| **左冠動脈主幹部<br>（LMCA）** | ・起始部からLAD/LCx分岐部直前までの中央部、または最大径部<br>・大動脈洞（Valsalva洞）の漏斗状起始部（Funnel shape）は含めず、平行管状になった部位を測定する | ・高位胸骨左縁短軸像（High PSAX）<br>・左冠動脈洞からの立ち上がり角度に注意し、前壁・後壁の内膜が鏡面反射でシャープに見える断面を選択 |
| **左前下行枝<br>（LAD proximal）** | ・LMCA分岐直後（1〜3mm末梢）の近位部を測定<br>・走行を可能な限り遠位部まで追跡（心尖部アプローチ併用） | ・胸骨左縁短軸像または斜位像<br>・肺動脈弁直下の前室間溝へ潜り込む部位で音響陰影に入らないようプローブを微調整 |
| **回旋枝<br>（LCx proximal）** | ・分岐部直後、左房室間溝を後方へ巻き込む近位部を測定<br>・川崎病での単独病変頻度はLAD/RCAより低いが、多発例では拡張を認めるため見落とし厳禁 | ・胸骨左縁短軸像で時計回りにわずかにローテーション<br>・心尖部4腔像をやや後方に倒した断面 |
| **右冠動脈 近位部<br>（RCA segment 1）** | ・右冠動脈洞起始部から2〜5mm末梢の均一な走行部<br>・LMCAと同様、起始部の漏斗状拡大部は除外する | ・胸骨左縁短軸像（10〜11時方向）<br>・大動脈弁閉鎖期に内腔が最も円滑に抜けるポイントで測定 |
| **右冠動脈 中間部〜遠位部<br>（RCA segment 2, 3）** | ・segment 2：右室自由壁に沿って尾側へ下行する長軸部<br>・segment 3：急性縁（acute margin）を越え後下行枝（PDA）に至る屈曲部 | ・胸骨左縁修正長軸像（Modified PLAX）<br>・肋骨下短軸〜長軸像（Subcostal）<br>・屈曲部は超音波ビームが平行になりやすいため角度補正・別アプローチを併用 |

## 5. Zスコア（Z-score）の評価基準

川崎病における冠動脈径評価は、**小児冠動脈Zスコア**（日本の小野式/Kobayashi式、または北米AHAで用いられるMcCrindle式/Boston式など、院内で採用している算出式）を用います。

### 冠動脈病変の分類基準（AHA / 日本小児循環器学会参考）

| 分類 | Zスコア（Z-score）基準 | 臨床的定義・対応 |
| :--- | :--- | :--- |
| **正常（No involvement）** | **Z < 2.0** | 冠動脈拡張なし。 |
| **拡張（Dilation / Ectasia）** | **2.0 ≤ Z < 2.5** | 軽度拡張（境界域）。初期病変や局所性拡張の疑い。 |
| **小型冠動脈瘤（Small Aneurysm）** | **2.5 ≤ Z < 5.0** | 明らかな冠動脈瘤。絶対径が4mm未満であってもZ≥2.5なら小型瘤。 |
| **中等大冠動脈瘤（Medium Aneurysm）** | **5.0 ≤ Z < 10.0** かつ 絶対径 < 8.0 mm | 中等度の瘤。血栓形成・狭窄リスクに対する厳重管理が必要。 |
| **巨大冠動脈瘤（Giant Aneurysm）** | **Z ≥ 10.0** または 絶対径 ≥ 8.0 mm | 極めて高リスク。破裂、広範血栓閉塞、心筋梗塞のリスクが高い。 |

## 6. 小児科Dr（主治医）との対話トークスクリプト・カンファレンス提示法

検査技師が小児科医に対してエコー所見を報告・議論する際の、臨床フェーズ別超実践トークスクリプトです。

### 6.1 急性期初回評価（発病4〜7日目：ベースライン確認）

#### 報告の着眼点
- 全身炎症状態におけるベースライン血管径の把握
- Zスコア 2.0 以上の初期拡張の有無
- 冠動脈周囲の浮腫所見（Perivascular brightness）の有無
- 左室収縮能・僧帽弁逆流（MR）・心嚢液（Carditisの合併）

#### トークスクリプト例
> **技師**:  
> 「〇〇先生、〇〇ちゃん（生後8ヶ月、BSA 0.38 $\text{m}^2$）の初回心臓超音波検査が終了しました。  
> 冠動脈内径ですが、**LAD近位部が 2.1 mmで Zスコア +2.4** と軽度拡張の域に達しています。LMCAは 2.2 mm（Z=+1.5）、RCA segment 1は 1.8 mm（Z=+1.3）で保たれています。  
> また、絶対径は2.1mmと一見目立たない数値ですが、体表面積で補正するとZスコアが+2.0を超えており、**LAD分岐部から近位部にかけて周囲組織の輝度亢進（Perivascular brightness）**が明瞭です。軽度の心嚢液貯留も認められます。  
> 本日第5病日とのことですが、早期の冠動脈病変進展リスクが懸念されますので、画像をPACSにアップロードし計測断面をマークしておきました。ご確認ください。」

> **Dr**:  
> 「ありがとう。絶対径2.1mmだけ見ると見落としそうだったけれど、BSA 0.38だとZスコア+2.4なんだね。周囲の輝度亢進もあるなら、IVIG治療の反応を特に注視して追跡エコーを組むよ。」

---

### 6.2 IVIG不応例・追加治療検討時（発病7〜10日目：ΔZの追跡評価）

#### 報告の着眼点
- 初回検査からの経時変化（$\Delta Z$ スコアの推移）
- 拡張病変の進展（単なる内径増大か、新たな分枝への病変波及か）
- 瘤の形態（紡錘状 fusiform か 嚢状 saccular か）

#### トークスクリプト例
> **技師**:  
> 「先生、初回IVIG投与後も発熱が持続している〇〇ちゃんのフォロー心エコー結果です。  
> 前回（第5病日）と比較して冠動脈内径の急速な拡大を認めています。  
> **LAD近位部は前回 2.1 mm（Z=+2.4）から本日 3.2 mm（Z=+5.1）へ拡大し、$\Delta Z$ が +2.7 上昇して中等大冠動脈瘤の基準に入りました。**  
> さらに、前回正常だった**RCA segment 1も 1.8 mm（Z=+1.3）から 2.6 mm（Z=+3.4）へと小型瘤を形成**し始めています。LADの瘤は紡錘状で、内腔に明らかな血栓エコーは見られませんが、血管壁の炎症反応が両側で顕著に進行しています。」

> **Dr**:  
> 「短期間で$\Delta Z$が急激に跳ね上がっているね。RCAにも小型瘤が出現したか……。IVIG不応と判断して、インフリキシマブ（レミケード）またはパルス療法の追加プロトコルを直ちに検討するカンファレンスを開くよ。至急、最大径のフリーズ画像と経時変化の推移表を出してもらえるかい？」

> **技師**:  
> 「了解いたしました。各分枝の第5病日と本日の絶対径・Zスコア比較一覧表および最大径断面のキー画像を直ちに出力・連携いたします。」

---

### 6.3 遠隔期・退院前評価（発病2〜4週以降：退縮・リモデリング・血栓監査）

#### 報告の着眼点
- 冠動脈瘤の内径退縮（Regression / Remodeling）の確認
- 内膜肥厚・狭窄形成（Stenosis）の有無
- 瘤内血栓・石灰化（Calcification）の有無
- ドプラ法による冠血流速波形の評価（拡張期血流優位性の保たれ具合）

#### トークスクリプト例
> **技師**:  
> 「第30病日、退院前評価の〇〇ちゃんのエコー所見です。  
> 急性期に最大 4.2 mm（Z=+6.8）まで拡大していたLADの中等大瘤ですが、**本日の計測では 2.6 mm（Z=+2.9）まで縮小傾向（退縮：Regression）**を認めています。  
> ただし注意点として、**退縮部位の内膜が全周性に肥厚しており、輝度の上昇を伴っています。**カラードプラおよびパルスドプラで局所的な流速上昇（モザイクシグナル）は認めておらず、有意な狭窄には至っていませんが、リモデリングに伴う内膜増殖が始まっている所見です。  
> RCAに関しても最大 2.8 mm（Z=+3.8）から 2.1 mm（Z=+2.1）へ改善しています。瘤内血栓および石灰化陰影は両側とも認めません。」

> **Dr**:  
> 「内径の退縮傾向は良好だが、内膜肥厚によるリモデリング過程にあるわけだね。見かけ上の内径正常化でも将来的な狭窄リスクが残るから、抗血小板療法の継続と外来での定期的なドプラ血流評価・Zスコアモニタリングを計画するよ。」

---

### 6.4 「絶対径だけでなくZスコアで議論する」ための提案フレーズ集

臨床現場で医師が絶対径（ミリ数）のみで判断しそうな場合に、角を立てず自然にZスコア評価へ誘導するための技師側からの問いかけテンプレートです。

* **乳児（低体表面積）で絶対径が小さく見えるケース**:
  > 「先生、絶対径は 2.5 mmと一見それほど太く見えないのですが、この月齢（体重 6.5 kg、BSA 0.34 $\text{m}^2$）ですと**Zスコアは +3.8（小型瘤レベル）**に達しています。小児基準ですと介入強化を考慮するレンジに入りますが、いかがでしょうか？」
* **体格の大きな学童で絶対径が太く見えるケース**:
  > 「絶対径は 3.5 mm計測されていますが、この子は体重 32 kg（BSA 1.10 $\text{m}^2$）と体格が大きいため、**Zスコア上は +1.7 と正常上限内**に収まっております。局所的な瘤形成ではなく体格相応の血管径と考えられます。」
* **経時変化を強調したいケース**:
  > 「絶対径の変化は +0.4 mmの微増にとどまっていますが、**Zスコアでは +1.8 から +2.6 へと正常域から拡張・瘤形成域へ境界を跨いでいます（$\Delta Z = +0.8$）**。急性期の炎症活動性が残存している可能性が高いと考えられます。」
* **退院後のフォロー間隔を相談するケース**:
  > 「ガイドライン上、Zスコアが 2.5 未満に退縮したか、あるいは 2.5 以上が残存しているかによって遠隔期フォローアップ（エコー頻度や運動制限）のリスク分類が変わってまいります。今回の最新Zスコア（+2.6）をもとに次回の検査時期を設定いたしましょうか？」

## 7. カンファレンス用チェックリスト

心臓超音波検査カンファレンスで提示する前に確認すべき必須チェックリストです。

- [ ] **体表面積（BSA）の算出根拠**: 身長・体重が直近の測定値で入力されているか？
- [ ] **採用Zスコア式の明示**: 小野式、Kobayashi式、AHA（McCrindle）式のいずれで算出したかを記載しているか？
- [ ] **Inner-to-Innerの遵守**: 外膜高エコーや周囲浮腫（Perivascular brightness）を除外して内膜面で測れているか？
- [ ] **心電図同期**: 拡張末期フレームで再現性をもってフリーズ計測されているか？
- [ ] **主要分枝の網羅性**: LMCA、LAD、LCx、RCA（segment 1, 2, 3）がすべて評価されているか？
- [ ] **形態・合併症所見**: 瘤の形態（嚢状/紡錘状）、血栓エコー、心嚢液、弁逆流（MR/TR）、左室収縮能が記載されているか？
- [ ] **$\Delta Z$（前回比較）**: 前回検査日からのZスコアの増減値が即答できるように整理されているか？
