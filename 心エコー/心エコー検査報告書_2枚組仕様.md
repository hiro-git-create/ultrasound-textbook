## 【2枚目：詳細評価・血行動態・弁膜症精査】

### 1. 弁膜症 詳細定量的評価 (Quantitative Valvular Assessment)
- **大動脈弁 (AS/AR)**: AVA (連続の式) / Vmax / mean PG / DVI / AR PHT / VC / 形態（二尖弁・石灰化・ジェット偏位）
- **僧帽弁 (MS/MR)**: MVA (PHT / プライニメトリ) / mean PG / MR VC / EROA / RegVol / 形態（Carpentier分類・逸脱部位・テザリング）
- **三尖弁 (TS/TR)**: TR Vmax / TR-PG / VC / 収縮期肝静脈逆流 / 弁輪径
- **肺動脈弁 (PS/PR)**: PR end-diastolic PG (推定PADP) / PS peak PG
- **人工弁 (Prosthesis)**: 弁種・サイズ / PG / DVI / PPM評価 / 弁周囲逆流 (PVL) / 開閉制限
- **感染性心内膜炎 (IE)**: 疣贅 (Vegetation) 部位・サイズ・可動性 / 弁破壊・穿孔・膿瘍

### 2. 右心機能・肺高血圧 & 拡張能・心室相互作用詳細
- **右心系・肺循環**:
  - TAPSE (基準 ≥17mm)
  - RV s' (基準 ≥9.5cm/s)
  - RV-FAC (基準 ≥35%)
  - 推定右房圧 RAP (IVC径と虚脱率から 3 / 8 / 15 mmHg)
  - 推定肺動脈収縮期圧 ePASP (TR-PG + RAP, 基準 ≤35mmHg)
  - 肺動脈弁血流加速度時間 Act (中収縮期ノッチ有無)
- **左室拡張能アルゴリズム (ASE/EACVI準拠)**:
  - 中隔/側壁 e'
  - 平均 E/e' 比 (>14)
  - LAVI (>34 ml/m²)
  - TR Vmax (>2.8 m/s)
  - 肺静脈波 (Ar dur - A dur ≥ 30ms で LVEDP上昇)
  - Valsalva負荷 (擬似正常化の解除判定)
  - 拡張能グレード判定: [ 正常 / G1弛緩低下型 / G2偽正常型 / G3拘束型 ]

### 3. 心筋症・短絡疾患・大動脈・その他の詳細所見
- **心筋症 (HCM/DCM/アミロイド等)**: 肥大局在 (ASH, Apical, 同心性) / SAM / 閉塞性狭窄圧較差 / 心筋輝度・緻密化障害
- **大動脈基部・上行大動脈**: Valsalva洞径 / ST junction径 / 上行大動脈径 / 急性大動脈解離 (フラップ・ULP・偽腔)
- **先天性・短絡血流 (Shunt)**: ASD (心房中隔欠損) / PFO (卵円孔開存) / VSD (心室中隔欠損) / PDA / 奇異性塞栓リスク
- **心嚢液・心腔内腫瘤/血栓**: 心嚢液量・心タンポナーデ所見 (右室虚脱) / 左心耳・心尖部血栓

### 4. 総合所見・治療方針への提言 (Clinical Recommendation)
- 詳細考察・前回検査との比較
- 今後の推奨追跡間隔・追加推奨検査 (TEE / 心臓MRI / 冠動脈CT等)
- 検査者・診断医署名 / Page 2 / 2
