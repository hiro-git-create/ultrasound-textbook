# 川崎病における冠動脈Zスコア算出式と病態分類のエビデンス

本稿は、日本循環器学会/日本小児循環器学会合同ガイドライン（JCS/JSPCCS 2020年改訂版 ガイドライン）を中心とし、小林式（Kobayashi式）やMcCrindle/Boston式等の冠動脈Zスコア算出式、病態分類基準、体表面積（BSA）計算式、および従来の厚生省基準との比較検討をまとめた医学的エビデンス集である。

---

## 1. 冠動脈病変のZスコア分類（JCS/JSPCCS 2020年改訂版）

日本小児循環器学会・日本川崎病学会の知見を反映した『川崎病心臓血管後遺症の診断と治療に関するガイドライン（2020年改訂版）』において、冠動脈内径の評価は従来の絶対径基準からZスコア（体表面積で標準化した標準偏差スコア）を基盤とした分類へと移行している。

### 冠動脈病変分類基準表

| 分類区分 | 定義・判定条件 | 臨床的意義・管理方針 |
| :--- | :--- | :--- |
| **正常 (No involvement)** | $Z < 2.0$ | 冠動脈内径の有意な拡大なし。 |
| **拡大 (Dilation only)** | $2.0 \le Z < 2.5$ | または初診時・急性期観察中に内径が明らかに拡張したが $Z < 2.5$ にとどまるもの（一過性拡大）。 |
| **小動脈瘤 (Small aneurysm)** | $2.5 \le Z < 5.0$ | 局所性またはびまん性の拡張でZスコアが $2.5$ 以上 $5.0$ 未満。退縮（regression）率は高いが内膜肥厚遺残に留意。 |
| **中等度動脈瘤 (Medium aneurysm)** | $5.0 \le Z < 10.0$ **かつ** 絶対径 $< 8.0\,\text{mm}$ | 血栓形成リスク、狭窄病変移行リスクを有するため、厳重な抗血小板療法および定期的な心臓超音波検査を要する。 |
| **巨大動脈瘤 (Giant aneurysm)** | $Z \ge 10.0$ **または** 絶対径 $\ge 8.0\,\text{mm}$ | 冠動脈破裂・血栓性閉塞・心筋梗塞の超高リスク群。抗凝固療法（ワルファリン併用等）および厳格な心筋虚血評価が必須。 |

> [!IMPORTANT]
> - Zスコアが $5.0 \le Z < 10.0$ であっても、絶対径が $8.0\,\text{mm}$ 以上の場合は「**巨大動脈瘤**」に分類される。
> - 評価対象血管部位（左冠動脈主幹部、左前下行枝、回旋枝、右冠動脈）のうち、**最大のZスコアまたは最大内径**を示した部位に基づいて患者全体の病態分類が決定される。

## 2. 厚生省基準（絶対径基準）の限界とZスコア導入の臨床的・統計的根拠

### 従来の厚生省基準（1984年厚生省川崎病研究班基準）
厚生省基準では、年齢や体格にかかわらず以下の絶対径を用いて冠動脈瘤を判定していた：
1. **小動脈瘤**: 最大内径 $\le 4.0\,\text{mm}$（乳幼児では内径 $> 3.0\,\text{mm}$）
2. **中等度動脈瘤**: 内径 $> 4.0\,\text{mm}$ かつ $< 8.0\,\text{mm}$
3. **巨大動脈瘤**: 内径 $\ge 8.0\,\text{mm}$
4. **一過性拡大**: 周囲の正常径に対して $1.5$ 倍以上の局所的拡張を示し、急性期中に正常化したもの

### 厚生省基準が抱える重大な課題（なぜZスコアが必要なのか）
1. **乳児における過小評価（偽陰性・重症度の見誤り）**
   - 生後 $1 \sim 6$ か月の乳児における正常な冠動脈内径（左前下行枝など）は平均して **$1.2 \sim 1.5\,\text{mm}$** 程度である。
   - もし乳児の左前下行枝の内径が **$3.0\,\text{mm}$** に達していた場合、従来の厚生省基準では「正常〜軽度拡大」と判定されかねない。
   - しかし、Zスコアで計算すると $Z > +5.0 \sim +8.0$（中等度動脈瘤〜準巨大動脈瘤レベル）の高度拡張に該当する。つまり、正常径の $2$ 倍以上に拡張している病変を「軽症」と誤認し、必要な抗血小板・抗凝固療法が遅れる致命的リスクが存在した。
2. **年長児・体格大の小児における過剰診断（偽陽性）**
   - 逆に体表面積の大きい学童期（$10$ 歳以上など）では、正常な冠動脈内径自体が $2.5 \sim 3.0\,\text{mm}$ 近くになる。
   - 健常児であっても $3.0\,\text{mm}$ を超える場合があり、絶対径のみに依存すると「動脈瘤」と過剰診断される不利益があった。
3. **統計学的標準化による客観的病態評価**
   - 健常小児の大規模母集団データに基づき、体格（体表面積）に対して正規分布化した標準偏差（Zスコア）を用いることで、年齢・月齢・体格を問わず均一なリスク層別化が可能となった。

```mermaid

    A["心臓超音波検査による冠動脈内径計測"] --> B["体表面積（BSA）の算出"]
    B --> C["基準Zスコア回帰式（小林式等）へ代入"]
    C --> D{"Zスコアおよび絶対径の判定"}
    D -- "Z < 2.0" --> E["\"正常 (No involvement")"]
    D -- "2.0 <= Z < 2.5" --> F["\"拡大 (Dilation only")"]
    D -- "2.5 <= Z < 5.0" --> G["\"小動脈瘤 (Small aneurysm")"]
    D -- "5.0 <= Z < 10.0 かつ 絶対径 < 8.0mm" --> H["\"中等度動脈瘤 (Medium aneurysm")"]
    D -- "Z >= 10.0 または 絶対径 >= 8.0mm" --> I["\"巨大動脈瘤 (Giant aneurysm")"]
```

## 3. 代表的Zスコア算出式：小林式 vs McCrindle式 (Boston/Dallaire式)

冠動脈Zスコア算出式には、対象母集団の人種・体格データ、計測部位、統計的モデリング手法に応じた違いが存在する。

| 項目 | 小林式（Kobayashi et al.） | McCrindle式 / AHA基準（McCrindle et al.） | Boston式（Dallaire & Dahdah） |
| :--- | :--- | :--- | :--- |
| **主要文献** | *Circ J* 2006; 70: 1603–1609<br>*Pediatr Int* 2016; 58: 711–719 | *Circulation* 2007; 115: 1933–1940<br>*Circulation* 2017; 135: e927–e999 | *J Am Soc Echocardiogr* 2011; 24: 60–74 |
| **対象母集団** | **日本人健常小児**（多施設共同研究データ） | 北米多施設（多様な人種、白人・黒人・ヒスパニック主体） | カナダ小児母集団（白人主体） |
| **適応・推奨** | **日本国内ガイドライン（JCS/JSPCCS 2020）推奨** | 米国心臓協会（AHA 2017 Guidelines）推奨 | 北米・欧州の研究・治験で汎用 |
| **計測対象血管** | 左冠動脈主幹部 (LMCA)<br>左前下行枝 (LAD)<br>回旋枝 (LCx)<br>右冠動脈 (RCA segment 1, 2, 3) | LMCA, LAD, 近位部RCA | LMCA, LAD, LCx, RCA |
| **算出式の数学構造** | 予測平均値 $\ln(\text{内径}) = a \times \ln(\text{BSA}) + b$<br>$Z = \frac{\ln(\text{実測値}) - \text{予測平均値}}{\text{残差標準偏差}}$ | 重回帰/非線形モデリング、異分散補正（BSAに応じた標準偏差のモデル化） | パラメトリック対数変換モデル |
| **特徴・長所** | 日本人小児の体格特性に完全に合致。日本の日常臨床・治験において標準的。 | 症例数が膨大。国際共同治験・欧米論文との比較に適する。 | 小児心エコーの標準Zスコアとして北米で広く採用。 |

### 日本国内の臨床現場における選択
- 日本国内の小児循環器科・川崎病専門医においては、**小林式（Kobayashi式）** が第一選択として広く用いられている。
- 日本人小児は欧米児に比べて同一月齢・年齢での体格（BSA）や体脂肪率が異なるため、欧米の算出式をそのまま適用すると冠動脈径の評価に微小な偏り（バイアス）が生じる可能性が指摘されている。
- 一方で、国際共同研究や海外ジャーナルへの投稿論文においては、AHAガイドライン準拠の **McCrindle式** や **Boston式** の併記・比較検討が求められるケースがある。

## 4. 体表面積（BSA）計算式の指定と注意点

冠動脈Zスコアは体表面積（BSA: Body Surface Area, $\text{m}^2$）を変数として計算されるため、どのBSA算出式を用いるかによってZスコアの値に差異が生じる。

### 代表的なBSA計算式

1. **Haycock式（推奨）**
   $$\text{BSA}\,(\text{m}^2) = \text{体重}\,(\text{kg})^{0.5378} \times \text{身長}\,(\text{cm})^{0.3964} \times 0.024265$$
   - **特徴**: 新生児、乳幼児から小児全般において最も誤差が少なく、国際的な小児心エコーガイドライン（ASE等）や多くのZスコア算出式で標準指定されている。

2. **DuBois式（DuBois & DuBois式）**
   $$\text{BSA}\,(\text{m}^2) = \text{体重}\,(\text{kg})^{0.425} \times \text{身長}\,(\text{cm})^{0.725} \times 0.007184$$
   - **特徴**: 成人領域で広く用いられている古典的計算式。
   - **注意点**: 低体重児や乳幼児（特に体幹部と四肢の比率が成人と大きく異なる乳児期）では過小評価になりやすい。

3. **Mosteller式**
   $$\text{BSA}\,(\text{m}^2) = \sqrt{\frac{\text{身長}\,(\text{cm}) \times \text{体重}\,(\text{kg})}{3600}}$$
   - **特徴**: 簡便であり電子カルテ等で採用例が多いが、小児極小体格ではHaycock式との乖離に注意を要する。

### 臨床現場における重要注意事項
- **回帰式との整合性**: 小林式やMcCrindle式など、**各Zスコア算出式の導出元論文で指定されているBSA計算式（多くはHaycock式）と完全に一致させること**が原則である。
- 異なるBSA計算式を混用すると、特に境界領域（$Z = 2.0, 2.5, 5.0, 10.0$ 付近）において病態分類が一段階シフト（例：拡大から小動脈瘤へ、またはその逆）する危険性がある。

## 5. 心臓超音波検査における冠動脈内径計測の技術的留意点

1. **計測部位の明確化**
   - **左冠動脈主幹部 (LMCA)**: 大動脈弁洞からの起始部直後から分岐部手前の最狭小部または最大部。
   - **左前下行枝 (LAD)**: 起始部直後（proximal LAD）の内腔内縁間距離（inner-edge to inner-edge）。
   - **回旋枝 (LCx)**: 起始部付近の明瞭なエコーフリースペース。
   - **右冠動脈 (RCA)**: 近位部（segment 1: 起始直後の直線部）、中間部（segment 2）、遠位部（segment 3）。
2. **inner-edge to inner-edge 計測の徹底**
   - 超音波ビームのゲイン過多によるブルーミング現象を避け、血管内腔の内膜表面間を垂直に計測する。
3. **拡張末期フレームの選択**
   - 血管拡張動態や心拍動によるアーチファクトを抑えるため、心電図同期下で同一心時相（一般に収縮末期〜拡張末期）で一貫して記録・計測する。
