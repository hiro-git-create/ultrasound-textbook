# 📝 標準12誘導心電図 レポート作成ガイド（コピペ用テンプレート）

臨床現場（外来・病棟・健診）の電子カルテへ即座に貼り付けて使用できる、標準的かつ網羅的な心電図所見レポートテンプレートです。

---

## 1. 標準心電図レポート（フルセット形式）

```text
【心電図検査所見】
■ 基本情報
・心拍数: [  ] bpm（整 / 不整）
・基本調律: 洞調律 (Normal Sinus Rhythm) / 心房細動 (Atrial Fibrillation) / その他 [  ]
・電気軸: 正常軸 (0°〜+90°) / 左軸偏位 / 右軸偏位
・移行帯: V3-V4 / 反時計方向回転 (V1-V2) / 時計方向回転 (V5-V6)

■ 計測値
・PQ(PR)時間: [  ] ms (正常 120-200ms)
・QRS幅: [  ] ms (正常 ≤100ms)
・QT / QTc(Bazett): [  ] / [  ] ms (正常 QTc ≤450ms[男] / ≤460ms[女])

■ 波形所見
・P波: 正常 / 右房負荷(肺性P) / 左房負荷(僧帽性P)
・QRS波: 正常 / 左室肥大(Sokolow-Lyon [  ]mV) / 右室肥大 / 低電位 / 脚ブロック(CRBBB/CLBBB/IRBBB) / 異常Q波 [  ]
・ST部: 正常 / ST上昇 [ 誘導:     ] / ST低下 [ 誘導:     ]
・T波: 正常 / 陰性T波 [ 誘導:     ] / 平低T波 / テント状T波
・不整脈・期外収縮: なし / PAC [ 単発/多発 ] / PVC [ 単発/連発/Lown Class  ]

■ 総合診断 (Diagnosis / Conclusion)
1. [ 正常洞調律 (NSR) / 所見なし ]
2. [ 疑われる病態・診断名 ]

■ コメント / 推奨事項
・[ 前回家（202X/XX/XX）と比較し変化なし / 新たに出現した所見のため循環器精査推奨 ]
```

## 2. 健診・ドック用 簡略テンプレート（1行〜数行完結型）

```text
【所見】洞調律、心拍数 68bpm、正常軸、明らかなST-T変化・不整脈・伝導障害を認めず。
【判定】正常心電図 (A判定)
```

```text
【所見】洞調律、心拍数 72bpm、左軸偏位 (-45°)、I・aVLでqRパターンを認める (左脚前枝ブロック疑い)。ST-T変化なし。
【判定】要経過観察 (B/C判定)
```

```text
【所見】洞調律、SV1 + RV5 = 4.2mV (左室高電位/Sokolow-Lyon陽性)、V5-V6で非対称性ST低下・陰性T波を伴う (左室肥大・ストレインパターン)。
【判定】要精密検査・循環器内科受診 (D判定)
```

## 3. 主要所見別の定型文パーツ（組み合わせ用）

| 分野 | 臨床所見 | 電子カルテ記載定型文 |
| :--- | :--- | :--- |
| **調律** | 洞性徐脈 | `洞性徐脈 (HR: 48bpm)。洞停止・失神エピソード等の自覚症状の有無を確認。` |
| **調律** | 心房細動 | `心房細動 (Af)。心室応答 HR: 85bpm (整/不整)。CHADS2スコア評価及び抗凝固療法の適応確認推奨。` |
| **伝導** | 完全右脚ブロック | `完全右脚ブロック (CRBBB: QRS幅 130ms, V1 rsR'型, V6 幅広いS波)。基礎心疾患精査。` |
| **伝導** | 1度房室ブロック | `1度房室ブロック (PR時間: 240ms)。Wenckebachや高度房室ブロックへの進行注意。` |
| **肥大** | 左室肥大 | `左室高電位・肥大所見 (SV1+RV5=4.0mV, V5-V6 ST低下・陰性T波)。高血圧性心肥大疑い。` |
| **虚血** | ST低下・狭心症 | `V4-V6 水平成ST低下 (0.15mV)。労作時胸痛の有無確認、虚血性心疾患の精査推奨。` |
| **虚血** | 陳旧性下壁梗塞 | `II, III, aVF 異常Q波 (幅≥40ms, 深さ≥R/4)。陳旧性下壁心筋梗塞 (OMI) の疑い。` |
| **電解質** | 高K血症疑い | `II, III, V3-V5 左右対称性の先鋭化した高尖T波 (テント状T波)。高カリウム血症を疑い採血確認推奨。` |
