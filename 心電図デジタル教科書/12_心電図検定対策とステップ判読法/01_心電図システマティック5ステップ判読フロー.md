# 🧭 心電図システマティック5ステップ判読フロー

心電図の判読で最も多い失敗は、目立つ異常（顕著なST上昇や幅広QRSなど）に目を奪われ、背後に隠れた重大な所見（徐脈、微小な異常Q波、QT延長など）を見落とす「直感判読の罠」です。
**必ず同一の順序で全波形を網羅的に確認する5ステップ判読法**を身につけることで、見落としを完全にゼロにできます。

---

## 1. システマティック5ステップの全体概要

```mermaid

    S1["\"【Step 1】 調律 (Rhythm") & 心拍数 (HR)<br/>洞調律か？ 心拍数は正常か？"] --> S2["\"【Step 2】 電気軸 (Axis") & 移行帯 (Transition)<br/>I・aVF誘導とV1-V6の水平面回転"]
    S2 --> S3["\"【Step 3】 P波 & PQ(PR")時間<br/>心房負荷はあるか？ 房室伝導時間は正常か？"]
    S3 --> S4["【Step 4】 QRS波形・肥大・脚ブロック<br/>QRS幅・異常Q波・左室/右室肥大・脚ブロック"]
    S4 --> S5["【Step 5】 ST-T・QT時間・U波・電解質<br/>ST上昇/低下・陰性/尖鋭T波・QTc・U波"]
    S5 --> END["【総合診断 & 臨床レポート作成】"]
```

## 2. 各ステップの詳細判読手順

### 🔷 Step 1: 調律（Rhythm）と心拍数（Heart Rate）

```
【洞調律 (Sinus Rhythm) の3大条件】
① II, III, aVF で陽性P波、aVR で陰性P波
② P波とQRS波が 1:1 に規則正しく対応
③ 心拍数が 50〜100 bpm の範囲内
```

#### 心拍数の高速計算テクニック
- **300法（RR間隔の太枠数）**:
  - 太枠1マス（0.20秒）$= 300\,\text{bpm}$
  - 太枠2マス $= 150\,\text{bpm}$
  - 太枠3マス $= 100\,\text{bpm}$
  - 太枠4マス $= 75\,\text{bpm}$
  - 太枠5マス $= 60\,\text{bpm}$
  - 太枠6マス $= 50\,\text{bpm}$
- **不整脈時（心房細動など）の計算法**:
  - 30マス（6秒間）に含まれるQRS拍動数を数えて **$\times 10$** する。

---

### 🔷 Step 2: 電気軸（Electrical Axis）と移行帯（Transition Zone）

四肢誘導（前額面）のベクトルから電気軸を、胸部誘導（水平面）から移行帯を判定します。

```
【I誘導とaVF誘導を用いた簡易4象限判定】
              aVF (+)
                │
    右軸偏位    │    正常軸
   (+90°〜+180°)│   (0°〜+90°)
 ───────────────┼───────────────► I (+)
    極度の軸偏位 │    左軸偏位
  (-90°〜-180°) │   (0°〜-90°)
                │
              aVF (-)
```

#### 判定基準
- **正常軸（Normal axis）**: I誘導（$+$） かつ aVF誘導（$+$）［$-30^\circ \sim +90^\circ$］
- **左軸偏位（LAD）**: I誘導（$+$） かつ aVF誘導（$-$）［$-30^\circ \sim -90^\circ$］ $\to$ 左脚前枝ブロック、左室肥大、下壁梗塞を疑う。
- **右軸偏位（RAD）**: I誘導（$-$） かつ aVF誘導（$+$）［$+90^\circ \sim +180^\circ$］ $\to$ 右室肥大、肺塞栓、左脚後枝ブロックを疑う。
- **移行帯（Transition Zone）**:
  - 正常: $V_3 \sim V_4$（$R=S$ となる誘導）
  - **反時計方向回転**: $V_1 \sim V_2$ で $R=S$
  - **時計方向回転**: $V_5 \sim V_6$ で $R=S$（肺疾患、右室負荷）

---

### 🔷 Step 3: P波・PQ(PR)時間

心房の興奮と房室結節の伝導状態を計測します。

| 評価項目 | 正常基準値 | 異常時の所見と疑われる病態 |
| :--- | :--- | :--- |
| **P波の幅** | $\le 0.11\,\text{秒}\ (2.5\,\text{mm})$ | **左房負荷（僧帽性P）**: 幅 $\ge 0.12\,\text{秒}$、II誘導で二峰性P、V1で深い陰性終末部（Morris指数陽性） |
| **P波の高さ** | $\le 0.25\,\text{mV}\ (2.5\,\text{mm})$ | **右房負荷（肺性P）**: II, III, aVF で尖鋭な高大P波（$\ge 0.25\,\text{mV}$） |
| **PQ(PR)時間** | $0.12 \sim 0.20\,\text{秒}\ (3 \sim 5\,\text{マス})$ | **短縮（$< 0.12\,\text{秒}$）**: WPW症候群（デルタ波）、房室接合部調律<br/>**延長（$> 0.20\,\text{秒}$）**: 1度房室ブロック、薬剤性伝導遅延 |
| **PR部分の偏位** | 等電位線（基線）と一致 | **PR低下**: 急性心膜炎（広範）、心房梗塞 |

---

### 🔷 Step 4: QRS波形・心室肥大・脚ブロック

心室の脱分極波形（幅、電位、形態異常）を精査します。

```
【QRS幅の鑑別基準】
・QRS ≤ 0.10s (2.5マス): 正常心室内伝導
・QRS 0.10〜0.11s: 不完全脚ブロック / 室内伝導遅延
・QRS ≥ 0.12s (3マス): 完全脚ブロック (CRBBB/CLBBB) / 心室起源 / WPW
```

#### 心室肥大・脚ブロックの診断基準
1. **完全右脚ブロック（CRBBB）**:
   - QRS幅 $\ge 0.12\,\text{秒}$ ＋ $V_1$ で $rsR'$（ウサギの耳型）＋ I, $V_6$ で幅広いS波。
2. **完全左脚ブロック（CLBBB）**:
   - QRS幅 $\ge 0.12\,\text{秒}$ ＋ I, aVL, $V_5, V_6$ で幅広い分裂R波 ＋ $V_1$ で深いQS型。
3. **左室肥大（LVH）基準**:
   - **Sokolow-Lyon基準**: $S_{V1} + R_{V5/V6} \ge 3.5\,\text{mV}\ (35\,\text{mm})$
   - **Cornell電圧基準**: $R_{\text{aVL}} + S_{V3} > 2.8\,\text{mV}$（男性） / $> 2.0\,\text{mV}$（女性）
4. **異常Q波（Pathological Q wave）**:
   - 幅 $\ge 0.04\,\text{秒}$（1マス） または 深さ $\ge R\text{波の} 1/4$（陳旧性心筋梗塞 OMI）。

---

### 🔷 Step 5: ST部・T波・QT時間・電解質

心室の再分極異常（虚血、電解質、遺伝性不整脈）を最終確認します。

| 評価項目 | 正常所見 | 異常所見と疑われる病態 |
| :--- | :--- | :--- |
| **ST部** | 基線（TP部）と同電位 | **ST上昇**: 急性心筋梗塞（STEMI）、急性心膜炎、たこつぼ心筋症、Brugada波形<br/>**ST低下**: 心筋虚血（水平/下降型）、左室肥大ストレイン、ジギタリス効果（盆状） |
| **T波** | 左右非対称の陽性波 | **対称性冠性T波（陰性T波）**: 心筋虚血、たこつぼ心筋症<br/>**テント状T波（尖鋭高大T波）**: 高カリウム血症、超急性期心筋梗塞 |
| **QTc時間** | $\le 450\,\text{ms}$（男）/ $\le 460\,\text{ms}$（女） | **延長（$> 460 \sim 480\,\text{ms}$）**: QT延長症候群（LQTS）、低K/低Mg血症、TdPリスク<br/>**短縮（$\le 340\,\text{ms}$）**: 短縮QT症候群（SQTS）、高Ca血症 |
| **U波** | 軽度の陽性低電位 | **巨大U波**: 低カリウム血症、徐脈<br/>**陰性U波**: 重症心筋虚血、左室過負荷 |
