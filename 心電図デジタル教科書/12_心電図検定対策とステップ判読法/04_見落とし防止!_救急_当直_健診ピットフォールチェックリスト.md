# 🚨 見落とし防止！救急・当直・健診ピットフォールチェックリスト

心電図判読において、**「一見軽微に見えるが数時間以内に心停止・心筋壊死に至る超危険サイン（STEMI等価物）」** や **「他疾患に偽装する電解質・特殊病態」** の見落としは絶対に防がなければなりません。本稿では当直医・救急医・健診医が即座に確認すべきピットフォールを網羅します。

---

## 1. 致死性STEMI等価物（STEMI Equivalents）の6大サイン

標準的なSTEMI診断基準（J点ST上昇）を満たさなくても、**直ちに緊急冠動脈造影（心カテ）を要する超高リスク病態**です。

```
【① Wellens症候群 Type A】           【① Wellens症候群 Type B】
      ▲ R                                   ▲ R
     / \     /\                            / \
 ---'   \___/  \ (二峰性T波 in V2-V3)   ---'   \________
                \_______                                \            /---
                                                         \__________/ (深い対称性陰性T波)

【② de Winter サイン (V1-V6)】        【③ 後壁梗塞の鏡面像 (V1-V3)】
      ▲ R                                   ▲ 高いR波 (R/S > 1)
     / \   /\ (高峻対称性T波)               / \
 ---'   \_/  \______                    ---'   \_______ (ST低下 + 直立T波)
        (J点低下 1-3mm)
```

### 6大STEMI等価物の詳細と対応

| サイン名 | 心電図特徴 | 責任病変・病態 | 緊急対応 |
| :--- | :--- | :--- | :--- |
| **① Wellens症候群**<br/>（ウェレンズ） | **胸痛軽快時**に $V_2 \sim V_3$（$V_4$）で出現する<br/>・Type A: **二峰性（Plus-Minus）T波**（25%）<br/>・Type B: **深く左右対称な陰性T波**（75%） | **左前下行枝（LAD）近位部の 89〜99% 重症狭窄**（切迫心筋梗塞） | **運動負荷試験は絶対禁忌！**<br/>直ちに緊急心カテ |
| **② de Winterサイン**<br/>（ド・ウィンター） | 前胸部誘導（$V_1 \sim V_6$）で **$1 \sim 3\,\text{mm}$ の上向き凹J点ST低下から立ち上がる高峻対称性T波** ＋ **aVRで $1 \sim 2\,\text{mm}$ のST上昇** | **LAD近位部の急性完全閉塞**（前壁STEMIの超急性期等価物） | **直ちに緊急心カテ**（再灌流プロトコル起動） |
| **③ aVR ST上昇 ＋<br/>広範誘導のST低下** | **aVR誘導でST上昇 $\ge 1.0\,\text{mm}$**（$aVR \ge V_1$） ＋<br/>**6誘導以上（I, II, aVL, $V_3 \sim V_6$）で著明なST低下** | **左冠動脈主幹部（LMT）閉塞**<br/>または **重症3枝病変** | **極めて予後不良・心原性ショック直前**<br/>直ちに緊急心カテ・外科待機 |
| **④ 後壁心筋梗塞**<br/>（Posterior MI） | 前胸部 $V_1 \sim V_3$ における **高いR波（$R/S > 1$）** ＋ **水平型ST低下** ＋ **直立高大T波**（後壁の鏡面像） | **左回旋枝（LCx）または右冠動脈（RCA）閉塞** | **背部誘導（$V_7 \sim V_9$）を追加記録**<br/>（$0.5\,\text{mm}$ 以上のST上昇で確定） |
| **⑤ 右室梗塞**<br/>（RV Infarction） | 下壁梗塞（II, III, aVF ST上昇）合併時に **$V_1$ のST上昇** または **$V_2$ より $V_1$ のST上昇が高い** | **右冠動脈近位部（RCA Proximal）閉塞** | **右側胸部誘導（$V_3R \sim V_5R$）を追加記録**<br/>（ニトロ・利尿薬は禁忌・急速輸液） |
| **⑥ CLBBB / ペーシング下の梗塞** | 完全左脚ブロックや右室ペーシング波形下に急性虚血が合併した状態（下記Sgarbossa基準） | 急性冠閉塞 | **改訂Sgarbossa基準**で即座に判定 |

## 2. 完全左脚ブロック（CLBBB）時のSTEMI診断（Smith改訂Sgarbossa基準）

左脚ブロックやペーシング心電図では通常、QRS主波と反対方向にST-Tが偏位（Secondary ST-T changes）するためSTEMIの判定が困難です。**改訂Sgarbossa基準（Modified Sgarbossa Criteria）** を用いて診断します。

```mermaid
graph TD
    A["CLBBB または 心室ペーシング心電図"] --> B{"① QRSと同方向のST上昇 ≥ 1mm（一致性ST上昇）"}
    B -->|"Yes (特異度98%)"| STEMI["\"急性心筋梗塞 (STEMI") 確定"]
    B -->|"No"| C{"② V1-V3で QRSと同方向のST低下 ≥ 1mm（一致性ST低下）"}
    C -->|"Yes (特異度96%)"| STEMI
    C -->|"No"| D{"\"③ QRSと反対方向の過度なST上昇<br/>(ST上昇高 / S波の深さ ≥ 0.25: 改訂Smith基準")"}
    D -->|"Yes (感度・特異度約90%)"| STEMI
    D -->|"No"| NON["\"急性梗塞の確証なし (臨床症状・心エコーで総合判断")"]
```

## 3. 救急・当直で冷や汗をかくピットフォール

### ① 高カリウム血症の「偽装（カメレオン）」
- 高K血症は「テント状T波」だけでなく、**偽性STEMI（ST上昇）**、**偽性Brugada型波形**、**偽性左脚/右脚ブロック**、**正弦波（Sine wave）** などあらゆる異常波形を模倣します。
- **原則**: 透析患者や急性腎不全患者の徐脈・幅広QRSを見たら、心電図の細部を悩む前に**即座にグルコン酸カルシウム（カルチコール）静注を準備**する。

### ② 発熱によるBrugada波形の顕性化
- 通常時は正常またはsaddle-back型（Type 2/3）の患者が、**$38^\circ\text{C}$以上の発熱時に突如としてType 1 coved型ST上昇へ移行**し、心室細動（VF）を発症することがあります。
- **対応**: 発熱患者の心電図で右側胸部ST上昇を見たら、直ちに解熱薬投与とモニター監視を行う。

## 4. 健診・ドックでの要注意所見とトリアージ基準

| 健診所見 | 良性パターン（経過観察） | 要精査・循環器紹介パターン |
| :--- | :--- | :--- |
| **Brugada型波形** | Saddle-back型（Type 2/3）で無症状・家族歴なし | **Type 1（coved型）自然出現**、または失神歴・突然死家族歴あり |
| **QT延長** | 男性 QTc $\le 450\,\text{ms}$、女性 QTc $\le 460\,\text{ms}$ | **QTc $\ge 480 \sim 500\,\text{ms}$**、または家族歴・失神歴あり |
| **WPW症候群** | デルタ波のみで動悸発作歴なし（間欠性） | **動悸・頻拍発作歴あり**、または職業運転手・パイロット等 |
| **早期再分極（J波）** | 上向き凹の急峻なST上昇（Ascending ST） | **下壁誘導（II, III, aVF）で水平・下降型ST低下を伴うJ波**（悪性型ERS） |
| **左室高電位** | 単なる電位増高（若年者・やせ型）、ST-T正常 | **ストレイン型ST低下・陰性T波を伴う左室肥大** |

## 5. 当直・救急 携帯用チェックリスト

```text
【見落とし厳禁！当直・救急心電図チェックリスト】
□ 1. aVR誘導のSTは上昇していないか？（LMT主幹部 / de Winter）
□ 2. V2-V3のT波は二峰性または深い左右対称陰性Tではないか？（Wellens症候群）
□ 3. V1-V3のR波が高く、ST低下＋直立T波はないか？（後壁梗塞 ⇒ V7-V9記録）
□ 4. 下壁ST上昇時にV1のST上昇はないか？（右室梗塞 ⇒ V3R-V5R記録）
□ 5. QTc時間は500msを超えていないか？（TdP・致死的不整脈リスク）
□ 6. 幅広いQRSや徐脈を見たとき、高K血症を除外したか？（血液ガス・K測定）
□ 7. CLBBB患者の胸痛でSgarbossa基準（一致性ST変化）を満たしていないか？
```
