# 03 WPW症候群と副伝導路 (Kent束局在診断)

WPW症候群（Wolff-Parkinson-White Syndrome）は、心房と心室の間に先天的な副伝導路（**Kent束**）が存在し、房室結節の生理的遅延伝導を介さずに心室の一部が早期に脱分極（心室早期興奮: Pre-excitation）する症候群です。発作性上室性頻拍（AVRT）や、致死的な心房細動合併（**偽性VT / FBI頻拍**）の母地となります。

---

## 1. WPW症候群の電気生理と古典的三徴

```mermaid
graph TD
    SA["\"洞結節 (SA node")"] --> Atrium["心房脱分極"]
    
    Atrium --> AVN["\"房室結節 (生理的伝導遅延あり")"]
    Atrium --> Kent["\"副伝導路: Kent束 (伝導遅延なし・高速伝播")"]
    
    Kent --> PreEx["\"心室心筋の早期脱分極<br>⇒ ① 短PQ時間 (<0.12s")<br>"⇒ ② デルタ波 (立ち上がりのスロープ")"]
    AVN --> His["ヒス-プルキンエ系"]
    
    PreEx & His --> Fusion["\"心室融合収縮<br>⇒ ③ QRS幅拡大 (≥0.12s") ＋ 二次性ST-T変化"]
```

### WPW症候群の古典的三大徴候
| 徴候 | 計測基準値・所見 | メカニズム |
| :--- | :--- | :--- |
| **① 短PQ（PR）時間** | **$< 0.12$ 秒 (120 ms)** | 房室結節の遅延伝導をバイパスしてKent束を興奮が直通するため。 |
| **② デルタ波 (Delta wave)** | QRS波の立ち上がり（または立ち下がり）の**緩徐な初期スロープ** | プルキンエ線維を通らず、作業心筋間をゆっくり伝わる早期心室脱分極。 |
| **③ QRS幅の拡大** | **$\ge 0.12$ 秒 (120 ms)** ＋ 二次性ST-T変化 | 早期興奮心筋と正常伝導系心筋の「融合波（Fusion beat）」となるため。 |

## 2. 副伝導路（Kent束）の局在診断

心電図のデルタ波およびQRS波の極性から、心房・心室弁輪部におけるKent束の付着部位を推定します。

```mermaid
graph TD
    Loc["Kent束 局在診断フロー"]
    Loc --> V1_Check{"V1誘導のデルタ波・QRS極性"}
    
    V1_Check -->|陽性 (R波優位: 上向き)| LeftSide["\"【A型: 左側副伝導路 (Left-sided")】<br>"左室側壁・左室後壁など\""]
    V1_Check -->|陰性 (QS / rS: 下向き)| RightSide["\"【B型: 右側副伝導路 (Right-sided")】<br>"右室自由壁・右室前壁など\""]
    
    LeftSide & RightSide --> Inf_Check{"\"下壁誘導 (II, III, aVF") の極性"}
    Inf_Check -->|陽性 (+)| Anterior["\"前壁・前側壁起源 (刺激が上方から下方へ")"]
    Inf_Check -->|陰性 (-)| Posterior["\"後壁・後中隔起源 (刺激が下方から上方へ: 異常Q波様")"]
```

### 1. 古典的Rosenbaum分類（ローゼンバウム分類）
- **A型 (Type A)**:
  - **V1誘導で正（上向き）のデルタ波、高いR波（R/S > 1）**。
  - **局在**: **左心室側（左側自由壁・左側側壁）**。刺激が左室から右前方へ向かうためV1で陽性。
- **B型 (Type B)**:
  - **V1誘導で負（下向き）のデルタ波、深いQS波またはrS波**。
  - **局在**: **右心室側（右室自由壁・右側側壁）**。刺激が右室から左後方へ向かうためV1で陰性（左脚ブロック様波形）。
- **C型 (Type C)**:
  - V1で陽性、V5/V6で負のデルタ波（中隔〜前側壁）。

### 2. 近代的12誘導局在推定法（Arruda / Gallagher等の統合）

| 局在部位 | V1誘導 | II, III, aVF (下壁) | I, aVL (側壁) | 特徴とピットフォール |
| :--- | :---: | :---: | :---: | :--- |
| **左側自由壁 (Left Free Wall)** | **陽性 (+)** (高いR波) | **陽性 (+)** | **陰性 (-)** (aVLでq波) | 最も頻度が高い（約50%）。右室肥大と誤認注意。 |
| **右側自由壁 (Right Free Wall)** | **陰性 (-)** (QS/rS) | **陽性 (+)** | **陽性 (+)** | 左脚ブロック（CLBBB）と類似波形。 |
| **後中隔 (Posteroseptal)** | **陰性 (-)** または 二相性 | **著明な陰性 (-)** (QS波) | **陽性 (+)** | **下壁心筋梗塞（OMI）の異常Q波と酷似**（偽梗塞波形）。 |
| **前中隔 (Anteroseptal)** | **陰性 (-)** (QS波) | **高い陽性 (+)** | **陽性 (+)** | ヒス束に近接（アブレーション時AVブロックリスク）。 |

## 3. 潜在性WPW症候群（Concealed WPW）

- **定義**: Kent束が**「逆行性伝導（心室 $\rightarrow$ 心房）」のみ可能で、「順行性伝導（心房 $\rightarrow$ 心室）」ができない**病態。
- **心電図**: 洞調律時の心電図ではデルタ波や短PQ時間は**一切出現せず完全に正常**。
- **発症**: 順行性AVRT（Narrow QRS頻拍）の発作時のみ顕在化します。

---

## 4. 致死的不整脈：偽性VT（FBI頻拍: Fast, Broad, Irregular）

WPW症候群に心房細動（AF）が合併した病態を**「偽性心室頻拍（Pseudo-VT）」**または**「FBI頻拍（Fast, Broad, Irregular）」**と呼びます。

```mermaid
graph TD
    AF["\"心房細動 (AF") の発生<br>"(心房レート 350〜600 bpm")"] --> Bypass["\"房室結節の保護機能 (遅延伝導") を完全無視"]
    Bypass --> FastKent["不応期の極めて短い Kent束を介して<br>心室へ1:1に近い猛スピードで直通伝導"]
    
    FastKent --> FBI["\"🚨 【偽性VT (FBI頻拍")】<br>"・Fast: 心拍数 200〜300 bpm<br>・Broad: 幅広いQRS (デルタ波の最大化")<br>"・Irregular: RR間隔が完全に不規則\""]
    
    FBI --> VF["\"⚡ 心室細動 (VF") へ移行 ➔ 心突然死"]
```

### 偽性VTにおける禁忌薬と治療プロトコル
> [!CAUTION]
> **偽性VTにおける絶対禁忌薬（Fatal Contraindication）**
> - **禁忌薬**: **ジギタリス、ベラパミル（ワソラン）、ジルチアゼム（ヘルベッサー）、β遮断薬、アデノシン（ATP）**
> - **禁忌理由**: これらの薬剤は「房室結節伝導を強力に抑制」するため、心房からの興奮が**100% Kent束へと迂回・集中**し、心室拍数がさらに加速して**瞬時に心室細動（VF）を誘発**します。

```mermaid
flowchart TD
    Detect_FBI["\"偽性VT / FBI頻拍 (Wide QRS, Irregular, HR>200") の診断"] --> Instab{"\"血行動態不安定？<br>(意識消失, ショック, 血圧低下")"}
    
    Instab -->|Yes (不安定)| SyncDC["\"🚨 直ちに同期電気的除細動 (Cardioversion: 100〜200J")"]
    
    Instab -->|No (安定)| Drug["\"Naチャネル遮断薬 (Kent束の伝導を直接抑制")<br>"・プロカインアミド (アミサリン") 静注<br>"・ピルジカイニド (サンリズム") 静注"]
    
    SyncDC & Drug --> Ablation["\"治癒後: カテーテルアブレーション (Class I適応")"]
```

## 5. レポート記載例

### A型WPW症候群（左側副伝導路）
```text
【心電図所見】
洞調律 64bpm。
PR間隔 96ms (< 120ms: 短縮)、QRS幅 132ms。
全誘導において明瞭なデルタ波を認める。
V1誘導にて正のデルタ波および高い単相性R波 (R/S > 1.0) を認め、aVL誘導にて負のデルタ波を認める。

【診断】
WPW症候群 (A型 / 左側自由壁副伝導路)
【コメント】
心室早期興奮所見です。動悸発作の既往があればPSVT（AVRT）や偽性VT予防のため、カテーテルアブレーションの適応評価を推奨します。
```

### 偽性VT（超緊急）
```text
【心電図所見】
心拍数 平均 230bpm (最大 280bpm)。
著明に幅広く変形したQRS波 (Wide QRS) が、極めて不規則なRR間隔 (Irregular) で連続出現している。

【診断】
WPW症候群合併 心房細動 (偽性心室頻拍: Pseudo-VT / FBI頻拍)
【至急対応コメント】
🚨 極めて致死的な超緊急不整脈です。心室細動（VF）移行の危険が切迫しています。房室結節抑制薬（ジギタリス・ワソラン・β遮断薬・ATP）は絶対禁忌です。直ちに同期電気的除細動器を準備し、循環器緊急コールを行ってください。
```
