# 04 心房細動 (AF)・心房粗動 (AFL)・心房頻拍 (AT)

心房細動（AF）、心房粗動（AFL）、心房頻拍（AT）は、心房起源の代表的な3大頻脈性不整脈です。心電図波形（P波・F波・f波）、基線の性状（等電位線の有無）、およびRR間隔の規則性を分析することで確実に鑑別でき、それぞれ抗凝固療法やカテーテルアブレーションなどの治療方針が明確に定まっています。

## 2. 心房細動（Atrial Fibrillation: AF）

```mermaid
graph LR
    AF_Diag["\"心房細動 (AF") の診断三徴"]
    AF_Diag --> Sign1["① 洞性P波の消失"]
    AF_Diag --> Sign2["\"② 基線の微細な揺らぎ (f波: fibrillatory waves")"]
    AF_Diag --> Sign3["\"③ RR間隔の絶対的不整 (Absolute Arrhythmia")"]
```

### 臨床分類と治療戦略
- **発作性（Paroxysmal）**: 7日以内（通常48時間以内）に自然停止。
- **持続性（Persistent）**: 7日を超えて持続。
- **長期持続性（Long-standing Persistent）**: 1年以上持続し、リズム回復治療を考慮。
- **永続性（Permanent）**: リズム正常化を断念し、レートコントロールのみを行う。

> [!IMPORTANT]
> **心房細動管理の2大ピラー**
> 1. **心原性脳塞栓症の予防（抗凝固療法）**:
>    - **CHADS2 スコア**（心不全1点、高血圧1点、75歳以上1点、糖尿病1点、脳梗塞/TIA既往2点）
>    - **CHA2DS2-VASc スコア**
>    - 1点以上（特に2点以上）で **DOAC（直接経口抗凝固薬）** またはワーファリンを導入。
> 2. **カテーテルアブレーション（肺静脈隔離術: PVI）**:
>    - 発作性・持続性AFに対する標準的根治治療（成功率70〜85%）。

## 3. 心房粗動（Atrial Flutter: AFL）

### 典型的心房粗動（Common / Typical AFL: 反時計回転 Counterclockwise）
- **リエントリー回路**: 右房の三尖弁輪周囲を、下大静脈-三尖弁輪峡部（**CTI: Cavo-Tricuspid Isthmus**）を通って反時計回りに旋回。
- **心電図特徴**:
  - 下壁誘導（II, III, aVF）で**明瞭な下向きの鋸歯状波（F波: Sawtooth wave）**。
  - V1誘導で**直立（上向き）のF波**。
  - 心房粗動レートは**約 300 bpm（250〜350 bpm）**。

```mermaid
graph TD
    AFL_Rate["\"典型的心房粗動 (F波レート 300 bpm") の房室伝導比"]
    
    AFL_Rate --> Cond2["\"【2:1 伝導】(最頻出")<br>"心室拍数: 150 bpm (規則的")<br>"※『心拍数150前後の規則的頻拍』を見たらまずAFLを疑う！\""]
    AFL_Rate --> Cond4["\"【4:1 伝導】<br>心室拍数: 75 bpm (規則的")"]
    AFL_Rate --> CondVar["\"【変動伝導 (Variable conduction")】<br>"3:1や4:1が混在し不規則なRR間隔を呈する\""]
    AFL_Rate --> Cond1["\"🚨 【1:1 伝導】(超緊急")<br>"心室拍数: 300 bpm ➔ 血行動態破綻\""]
```

> [!WARNING]
> **心拍数 150 bpm の規則的頻拍＝心房粗動（2:1伝導）を最優先で疑え！**
> 2:1伝導のAFLでは、2つあるF波のうち1つがちょうどQRS波やT波の頂部に隠れるため、一見すると「洞性頻脈」や「PSVT」に見えます。迷走神経刺激やATP投与で房室ブロックを一時的に誘導すると、隠れていた連続する鋸歯状F波が露わになり確定診断できます。

## 4. AF vs AFL vs AT 徹底鑑別比較表

| 鑑別項目 | 心房細動 (AF) | 心房粗動 (AFL: 典型的) | 心房頻拍 (AT) |
| :--- | :--- | :--- | :--- |
| **心房興奮レート** | **350〜600 bpm** | **250〜350 bpm**（典型 300） | **150〜250 bpm** |
| **心房波の形態** | 不規則・微小な **f波** | 規則的な **鋸歯状波 (F波)** | 一定形状の **異所性P'波** |
| **等電位線 (基線)** | なし（常に微細動） | **なし**（波が連続） | **あり（P'波間に平坦な基線）** |
| **下壁誘導 (II, III, aVF)** | 不規則な小刻み波 | **連続する下向き鋸歯状波** | 異所性焦点に応じたP'波 |
| **V1 誘導** | 微小f波（時に粗大f波） | **上向き直立F波** | P'波（通常直立または二相性） |
| **RR間隔の規則性** | **絶対的不整**（完全不規則） | **規則的**（2:1等）または周期的 | **規則的**（1:1または2:1等） |
| **根治治療** | 肺静脈隔離術 (PVI) | **CTIアブレーション (成功率>95%)** | 異所性焦点・回路アブレーション |

## 5. レポート記載例

### 典型的心房細動（AF）のレポート
```text
【心電図所見】
心拍数 平均 112bpm (88〜142bpm)、RR間隔は絶対的不整。
全誘導において洞性P波は消失し、基線に微小で不規則な心房細動波 (f波) を認める。
明らかなST上昇や虚血性変化なし。

【診断】
頻脈性心房細動 (Atrial Fibrillation: AF with rapid ventricular response)
【推奨コメント】
脳梗塞リスク評価（CHADS2スコア算出）に基づく抗凝固療法（DOAC）の導入、および心不全合併予防のためのレートコントロール（β遮断薬等）をご検討ください。
```

### 典型的心房粗動（AFL: 2:1伝導）のレポート
```text
【心電図所見】
心室拍数 150bpm、規則的な Narrow QRS 頻拍。
下壁誘導（II, III, aVF）においてレート 300bpm の連続する陰性鋸歯状波 (F波: Sawtooth wave) を認め、2:1の房室伝導比を呈している。V1誘導では上向きのF波を認める。

【診断】
典型的心房粗動 (Typical Atrial Flutter: AFL / 2:1房室伝導)
【コメント】
三尖弁輪峡部（CTI）依存性の大リエントリー性頻拍です。カテーテルアブレーション（CTI焼灼術）により極めて高い確率（>95%）で根治が可能です。
```
