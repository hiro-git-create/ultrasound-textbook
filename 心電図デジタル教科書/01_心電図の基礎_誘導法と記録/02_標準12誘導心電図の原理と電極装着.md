# 02 標準12誘導心電図の原理と電極装着

標準12誘導心電図は、心臓の電気的活動を空間的に立体観察するため、**前額面（Frontal plane）6誘導**と**水平面（Horizontal plane）6誘導**の合計12方向から記録する臨床検査の基本です。各誘導の幾何学的原理と正確な解剖学的装着部位を熟知することは、誤診を防ぎ微細な虚血・伝導異常を捉えるための必須要件です。

---

## 1. 12誘導の空間的分類と観察領域

```mermaid
graph TD
    ECG12["標準12誘導心電図"] --> Frontal["\"前額面誘導 (四肢誘導 6誘導")<br>"心臓を上下・左右から観察\""]
    ECG12 --> Horizontal["\"水平面誘導 (胸部誘導 6誘導")<br>"心臓を輪切り・前後左右から観察\""]
    
    Frontal --> Bipolar["\"双極肢誘導 (アイントーベン")<br>"I, II, III 誘導\""]
    Frontal --> UnipolarLimb["\"増幅単極肢誘導 (ゴールドバーガー")<br>"aVR, aVL, aVF 誘導\""]
    
    Horizontal --> Precordial["\"単極胸部誘導 (ウィルソン")<br>"V1, V2, V3, V4, V5, V6 誘導\""]
```

| 誘導群 | 構成誘導 | 観察する心臓の壁・領域 | 主な灌流冠動脈 |
| :--- | :--- | :--- | :--- |
| **側壁誘導 (高位)** | I, aVL | 左室高位側壁 (High lateral wall) | 左回旋枝 (LCx) / LAD対角枝 (Diag) |
| **下壁誘導** | II, III, aVF | 左室下壁 (Inferior wall / 房室結節) | 右冠動脈 (RCA 約85%) / LCx (約15%) |
| **前額面右上方** | aVR | 左室腔内・心基底部・右房 | 主幹部 (LMT) / LAD近位部 (Reciprocal) |
| **中隔誘導** | V1, V2 | 心室中隔 (Septal wall / 右室前壁) | 左前下行枝中隔枝 (LAD septal) |
| **前壁誘導** | V3, V4 | 左室前壁 (Anterior wall) | 左前下行枝 (LAD) |
| **側壁誘導 (低位)** | V5, V6 | 左室側壁〜心尖部 (Lateral / Apical) | 左前下行枝 (LAD) / 左回旋枝 (LCx) |

## 2. 前額面誘導の原理（アイントーベンとゴールドバーガー）

### (1) 双極肢誘導（Bipolar limb leads: I, II, III）
Willem Einthoven（1901年）により考案された誘導法で、2点間の電位差を記録します。

```mermaid
graph TD
    RA["\"右手 (RA")<br>"Red\""] ---|"I 誘導 (0°)"| LA["\"左手 (LA")<br>"Yellow\""]
    RA ---|"II 誘導 (+60°)"| LL["\"左足 (LL")<br>"Green\""]
    LA ---|"III 誘導 (+120°)"| LL
    RL["\"右足 (RL: Black")<br>"接地電極 (Earth/Ground")"]
```

- **I 誘導 ($0^\circ$)**: $\text{電位} = V_{\text{LA}} - V_{\text{RA}}$（左手プラス、右手マイナス）
- **II 誘導 ($+60^\circ$)**: $\text{電位} = V_{\text{LL}} - V_{\text{RA}}$（左足プラス、右手マイナス）
- **III 誘導 ($+120^\circ$)**: $\text{電位} = V_{\text{LL}} - V_{\text{LA}}$（左足プラス、左手マイナス）

> [!NOTE]
> **アイントーベンの法則（Einthoven's Law）**
> 任意の瞬間において、以下の等式が数学的に常に成立します。
> $$\text{I 誘導} + \text{III 誘導} = \text{II 誘導}$$
> $$(V_{\text{LA}} - V_{\text{RA}}) + (V_{\text{LL}} - V_{\text{LA}}) = V_{\text{LL}} - V_{\text{RA}} = \text{II 誘導}$$
> この法則は四肢電極の付け間違い検出や波形整合性チェック（[[03_四肢電極の付け間違いパターンと見分け方]]）の基本原理となります。

### (2) 増幅単極肢誘導（Augmented unipolar limb leads: aVR, aVL, aVF）
Emanuel Goldberger（1942年）により考案されました。関電極以外の2つの電極を接続して基準電極（結合基準点）とすることで、電位の振幅を $1.5$ 倍（Augmented: a）に増幅して記録します。

- **aVR 誘導 ($-150^\circ$)**: 右手電極（RA）を探査電極とし、左手（LA）と左足（LL）の平均電位を不関電極とする。
  $$aVR = V_{\text{RA}} - \frac{V_{\text{LA}} + V_{\text{LL}}}{2}$$
- **aVL 誘導 ($-30^\circ$)**: 左手電極（LA）を探査電極とし、右手（RA）と左足（LL）の平均電位を不関電極とする。
  $$aVL = V_{\text{LA}} - \frac{V_{\text{RA}} + V_{\text{LL}}}{2}$$
- **aVF 誘導 ($+90^\circ$)**: 左足電極（LL）を探査電極とし、右手（RA）と左手（LA）の平均電位を不関電極とする。
  $$aVF = V_{\text{LL}} - \frac{V_{\text{RA}} + V_{\text{LA}}}{2}$$

## 3. 水平面胸部誘導の原理と解剖学的電極配置

Norman Wilson（1934年）が考案した**ウィルソンの結合電極（Wilson's Central Terminal: WCT）**は、四肢3点（RA, LA, LL）を高抵抗（各 $5\text{ k}\Omega$）で結んで中心電位 $V_W = \frac{V_{\text{RA}} + V_{\text{LA}} + V_{\text{LL}}}{3} \approx 0\text{ mV}$ を作り、胸壁上に置いた探査電極（V1〜V6）との電位差を単極記録します。

### (1) 標準胸部誘導（V1〜V6）の装着部位一覧表

```mermaid
graph LR
    V1["\"V1: 第4肋間 胸骨右縁 (赤")"] --> V2["\"V2: 第4肋間 胸骨左縁 (黄")"]
    V2 --> V4["\"V4: 第5肋間 鎖骨中線上 (茶")"]
    V2 -.->|"V2とV4の中間"| V3["\"V3: 第5肋骨上 (緑")"]
    V4 --> V5["\"V5: 第5肋間 前腋窩線上 (黒")"]
    V5 --> V6["\"V6: 第5肋間 中腋窩線上 (紫")"]
```

| 誘導 | 電極カラー | 解剖学的装着位置 | 触診・同定のポイント |
| :--- | :--- | :--- | :--- |
| **V1** | 🔴 赤 (Red) | **第4肋間 胸骨右縁** | 胸骨角（ルイス角: Angle of Louis）の真横が第2肋骨。その直下が第2肋間。順に第3、第4肋間を触知。 |
| **V2** | 🟡 黄 (Yellow) | **第4肋間 胸骨左縁** | V1と左右対称の胸骨左縁に配置。 |
| **V3** | 🟢 緑 (Green) | **V2とV4を結ぶ直線の中点** | **必ず先にV4の位置を確定させてから**、V2-V4間に貼付する。 |
| **V4** | 🟤 茶 (Brown) | **第5肋間 左鎖骨中線上** | 鎖骨中央から下ろした垂線と第5肋間の交点。乳頭位置は個体差が大きいため目印にしない。 |
| **V5** | ⚫ 黒 (Black) | **第5肋間 左前腋窩線上** | V4と同じ水平面上（第5肋間の高さ）で、左前腋窩線との交点。 |
| **V6** | 🟣 紫 (Purple) | **第5肋間 左中腋窩線上** | V4・V5と同じ水平面上で、腋窩中央から下ろした左中腋窩線との交点。 |

> [!TIP]
> **胸部電極カラーの覚え方（語呂合わせ）**
> 「**せき・とう・りょく・ちゃ・こく・し**（赤・黄・緑・茶・黒・紫）」または「**赤黄み茶く紫**（あか・き・みどり・ちゃ・くろ・むらさき）」で覚えるのが臨床・国家試験の定番です。

## 4. 特殊誘導（右側胸部誘導・背部誘導・高位肋間誘導）

標準12誘導のみでは観察が困難な「右室」「左室後壁」「Brugada型心電図」を評価するために、追加誘導が用いられます。

```mermaid
graph TD
    SpecialLeads["特殊誘導法"]
    SpecialLeads --> Right["\"右側胸部誘導 (V3R, V4R, V5R")<br>"適応: 下壁STEMI合併の右室梗塞疑い\""]
    SpecialLeads --> Posterior["\"背部誘導 (V7, V8, V9")<br>"適応: V1-V3鏡面像(ST低下")時の真の後壁梗塞"]
    SpecialLeads --> HighIntercostal["\"高位肋間誘導 (第2/第3肋間 V1-V3")<br>"適応: Brugada症候群(Type 1 coved型")の検出"]
```

### (1) 右側胸部誘導（V3R, V4R, V5R）
- **配置**: 標準胸部誘導のV3〜V5と胸骨を挟んで左右線対称の右胸壁位置に装着（特に **V4R: 第5肋間右鎖骨中線** が最重要）。
- **臨床的意義**: 下壁心筋梗塞（II, III, aVFでST上昇）を認めた場合、約30〜50%に右室梗塞が合併します。**V4Rで $\ge 0.5\text{ mm} (0.05\text{ mV})$ のST上昇**があれば右室梗塞と診断できます（硝酸薬や利尿薬の投与が禁忌となるため救急で極めて重要）。

### (2) 背部誘導（V7, V8, V9）
- **配置**: V4〜V6と同じ第5肋間の水平面上で背部に延長装着。
  - **V7**: 左後腋窩線上
  - **V8**: 左肩甲骨線（肩甲骨下角を通る垂線）上
  - **V9**: 左脊柱傍線上
- **臨床的意義**: 左室後壁心筋梗塞（Posterior MI）では、標準誘導のV1〜V3で「mirror image（鏡面像）」として水平型ST低下・高いR波・直立高T波が現れます。**V7〜V9で $\ge 0.5\text{ mm}$ のST上昇**を確認することで後壁梗塞を確定診断します。

### (3) 高位肋間誘導（第2・第3肋間）
- **配置**: V1, V2, V3の電極を第4肋間から「第3肋間」または「第2肋間」に1〜2肋間引き上げて記録。
- **臨床的意義**: Brugada症候群における右室流出路（RVOT）由来の心電図変化は上方に偏在するため、高位肋間誘導によりType 1（coved型 $\ge 2\text{ mm}$ ST上昇）の顕在化率が大幅に向上します。

## 5. 心電図記録の標準規格と機器設定

| パラメータ | 標準規格 | 変更時の注意点・臨床的理由 |
| :--- | :--- | :--- |
| **紙送り速度** | **25 mm/s** | 小マス1mm = **0.04 秒 (40 ms)**、大マス5mm = **0.20 秒 (200 ms)**。<br>※頻拍時のP波同定目的で 50 mm/s に増速する場合あり（時間軸が2倍）。 |
| **電圧感度** | **10 mm / 1 mV** | 1小マス1mm = **0.1 mV**、大マス5mm = **0.5 mV**。<br>※左室肥大で波形が重なる場合は 1/2感度（5mm/1mV）、低電位精査時は 2倍感度（20mm/1mV）に調整。校正波（キャリブレーション矩形波）で確認必須。 |
| **周波数特性 (帯域)** | **0.05 Hz 〜 150 Hz** | 国際基準（AHA/ACC/HRS）。診断用基準。 |
| **筋電図フィルタ** | **OFF / 35 Hz / 20 Hz** | 筋電図ノイズ混入時にONにするが、**QRS波高が低下しST-T変化が平坦化・減衰する**ため、診断確定時は可能な限りフィルタを弱める。 |
| **基線動揺フィルタ** | **0.5 Hz / 0.05 Hz** | 呼吸性基線動揺を除去。0.5HzフィルタはST偏位を修飾する可能性があるため注意。 |

## 6. 電極装着の実務テクニックとエラー回避

1. **皮膚前処理（Skin Preparation）**:
   - 角質層・皮脂・汗は接触抵抗（インピーダンス）を跳ね上げ、基線動揺や交流障害（ハムノイズ）の原因となります。
   - アルコール綿または電極用ペースト（スキナペースト等）で軽く摩擦清拭し、十分に乾燥させてから装着します。
2. **女性患者・乳房の取り扱い**:
   - 巨大乳房の患者では、乳房の上に電極を貼ると電極間距離が心臓から離れ低電位や波形歪みを生じます。
   - **「乳房を持ち上げて乳房下縁の胸壁（第5肋間）」**に正確に貼付します。
3. **肢電極の貼付部位**:
   - 四肢末端（手首・足首の内側）が基本ですが、体動や振戦が激しい場合は前腕・上腕、下腿・大腿など近位部に移動可能です。ただし左右対称の位置に貼付します。
