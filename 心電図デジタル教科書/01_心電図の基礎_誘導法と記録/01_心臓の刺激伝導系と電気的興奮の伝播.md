# 01 心臓の刺激伝導系と電気的興奮の伝播

心電図（Electrocardiogram: ECG）の波形は、心臓を構成する特殊心筋（刺激伝導系）および固有心筋の個々の細胞活動電位が時間的・空間的に統合された結果として体表面に記録される電位差です。心電図の正しい判読には、興奮がどの順序で伝播し、どのようなイオン電流によって電位差が生じるのかという「電気生理学的機序」の完全な理解が不可欠です。

---

## 1. 刺激伝導系の解剖学的構造と自動能階層

心臓の刺激伝導系は、自律的に電気インパルスを発生させる「ペースメーカ細胞」と、発生した興奮を心室全体へ高速かつ秩序立てて伝える「高速伝導線維」から構成されています。

```mermaid
graph TD
    SAN["\"洞結節 (SA node")<br>"主ペースメーカ: 60〜100 bpm\""] --> Pathways["\"結節間伝導路 / Bachmann束<br>(右房・左房への伝播")"]
    Pathways --> AVN["\"房室結節 (AV node")<br>"生理的伝導遅延 (0.05〜0.10s")<br>"潜在ペースメーカ: 40〜60 bpm\""]
    AVN --> His["\"ヒス束 (Bundle of His")"]
    His --> Branches["\"脚分枝 (Bundle Branches")"]
    Branches --> RBB["\"右脚 (Right Bundle Branch")"]
    Branches --> LBB["\"左脚 (Left Bundle Branch")"]
    LBB --> LAF["\"左脚前枝 (Left Anterior Fascicle")"]
    LBB --> LPF["\"左脚後枝 (Left Posterior Fascicle")"]
    RBB --> Purkinje["\"プルキンエ線維網 (Purkinje fibers")<br>"伝導速度: 2.0〜4.0 m/s<br>潜在ペースメーカ: 20〜40 bpm\""]
    LAF --> Purkinje
    LPF --> Purkinje
    Purkinje --> Myocardium["\"心室作業心筋 (Ventricular Myocardium")<br>"心内膜側 ➔ 心外膜側へ興奮\""]
```

### (1) 自動能の階層（Overdrive Suppression: オーバードライブ抑制）
健常心では最も固有発火頻度の高い**洞結節（SAN: 60〜100回/分）**が心臓全体の調律を支配します。下位のペースメーカ部位（房室結節: 40〜60回/分、プルキンエ線維・心室固有調律: 20〜40回/分）は、洞結節からの高頻度刺激によって過分極され、自発興奮が抑制されています（オーバードライブ抑制）。洞結節機能不全や伝導ブロックが生じると、下位中枢が自発脱分極を開始し「補充調律（Escape rhythm）」として心停止を回避します。

### (2) 刺激伝導系各部位の生理学的特性対照表

| 部位 | 主な解剖的位置 | 伝導速度 (m/s) | 固有自動能 (bpm) | 主要イオンチャネル・特徴 |
| :--- | :--- | :--- | :--- | :--- |
| **洞結節 (SAN)** | 上大静脈と右心房の接合部外側 | 0.05 | 60〜100 | $I_f$ (HCNチャネル/Funny電流), $I_{\text{Ca,L}}$, $I_{\text{Ca,T}}$（緩徐脱分極） |
| **心房作業心筋** | 右房壁・左房壁・Bachmann束 | 0.8〜1.0 | なし (通常) | $I_{\text{Na}}$（急速立ち上がり）, $I_{\text{Kur}}$, $I_{\text{to}}$ |
| **房室結節 (AVN)** | コッホの三角（Koch's triangle）頂点 | **0.02〜0.05 (最遅)** | 40〜60 | $I_{\text{Ca,L}}$ 主体、不応期が長く生理的ブロック機構を担う |
| **ヒス束 (His)** | 線維性房室中隔を貫通 | 1.5〜2.0 | 40〜50 | $I_{\text{Na}}$、狭小な線維束のため小病変で完全房室ブロック |
| **右脚・左脚** | 心室中隔両側膜様部〜筋性部 | 2.0〜3.0 | 30〜40 | $I_{\text{Na}}$、左脚は前枝・後枝に早期分岐 |
| **プルキンエ線維** | 心室心内膜下網目状構造 | **2.0〜4.0 (最速)** | 20〜40 | $I_{\text{Na}}$、太い細胞径と高密度のGap junction（コネキシン40/43） |
| **心室作業心筋** | 心室自由壁・心尖部・心基底部 | 0.4〜0.9 | なし (通常) | $I_{\text{Na}}$, $I_{\text{Ca,L}}$, $I_{\text{Kr}}$, $I_{\text{Ks}}$, $I_{\text{K1}}$（安定した静止膜電位） |

## 2. 心筋細胞活動電位と体表面心電図の対比

心筋細胞は、活動電位の形態と立ち上がり機序から「**緩徐応答型（Slow response）**」と「**急速応答型（Fast response）**」の2群に大別されます。

```mermaid
graph LR
    subgraph ActionPotential["心室筋活動電位 (Fast Response)"]
        P0["\"Phase 0: 急速脱分極<br>(Na+流入")"] --> P1["\"Phase 1: 初期一過性再分極<br>(Ito K+流出")"]
        P1 --> P2["\"Phase 2: プラトー相<br>(Ca2+流入 vs K+流出")"]
        P2 --> P3["\"Phase 3: 急速再分極<br>(IKr/IKs K+流出")"]
        P3 --> P4["\"Phase 4: 静止膜電位<br>(IK1内向き整流")"]
    end
    subgraph ECGWave["体表面心電図対応"]
        P0 -.-> QRS["\"QRS群 (心室脱分極")"]
        P2 -.-> ST["\"ST部分 (等電位線")"]
        P3 -.-> T["\"T波 (心室再分極")"]
        P4 -.-> TP["\"TP部分 (等電位基線")"]
    end
```

### (1) 急速応答細胞（心室筋・心房筋・プルキンエ線維）の5相
1. **Phase 0（急速脱分極相）**: 電位依存性速い $\text{Na}^+$ チャネルが開き、細胞内へ $\text{Na}^+$ が急激に流入。膜電位は約 $-90\text{ mV}$ から $+20 \sim +30\text{ mV}$ へ逆転（オーバーシュート）。心電図上は **QRS群** に対応。
2. **Phase 1（初期一過性再分極相）**: $\text{Na}^+$ チャネルが急速に不活性化し、一過性外向き $\text{K}^+$ 電流（$I_{\text{to}}$）により電位がわずかに低下。
3. **Phase 2（プラトー相）**: L型 $\text{Ca}^{2+}$ チャネル（$I_{\text{Ca,L}}$）からの持続的 $\text{Ca}^{2+}$ 流入と、遅延整流 $\text{K}^+$ チャネル（$I_{\text{Ks}}, I_{\text{Kr}}$）からの $\text{K}^+$ 流出が電気的に拮抗。全心室筋の電位差がほぼゼロとなるため、心電図上は **ST部分（等電位線）** を形成。
4. **Phase 3（急速再分極相）**: $\text{Ca}^{2+}$ チャネルが閉じ、急速遅延整流 $\text{K}^+$ 電流（$I_{\text{Kr}}$）および緩徐遅延整流 $\text{K}^+$ 電流（$I_{\text{Ks}}$）が優位となって $\text{K}^+$ が大量流出。膜電位が急速に静止膜電位へ復帰。心電図上は **T波** に対応。
5. **Phase 4（静止膜電位相）**: 内向き整流 $\text{K}^+$ 電流（$I_{\text{K1}}$）と $\text{Na}^+/\text{K}^+$ ATPase ポンプにより約 $-90\text{ mV}$ を維持。心電図上は **TP部分**。

### (2) 緩徐応答細胞（洞結節・房室結節）
- 静止膜電位が浅く（$-55 \sim -65\text{ mV}$）、速い $\text{Na}^+$ チャネルは恒常的に不活性化状態。
- **Phase 4 自発脱分極**: 過分極応答性陽イオンチャネル（HCNチャネル）による Funny電流（$I_{\text{f}}$）と T型 $\text{Ca}^{2+}$ 電流（$I_{\text{Ca,T}}$）により、閾値電位（約 $-40\text{ mV}$）まで緩徐に自発脱分極。
- **Phase 0 脱分極**: L型 $\text{Ca}^{2+}$ 電流（$I_{\text{Ca,L}}$）により緩徐に立ち上がる（伝導速度が遅い理由）。

> [!NOTE]
> **房室結節における生理的伝導遅延の重要性**
> 房室結節の伝導速度は $0.02 \sim 0.05\text{ m/s}$ と心筋内で最も遅延します。この約 $0.05 \sim 0.10$ 秒の伝導遅延により、心室収縮が始まる前に「心房収縮による心室への血液充満（Atrial kick）」が完全に完了します。また、心房細動や粗動などの高頻度上室性不整脈が発生した際、房室結節の長い不応期がフィルターとして働き、致死的な心室頻拍への移行を防いでいます。

## 3. 電気的興奮伝播の時系列シーケンスとベクトル

```mermaid
sequenceDiagram
    autonumber
    participant SAN as 洞結節
    participant Atria as 心房筋 (RA/LA)
    participant AVN as 房室結節
    participant His as ヒス束
    participant Septum as 心室中隔 (左室側)
    participant Ventricles as 心室自由壁 (内膜→外膜)
    participant Base as 心室基底部

    SAN->">Atria: ① 洞結節自発興奮 (体表面ECGには平坦")
    Atria-->">AVN: ② 心房脱分極 (P波形成: 右房→左房")
    AVN->">His: ③ 房室遅延伝導 (PRセグメント")
    His->">Septum: ④ 心室中隔初期脱分極 (中隔q波 / 初期r波")
    Septum->">Ventricles: ⑤ 心室主部脱分極 (主R波 / 深いS波")
    Ventricles->">Base: ⑥ 心室基底部終末脱分極 (終末s波 / r'波")
    Ventricles-->">Ventricles: ⑦ 心室再分極 (外膜側から先行→T波形成")
```

### (1) 心房脱分極とP波
- **右心房脱分極（前半）**: 洞結節から下方・前方へ進行。
- **左心房脱分極（後半）**: Bachmann束を経由して左後下方へ進行。
- **統合ベクトル**: 右後上方から左前下方（およそ $+60^\circ$）を向き、II誘導で明瞭な陽性波、V1誘導では前半陽性・後半陰性の二相性（Biphasic）P波を形成。

### (2) 心室脱分極の3相とQRS群
1. **初期中隔脱分極（0.01〜0.02秒）**:
   - 左脚から心室中隔の左室側へ先行して伝わり、**中隔を左から右へ、かつ前方へ**興奮。
   - 左側誘導（I, aVL, V5, V6）では遠ざかるため「微小な中隔q波」、右側誘導（V1, V2）では向かってくるため「初期小r波」となる。
2. **心室主部脱分極（0.02〜0.06秒）**:
   - プルキンエ線維を介して**心内膜側から心外膜側へ**向かって興奮。
   - 左室筋量は右室筋量の約3倍あるため、電気ベクトルは**左後下方**へ圧倒的に傾く。
   - V5, V6誘導で「高いR波」、V1, V2誘導で「深いS波」を形成。
3. **心室基底部終末脱分極（0.06〜0.08秒）**:
   - 心室中隔基底部および右室流出路（RVOT）が最後に脱分極。ベクトルは**上後方**を向く（終末部s波）。

### (3) 心室再分極のパラドックスとT波の極性
物理学的には「脱分極が向かってくると陽性波」「再分極が向かってくると陰性波」となります。しかし正常心電図では、QRS主波が陽性の誘導（I, II, V5, V6など）において **T波も同方向の陽性波** となります。

> [!IMPORTANT]
> **なぜT波はQRSと同じ陽性方向になるのか？**
> 心室の脱分極は「心内膜側 $\rightarrow$ 心外膜側」へ進みますが、心室の再分極は**「心外膜側 $\rightarrow$ 心内膜側」へと逆方向**に進みます。
> これは、心内膜側が高圧迫下にあって活動電位持続時間（APD: Action Potential Duration）が長いのに対し、心外膜側はAPDが短いためです。
> 「マイナスの電位（再分極）が観測電極から遠ざかる（外膜から内膜へ向かう）」ため、電極側では**プラス（陽性）の電位変化**として記録され、QRSとT波の向きが一致します（これを **Concordant T波** と呼びます）。

## 4. 臨床・心電図検定での要点チェック

1. **洞結節の血液供給**: 洞結節動脈は右冠動脈（RCA）から約60%、左回旋枝（LCx）から約40%分岐します。下壁心筋梗塞（RCA閉塞）時に洞徐脈や洞停止が高頻度に生じる理由です。
2. **房室結節の血液供給**: 房室結節動脈は右冠動脈（RCA）から約90%（右優位結節）、LCxから約10%分岐します。
3. **ヒス束・脚系の脆弱性**: 左脚前枝は薄く長く単一血流（LAD中隔枝）支配のためブロックを起こしやすい（[[03_左脚前枝ブロック_LAFB_と左脚後枝ブロック_LPFB]] 参照）。一方、左脚後枝は太く扇状で二重血流支配（LAD中隔枝 + RCA/LCx後下行枝）のため単独ブロックは稀です。
4. **変行伝導（Aberrant Conduction）**: 上室期外収縮（PAC）などが早期に入力した際、右脚の不応期が左脚より生理的に長いため、一時的に右脚ブロック波形（rsR' pattern）を呈して伝導します（[[01_上室期外収縮_PAC_と変行伝導]] 参照）。
