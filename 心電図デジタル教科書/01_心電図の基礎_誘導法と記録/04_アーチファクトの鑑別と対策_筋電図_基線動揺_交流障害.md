# 04 アーチファクトの鑑別と対策 筋電図・基線動揺・交流障害

心電図におけるアーチファクト（Artifact: 雑音・人工的歪み）は、心臓本来の電気現象以外の要因によって波形が乱れる現象です。アーチファクトを「心室頻拍（VT）」「心室細動（VF）」「心房細動（AF）」「心筋梗塞（ST上昇）」などの致死的不整脈・緊急疾患と誤認すると、不必要な電気的除細動、胸骨圧迫、抗不整脈薬投与、緊急カテーテル検査といった重大な医療事故に直結します。

---

## 1. アーチファクトの4大分類と特徴対照表

```mermaid
graph TD
    Artifact["心電図アーチファクトの分類"]
    Artifact --> EMG["\"① 筋電図ノイズ (EMG Noise")<br>"不規則な高周波棘波 (20〜200Hz")<br>"原因: 寒冷, 筋緊張, 振戦\""]
    Artifact --> BW["\"② 呼吸性基線動揺 (Baseline Wander")<br>"緩やかな低周波うねり (0.1〜0.5Hz")<br>"原因: 呼吸, 発汗, 体動\""]
    Artifact --> AC["\"③ 交流障害 (Hum Noise")<br>"規則的微細正弦波 (50/60Hz")<br>"原因: 商用電源, アース不良\""]
    Artifact --> Mech["④ 接触不良・機械的ノイズ<br>急激な基線跳躍・偽スパイク<br>原因: 電極乾燥, 牽引, 摩耗"]
```

| アーチファクト種類 | 周波数帯域 | 波形の特徴 | 主な原因 | 即座に取るべき対策 |
| :--- | :--- | :--- | :--- | :--- |
| **① 筋電図ノイズ** | **高周波**<br>(20〜200 Hz) | 不規則で鋭い微小なトゲ状（Spike）波形が基線上に重畳。 | ・患者の緊張・力み<br>・寒冷によるシバリング<br>・パーキンソン病等の振戦 | ・声かけでリラックス・脱力<br>・室温調整・毛布で保温<br>・肢電極を四肢近位部へ装着<br>・筋電図フィルタON |
| **② 呼吸性基線動揺** | **超低周波**<br>(0.1〜0.5 Hz) | 等電位基線が呼吸周期に合わせて上下に大きくうねる。 | ・過換気・努力呼吸<br>・多量の発汗<br>・電極の密着不良 | ・呼気位での一時的息止め<br>・皮膚の汗を拭き取り清拭<br>・基線動揺フィルタON |
| **③ 交流障害 (ハム)** | **商用単一**<br>(50/60 Hz) | 規則正しく均一な幅の微細な波（黒く塗りつぶされた帯状）。 | ・電源コードの交差<br>・ベッドの金属部接触<br>・接地（アース）不良<br>・近隣医療機器（輸液ポンプ等） | ・交流フィルタ（Hum filter）ON<br>・電源コードと患者コードを離す<br>・ベッド金属フレームから離す<br>・アース線の確実な接地 |
| **④ 接触不良・脱落** | **不規則・突発** | 基線の急激な垂直方向への跳躍、電位の完全消失（直線化）。 | ・電極ペースト・ゲルの乾燥<br>・コードの引っ張り・断線<br>・皮膚角質の皮脂汚れ | ・スキナペーストで前処理<br>・新しい電極への貼り替え<br>・コードクリップで固定 |

## 2. 救急・当直で最も危険な「偽性不整脈（Pseudo-arrhythmias）」の見抜き方

### (1) 偽性心室頻拍（Pseudo-VT）/ 偽性心室細動（Pseudo-VF）
患者が歯磨きをしている時、体動時、またはパーキンソン病・振戦発作時に、モニター上で一見「Wide QRS頻拍」や「粗大VF」に酷似した波形が出現します。

```mermaid
graph LR
    subgraph Danger["誤認リスク"]
        Shock["誤った除細動・胸骨圧迫・挿管"]
    end
    subgraph Differentiation["真偽の鑑別ポイント"]
        Sign1["\"① 意識・脈拍・血圧の確認 (無脈なら真のVF/VT")"]
        Sign2["\"② ノイズの谷間に隠れた『等間隔のQRSスパイク』を探す (Marching P/QRS")"]
        Sign3["③ 四肢誘導と胸部誘導でノイズ強度に極端な乖離がないか確認"]
    end
    Differentiation --> Danger
```

> [!WARNING]
> **【偽性VT/VFの決定的見分け方】“Marching rhythm” を探せ**
> アーチファクトによる偽性VT/VFでは、激しいノイズの波形の中に、**本来の規則正しい正常QRS波の先端（R波スパイク）が一定のRR間隔で透けて見える**ことが多々あります。ディバイダーや紙の角を当てて等間隔のQRSが存在することを確認できれば、心臓は正常洞調律を保っています。

### (2) パーキンソン病振戦による偽性心房粗動（Tremor Flutter）
パーキンソン病の安静時振戦（4〜7Hz = 240〜420回/分）は、心房粗動（AFL）のF波（250〜350/分）の周波数と完全に一致します。

- **見分け方**:
  - 右手の振戦によるノイズの場合、**右手電極（RA）を含む誘導（I, II, aVR）にのみ激しい鋸歯状波**が出現し、右手を含まない **III誘導（LA-LL）や胸部誘導（V1〜V6）には全く鋸歯状波が出現しない（または軽微）**という誘導間の不一致が決定打となります。
  - 心房粗動（AFL）であれば、II, III, aVFおよびV1で全誘導的に明瞭なF波が観察されます。

## 3. 実践！ノイズフリー記録のための現場テクニック

### (1) 電極装着部位の移動（近位部装着法）
四肢の振戦や不随意運動が激しい患者では、電極を手首・足首から「**上腕・肩甲骨下部・大腿部**」などの体幹に近い近位部へ装着することで、筋電図ノイズを劇的に低減できます。

```mermaid
graph TD
    Wrist["\"手首・足首 (末端装着")<br>"⚠️ 振戦・体動ノイズ大\""] -->|"体幹近位部へ移動"| Proximal["\"上腕・鎖骨下・大腿部装着<br>✅ ノイズ大幅減衰 (波形は概ね同等")"]
```

> [!TIP]
> **電極移動時の注意点**
> 四肢誘導電極を体幹部へ近づけると、前額面QRS電気軸がわずかに変化（通常右軸方向へシフト）したりQRS電位が増加することがありますが、調律判定や不整脈診断には全く支障ありません。

### (2) フィルタ設定の適切な使い分け

| フィルタ名 | 設定値 | メリット | デメリット・注意点 |
| :--- | :--- | :--- | :--- |
| **筋電図フィルタ (EMG)** | **35 Hz / 20 Hz** | 高周波ノイズをカットし、調律やP波・QRSの計測を容易にする。 | **QRS波高が低下し、ノッチが消失**。微小なST上昇・ST低下が平坦化されるため、急性心筋梗塞（STEMI）の判定時はOFFにして原波形を確認する。 |
| **交流フィルタ (Hum)** | **50 Hz / 60 Hz** | 電源ノイズのみを鋭利に除去（ノッチフィルタ）。 | 心電図波形の歪みは極めて小さく、**常時ONで問題ない**。地域（東日本50Hz / 西日本60Hz）に正しく設定。 |
| **基線ドリフトフィルタ** | **0.5 Hz / 0.05 Hz** | 呼吸性変動を抑制し、波形が画面外に飛び出るのを防ぐ。 | **0.5Hz設定はST部分のレベルを歪める**危険性がある。国際学会推奨は 0.05Hz。 |
