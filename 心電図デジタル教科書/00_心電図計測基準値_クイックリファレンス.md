# 📊 心電図計測基準値 クイックリファレンス

標準12誘導心電図（記録速度 25mm/s、感度 10mm/1mV）における各波形・間隔・電気軸・電位の正常基準値および異常判定カットオフ値一覧です。

---

## 1. 時間・間隔の基準値（記録速度 25mm/s: 小マス1mm=0.04s, 大マス5mm=0.20s）

| 計測項目 | 正常範囲 (秒 / ms) | マス数換算 | 異常の判定基準 | 主な臨床的意義 |
| :--- | :--- | :--- | :--- | :--- |
| **心拍数 (HR)** | 50〜100 bpm | RR間隔 15〜30小マス | <50 bpm: 徐脈<br>>100 bpm: 頻脈 | 洞性徐脈、洞性頻脈、不整脈 |
| **P波 幅** | ≤0.11 s (≤110 ms) | <3小マス未満 | ≥0.12 s (≥120 ms) | 左房負荷 (僧帽性P波)、心房内伝導遅延 |
| **PQ (PR) 時間** | 0.12〜0.20 s (120〜200 ms) | 3〜5小マス | <0.12 s: 短縮<br>>0.20 s: 延長 | 短縮: WPW症候群、接合部調律<br>延長: 1度房室ブロック |
| **QRS幅** | 0.06〜0.10 s (60〜100 ms) | 1.5〜2.5小マス | ≥0.12 s (≥120 ms): 幅広<br>0.10〜0.11 s: 不完全脚ブロック | 完全脚ブロック(CRBBB/CLBBB)、心室調律、WPW |
| **VAT (心室興奮時間)** | 右側(V1): ≤0.03 s<br>左側(V5/V6): ≤0.05 s | V1: <1マス<br>V5/6: 1.25マス | V1 >0.03 s: 右室負荷/RBBB<br>V5/6 >0.05 s: 左室肥大/LBBB | 心室内興奮伝播の遅延指標 |
| **QT時間 (生値)** | 0.35〜0.44 s | 心拍数依存 | 計測は最大QT誘導(通常IIまたはV5) | 心室の脱分極〜再分極時間 |
| **QTc (Bazett補正)** | 男性: ≤450 ms<br>女性: ≤460 ms | - | >450ms(男) / >460ms(女): 延長<br>>500 ms: TdP超高リスク<br><340 ms: QT短縮 | 先天性/薬剤性LQTS、電解質異常(低K/Ca/Mg)、SQTS |

$$\text{QTc (Bazett)} = \frac{\text{QT (秒)}}{\sqrt{\text{RR (秒)}}}$$
$$\text{QTc (Fridericia)} = \frac{\text{QT (秒)}}{\sqrt[3]{\text{RR (秒)}}}$$

## 2. 電位・高さ・深さの基準値（感度 10mm/1mV: 1小マス=0.1mV, 1大マス=0.5mV）

| 項目 | 正常基準値 | 異常カットオフ値 | 臨床的意義 |
| :--- | :--- | :--- | :--- |
| **P波 電位 (高さ)** | ≤0.25 mV (2.5mm, II誘導) | >0.25 mV | 右房負荷 (肺性P波: II, III, aVF) |
| **Q波** | 幅 <0.04s, 深さ <R波の1/4 | 幅 ≥0.04s または 深さ ≥Rの1/4 (異常Q波) | 心筋梗塞 (壊死組織)、QSパターン |
| **Sokolow-Lyon (LVH)** | SV1 + RV5 (または RV6) < 3.5 mV | **≥ 3.5 mV (35mm)** | 左室肥大 (LVH) (特異度高) |
| **Cornell 電圧 (LVH)** | RaVL + SV3 | 男性: **≥ 2.8 mV (28mm)**<br>女性: **≥ 2.0 mV (20mm)** | 左室肥大 (LVH) (感度・特異度バランス良) |
| **Cornell 積** | QRS幅(ms) × Cornell電圧(mm) | **> 2440 mm·ms** | 左室肥大 (LVH) |
| **右室肥大 (RVH)** | V1 R/S比 ≤ 1.0, RV1 ≤ 0.7 mV | **RV1 > 0.7 mV または V1 R/S > 1.0**<br>(+ 右軸偏位 >+90°) | 右室肥大 (RVH)、肺高血圧症、肺性心 |
| **四肢低電位** | 四肢全誘導(I, II, III, aVR, aVL, aVF) | **全誘導で QRS高 < 0.5 mV (5mm)** | 心嚢液貯留、心アミロイドーシス、肺気腫、高度肥満 |
| **全誘導低電位** | 胸部全誘導(V1〜V6) | **全誘導で QRS高 < 1.0 mV (10mm)** | 上記 + 重症心筋症 |

| :--- | :--- | :--- | :--- |
| **電気軸** | -30° 〜 +90° | **左軸偏位 (-30°〜-90°)** | 左脚前枝ブロック、左室肥大、下壁梗塞 |
| | | **右軸偏位 (+90°〜+180°)** | 右室肥大、左脚後枝ブロック、側壁梗塞、若年者、肺塞栓 |
