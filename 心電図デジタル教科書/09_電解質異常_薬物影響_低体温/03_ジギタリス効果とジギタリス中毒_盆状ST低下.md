# ジギタリス製剤の影響：ジギタリス効果（盆状ST低下）と致死的ジギタリス中毒の心電図スペクトラム

ジギタリス製剤（ジゴキシン、メチルジゴキシン）は、心房細動の心拍数コントロールや重症心不全の症状緩和に用いられる古典的強心薬です。
ジギタリスの服用下では、治療域内の常用量であっても特徴的な心電図修飾である **「ジギタリス効果（Digitalis Effect）」** を呈します。一方で、ジギタリスは **治療有効域が極めて狭く（Therapeutic window: 0.5〜0.9 ng/mL）**、過量投与・腎不全・電解質異常（低K、低Mg、高Ca）などを契機に重篤かつ多彩な不整脈を引き起こす **「ジギタリス中毒（Digitalis Toxicity）」** へ容易に進展するため、両者の厳格な鑑別が不可欠です。

---

## 1. 作用機序と心筋電気生理

```mermaid
flowchart TD
    Digoxin["ジギタリス投与"] --> NaK["心筋細胞膜 Na+/K+-ATPase の阻害"]
    NaK --> InNa["細胞内 Na+ 濃度上昇"]
    InNa --> NaCa["\"Na+/Ca2+ 交換系 (NCX") を介した Ca2+ 排出抑制"]
    NaCa --> InCa["\"細胞内 Ca2+ 濃度上昇 (筋小胞体Ca2+充満")"]
    
    InCa --> Force["【陽性変力作用】 心筋収縮力増大"]
    InCa --> Triggered["\"【過剰時】 遅延後脱分極 (DAD") ➔ 異所性自動能亢進 (PVC/VT)"]
    
    Digoxin --> Vagus["中枢性迷走神経刺激 ➔ アセチルコリン遊離"]
    Vagus --> Node["\"【陰性変時・変伝導作用】 洞結節抑制・房室結節伝導遅延 (徐脈/AVB")"]
```

- **心筋細胞レベル**: $Na^+/K^+$-ATPase阻害 ➔ 細胞内 $Ca^{2+}$ 増加 ➔ 収縮力増強（陽性変力作用）。過剰時は遅延後脱分極（Delayed Afterdepolarization: DAD）を惹起し、トリガードアクティビティによる期外収縮・頻拍を誘発。
- **自律神経レベル**: 迷走神経（副交感神経）トーンの亢進 ➔ 洞結節の自律興奮性低下（徐脈）および房室結節の不応期延長・伝導抑制（PR延長、心房細動時の心室応答抑制）。

## 2. ジギタリス効果（Digitalis Effect：常用域の生理的変化）

治療域の血中濃度（0.5〜0.9 ng/mL）であっても、ほぼ必発で見られる心電図変化です。**「服薬していることの証拠」であり、中毒を意味するものではありません**。

```mermaid
flowchart LR
    Effect["ジギタリス効果の4大徴候"] --> E1["\"① 盆状ST低下 (Scooped / Sagging ST depression")"]
    Effect --> E2["\"② QTc時間の短縮 (心室再分極時間の短縮")"]
    Effect --> E3["③ T波の平低化・二相化・逆転"]
    Effect --> E4["\"④ PQ(PR")時間の軽度延長 (迷走神経作用)"]
```

### 1) 盆状ST低下（Scooped / Sagging ST Depression）
- **形態特徴**: ST部分が **下向きに丸みを帯びた弧（スプーン状・洗面器状）** を描いて下垂する。
- 画家サルバドール・ダリの口髭に似ていることから **"Salvador Dalí's mustache"** と形容される。
- **好発誘導**: R波の高い誘導（**V4〜V6、II、III、aVF**）。
- **虚血性ST低下との鑑別**: 虚血性の水平成・下降性ST低下のような直線的な下降ではなく、滑らかなU字型の凹みを呈する。

### 2) その他の心電図修飾
- **QT / QTc時間の短縮**: 心室筋細胞内カルシウム増加により第2相が短縮するため。
- **T波の変化**: T波の振幅が減高し、平低化、二相性、あるいは浅い陰性T波となる。
- **U波の明瞭化**: T波の減高に伴い、相対的にU波が目立つことがある。
- **PR時間延長**: 迷走神経刺激による房室結節伝導遅延（通常 0.20〜0.24s 程度）。

## 3. ジギタリス中毒（Digitalis Toxicity：過量・中毒時の病態）

血中ジゴキシン濃度の上昇（通常 **> 2.0 ng/mL**、高齢者・低K血症下では1.5 ng/mL以上でも発症）により生じる致死的病態です。

```mermaid
flowchart TD
    Tox["ジギタリス中毒の病態"] --> Branch1["\"【刺激伝導系の抑制】 (迷走神経作用亢進")"]
    Tox --> Branch2["\"【異所性自動能の亢進】 (細胞内Ca2+過負荷/DAD")"]
    
    Branch1 --> Arr1["\"・高度洞性徐脈 / 洞停止<br/>・2度〜3度完全房室ブロック (AVB")"]
    Branch2 --> Arr2["\"・心室期外収縮 (PVC: 多源性・二段脈")<br/>・発作性心房頻拍+房室ブロック (PAT with block)<br/>・非発作性房室接合部頻拍 (NPJT)<br/>・双方向性心室頻拍 (Bidirectional VT)"]
```

### 1) 中毒性不整脈の多彩なスペクトラム

| 不整脈の種類 | 心電図特徴 | 特異性・臨床的意義 |
| :--- | :--- | :--- |
| **心室期外収縮 (PVC)** | **多源性PVC、二段脈（Bigeminy）、連発** | **最も頻度の高い（約50%）初期中毒サイン** |
| **PAT with block**<br>*(発作性心房頻拍+房室ブロック)* | 心房レート 150〜220 bpm の異所性P'波に対し、**2:1やWenckebach型の房室ブロックが合併** | **ジギタリス中毒に極めて特異的（★★★★★）** |
| **非発作性房室接合部頻拍<br>(NPJT)** | 心拍数 70〜130 bpm の規則的な幅の狭いQRS、房室解離 | 房室接合部の自動能亢進による特異的所見 |
| **心房細動時の徐脈・整調化** | 心房細動（Af）であるにもかかわらず、**RR間隔が完全に規則的で徐脈（30〜50bpm）** | **完全房室ブロック + 接合部補充調律** の合併を示唆 |
| **双方向性心室頻拍<br>(Bidirectional VT)** | 幅広い変形QRS頻拍で、**1拍ごとに電気軸が右上（上向き）と左下（下向き）へ交互に入れ替わる** | **ジギタリス中毒に最も特異的な致死的不整脈** |

```mermaid
flowchart LR
    Factors["ジギタリス中毒の誘発因子"] --> F1["\"① 低カリウム血症 (K < 3.5")<br/>➔ Na+/K+-ATPaseへのジゴキシン結合促進"]
    Factors --> F2["\"② 低マグネシウム血症 (Mg < 1.8")<br/>➔ 心筋感受性亢進"]
    Factors --> F3["\"③ 高カルシウム血症 (Ca > 10.5")<br/>➔ 細胞内Ca過負荷増強"]
    Factors --> F4["\"④ 腎機能障害 (eGFR低下")<br/>➔ ジゴキシン排泄遅延・蓄積"]
    Factors --> F5["\"⑤ 併用薬物 (相互作用")<br/>・アミオダロン (血中濃度2倍上昇)<br/>・ベラパミル / キニジン / クラリスロマイシン"]
```

## 5. ジギタリス効果 vs ジギタリス中毒 比較まとめ

| 評価項目 | ジギタリス効果（Digitalis Effect） | ジギタリス中毒（Digitalis Toxicity） |
| :--- | :--- | :--- |
| **血中ジゴキシン濃度** | 治療域内（**0.5〜0.9 ng/mL**） | 中毒域（通常 **> 2.0 ng/mL**） |
| **臨床的意義** | 正常な薬理作用・服薬の証拠 | 治療中止・緊急解毒を要する中毒病態 |
| **ST部分** | **典型的な盆状ST低下（ダリの口髭様）** | 盆状ST低下 + 悪性不整脈 |
| **QTc時間** | **短縮** | 短縮（不整脈合併） |
| **心室性不整脈** | 認めない（または既存の散発PVC） | **多源性PVC、二段脈、双方向性VT** |
| **上室性不整脈** | 心房細動の心室応答良好に制御 | **PAT with block、非発作性接合部頻拍** |
| **伝導系障害** | 軽度のPQ延長（< 0.24s） | **洞停止、2度〜3度完全房室ブロック** |
| **全身自覚症状** | なし | 悪心・嘔吐、食欲不振、**黄視症（視野が黄色く見える）**、全身倦怠感 |

## 6. ジギタリス中毒の緊急治療マネジメント

1. **直ちにジギタリス製剤を中止**。
2. **電解質補正**: **血清カリウムを正常高値（4.5〜5.0 mEq/L）に維持**（K投与によりジゴキシンの受容体結合を競合阻害）。低Mg血症も補正。
3. **重症中毒・致死的不整脈時の治療**:
   - **抗ジゴキシン特異抗体Fabフラグメント（DigiFab® / Digibind®）**: 最も確実な中和療法。
   - **心室性頻拍・PVC**: **リドカイン** または **フェニトイン** 静注。
   - **高度徐脈・完全房室ブロック**: **アトロピン静注** または **体外式一時ペーシング**。※電気的除細動（DC）は難治性VFを誘発するリスクがあるため低エネルギーから慎重に行う。

## 7. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 心房細動 (Atrial Fibrillation、f波を認める)
・心拍数: 44 bpm (著明な徐脈)
・RR間隔: 心房細動であるにもかかわらず、RR間隔が 1,360 ms で完全に一定・整 (Regularized RR intervals)。
・ST-T所見: 
  - V4〜V6およびII, III, aVF誘導にて、下向きに丸みを帯びた特徴的な盆状ST低下 (Scooped ST depression: 1.5mm) を認める。
  - QTc時間: 365 ms (短縮傾向)。
・不整脈判定: 心房細動に完全房室ブロックを合併し、房室接合部補充調律 (44 bpm) が出現している。

【総合判定】
ジギタリス中毒疑い (Digitalis Toxicity: 盆状ST低下 + 心房細動に伴う完全房室ブロック)

【緊急対応・指示】
1. 直ちにジギタリス製剤(ジゴキシン)を服薬中止。
2. 至急で血中ジゴキシン濃度、血清電解質(K, Mg, Ca)、腎機能(Cre, eGFR)を採血測定。
3. 高度徐脈による血圧低下や心室性不整脈の出現に備え、心電図モニター監視と一時的ペーシングをスタンバイしてください。
```
