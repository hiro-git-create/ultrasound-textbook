# カルシウム異常（高Ca・低Ca血症）とマグネシウム異常：活動電位第2相とQT時間変化の電気生理

血清カルシウムイオン（$Ca^{2+}$）およびマグネシウムイオン（$Mg^{2+}$）は、心筋活動電位の **第2相（プラトー相: Plateau phase）** における内向きカルシウム電流（$I_{\text{Ca,L}}$）と細胞内シグナル伝達を制御します。
カルシウム濃度の変化は、主に **ST部分の長さを伸縮させることでQT間隔を直接変化** させます。高カルシウム血症による **QT短縮**、低カルシウム血症による **ST延長・QT延長**、ならびに低マグネシウム血症が引き起こす致死的不整脈 **Torsades de Pointes（TdP）** の心電図特徴と病態を網羅します。

---

## 1. カルシウムと活動電位プラトー相（第2相）の電気生理

```mermaid
flowchart TD
    A["血清 Ca2+ 濃度"] --> B["\"心筋活動電位 第2相 (プラトー相") の長さ決定"]
    B --> C["高カルシウム血症: 内向きCa2+流入が早期完了 ➔ 第2相短縮 ➔ ST部短縮/消失 ➔ QT短縮"]
    B --> D["低カルシウム血症: 内向きCa2+流入の持続 ➔ 第2相延長 ➔ ST部等電位延長 ➔ QT延長"]
```

- **心室筋活動電位の各相と心電図の対応**:
  - 第0相（急速脱分極: $Na^+$ 流入） ➔ **QRS波**
  - 第1相（初期急速再分極: $I_{\text{to}}$） ➔ **J点**
  - **第2相（プラトー相: $I_{\text{Ca,L}}$ 流入 vs 遅延整流 $K^+$ 流出の拮抗） ➔ ST部分**
  - 第3相（急速再分極: $I_{\text{Kr}} / I_{\text{Ks}}$ 流出） ➔ **T波**
- **カルシウム濃度の特異性**: カルシウム異常はT波そのものの幅や形態にはほとんど影響を与えず、**純粋にST部分（第2相）の長さのみを変化** させます。

---

## 2. 高カルシウム血症（Hypercalcemia）の心電図変化

血清補正カルシウム濃度が **> 10.5 mg/dL**（重症 > 12〜14 mg/dL）に上昇した場合の心電図特徴です（原発性副甲状腺機能亢進症、悪性腫瘍の骨転移、ビタミンD中毒などで発症）。

```mermaid
flowchart LR
    HighCa["\"高カルシウム血症 (補正Ca > 10.5 mg/dL")"] --> ECG1["① ST部分の極端な短縮または消失"]
    HighCa --> ECG2["\"② QTc時間の著明な短縮 (QTc < 340〜360 ms")"]
    HighCa --> ECG3["③ QRS直後から直ちにT波が立ち上がる"]
    HighCa --> ECG4["④ 重症時: Osborn様J波、徐脈、房室ブロック、VF"]
```

| 診断項目 | 心電図所見・特徴 |
| :--- | :--- |
| **ST部分** | **著明な短縮、または完全に消失**（QRSの終末から即座にT波の上行脚が開始する）。 |
| **QT / QTc時間** | **著明なQT短縮**（**QTc < 340〜360 ms**）。先天性短縮QT症候群（SQTS）との鑑別が必要。 |
| **T波形態** | T波自体の幅・立ち上がりは正常であるが、QRSのすぐ直後に位置するため幅広に見えることがある。重症例ではT波の平低化・二相化。 |
| **重症高Ca血症の所見** | ・**Osborn波様のJ点隆起（J波）**<br>・洞性徐脈、洞停止<br>・1度〜完全房室ブロック（AVB）<br>・心室細動（VF）や心停止のリスク |

---

## 3. 低カルシウム血症（Hypocalcemia）の心電図変化

血清補正カルシウム濃度が **< 8.5 mg/dL**（イオン化Ca < 1.0 mmol/L）に低下した場合の心電図特徴です（副甲状腺機能低下症、急性膵炎、慢性腎不全、大量輸血後、低アルブミン血症などで発症）。

```mermaid
flowchart LR
    LowCa["\"低カルシウム血症 (補正Ca < 8.5 mg/dL")"] --> ECG_LC1["\"① ST部分の平坦な等電位延長 (Isoelectric ST prolongation")"]
    LowCa --> ECG_LC2["\"② QTc時間の著明な延長 (QTc > 450/460 ms")"]
    LowCa --> ECG_LC3["③ T波の形態・幅自体は正常に保たれる"]
    LowCa --> ECG_LC4["\"④ Torsades de Pointes (TdP") の誘発 (低K/低Mg合併時)"]
```

| 診断項目 | 心電図所見・特徴 |
| :--- | :--- |
| **ST部分** | **基線（等電位線）に沿って水平に長く延長する（Flat, Isoelectric ST segment prolongation）**。 |
| **QT / QTc時間** | **著明なQT延長**（**QTc > 450 ms[男性] / > 460 ms[女性]**、重症時 > 500 ms）。 |
| **T波形態** | **T波の幅や高さ、対称性は正常に保たれる**（低K血症のT波平低化や、抗不整脈薬によるT波拡大・ノッチ形成と異なる決定的な鑑別点）。 |
| **不整脈リスク** | 単独でのTdP発生は低カリウム血症ほど高くないが、低K血症や低Mg血症が合併すると致死的な **多形性VT（Torsades de Pointes）** を引き起こす。 |

> [!TIP]
> **QT延長の形態別鑑別の極意**
> - **低Ca血症によるQT延長**: 「**ST部分だけが長く**、T波は普通にポンと出る」。
> - **低K血症によるQT延長**: 「**ST低下 + T波平低化 + 巨大U波** が合体して長く見える（QU延長）」。
> - **Class III抗不整脈薬/先天性LQT2によるQT延長**: 「**T波自体の幅が広く、ノッチや二峰性** を伴う」。

## 4. マグネシウム異常（Magnesium Disorders）

マグネシウム（$Mg^{2+}$）は細胞内主要酵素の補因子であり、心筋細胞膜の $Na^+/K^+$-ATPase や各種イオンチャネル（$I_{\text{Ca,L}}, I_{\text{Kr}}$）の開閉を調節しています。

```mermaid
flowchart TD
    Mg["血清 Mg2+ 異常"] --> LowMg["\"低マグネシウム血症 (< 1.8 mg/dL")"]
    Mg --> HighMg["\"高マグネシウム血症 (> 2.5 mg/dL")"]
    
    LowMg --> LowMgECG["\"・Na+/K+-ATPase抑制 ➔ 細胞内K+低下<br/>・早発後脱分極 (EAD") の誘発<br/>・Torsades de Pointes (TdP) の直接の引き金"]
    HighMg --> HighMgECG["\"・房室結節・室内伝導遅延 (PR延長, QRS拡大")<br/>・高度徐脈 ➔ 心停止 (Asystole)"]
```

### 1) 低マグネシウム血症（Hypomagnesemia: < 1.8 mg/dL）
- **臨床背景**: アルコール多飲、利尿薬長期使用、低栄養、PPI長期内服、難治性下痢。
- **心電図特徴**:
  - 低カリウム血症・低カルシウム血症を高頻度に併発するため、単独の心電図変化を特定することは困難だが、**QT延長、U波増高、ST低下、心室性期外収縮（PVC）多発** を呈する。
  - **Torsades de Pointes（TdP）の最大のトリガー**: 早期後脱分極（Early Afterdepolarization: EAD）を惹起し、QT延長患者におけるTdP発症の直接の引き金となる。
- **緊急治療**: **硫酸マグネシウム（マグネゾール® / コンチーム®） 1〜2g を 10〜15分かけて点滴静注**（TdP発症時の第一選択薬）。

### 2) 高マグネシウム血症（Hypermagnesemia: > 2.5 mg/dL）
- **臨床背景**: 腎不全患者への酸化マグネシウム製剤（下剤）やMg含有胃腸薬の投与、子癇治療時の過量投与。
- **心電図特徴**:
  - $Mg > 4〜5\text{ mg/dL}$: **PQ時間延長、QRS幅拡大、QT延長**（伝導抑制）。
  - $Mg > 10〜12\text{ mg/dL}$: **完全房室ブロック、高度徐脈、心停止**、呼吸停止。

## 5. 電解質異常の心電図鑑別マトリックス

| 電解質異常 | PQ(PR)時間 | QRS幅 | ST部分 | T波 | U波 | QTc時間 | 主な催不整脈 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **高カリウム血症** | 延長 ➔ 消失 | **著明拡大** | 融合 | **テント状T波** | 消失 | **短縮** | 正弦波 ➔ VF/心静止 |
| **低カリウム血症** | 軽度短縮 | 正常 | **低下** | **平低化・陰転** | **著明増高** | 見かけ上延長 | PVC, AF, TdP |
| **高カルシウム血症** | 正常〜軽度延長 | 正常〜軽度拡大 | **短縮・消失** | 正常 | なし | **著明短縮** | 徐脈, 房室ブロック, VF |
| **低カルシウム血症** | 正常 | 正常 | **等電位延長** | 正常 | なし | **著明延長** | TdP (低K/Mg併発時) |
| **低マグネシウム血症**| 正常〜延長 | 正常 | 低下傾向 | 平低化 | 増高傾向 | 延長 | **Torsades de Pointes** |

## 6. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 洞調律 (Heart Rate: 62 bpm)
・計測値: 
  - PQ時間: 160 ms (正常)
  - QRS幅: 80 ms (正常)
  - QT / QTc(Bazett): 510 ms / 517 ms (著明なQTc延長)
・ST-T所見: 
  - 全胸部誘導および肢誘導において、ST部分が基線に沿って水平に著明に延長している (Isoelectric ST prolongation)。
  - T波自体の形態・振幅および極性は正常に保たれている。
  - 明らかなU波の増高やST低下は認めず。

【総合判定】
著明なQTc延長（低カルシウム血症パターン）

【推奨コメント】
ST部分の単独延長による著明なQTc延長を認め、低カルシウム血症が強く疑われます。血清補正カルシウムおよび電解質（K, Mg, P）、アルブミン値の至急確認を推奨します。低K・低Mg血症合併時のTdP発症に注意してください。
```
