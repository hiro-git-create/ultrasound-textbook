# カリウム異常：高カリウム血症の段階的推移（テント状T波〜正弦波）と低カリウム血症の心電図変化

血清カリウムイオン（$K^+$）は、心筋細胞の静止膜電位および活動電位第3相（急速再分極相）を決定づける最重要電解質です。
カリウム濃度異常は、心筋の興奮性・自動能・伝導性に重大な影響を及ぼし、放置すれば速やかに致死的不整脈（心室細動・心静止）へと進展します。
**高カリウム血症（Hyperkalemia）** における血清濃度依存性の段階的心電図推移と、**低カリウム血症（Hypokalemia）** における特徴的なU波増高・不整脈誘発機序を徹底解説します。

---

## 1. カリウムと心筋電気生理の基本機序

```mermaid
flowchart TD
    A["血清 K+ 濃度"] --> B["ネルンストの式による静止膜電位の決定"]
    B --> C["\"高K血症: 静止膜電位の上昇 (脱分極") ➔ Naチャネル不活化 ➔ 伝導遅延/停止"]
    B --> D["\"高K血症: 外向きK電流 (IKr/IKs") 増大 ➔ 第3相急速再分極短縮 ➔ テント状T波"]
    B --> E["\"低K血症: 静止膜電位の過分極 ➔ 再分極遅延 (第3相延長") ➔ U波増高/TdP"]
```

- **高カリウム血症**:
  - 外向き遅延整流K+電流（$I_{\text{Kr}}$）が促進 ➔ **再分極が急速に完了（第3相短縮） ➔ 基底部の狭い先鋭なT波（テント状T波）**。
  - 静止膜電位が脱分極側に浅くなり、電位依存性Na+チャネルが不活化 ➔ **脱分極速度低下 ➔ P波減高・PR延長・QRS幅拡大・伝導ブロック**。
- **低カリウム血症**:
  - 外向きK+電流が抑制 ➔ **再分極が著明に遅延（第3相延長） ➔ T波平低化、U波増高、見かけ上のQT（QU）延長**。

---

## 2. 高カリウム血症の段階的推移（Progressive ECG Changes）

血清カリウム濃度の上昇に伴い、心電図は極めて規則的かつ進行性に変化します。

```mermaid
flowchart LR
    K1["\"① 軽度 (5.5〜6.5 mEq/L")<br/>テント状T波 (Peaked T)<br/>QT短縮"] --> K2["\"② 中等度 (6.5〜7.5 mEq/L")<br/>P波平低化・PQ延長<br/>QRS幅拡大・S波深化"]
    K2 --> K3["\"③ 高度 (7.5〜8.5 mEq/L")<br/>P波消失 (洞心室調律)<br/>著明なQRS拡大"]
    K3 --> K4["\"④ 致死性 (> 8.5 mEq/L")<br/>正弦波 (Sine Wave Pattern)<br/>➔ VF / 心静止"]
```

| 病期 / 血清K濃度 | 心電図波形特徴 | 心筋電気生理学的病態 |
| :--- | :--- | :--- |
| **① 軽度<br>(5.5〜6.5 mEq/L)** | ・**テント状T波（Tent-shaped / Tall Peaked T wave）**<br>（左右対称、基底部の幅が狭く、先鋭化した高いT波）<br>・QT/QTc時間の短縮 | 心室筋第3相再分極の異常な急速化 |
| **② 中等度<br>(6.5〜7.5 mEq/L)** | ・**P波の平低化・幅延長**、**PQ(PR)時間延長**<br>・**QRS幅の拡大（室内伝導障害）**<br>・R波の減高、S波の深化・幅延長 | 心房筋およびヒス・プルキンエ系の脱分極伝導速度の低下 |
| **③ 高度・重症<br>(7.5〜8.5 mEq/L)** | ・**P波の完全消失（洞心室調律: Sinuventricular rhythm）**<br>（洞結節は興奮しているが心房筋が脱分極不能で結節間路経由で直接心室へ伝導）<br>・QRS幅が著明に拡大（脚ブロック様・変形）<br>・ST-TとQRSが一体化 | 心房筋の興奮性完全喪失、全心室内伝導遅延 |
| **④ 致死的・極期<br>(> 8.5 mEq/L)** | ・**正弦波パターン（Sine Wave Pattern）**<br>（幅広いQRS波とT波が融合し滑らかなサインカーブを描く）<br>・**心室細動（VF） / 心室静止（Asystole） / PEA** | 心室筋の脱分極・再分極の同期崩壊、心停止直前像 |

> [!WARNING]
> **テント状T波と超急性虚血T波（Hyperacute T wave）の鑑別**
> - **テント状T波（高K血症）**: **「基底部の幅が狭い（Narrow base）」「先端が針のように尖っている」「左右対称」「全誘導（特に胸部誘導）に広範」**。
> - **超急性虚血T波（AMI超急性期）**: **「基底部の幅が広い（Broad base）」「非対称性または丸みを帯びる」「冠動脈責任領域の誘導に局在し、対向誘導に鏡面像を伴う」**。

## 3. 高カリウム血症の緊急治療プロトコル

```mermaid
flowchart TD
    HyperK["\"高カリウム血症心電図 (QRS拡大 / Sine wave / P波消失") の検知"] --> Step1["\"【最優先】心筋細胞膜の安定化<br/>グルコン酸カルシウム (カルチコール®") 10ml を 3〜5分かけて静注"]
    Step1 --> Step2["\"細胞内へのK+シフト療法<br/>① GI療法 (ブドウ糖 25〜50g + 速効型インスリン 5〜10単位 点滴")<br/>② 炭酸水素ナトリウム (メイロン®) 50〜100ml 静注 (アシドーシス時)<br/>③ 吸入β2刺激薬 (サルブタモール吸入)"]
    Step2 --> Step3["\"体外へのカリウム排泄促進<br/>① ループ利尿薬 (フロセミド")<br/>② 陽イオン交換樹脂 (ケイキサレート® / ロケルマ®)<br/>③ 緊急血液透析 (HD) の施行"]
```

> [!IMPORTANT]
> **グルコン酸カルシウムの役割**
> グルコン酸カルシウムは **「血清カリウム濃度を下げる薬ではなく、閾値電位を上方シフトさせて心筋細胞膜を安定化し、直ちに心停止（VF/Asystole）を防ぐ薬」** です。投与後1〜3分で心電図上のQRS幅縮小・P波再出現効果が得られますが、効果は30〜60分で切れるため、必ず並行してGI療法や透析などのカリウム除去療法を行います。

## 4. 低カリウム血症（Hypokalemia）の心電図変化

血清カリウム濃度が低下（$< 3.5\text{ mEq/L}$、重症 $< 2.5\text{ mEq/L}$）すると、心室筋の再分極時間が著明に延長し、以下の連続的変化が生じます。

```mermaid
flowchart TD
    LowK["\"低カリウム血症 (K < 3.5 mEq/L")"] --> Change1["① T波の平低化・二相化・陰転化"]
    LowK --> Change2["\"② 著明なU波の増高 (U波振幅 > T波振幅, V2-V4で顕著")"]
    LowK --> Change3["\"③ 見かけ上のQT時間延長 (実際はQ-U融合によるQU時間延長")"]
    LowK --> Change4["\"④ 軽度のST低下 (0.5〜1.0mm")"]
    Change2 & Change3 --> Arrhythmia["\"心室性不整脈の誘発 (PVC, PAC, 多形性VT, Torsades de Pointes")"]
```

| 項目 | 低カリウム血症の心電図所見 | 臨床的ピットフォール |
| :--- | :--- | :--- |
| **U波の増高** | **V2〜V4誘導で U波高 > 1 mm（または U波 > T波）** となる | 正常U波（< 1mm）と異なり、T波の背丈を凌駕する。 |
| **T波の平低化** | T波振幅が低下し、平坦化または浅い陰性T波となる | 虚血性T波変化と誤認されやすい。 |
| **QU時間延長** | T波と増高したU波が連続・融合（T-U fusion）し、**見かけ上のQT時間が著しく延長** する | 自動解析装置が「QT延長」と誤判定することが多い。 |
| **ST低下** | 水平成または緩徐な下垂性ST低下（0.5〜1.0mm） | 心内膜下虚血やジギタリス効果との鑑別を要する。 |
| **催不整脈性** | PVC頻発、二段脈、心房細動、**Torsades de Pointes（TdP）** | ジギタリス服用患者では重篤なジギタリス中毒を誘発。 |

---

## 5. 高K血症 vs 低K血症 鑑別対照表

| 評価項目 | 高カリウム血症（Hyperkalemia） | 低カリウム血症（Hypokalemia） |
| :--- | :--- | :--- |
| **P波** | 平低化 ➔ **消失（洞心室調律）** | 振幅増大（尖鋭化） |
| **PQ(PR)時間** | **延長** | 軽度短縮または正常 |
| **QRS幅** | **著明に拡大（幅広・変形）** | 正常〜軽度拡大 |
| **ST部** | QRSおよびT波と融合 | **軽度低下（0.5〜1mm）** |
| **T波** | **テント状T波（高く先鋭・基部狭い）** | **平低化・陰転化** |
| **U波** | 消失 | **著明に増高（U > T）** |
| **QT/QU時間** | **QT短縮** | **見かけ上のQT延長（QU延長）** |
| **致死的不整脈** | **正弦波 ➔ 心室細動・心静止** | **多形性心室頻拍・Torsades de Pointes** |

## 6. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 洞心室調律 (心拍数: 52 bpm、P波は全誘導で完全消失)。
・QRS波: QRS時間 160 ms (著明なびまん性室内伝導遅延、脚ブロック様変形)。
・ST-T所見: 
  - V2〜V5誘導およびII, III, aVF誘導にて、基底部の極めて狭い左右対称性の先鋭な高尖T波 (テント状T波: 高さ 11mm) を認める。
  - QRS終末部とST部が移行部で融合傾向を示す。

【総合判定】
重症高カリウム血症疑い (Severe Hyperkalemia Pattern / Sinuventricular rhythm)

【緊急対応・指示】
致死的不整脈(正弦波・心室細動・心停止)へ移行する極めて危険なサインです。
1. 直ちにグルコン酸カルシウム (カルチコール®) 10ml 静注 (心筋膜安定化)。
2. 緊急採血 (電解質・血液ガス) を施行し、GI療法および緊急血液透析の準備を開始してください。
```
