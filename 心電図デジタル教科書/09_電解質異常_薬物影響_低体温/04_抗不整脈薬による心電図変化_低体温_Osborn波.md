# 抗不整脈薬の心電図修飾・催不整脈作用（Vaughan Williams分類）と低体温心電図（Osborn波）

抗不整脈薬は、心筋のイオンチャネルや受容体を修飾することで不整脈を抑制する一方、用量依存的または特異体質性に伝導障害や新たな致死的不整脈を惹起する **「催不整脈作用（Proarrhythmia）」** を持ちます。Vaughan Williams分類（およびSicilian Gambit）に基づく各薬剤群の心電図変化パラメータ（PQ時間、QRS幅、QTc時間）の監視基準を体系化します。
また、偶発性低体温症（Accidental Hypothermia）における特異的診断サインである **Osborn波（J波）** の電気生理学的発生機序と重症度判定を解説します。

---

## 1. 抗不整脈薬の分類（Vaughan Williams分類）と心電図修飾

```mermaid
flowchart TD
    Drugs["抗不整脈薬の主要ターゲット"] --> ClassI["\"Class I (Naチャネル遮断")<br/>・Ia: QRS拡大 + QT延長<br/>・Ib: 心電図変化軽微 / QT短縮<br/>・Ic: 著明なQRS幅拡大"]
    Drugs --> ClassII["\"Class II (β遮断薬")<br/>・洞徐脈 + PQ延長"]
    Drugs --> ClassIII["\"Class III (Kチャネル遮断")<br/>・著明なQT/QTc延長 + T-U融合"]
    Drugs --> ClassIV["\"Class IV (Ca拮抗薬")<br/>・PQ延長 + 洞徐脈"]
```

### 1) 各群の電気生理作用と心電図パラメータ変化

| クラス | 主な代表薬剤 | 主なイオンチャネル・作用 | PQ時間 | QRS幅 | QTc時間 | 主な催不整脈リスク (Proarrhythmia) |
| :--- | :--- | :--- | :---: | :---: | :---: | :--- |
| **Ia群** | キニジン、プロカインアミド、ジソピラミド、シベンゾリン | 中等度 $Na^+$ 遮断<br>＋ $K^+$ 遮断（$I_{\text{Kr}}$） | 延長 | **拡大** | **延長** | **Torsades de Pointes（TdP）**、伝導ブロック |
| **Ib群** | リドカイン、メキシレチン、アプリンジン | 弱い $Na^+$ 遮断<br>（解離速度が速い） | 変化なし | 変化なし | **短縮傾向** | 洞停止、中枢神経毒性（痙攣） |
| **Ic群** | ピルジカイニド、フレカイニド、プロパフェノン | **強力な $Na^+$ 遮断**<br>（解離速度が極めて遅い） | **延長** | **著明拡大** | 変化なし<br>(※QRS拡大分のみ) | **Wide QRS頻拍（IC粗動）**、**Brugada波形の顕性化**、心原性ショック |
| **II群** | ビソプロロール、カルベジロール、メトプロロール | $\beta_1$ 受容体遮断 | **延長** | 変化なし | 変化なし | 高度徐脈、洞不全、完全房室ブロック |
| **III群** | アミオダロン、ソタロール、ニフェカラント | **強力な $K^+$ 遮断（$I_{\text{Kr}} / I_{\text{Ks}}$）**<br>(アミオダロンはNa/Ca/βも遮断) | 延長 | 正常〜軽度拡大 | **著明延長** | **Torsades de Pointes（TdP）**<br>※アミオダロンは比較的TdP頻度低 |
| **IV群** | ベラパミル、ジルチアゼム | L型 $Ca^{2+}$ チャネル遮断 | **延長** | 変化なし | 変化なし | 洞徐脈、完全房室ブロック、陰性変力による心不全悪化 |

## 2. 抗不整脈薬の安全性監視基準（安全限界カットオフ値）

抗不整脈薬投与中は、定期的な12誘導心電図記録により以下の **「投与中止・減量基準（Safety Cutoffs）」** を厳格にモニタリングします。

```mermaid
flowchart LR
    Monitor["抗不整脈薬投与中の心電図モニタリング"] --> Limit1["\"① QRS幅の拡大限界<br/>・投与前より 25% 以上拡大<br/>・絶対値 QRS ≥ 120〜130 ms (Ic群")"]
    Monitor --> Limit2["\"② QTc時間の延長限界<br/>・投与前より 60 ms 以上延長<br/>・絶対値 QTc ≥ 500 ms (Ia/III群")"]
    Monitor --> Limit3["③ PR時間の延長限界<br/>・PR ≥ 240 ms / 2度房室ブロック出現"]
```

> [!WARNING]
> **Ic粗動（Ic Flutter）とBrugada誘発**
> - **Ic粗動**: 心房細動・心房粗動患者にピルジカイニドやフレカイニドを投与すると、心房伝導が遅延して粗動レートが200bpm程度に低下し、**房室結節が 1:1 伝導して 200bpmの Wide QRS頻拍（VT酷似）** を引き起こす危険があります。これを防ぐため、通常はβ遮断薬やCa拮抗薬を併用します。
> - **潜在性Brugada症候群の顕性化**: Ic群薬（ピルジカイニドなど）の強力なNa遮断作用により、潜在していた右側胸部誘導の **coved型ST上昇（Brugada Type 1波形）** が誘発・顕性化することがあります（ピルジカイニド負荷試験の原理）。

## 3. 低体温症（Accidental Hypothermia）の心電図所見

深部体温（Core temperature）が **35℃未満** に低下した低体温症では、心筋のすべての電気生理学的過程（脱分極・再分極・伝導速度）が遅延し、特異的な波形変化を呈します。

```mermaid
flowchart TD
    Cold["\"低体温 (深部体温低下")"] --> Ito["\"心室心外膜側 Ito (一過性外向きK電流") の再分極電位差増大"]
    Ito --> Osborn["\"① Osborn波 (J波 / Camel-Hump Sign") の出現"]
    Cold --> Slow["\"② 著明な洞性徐脈 / 接合部調律 (代謝低下")"]
    Cold --> Broad["\"③ 全伝導遅延 (PR延長, QRS幅拡大, QTc著明延長")"]
    Cold --> Shiver["④ シバリングによる高周波筋電図アーチファクト"]
    Cold --> Fib["\"⑤ 低体温性心房細動 (Slow AF") ➔ 致死性VF / 心静止"]
```

## 4. Osborn波（J波：J Wave / Camel-Hump Sign）

```mermaid
flowchart LR
    A["\"QRS波の終末部 (J点")"] --> B["\"ドーム状・コブ状の陽性隆起 (Osborn波")"]
    B --> C["ST部分へ移行"]
```

### 1) 特徴と電気生理学的機序
- **形態**: **QRS波の終末部（J点接合部）に生じるドーム状・山型（ラクダのコブ様: Camel-hump）の明瞭な隆起**。
- **好発誘導**: 左室側壁および下壁誘導（**II, III, aVF, V3〜V6**）。
- **機序**: 低体温下では、心外膜側心筋の一過性外向きカリウム電流（$I_{\text{to}}$）が心内膜側よりも著しく強調されるため、心室壁内外に大きな電位勾配が生じ、J点に顕著な陽性波（J波）として描出されます。
- **体温との相関**: **深部体温が低下するほどOsborn波の振幅（高さ）は増大** し、体温が 32℃ を下回るとほぼ全例に出現します。復温に伴い速やかに縮小・消失します。

## 5. 低体温症の重症度別心電図変化

| 重症度分類 | 深部体温 | 特徴的心電図変化 | 臨床状態・不整脈リスク |
| :--- | :---: | :--- | :--- |
| **軽度低体温<br>(Mild)** | **32〜35℃** | ・洞性徐脈<br>・**シバリングによる激しい筋電図アーチファクト（基線動揺）**<br>・PR時間・QT時間の軽度延長 | 意識清明〜軽度混濁、体温調節機構は保持 |
| **中等度低体温<br>(Moderate)** | **28〜32℃** | ・**明瞭なOsborn波（J波）の出現**<br>・著明な徐脈（30〜40 bpm）<br>・QRS幅拡大、QTcの極端な延長<br>・**低体温性心房細動（Slow AF with slow ventricular response）** | 意識障害、シバリング消失、不整脈感受性亢進 |
| **重度低体温<br>(Severe)** | **< 28℃** | ・巨大なOsborn波<br>・高度房室ブロック、心室固有調律<br>・**心室細動（VF） / 心静止（Asystole）** | 昏睡、心停止リスク極めて高い（わずかな機械的刺激でVF誘発） |

> [!CAUTION]
> **低体温患者の管理上の超重要注意点**
> 中等度〜重度低体温の心筋は極めて電気的に不安定であり、**気管挿管や中心静脈カテーテル挿入、不用意な体位変換などのわずかな物理的刺激によって難治性心室細動（VF）が容易に誘発** されます。低体温下でのVFは通常の除細動（DC）や抗不整脈薬に反応しにくいため、体外循環（ECMO/PCPS）等を用いた **能動的中枢復温（30〜32℃以上への復温）を最優先** します。

## 6. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 洞性徐脈 (Heart Rate: 38 bpm)
・計測値: 
  - PQ時間: 220 ms (軽度延長)
  - QRS幅: 130 ms (軽度室内伝導遅延)
  - QT / QTc(Bazett): 580 ms / 462 ms (著明なQT延長)
・波形所見: 
  - II, III, aVFおよびV4〜V6誘導のQRS終末部(J点)において、振幅 3.5mm の明瞭なドーム状隆起 (Osborn波 / J波) を認める。
  - 全誘導において軽度の体動・シバリング様筋電図アーチファクトが重畳。

【総合判定】
中等度偶発性低体温症パターン (Moderate Hypothermia: 著明な徐脈 + Osborn J波 + QTc延長)

【対応・指示】
1. 直ちに直腸温または膀胱温にて深部体温を測定 (目標体温評価)。
2. 加温ブランケット・加温輸液による能動的復温を開始。
3. 機械的刺激による難治性心室細動(VF)誘発に最大限注意し、愛護的な処置を徹底してください。
```
