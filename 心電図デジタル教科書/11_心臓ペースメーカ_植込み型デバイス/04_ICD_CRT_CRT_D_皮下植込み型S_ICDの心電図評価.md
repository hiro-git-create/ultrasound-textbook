# 🛡️ ICD・CRT・CRT-D・皮下植込み型S-ICDの心電図評価

重症心不全や致死的不整脈の治療に用いられる高度植込み型心臓デバイス（**ICD, CRT-P, CRT-D, S-ICD**）の心電図上の特徴、両室ペーシング波形の判読法、および作動評価を解説します。

---

## 1. 各種植込み型デバイスの機能と適応比較

| デバイス名 | 主な機能 | 植込みリード | 主な適応疾患 | 心電図上の主目的 |
| :--- | :--- | :--- | :--- | :--- |
| **ICD**<br/>（植込み型除細動器） | 徐脈ペーシング ＋<br/>**VT/VFの検出・ATP・ショック治療** | 右室ショックリード<br/>（＋心房リード） | 致死性不整脈既往（二次予防）、Brugada/LQTS/心筋症高リスク群（一次予防） | VT/VF停止作動の確認、不適切作動の除外 |
| **CRT-P**<br/>（心臓再同期療法ペーシング） | **両心室ペーシング（BiV）**<br/>による心室同期性の改善 | 右房 ＋ 右室 ＋<br/>**左室（冠静脈洞経由）** | 重症心不全（LVEF $\le 35\%$）、CLBBB（QRS $\ge 130\,\text{ms}$） | **QRS幅の短縮（再同期達成）**、BiVペーシング維持率 $\ge 98\%$ |
| **CRT-D**<br/>（除細動機能付きCRT） | **CRT機能 ＋ ICD機能** | 右房 ＋ 右室ショック ＋<br/>左室リード | 致死性不整脈リスクを伴う重症心不全 | 両室ペーシング評価 ＋ 抗頻拍作動の確認 |
| **S-ICD**<br/>（皮下植込み型除細動器） | **完全皮下でのVF除細動**<br/>（血管・心腔内リードなし） | 胸骨左縁の皮下リードのみ | ペーシング不要な若年者、血管アクセス困難例、感染高リスク例 | **T波オーバセンシング（TWOS）の回避**、除細動作動 |

## 2. 心臓再同期療法（CRT）の両室ペーシング心電図波形

CRTでは、左室側壁（冠静脈洞枝）と右室中隔/心尖部の両方を同時に刺激することで、左脚ブロックによる心室同期不全を劇的に改善します。

```
【CRT（両室ペーシング: BiV）の典型波形】

【V1誘導: 陽性R波優位】       【I・aVL誘導: 深い陰性QS型】
         ▲ R (左室側壁からの興奮)     ───┬──┐
        / \                             │  │
    ───┬'  \_______                  ───┘  │
       │                                   │
                                           \_______ (QS型)
```

### 両室ペーシング（BiV）波形の4大特徴
1. **$V_1$ 誘導でR波が優位（陽性QRS）**:
   - 通常の右室ペーシング（$V_1$で深いQS型）と異なり、**左室側壁から右方向へ向かう電気ベクトル**が生じるため、$V_1$で高いR波（$R > S$ または $Rs$ 型）が形成されます。
2. **I・aVL誘導で深い陰性QSパターン**:
   - 左室側壁から中隔方向へ電気刺激が離れていくため、側壁誘導（I, aVL）で深い下向き波となります。
3. **QRS幅の顕著な短縮（Narrowing of QRS）**:
   - 術前の完全左脚ブロック（幅 $160 \sim 180\,\text{ms}$）に比べ、両室ペーシング成功時は**QRS幅が $120 \sim 140\,\text{ms}$ 前後まで狭小化**します（QRS短縮が大きいほど心不全改善レスポンダー）。
4. **二重ペーシングスパイク**:
   - 右室と左室の刺激タイミングを数ミリ秒ずらす設定（VV delay）の場合、2連の微小スパイクが観察されます。

## 3. ICD（植込み型除細動器）の抗頻拍治療と心電図

ICDは頻拍（VT/VF）を検出すると、段階的に以下の治療を自動実行します。

```mermaid
graph TD
    A["致死性心室性不整脈の発生"] --> B{"心拍数ゾーン判定"}
    B -->|"VTゾーン (例: 170-200bpm)"| C["\"① 抗頻拍ペーシング (ATP: Burst / Ramp")<br/>頻拍よりわずかに速いペーシングでリエントリー回路を停止"]
    C -->|"停止成功"| D["正常洞調律復帰"]
    C -->|"停止不成功 / 頻拍加速"| E["\"② カルディオバージョン (同期ショック: 10-35J")"]
    B -->|"VFゾーン (例: >200bpm)"| F["\"③ 最大エネルギー非同期除細動ショック (35-40J")"]
    E --> D
    F --> D
```

> [!IMPORTANT]
> **抗頻拍ペーシング（ATP）の心電図**
> VTの最中に、頻拍周期より約10〜15%速い周期で8〜10発の連続心室ペーシングスパイクが撃ち込まれ、直後に頻拍が停止して洞調律に復帰する様子が心電図モニターに記録されます。

## 4. 完全皮下植込み型除細動器（S-ICD）の心電図評価

S-ICDは心筋内に電極を接触させず、前胸部皮下の電位差を感知するため、**術前の体表面12誘導心電図スクリーニングが必須**となります。

```
【S-ICDの3つの皮下センシングベクトル】
      [A] 上部胸骨電極
       │
       │  (Primary: A-B)
       │  (Secondary: A-ジェネレータ)
      [B] 下部胸骨電極 ─────── [ジェネレータ] (側胸部)
                        (Alternate: B-ジェネレータ)
```

### S-ICDスクリーニングとT波オーバセンシング（TWOS）
- **判定基準**: 仰臥位および立位の全誘導において、**QRS波に対するT波の高さ（T/QRS比）が小さく、3つのベクトルのうち少なくとも1つ以上で適合（Pass）** すること。
- **不適切作動のリスク**: T波が高大であると、S-ICDが「QRS波」と「T波」を二重に感知し、心拍数が2倍（ダブルカウント）と計算されて心室頻拍と誤認し、意識清明な患者に**不適切除細動ショック**が作動してしまいます。

## 5. 心電図所見の記載例

```text
【心電図所見】
両心室ペーシング調律 70bpm。
各QRS波の直前にペーシングスパイクを認め、V1誘導において高いR波（Rsパターン）、I・aVL誘導において深いQSパターンを呈する。
ペーシングQRS幅は125msであり、植込み前の完全左脚ブロック波形（QRS幅 170ms）と比較して著明なQRS幅短縮（再同期達成）を認める。

【診断】
CRT-D正常作動（有効な両室ペーシングによる心室再同期）

【判定】
良好なペーシング状態
```
