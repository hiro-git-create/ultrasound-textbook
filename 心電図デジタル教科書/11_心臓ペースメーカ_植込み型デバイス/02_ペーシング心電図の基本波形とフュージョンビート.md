# 📈 ペーシング心電図の基本波形とフュージョンビート

ペースメーカ植込み患者の心電図では、ペーシングリードの留置部位や自己興奮とのタイミング関係によって多彩な波形が出現します。本稿では部位別の典型波形、生理的ペーシング、および融合収縮（Fusion beat）の鑑別法を解説します。

---

## 1. ペーシングスパイク（Pacing Spike）の基本

ペーシング刺激が出力される瞬間に記録される急峻な電位変化を「スパイク」と呼びます。

```
【単極ペーシング (Unipolar)】         【双極ペーシング (Bipolar)】
         │                                   
         │ (巨大なスパイク 10〜30mm)           │ (微小なスパイク 1〜2mm)
         │                                   │
      ┌──┴──┐                             ┌──┴──┐
   ───┘     └──────                    ───┘     └──────
```

- **単極ペーシング（Unipolar）**:
  - リード先端（陰極）とペースメーカ本体金属ケース（陽極）間で通電。
  - 誘導距離が長いため、**心電図上に巨大なペーシングスパイク**が明瞭に記録されます。
- **双極ペーシング（Bipolar）**:
  - リード先端（陰極）と先端数ミリ手前のリング電極（陽極）間で通電。
  - 電極間距離が極めて短いため、**スパイクは非常に小さく**、現代のデジタル心電計では内部処理マーカーとして微小に表示されます。

---

## 2. 心室ペーシング部位とQRS形態の対比

心室ペーシングでは、人工刺激が最初に伝導した部位から心室全体へ筋肉伝導（遅い伝導）で広がるため、刺激部位に応じた特徴的なQRS軸・脚ブロックパターンを呈します。

```
【右室心尖部 (RVA) ペーシング】
・V1: 深いQS型 (左脚ブロック様)
・II, III, aVF: 深い陰性QS型 (上軸偏位)
      V1              II, III, aVF
   ───┬──┐              ───┬──┐
      │  │                 │  │
      │  │                 │  │
      │  │                 │  │
      │  \                 │  \
      │   \_______         │   \_______
```

### ペーシング部位別の心電図特徴

| ペーシング部位 | QRS幅 | $V_1$ 波形 | 肢誘導電気軸（II, III, aVF） | 特徴と臨床的意義 |
| :--- | :--- | :--- | :--- | :--- |
| **右室心尖部**<br/>（RVA: Traditional） | 広い（$\ge 150\,\text{ms}$） | **完全左脚ブロック様（QS型）** | **上軸偏位（深い陰性波）** | 従来標準。長期では左室同期不全・心不全リスク（Pacing-induced cardiomyopathy）。 |
| **右室中隔・流出路**<br/>（RVS / RVOT） | 広い（$130 \sim 150\,\text{ms}$） | **完全左脚ブロック様（rS型）** | **正常軸〜下方軸（陽性R波）** | 心室中隔から下方へ向かう興奮伝播。RVAより生理的。 |
| **ヒス束ペーシング**<br/>（HBP: 生理的） | **正常（$\le 100 \sim 110\,\text{ms}$）** | **正常自己波形と同一** | **正常軸** | 固有刺激伝導系を直接刺激。最も理想的な生理的ペーシング。 |
| **左脚領域ペーシング**<br/>（LBBAP: 生理的） | 狭い（$\le 120\,\text{ms}$） | **不完全右脚ブロック様（$rSR'$ / $qR$）** | **正常軸** | 中隔を深く貫通し左脚を直接興奮。現在世界的に急速普及。 |

## 3. フュージョンビート（Fusion Beat）と偽融合収縮（Pseudo-fusion）

自己の心室脱分極とペースメーカの電気刺激がほぼ同時に発生した際、波形が合体する現象です。

```
【波形比較（自己・融合・偽融合・完全ペーシング）】

① 自己拍動 (Pure Native)       ② 融合収縮 (Fusion)
         ▲                               ▲
        / \                             / \
    ---'   \___                    ───┬'   \___ (スパイクあり、自己とペーシングの中間形)
                                      │

③ 偽融合収縮 (Pseudo-fusion)   ④ 完全ペーシング (Pure Paced)
         ▲                               ┌──┐
        / \                              │  │
    ───┬'  \___ (スパイク重なるが          │  │
       │        波形は自己そのもの)       │  \
                                         │   \____ (CLBBB様 Wide QRS)
```

### 融合現象の詳細比較

| 現象 | スパイクの有無 | QRS形態 | 電気生理学的機序 | 臨床的意義 |
| :--- | :---: | :--- | :--- | :--- |
| **完全ペーシング**<br/>（Pure Paced Beat） | あり | 完全なペーシング波形<br/>（Wide QRS） | ペースメーカ刺激のみで心室全体が脱分極。 | 正常作動。 |
| **フュージョンビート**<br/>（Fusion Beat: 融合収縮） | あり | **自己波形とペーシング波形の中間形** | 自己伝導による心室内脱分極とペーシング刺激による脱分極が**同時に心筋を興奮・合体**したもの。 | **正常な競合現象**。<br/>センシング不全ではない。 |
| **シュードフュージョン**<br/>（Pseudo-fusion: 偽融合収縮） | あり | **自己固有のQRS波形と完全に一致** | 自己脱分極が始まった直後（心室リードがまだ感知できない極初期）に**無駄なスパイクが重なって落ちた**もの。心室捕捉には寄与していない。 | **正常タイミングの境界現象**。<br/>スパイクが出ても心室は既に自己興奮で不応期のため影響なし。 |

> [!IMPORTANT]
> **心電図検定・臨床での注意点**
> フュージョンビートやシュードフュージョンビートを見て、「自己波形が出ているのにスパイクが出ているからアンダードセンシング（感知不全）だ！」と誤認しないように注意が必要です。
> 自己心拍のタイミングとペースメーカのタイマー満了がミリ秒単位で一致した際に生じる**正常な生理的現象**です。

## 4. 心房ペーシング波形の特徴

- **右心耳（RAA）ペーシング**: 洞結節近傍からの興奮伝播となるため、II, III, aVF で陽性の正常洞性P波に極めて類似したP波を形成。
- **低位右房・冠静脈洞開口部ペーシング**: 下から上へ興奮が広がるため、II, III, aVF で深い**陰性P波**を形成。

---

## 5. 心電図所見の記載例

```text
【心電図所見】
洞調律 72bpm。
調律の移行部において、心室ペーシングスパイクに続いて自己QRS波形と右室ペーシング波形の中間形態を示すQRS波（融合収縮: Fusion beat）を認める。
持続する心室ペーシング時はV1でQS型、II・III・aVFで深い陰性QRS（右室心尖部ペーシング波形）を呈する。

【診断】
正常ペースメーカ作動（間欠的自己調律出現に伴うFusion beat）

【判定】
機能異常なし
```
