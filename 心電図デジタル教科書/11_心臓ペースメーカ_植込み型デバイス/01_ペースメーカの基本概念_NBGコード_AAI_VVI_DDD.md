# ⚙️ ペースメーカの基本概念・NBGコード（AAI / VVI / DDD）

心臓ペースメーカは、徐脈性不整脈（洞不全症候群、房室ブロック等）に対して人工的な電気刺激を与えて心拍数を維持し、心拍出量を確保する植込み型医療機器です。

---

## 1. NBGコード（NASPE/BPEG Generic Code）の体系

ペースメーカの作動モードは、国際標準である**NBGコード（5文字表記）** で定義されます。通常は最初の3文字（またはレート応答「R」を含めた4文字）が臨床で頻用されます。

| 桁（Position） | 項目名 | 定義と記号 |
| :---: | :--- | :--- |
| **第1文字** | **ペーシング心腔**<br/>（Chamber Paced） | **A**: 心房（Atrium）<br/>**V**: 心室（Ventricle）<br/>**D**: 両方（Dual: A+V）<br/>**O**: なし（None） |
| **第2文字** | **センシング心腔**<br/>（Chamber Sensed） | **A**: 心房（Atrium）<br/>**V**: 心室（Ventricle）<br/>**D**: 両方（Dual: A+V）<br/>**O**: なし（None） |
| **第3文字** | **応答様式**<br/>（Response to Sensing） | **I**: 抑制（Inhibited: 自己心拍感知でペーシング休止）<br/>**T**: トリガー（Triggered: 感知と同時にペーシング出力）<br/>**D**: 二重応答（Dual: 心房感知で心室トリガー/心房抑制、心室感知で心室抑制）<br/>**O**: なし（None: 固定レート同期なし） |
| **第4文字** | **レート応答機能**<br/>（Rate Modulation） | **R**: あり（Rate responsive: 体動センサー/呼吸センサー等で労作時に自動増拍）<br/>**O**: なし |
| **第5文字** | **多部位ペーシング**<br/>（Multisite Pacing） | **A**: 心房多部位<br/>**V**: 心室多部位（両室ペーシング/CRT）<br/>**D**: 両方 |

## 2. 主要ペーシングモードの作動機序と適応

```mermaid
graph TD
    A["徐脈性不整脈の診断"] --> B{"房室伝導能の評価"}
    B -->|"正常（房室ブロックなし）<br/>洞不全症候群 (SSS)"| C["\"AAI / AAIR<br/>(心房のみ刺激・感知")"]
    B -->|"心房細動 (AF) 合併徐脈<br/>心房機能消失"| D["\"VVI / VVIR<br/>(心室のみ刺激・感知")"]
    B -->|"房室ブロック (AVB)<br/>洞機能正常〜低下"| E["\"DDD / DDDR<br/>(房室同期ペーシング")"]
```

### 主要モードの比較

| モード | ペーシング部位 | センシング部位 | 動作特徴 | 主な適応疾患 | 長所と短所 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **AAI** | 心房 | 心房 | 自己P波があれば抑制、なければ心房ペーシング（自己房室伝導を利用） | 房室伝導が正常な洞不全症候群（SSS） | **長所**: 最も生理的<br/>**短所**: 房室ブロック合併時に心停止 |
| **VVI** | 心室 | 心室 | 自己QRSがあれば抑制、なければ心室ペーシング | 徐脈性心房細動、慢性AFに伴う停止 | **長所**: リード1本で簡便<br/>**短所**: ペースメーカ症候群（房室不同期） |
| **DDD** | 心房 ＋ 心室 | 心房 ＋ 心室 | 心房・心室の自己心拍を監視し、房室同期を保ちつつ必要時にペーシング | 房室ブロック、洞不全症候群＋房室伝導障害 | **長所**: 房室同期維持、心拍出量最大化<br/>**短所**: リード2本必要、PMTのリスク |
| **DDDR** | 心房 ＋ 心室 | 心房 ＋ 心室 | DDDの機能 ＋ 体動加速度センサー等で労作時にレート自動上昇 | 変時不全（労作時に心拍数が上がらない病態） | **長所**: 労作耐用能の著明な改善 |

## 3. ペースメーカの基本タイミングパラメータ

```
【DDDモードのタイミング周期】
     心房スパイク                 心室スパイク
         │                            │
         ▼ (心房ペーシング)            ▼ (心室ペーシング)
       ┌─┐                          ┌──┐
       │ │  P波                      │  │  QRS
   ────┘ └──/\───────────────────────┘  └───/\/\───────
       ├────────────┤
          AVディレイ (AV delay)
       ├─────────────────────────────────────────────┤
              基本レート間隔 (Lower Rate Interval)
                    ├─────────────────┤
                      PVARP (心室後心房不応期)
```

### 必須用語とタイミング解説
1. **下限レート（LRL: Lower Rate Limit / 基本レート）**:
   - 自己心拍が出現しない場合に維持する最低心拍数（通常 $60\,\text{bpm} = 1000\,\text{ms}$）。
2. **上限レート（URL: Upper Rate Limit / MTR: Maximum Tracking Rate）**:
   - 心房自己頻拍（AF, AT等）に追従して心室をペーシングする上限心拍数（通常 $120 \sim 130\,\text{bpm}$）。
3. **房室遅延時間（AV delay）**:
   - 心房興奮（自己Pまたは心房ペーシング）から心室ペーシングを出力するまでの設定待機時間（通常 $150 \sim 200\,\text{ms}$）。
4. **心室後心房不応期（PVARP: Post-Ventricular Atrial Refractory Period）**:
   - 心室ペーシング（または自己QRS）の直後、**心室から心房へ逆行性に伝わった興奮（VA逆伝導）を心房リードが誤感知しないように設定された心房不応期**。

## 4. ペースメーカ誘発性頻拍（PMT: Pacemaker-Mediated Tachycardia）

DDDペースメーカにおける重要な合併症で、**無限ループ頻拍（Endless Loop Tachycardia: ELT）** とも呼ばれます。

```mermaid
graph LR
    A["\"心室ペーシング (またはPVC")"] -->|"心室から心房へ逆伝導 (VA逆伝導)"| B["逆行性P'波の発生"]
    B -->|"PVARP終了後に心房リードが感知 (AS)"| C["心房センシング"]
    C -->|"AV delay経過後"| D["\"心室ペーシング出力 (VP")"]
    D -->|"再び逆伝導"| A
```

### PMTの特徴と対策
- **心電図特徴**: 上限レート（MTR: 120〜130bpm付近）に張り付いた規則的なWide QRS頻拍（心室ペーシング波形）。
- **発生契機**: PVC（心室期外収縮）や心房センシング脱落に伴うVA逆伝導。
- **対策プログラミング**:
  1. **PVARPの延長**: 逆行性P波を不応期内に落とし込んで感知させない。
  2. **自動PMT停止機能（PMT Termination Algorithm）**: MTR連続時に自動的に1周期だけPVARPを延長してループを遮断。

> [!TIP]
> **マグネット（磁石）によるPMTの緊急停止**
> ペースメーカ植込み部に専用マグネットを当てると、**センシング機能が無効化され非同期固定ペーシング（DOO / VOOモード、85〜100bpm）** に切り替わるため、PMTループを即座に強制停止できます。

## 5. 心電図所見の記載例

```text
【心電図所見】
心室ペーシング調律 60bpm（完全ペーシング）。
各QRS波の直前に明瞭なペーシングスパイクを認め、QRS波形は完全左脚ブロック様・下方誘導（II, III, aVF）で深い陰性（右室心尖部ペーシングパターン）。
自己P波に対して設定AVディレイ（180ms）で心室ペーシングが出力されている（VAT/DDD同期動作）。

【診断】
DDDペースメーカ作動（正常房室同期ペーシング）

【判定】
ペースメーカ機能正常
```
