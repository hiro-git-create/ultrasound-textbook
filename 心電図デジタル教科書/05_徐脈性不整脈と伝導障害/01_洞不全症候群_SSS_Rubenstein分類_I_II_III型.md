# 01 洞不全症候群 (SSS) とRubenstein分類 (I・II・III型)

洞不全症候群（Sick Sinus Syndrome: SSS）は、心臓の自然ペースメーカである**洞結節（Sinoatrial Node: SA node）のインパルス自動能の低下**、または**洞房伝導（SA伝導）の障害**により、生体が必要とする心拍数を維持できなくなる症候群です。倦怠感、立ちくらみ、労作時息切れ、さらには失神（Adams-Stokes発作）などの多彩な症状を惹起します。

---

```mermaid
    Patho --> SSS_III["\"【III型】徐脈頻脈症候群 (BTS")<br>"心房頻拍/AF停止後のオーバードライブ抑制\""]
```

## 2. Rubenstein分類（ルーベンスタイン分類）と心電図特徴

臨床現場および心電図検定において最も広く用いられる国際的分類です。

```mermaid
graph LR
    SSS["\"洞不全症候群 (Rubenstein分類")"]
    SSS --> Type1["【I型】持続性洞性徐脈<br>・安静時 HR < 50 bpm<br>・運動時にも心拍上昇不良"]
    SSS --> Type2["\"【II型】洞停止 / 洞房ブロック<br>・長い休止期 (通常 > 2〜3秒")<br>"・補充収縮の遅延\""]
    SSS --> Type3["\"【III型】徐脈頻脈症候群 (BTS")<br>"・発作性AF/AFL/AT停止直後に<br>　長時間の洞停止が出現し失神\""]
```

| 分類 | 名称・病態 | 心電図所見 | 臨床的特徴・注意点 |
| :--- | :--- | :--- | :--- |
| **I型** | **持続性洞性徐脈**<br>(Persistent sinus bradycardia) | - 覚醒・安静時にも **心拍数 < 50 bpm** が持続。<br>- P波の形態は正常洞性。<br>- 運動やアトロピン投与でも十分な心拍数上昇が得られない（変時応答不全）。 | 健常アスリートの生理的徐脈や甲状腺機能低下症、β遮断薬・Ca拮抗薬等の薬剤性徐脈との鑑別が必須。 |
| **II型** | **洞停止 / 洞房ブロック**<br>(Sinus arrest / SA exit block) | - 突然の **P波消失を伴う長い休止期（Pause）**。<br>- 洞停止: 休止期が基本PP間隔の非整数倍。<br>- 洞房ブロック: 休止期が基本PP間隔の正確な整数倍（2倍、3倍など）。 | 休止期が **3秒以上**（無症候でも5秒以上）に及ぶ場合、失神や脳虚血症状を高頻度に引き起こす。[[04_洞停止_洞房ブロック_徐脈性心房細動]] |
| **III型** | **徐脈頻脈症候群**<br>(Bradycardia-Tachycardia Syndrome: BTS) | - 発作性心房細動（PAF）、心房粗動、心房頻拍などの頻脈発作が停止した瞬間に、**長時間の洞停止（Overdrive suppression）** が出現する。 | **最も失神（Adams-Stokes発作）を起こしやすい型**。頻脈に対する抗不整脈薬が徐脈を悪化させるため治療が極めて困難。血栓塞栓症（脳梗塞）リスクが高い。 |

## 4. 治療戦略とペースメーカ適応（JCS 2024年ガイドライン）

> [!IMPORTANT]
> **SSSにおけるペースメーカ植込みの基本原則**
> - **有症候性（症状と心電図所見の一致）が絶対条件**です。無症候性の徐脈単独では原則としてペースメーカ適応になりません。
> - ただし、**無症候であっても洞停止が5秒を超える場合や、運動耐容能の著明な低下がある場合**は適応（Class IIa）が考慮されます。

```mermaid
graph TD
    SSS_Treat["洞不全症候群の治療方針"]
    
    SSS_Treat --> Step1["\"原因薬剤 (β遮断薬, ジギタリス, 非ジヒドロピリジン系Ca拮抗薬, 抗不整脈薬") の中止・減量"]
    
    SSS_Treat --> Step2["\"永久ペースメーカ植込み術 (有症候性徐脈")"]
    Step2 --> Mode_AAI["房室伝導が正常な場合: AAIモード"]
    Step2 --> Mode_DDD["\"房室伝導障害合併・疑い: DDDモード (最も推奨")"]
    
    SSS_Treat --> Step3["\"III型 (BTS") の抗凝固療法"]
    Step3 --> Anticoag["心房細動合併例として CHADS2 / CHA2DS2-VASc スコアに基づき DOAC 導入"]
```

## 5. レポート記載例

### Rubenstein II型（洞停止）のレポート
```text
【心電図所見】
洞調律（基礎心拍数 52bpm）。
記録開始後 4.2秒目に先行P波を伴わない突然の心停止（Pause: 最大 3.8秒間）を認める。
その後、房室接合部補充収縮が出現し洞調律へ復帰。

【診断】
洞不全症候群 (Rubenstein II型: 洞停止 3.8秒)
【推奨コメント】
長時間の洞停止を認めます。めまいやふらつき、失神の既往を確認してください。有症候性であれば永久ペースメーカ植込みの適応となります。
```

### Rubenstein III型（徐脈頻脈症候群: BTS）のレポート
```text
【心電図所見】
発作性心房細動（心室拍数 約140bpm）が持続。
心房細動停止直後に 4.6秒間の長大な洞停止（Overdrive suppression）が出現し、失神前駆症状（眼前暗黒感）を自覚。その後徐脈性洞調律（42bpm）に復帰。

【診断】
洞不全症候群 (Rubenstein III型: 徐脈頻脈症候群)
【至急対応コメント】
頻脈停止後の著明な洞停止による脳虚血発作です。直ちにペースメーカ植込みの適応評価および心源性脳塞栓症予防のための抗凝固療法（DOAC）導入を検討してください。
```
