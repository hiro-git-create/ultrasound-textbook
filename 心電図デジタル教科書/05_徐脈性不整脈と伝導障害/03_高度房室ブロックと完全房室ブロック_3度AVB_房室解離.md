# 03 高度房室ブロックと完全房室ブロック (3度AVB・房室解離)

完全房室ブロック（Complete Atrioventricular Block: CAVB / 3度AVB）および高度房室ブロック（High-grade AVB）は、心房から心室への興奮伝導が広範または完全に遮断される最重症の伝導障害です。心室は下位の自律的ペースメーカ（補充調律）に依存するため、著明な徐脈、心拍出量低下、Adams-Stokes発作（失神）、さらには心停止（Asystole）をきたす致死的不整脈です。

---

## 1. 高度房室ブロック（Advanced / High-grade AV Block）

```mermaid
graph LR
    Def["高度房室ブロックの定義"]
    Def --> Consec["\"連続する2拍以上のP波が心室へ伝導せず脱落<br>(例: 3:1 伝導, 4:1 伝導")"]
    Def --> Status["\"房室伝導能が極限まで低下した状態<br>(完全房室ブロックの一歩手前")"]
```

- **心電図特徴**:
  - P波の2拍以上が連続してブロックされ、QRS波が欠落します。
  - ときおり1拍だけ心室へ伝導（捕捉拍動: Capture beat）が認められます。
- **危険度**: いつ完全房室ブロックや心室静止に移行してもおかしくないため、**完全房室ブロックと同等の緊急度**として扱います。

---

## 2. 完全房室ブロック（3度AVB）の電気生理と診断基準

```mermaid
graph TD
    SA["\"洞結節 (SA node")<br>"心房レート: 60〜100 bpm (P-P間隔一定")"] 
    --> Atria["\"心房の脱分極 (P波")"]
    
    Atria -.->|⚡ 房室伝導 100% 完全遮断| BlockSite["房室結節 / ヒス束 / 脚"]
    
    SubPacer["\"下位ペースメーカ (補充調律")<br>"心室レート: 20〜50 bpm (R-R間隔一定")"] 
    --> Ventricles["\"心室の脱分極 (QRS群")"]
    
    Atria --- Independent["\"【完全房室解離】<br>P波とQRS群は互いに全く無関係に独立して拍動<br>(心房レート > 心室レート")"]
    Ventricles --- Independent
```

### 完全房室ブロック（3度AVB）の確定診断基準
1. **P-P間隔が一定**: 洞結節からのインパルスにより、P波は規則正しく出現します（洞性頻脈を伴うことも多い）。
2. **R-R間隔が一定**: 下位中枢からの自律的「補充調律（Escape rhythm）」により、QRS波は規則正しく出現します。
3. **心房拍数 ＞ 心室拍数**: **P波のレート（通常 60〜100 bpm）が QRS群のレート（通常 20〜50 bpm）より常に高い**。
4. **房室伝導の完全な消失（房室解離）**: P波とQRS群の間に一定の前後関係（PQ時間）が全く存在しない。P波がST部分やT波の頂部、QRS内部に偶然重なり合って波形を歪ませます。

---

## 3. 補充調律の発生部位による分類とリスク

完全房室ブロック発生時、心室の拍動を維持する「補充調律（Escape rhythm）」の発生部位により、血行動態の安定性と危険度が決定されます。

```mermaid
graph TD
    Escape["\"補充調律 (Escape Rhythm") の部位"]
    
    Escape --> Junction["\"【房室接合部補充調律】(Junctional")<br>"・ブロック部位: 房室結節内 (Supra-Hisian")<br>"・QRS幅: Narrow QRS (< 0.10s")<br>"・レート: 40〜60 bpm<br>・安定度: 比較的安定, アトロピン反応あり\""]
    
    Escape --> Ventricular["\"【心室補充調律】(Ventricular / Idioventricular")<br>"・ブロック部位: ヒス束下・脚プルキンエ系 (Infra-Hisian")<br>"・QRS幅: 幅広い Wide QRS (≥ 0.12s")<br>"・レート: 20〜40 bpm<br>・安定度: 極めて不安定, 突然の心停止・TdPリスク高\""]
```

| 項目 | 房室接合部補充調律 (Junctional) | 心室補充調律 (Idioventricular) |
| :--- | :--- | :--- |
| **QRS幅** | **Narrow QRS**（正常形態 $<0.10$秒） | **Wide QRS**（脚ブロック型 $\ge 0.12$秒） |
| **心拍数 (レート)** | **40〜60 bpm** | **20〜40 bpm**（極度の徐脈） |
| **発生頻度・好発** | 下壁心筋梗塞、ジギタリス中毒 | 前壁心筋梗塞、広範心筋線維化、Lenègre病 |
| **安定性・予後** | 比較的保たれる（自律神経に反応） | **極めて不安定**（突然消失して心静止を起こす） |
| **薬物反応性** | アトロピンで心拍数増加が期待できる | アトロピン無効（イソプロテレノールのみ一部反応） |

## 4. 「房室解離」と「完全房室ブロック」の厳密な概念整理

> [!NOTE]
> **用語の厳密な使い分け**
> - **房室解離 (AV Dissociation)**: 心房と心室が独立して興奮している「現象そのもの」を指す広い用語。
> - **完全房室ブロック (Complete AVB)**: 房室伝導が遮断された結果として生じる「病理的房室解離」。

```mermaid
graph TD
    AVD["\"房室解離 (AV Dissociation") の分類"]
    
    AVD --> Patho["伝導障害による房室解離<br>【完全房室ブロック】<br>心房レート ＞ 心室レート"]
    
    AVD --> Physio["\"頻拍・促進調律による房室解離<br>【干渉性房室解離 (Interference Dissociation")】<br>"心室レート ＞ 心房レート<br>（例: VT, AIVR, 接合部頻拍 JT）\""]
```

- **心室頻拍（VT）やAIVRでの房室解離**: 心室の自動能が洞結節より速いため、房室結節が逆行性不応期となり心房の興奮が心室へ伝わらない「生理的・干渉的」な解離です（房室ブロックではありません）。

## 6. レポート記載例

### 心室補充調律を伴う完全房室ブロック（超緊急）
```text
【心電図所見】
心房調律: P波は規則的 (PP間隔 720ms, 心房拍数 83bpm)。
心室調律: 幅広いQRS波 (QRS幅 158ms, RR間隔 1880ms, 心室拍数 32bpm, 心室補充調律)。
P波とQRS群は完全に独立して拍動しており、房室伝導は完全に途絶している (心房拍数 > 心室拍数)。
P波がT波およびST部に偶然重なり認める。

【診断】
完全房室ブロック (Complete AV Block: 3度AVB)、心室補充調律 (32bpm)
【至急対応コメント】
🚨 致死的な重症徐脈性不整脈です。失神（Adams-Stokes発作）や心室細動（TdP）への進展リスクが極めて高いため、直ちにモニター装着・経皮ペーシング準備を行い、循環器当直医へコールして一時的ペーシング留置および恒久ペースメーカ植込みをご手配ください。
```
