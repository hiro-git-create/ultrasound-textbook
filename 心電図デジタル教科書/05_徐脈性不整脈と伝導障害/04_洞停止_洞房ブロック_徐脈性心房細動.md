# 04 洞停止・洞房ブロック・徐脈性心房細動

長大な心休止期（Pause）や高度な徐脈を呈する代表的病態として、洞結節の自動能停止である「洞停止」、洞結節から心房への伝導障害である「洞房ブロック」、そして心房細動に高度な房室伝導抑制が加わった「徐脈性心房細動」があります。それぞれのメカニズムと心電図上の鑑別点を解説します。

---

```mermaid
    Gen --> Trans
    Trans -.->|出口で伝導ブロック| SABlock["\"【洞房ブロック (SA Block")】<br>"休止期はPP間隔の正確な整数倍\""]

```

## 2. 洞停止（Sinus Arrest / Sinus Pause）の診断

```mermaid
graph LR
    Arrest_Def["\"洞停止 (Sinus Arrest")"]
    Arrest_Def --> P1["洞結節のインパルス生成が一時的に完全に停止"]
    Arrest_Def --> P2["\"P波もQRS波も出現しない平坦な基線 (休止期")"]
    Arrest_Def --> P3["【極めて重要】<br>休止期の長さは、直前の基本PP間隔の『整数倍にならない』"]
```

- **心電図特徴**:
  - 規則的なP-P間隔の途中で、突然P波とQRS波が消失します。
  - 休止期（Pause）の時間は、**直前の基本P-P間隔の整数倍（2倍、3倍など）と一致せず、中途半端な長さ**になります。
  - 長大な休止期の後に、房室接合部補充収縮または洞性P波が出現して再開します。

---

## 3. 洞房ブロック（Sinoatrial Exit Block: SA Block）の診断と分類

洞結節内でインパルスは生成されていますが、**周囲の心房作業心筋への出口で伝導がブロック**される病態です。

```mermaid
graph TD
    SAB["\"洞房ブロック (SA Block") の分類"]
    
    SAB --> First["\"1度洞房ブロック<br>(洞房伝導時間の延長: 体表心電図では判読不能")"]
    
    SAB --> Second_I["\"2度洞房ブロック Type I (Wenckebach型")<br>"・洞房伝導時間が漸増<br>・PP間隔が拍動ごとに徐々に短縮<br>・脱落時の休止期は基本PP間隔の2倍未満\""]
    
    SAB --> Second_II["\"2度洞房ブロック Type II (Mobitz II型")<br>"・洞房伝導は一定のまま突然ブロック<br>・【決定的特徴】休止期の長さが<br>　基本PP間隔の『正確な整数倍 (2倍・3倍等")』になる"]
    
    SAB --> Third["\"3度洞房ブロック (完全洞房ブロック")<br>"(体表心電図上は洞停止と区別不能")"]
```

## 4. 洞停止 vs 洞房ブロック 徹底比較表

| 鑑別項目 | 洞停止 (Sinus Arrest) | 2度洞房ブロック Type II (Mobitz II型) | 2度洞房ブロック Type I (Wenckebach型) |
| :--- | :--- | :--- | :--- |
| **病態** | 洞結節の**インパルス発生停止** | 洞結節出口の**完全伝導途絶** | 洞結節出口の**伝導漸減・遅延** |
| **休止期の長さ** | **基本PP間隔の非整数倍**<br>（全く無関係な時間） | **基本PP間隔の正確な整数倍**<br>（正確に2倍、3倍、4倍） | **基本PP間隔の2倍未満**<br>（脱落直前のPPは最短） |
| **休止期前後のPP間隔** | 復帰後のPP間隔は不規則になりやすい | 前後のPP間隔は完全に一定 | PP間隔が徐々に短縮した後に脱落 |
| **臨床的重症度** | 3秒以上でAdams-Stokes発作リスク | 2〜3拍連続脱落で高度徐脈・失神 | 迷走神経緊張などで比較的良性 |

## 5. 徐脈性心房細動（AF with Slow Ventricular Response）

心房細動（AF）が存在する中で、房室結節の伝導能低下や薬剤性抑制により、心室拍数が著明に低下（$< 50$ bpm）した状態です。

```mermaid
graph TD
    AF_Slow["\"徐脈性心房細動 (Slow AF") の心電図所見"]
    AF_Slow --> Fwave["\"① P波消失、基線の不規則な微細波 (f波")"]
    AF_Slow --> Irreg["\"② RR間隔は不規則 (絶対的不整") だが間隔が著明に延長 (HR < 50 bpm)"]
    AF_Slow --> Pause["\"③ 長大な心室休止期 (RR pause > 3.0秒以上") を認める"]
    
    AF_Slow --> Danger["🚨 超重要ピットフォール:<br>【AF ＋ 完全房室ブロック】の合併"]
    Danger --> Danger_Desc["\"f波が存在するにもかかわらず、<br>『RR間隔が完全に規則正しく一定 (40〜50bpm")』になった場合<br>"＝ ジギタリス中毒・完全房室ブロックのサイン！\""]
```

> [!CAUTION]
> **AFなのにRR間隔が規則正しい場合の危険信号（ジギタリス中毒）**
> - 心房細動の本質は「絶対的不整（RR間隔が完全にバラバラ）」です。
> - もし **「心房細動（f波）の基線なのに、QRSが完全に等間隔（規則的）に出現」** している場合、心房からの無秩序な興奮が房室結節で100%ブロックされ、下位の房室接合部が自律的に規則正しく拍動（接合部補充調律）していることを示します。
> - **原因**: **ジギタリス過剰投与・中毒**、高度高カリウム血症、重症心筋症など。

## 6. レポート記載例

### 2度洞房ブロック（Mobitz II型）のレポート
```text
【心電図所見】
洞調律（基礎心拍数 60bpm、基本PP間隔 1000ms）。
第4拍目の後に突然P波・QRS波が1拍脱落し、2000ms（基本PP間隔の正確に2.0倍）の休止期を認める。
休止期の前後でPP間隔の変動は認めず。

【診断】
2度洞房ブロック (Mobitz II型 / Type II SA exit block)
【コメント】
洞結節出口の一時的な伝導途絶を認めます。自覚症状（眼前暗黒感・めまい）の有無を確認し、頻発や長大化を認める場合はホルター心電図精査を推奨します。
```

### 徐脈性心房細動（長大ポーズ合併）のレポート
```text
【心電図所見】
心房細動調律（P波消失、基線に細動f波を認める）。
心室拍数は平均 44bpm と徐脈傾向。
記録中、最大 4.1秒間の長大な心室休止期（RR pause）を認め、その後に幅狭い接合部補充収縮が出現。

【診断】
徐脈性心房細動 (Atrial Fibrillation with Slow Ventricular Response)、長大心室休止期 (4.1秒)
【至急対応コメント】
🚨 著明な長大休止期を伴う徐脈性心房細動です。房室結節抑制薬（β遮断薬、Ca拮抗薬、ジギタリス等）の内服状況を確認し、中止・減量をご検討ください。有症候性または薬剤中止後も持続する場合はペースメーカ植込み（VVI/DDD）適応の評価が必要です。
```
