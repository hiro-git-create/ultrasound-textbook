# 02 房室ブロック (AVB) 1度・2度 (Wenckebach型 vs Mobitz II型)

房室ブロック（Atrioventricular Block: AVB）は、心房から心室への電気的興奮伝播が、房室結節（AV node）、ヒス束（Bundle of His）、または脚・プルキンエ線維網のいずれかの部位で遅延または途絶する病態です。重症度およびブロック部位（結節内 vs 結節下）によって臨床的リスクと治療方針が根本的に異なります。

---

## 1. 房室伝導系の解剖とブロック部位による予後の違い

```mermaid
    AVN --> His["\"ヒス束 (Bundle of His")"]
    His --> Infra["\"脚・プルキンエ系<br>【結節下: Infra-Hisian】<br>・全か無かの伝導・Na依存性<br>・Mobitz II型 (予後不良・PM適応")"]
```

| ブロック部位 | 生理学的特性 | 代表的波形 | QRS幅 | 運動・アトロピン時の変化 | 予後・危険度 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **結節内<br>(Supra-Hisian)** | 刺激頻度が増えると伝導が遅延する（漸減伝導） | 1度AVB、Wenckebach型2度AVB | **Narrow QRS**（正常幅） | 改善する（交感神経緊張で伝導促進） | **良好**（加齢・迷走神経緊張・薬剤性） |
| **結節下<br>(Infra-Hisian)** | 閾値を超えると突然完全にブロックする（全か無か） | Mobitz II型2度AVB、高度AVB | **Wide QRS**（脚ブロック合併） | **悪化する**（心拍数増加でブロック増悪） | **不良**（心停止・完全房室ブロックへ移行） |

## 2. 1度房室ブロック（First-degree AV Block）

```mermaid
graph LR
    First_AVB["1度房室ブロックの定義"]
    First_AVB --> PR["\"PQ (PR") 時間 > 0.20 秒 (200ms)"]
    First_AVB --> Ratio["\"房室伝導比 1:1<br>(すべてのP波の後にQRS波が必ず追従する")"]
```

- **心電図特徴**:
  - PQ（PR）時間が 0.20秒（記録速度25mm/sで大マス1個＝5小マス）を超えて延長。
  - P波の脱落は認められず、すべての心房興奮が心室へと伝導します。
- **臨床的意義**:
  - 多くは無症候性で生理的（迷走神経緊張）または薬剤性（β遮断薬、Ca拮抗薬、ジギタリス）。
  - **著明なPQ延長（Marked First-degree AVB: PQ > 0.30秒）**: 心室収縮が著しく遅れることで左房収縮期に房室弁が既に閉じている、または拡張末期に逆流が生じ、**ペースメーカ症候群様の心不全症状（呼吸困難・動悸）** を呈することがあり、ペーシング適応の検討対象となります。

## 3. 2度房室ブロック：Wenckebach型 vs Mobitz II型

心房からのインパルスが間欠的に心室へ伝導できず、**P波に続くQRS波が脱落**する病態です。

```mermaid
graph TD
    Second_AVB["2度房室ブロックの鑑別"]
    
    Second_AVB --> Wenck["\"【Wenckebach型 (Mobitz I型")】<br>"① PQ時間が1拍ごとに徐々に延長<br>② ついにP波が1拍脱落 (QRS欠落")<br>"③ 脱落直後のPQ時間は最短<br>④ RR間隔は次第に短縮する\""]
    
    Second_AVB --> Mobitz["\"【Mobitz II型】<br>① 先行PQ時間は完全に一定 (正常または延長")<br>"② 前兆なく突然P波が脱落<br>③ 脱落前後のPQ時間に変化なし<br>④ QRS幅が広いことが多い (脚ブロック合併")"]
```

### Wenckebach型（Mobitz I型）の周期的メカニズム
1. **PQ時間の漸増**: 房室結節の疲弊により、拍動を重ねるごとに伝導時間が長くなります（$PQ_1 < PQ_2 < PQ_3$）。
2. **QRS脱落**: 房室結節の不応期にぶつかり、P波が完全に遮断されます。
3. **RR間隔のパラドックス（漸減）**: PQ時間の「増分（増加幅）」は最初が最も大きく徐々に小さくなるため、**脱落直前のRR間隔は次第に短縮**します。
4. **リセット**: 休止期（脱落）によって房室結節が休息し、次の拍動のPQ時間は最短に戻ります。

---

### Wenckebach型 vs Mobitz II型 徹底鑑別表

| 鑑別ポイント | Wenckebach型 (Mobitz I型) | Mobitz II型 (Mobitz II) |
| :--- | :--- | :--- |
| **脱落直前のPQ時間** | **徐々に延長する（漸増）** | **完全に一定（不変）** |
| **脱落直後のPQ時間** | **最も短い（リセット）** | **脱落前と同一** |
| **QRS波の幅** | 通常 **Narrow QRS** ($<0.10$秒) | 通常 **Wide QRS** ($\ge 0.12$秒, 脚ブロック型) |
| **ブロックの解剖部位** | **房室結節内 (Supra-Hisian)** | **ヒス束内 / ヒス束下 (Infra-Hisian)** |
| **運動・交感神経緊張** | 伝導改善（P-Q短縮、脱落消失） | **伝導悪化（ブロック頻度増加）** |
| **迷走神経刺激 (頸動脈マッサージ)** | 伝導悪化（脱落増加） | 変化なし、または心房レート低下により伝導改善 |
| **アトロピン投与** | 伝導改善 | 伝導悪化（心房拍数増加に耐えられない） |
| **予後とペースメーカ適応** | **良性**（原則無症候なら経過観察） | **悪性・高リスク**（**無症候でもClass IIa/I適応**） |

---

## 4. 2:1 房室ブロックの鑑別ピットフォール

> [!CAUTION]
> **2:1房室ブロックはWenckebachかMobitz IIか？**
> P波が2回に1回脱落する「2:1房室ブロック」では、伝導する拍動が1つしかないため「PQが延長しているか一定か」を比較できません。
> 
> **【2:1 AVBの鑑別手順】**
> 1. **QRS幅の確認**: Narrow QRSなら結節内（Wenckebach型由来）の可能性が高く、Wide QRS（脚ブロック合併）なら結節下（Mobitz II型由来）の可能性が高い。
> 2. **運動負荷 / アトロピン投与**: 心拍数を上げた際に **1:1伝導へ改善すればWenckebach型**、**3:1や完全房室ブロックへ悪化すればMobitz II型**。
> 3. **長期モニタリング**: 前後の記録で 3:2 や 4:3 のWenckebach周期が出現しないかを確認する。

## 5. レポート記載例

### Wenckebach型2度房室ブロック（良性・夜間出現）
```text
【心電図所見】
洞調律 58bpm。
PQ時間が 180ms → 240ms → 300ms と段階的に延長した後に、4拍目のP波が心室へ伝導せずQRS波が脱落している（4:3 Wenckebach周期）。
QRS幅は 84ms (Narrow QRS)。

【診断】
2度房室ブロック (Wenckebach型 / Mobitz I型)
【コメント】
結節内伝導障害による良性の不整脈所見です。自覚症状（めまい・失神等）がなく、日中活動時に改善していれば経過観察可能です。
```

### Mobitz II型2度房室ブロック（高リスク・要精査）
```text
【心電図所見】
洞調律 72bpm。
PQ時間は 160ms で完全に一定のまま、前触れなく突然2拍に1拍の頻度でP波の後にQRS波が脱落している。
QRS幅 136ms、V1誘導にて rsR' パターン（完全右脚ブロック合併）。

【診断】
2度房室ブロック (Mobitz II型)、完全右脚ブロック (CRBBB)
【至急対応コメント】
🚨 結節下（ヒス-プルキンエ系）の重篤な伝導障害です。完全房室ブロックへの移行およびAdams-Stokes発作の危険性が極めて高いため、直ちに循環器専門医へコンサルトし、入院・恒久ペースメーカ植込みをご検討ください。
```
