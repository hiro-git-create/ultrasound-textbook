# 01 電気軸の判定法と軸偏位 正常軸・左軸・右軸・極度の軸偏位

平均前額面QRS電気軸（Mean Frontal QRS Axis）は、心室脱分極時に発生する無数の電気双極子を統合した**「心室全体の平均的な興奮方向ベクトル」**です。電気軸の評価は、心臓の解剖学的位置、心室肥大（左室・右室）、室内伝導ブロック（左脚前枝・後枝ブロック）、心筋梗塞巣の局在を瞬時に推測するための最重要ステップです。

---

## 1. カブレラ六軸座標系（Cabrera's Hexaxial Reference System）

前額面6誘導（I, II, III, aVR, aVL, aVF）は、心臓を中心とする $360^\circ$ の円上に $30^\circ$ 間隔で配置されています。

```mermaid
graph TD
    subgraph Hexaxial["カブレラ六軸座標系の角度配置"]
        aVL["\"aVL: -30° (左上方")"]
        I["\"I 誘導: 0° (真左")"]
        II["\"II 誘導: +60° (左下方")"]
        aVF["\"aVF: +90° (真下")"]
        III["\"III 誘導: +120° (右下方")"]
        aVR["\"aVR: -150° (右上方")"]
    end
```

### 電気軸の4大区分と角度定義（日本不整脈心電学会・AHA基準）

| 区分 | 角度範囲 | I 誘導の極性 | aVF 誘導の極性 | II 誘導の極性 |
| :--- | :--- | :--- | :--- | :--- |
| **正常軸 (Normal Axis)** | **$-30^\circ \sim +90^\circ$** | **上向き (+)** | **上向き (+)** | **上向き (+)** |
| **左軸偏位 (LAD)** | **$-30^\circ \sim -90^\circ$** | **上向き (+)** | **下向き (-)** | **下向き (-)** |
| **右軸偏位 (RAD)** | **$+90^\circ \sim +180^\circ$** | **下向き (-)** | **上向き (+)** | 不問（通常 +） |
| **極度の軸偏位 / 不定軸<br>(Extreme / Northwest Axis)** | **$-90^\circ \sim 180^\circ$** | **下向き (-)** | **下向き (-)** | 不問（通常 -） |

---

## 2. 3秒でできる実践的電気軸判定法（Quadrant法 ＋ II誘導チェック）

臨床現場や心電図検定では、**I誘導、aVF誘導、II誘導の3つのQRS主極性（上向きか下向きか）**を見るだけで $100\%$ 正確に判定できます。

```mermaid
graph TD
    Start["電気軸判定開始"] --> CheckI{"\"I 誘導の主極性は？<br>(R波 > S波 か？")"}
    
    CheckI -- "陽性 (+) [上向き]" --> CheckaVF1{"aVF 誘導の主極性は？"}
    CheckI -- "陰性 (-) [下向き]" --> CheckaVF2{"aVF 誘導の主極性は？"}
    
    CheckaVF1 -- "陽性 (+) [上向き]" --> Normal["\"✅ 正常軸 (0° 〜 +90°")"]
    CheckaVF1 -- "陰性 (-) [下向き]" --> CheckII{"II 誘導の主極性は？"}
    
    CheckII -- "陽性 (+) [上向き]" --> Normal2["\"✅ 正常軸 (-30° 〜 0°")<br>"(生理的左軸")"]
    CheckII -- "陰性 (-) [下向き]" --> LAD["\"🚨 左軸偏位 (-30° 〜 -90°")<br>"(Left Axis Deviation")"]
    
    CheckaVF2 -- "陽性 (+) [上向き]" --> RAD["\"🚨 右軸偏位 (+90° 〜 +180°")<br>"(Right Axis Deviation")"]
    CheckaVF2 -- "陰性 (-) [下向き]" --> Extreme["\"🚨 極度の軸偏位 / 不定軸<br>(-90° 〜 180°: Northwest")"]
```

> [!IMPORTANT]
> **なぜ I(+) ＆ aVF(-) のときに「II誘導」を見るのか？**
> aVFが陰性（$-90^\circ \sim 0^\circ$ の象限）であっても、**$0^\circ \sim -30^\circ$ は正常軸の許容範囲**です。
> II誘導の誘導軸は $+60^\circ$ であり、これに直交する境界線は **$-30^\circ$（$+60^\circ - 90^\circ$）** です。
> したがって、**II誘導が上向き（陽性）なら $-30^\circ$ より下（正常軸）**、**II誘導が下向き（陰性）なら $-30^\circ$ より上（真の左軸偏位）** と一発で切り分けられます。

---

## 3. 精密な電気軸算出法（等電位誘導直交法）

度数単位（例: $-45^\circ$, $+105^\circ$）で精密に電気軸を求める場合は、「等電位誘導（Equiphasic lead）」を用います。

```mermaid
graph LR
    Step1["\"① 肢誘導6誘導の中で<br>R波高とS波深さが最も等しい<br>(代数和 ≒ 0") 誘導を探す"] --> Step2["② その誘導の軸角度に対して<br>『90°直交する誘導』を特定"]
    Step2 --> Step3["\"③ 直交誘導の極性が陽性(+")なら<br>"その誘導の角度そのものが電気軸！\""]
```

- **具体例**:
  - aVL誘導（$-30^\circ$）で $R = S$（等電位）であった場合：
  - aVLに直交する誘導は **II誘導（$+60^\circ$）**。
  - II誘導のQRSが陽性（上向き）であれば、電気軸は **$+60^\circ$** と精密に求まります。

## 4. 左軸偏位（Left Axis Deviation: $-30^\circ \sim -90^\circ$）の鑑別

```mermaid
graph TD
    LADcauses["左軸偏位の主要原因"]
    LADcauses --> LAFB["\"① 左脚前枝ブロック (LAFB")<br>"【最多原因】軸 ≤ -45°, I/aVL qR, II/III/aVF rS\""]
    LADcauses --> LVH["\"② 左室肥大 (LVH")<br>"起電力増大による左上方シフト\""]
    LADcauses --> InfMI["\"③ 下壁心筋梗塞 (Inferior MI")<br>"下壁壊死Q波による相対的上向きベクトル\""]
    LADcauses --> WPWb["\"④ WPW症候群 (B型")<br>"右室自由壁・中隔副伝導路\""]
    LADcauses --> Congenital["\"⑤ 先天性心疾患<br>心内膜床欠損症 (ECD/AVSD"), 三尖弁閉鎖症"]
```

| 鑑別疾患 | 心電図特徴 | 発生機序・鑑別ポイント |
| :--- | :--- | :--- |
| **左脚前枝ブロック (LAFB)** | **軸 $\le -45^\circ$**<br>I, aVL: **qR型**<br>II, III, aVF: **rS型** | 左室前側壁への伝導遅延により終末ベクトルが左上方へ向く（[[03_左脚前枝ブロック_LAFB_と左脚後枝ブロック_LPFB]]）。 |
| **左室肥大 (LVH)** | 軸 $-30^\circ \sim -60^\circ$<br>Sokolow-Lyon / Cornell陽性 | 左室心筋重量の増大によるベクトルの左偏位。 |
| **陳旧性下壁心筋梗塞** | II, III, aVF で**異常Q波（QS型）** | 下壁の起電力喪失により、健常な前側壁ベクトルの残存（上方化）。 |
| **心内膜床欠損症 (ECD)** | **著明な左軸偏位（$-60^\circ \sim -120^\circ$）** | 先天的な房室結節・刺激伝導系の後下方偏位。小児・若年者で特徴的。 |

## 5. 右軸偏位（Right Axis Deviation: $+90^\circ \sim +180^\circ$）の鑑別

```mermaid
graph TD
    RADcauses["右軸偏位の主要原因"]
    RADcauses --> RVH["\"① 右室肥大 (RVH") / 肺性心<br>"肺高血圧症, COPD, V1高R波\""]
    RADcauses --> PE["\"② 急性肺血栓塞栓症 (APE")<br>"急性右心負荷 (S1Q3T3パターン")"]
    RADcauses --> LPFB["\"③ 左脚後枝ブロック (LPFB")<br>"軸 ≥ +120°, I/aVL rS, II/III/aVF qR\""]
    RADcauses --> LatMI["④ 高位側壁心筋梗塞<br>I, aVLの起電力喪失"]
    RADcauses --> LeadError["\"⑤ 電極付け間違い (RA-LA逆付け") / 右心症"]
    RADcauses --> ThinBody["\"⑥ 若年痩身者・無力体質 (垂直心")"]
```

| 鑑別疾患 | 心電図特徴 | 臨床的背景・鑑別点 |
| :--- | :--- | :--- |
| **右室肥大 (RVH)** | 軸 $>+110^\circ$<br>V1 で **R/S > 1.0**、右室ストレイン | 肺高血圧、肺動脈弁狭窄、慢性肺疾患（[[04_右室肥大_RVH_および両室肥大の心電図基準]]）。 |
| **急性肺塞栓症 (PE)** | 急速に出現した右軸偏位<br>**S1Q3T3**, 右胸部T陰転化 | 急激な肺動脈圧上昇に伴う右室拡大（急性右心不全）。 |
| **左脚後枝ブロック (LPFB)** | **軸 $\ge +120^\circ$**<br>I, aVL: **rS型**<br>III, aVF: **qR型** | 左脚後枝単独障害。右室肥大の除外が必須（稀な病態）。 |
| **右手-左手電極逆付け** | **I誘導でP-QRS-T全陰性** | 胸部誘導は正常（[[03_四肢電極の付け間違いパターンと見分け方]]）。 |

## 6. S1-S2-S3 パターンと極度の軸偏位（不定軸）

- **S1-S2-S3 パターン**: I, II, III のすべての肢誘導において、深くて幅広いS波（$S \ge R$）を認める状態。
  - **電気軸**: 心室終末部ベクトルが上後方（$-90^\circ \sim -150^\circ$）を向くため、**不定軸（Indeterminate axis / Northwest axis）** となります。
  - **臨床的意義**: 慢性閉塞性肺疾患（COPD）、肺性心、右室流出路肥大、あるいは若年健常者の正常変異。
- **心室頻拍（VT）の鑑別**: Wide QRS頻拍で極度の軸偏位（Northwest axis: $-90^\circ \sim 180^\circ$）を認めた場合、上室性頻拍（SVT）ではなく **心室頻拍（VT）** を強く支持する決定打となります。
