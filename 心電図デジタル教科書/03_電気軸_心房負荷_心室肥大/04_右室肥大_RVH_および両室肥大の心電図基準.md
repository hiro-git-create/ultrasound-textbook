# 04 右室肥大（RVH）および両室肥大の心電図基準

右室肥大（Right Ventricular Hypertrophy: RVH）は、肺動脈性肺高血圧症、慢性血栓塞栓性肺高血圧症（CTEPH）、肺塞栓症、慢性閉塞性肺疾患（COPD/肺性心）、先天性心疾患（ASD, PS, Fallot四徴症）などに伴い右室圧・容量負荷が増大して生じます。健常心では左室の大きな起電力に隠されていた右室ベクトルが、右室肥大により前面・右側へ露出し、**V1誘導での高いR波**や**著明な右軸偏位**として現れます。

## 2. 右室肥大（RVH）の心電図診断基準（JCS / AHA / Myers基準）

以下の基準項目のうち、複数の所見が重複して陽性となるほどRVHの診断確信度が高まります。

```mermaid
graph TD
    RVHCriteria["\"右室肥大 (RVH") の代表的心電図基準"]
    RVHCriteria --> V1Lead["\"① 右側胸部 (V1") の所見<br>"・R/S比 > 1.0<br>・RV1 ≥ 0.7 mV (7mm")<br>"・qR パターン in V1<br>・VAT > 0.035秒\""]
    RVHCriteria --> V6Lead["\"② 左側胸部 (V5/V6") の所見<br>"・R/S比 ≤ 1.0<br>・SV5/6 ≥ 0.7 mV (7mm")<br>"・時計方向回転 (Clockwise")"]
    RVHCriteria --> LimbLead["\"③ 四肢誘導の所見<br>・右軸偏位 (Axis > +90° または > +110°")<br>"・RaVR ≥ 0.5 mV (5mm")"]
    RVHCriteria --> StrainRV["④ 右室ストレイン所見<br>・V1〜V3 でのST低下＋非対称陰性T"]
```

| 誘導領域 | 診断基準パラメータ | カットオフ値 | 臨床的意義・解説 |
| :--- | :--- | :--- | :--- |
| **右側胸部 (V1)** | **$\text{V}_1 \text{ R/S比}$** | **$> 1.0$** | 正常（$r < S$）の逆転。RVHの最重要指標。 |
| | **$\text{RV}_1$ 電位** | **$\ge 0.7\text{ mV}$ ($7\text{ mm}$)** | 右室前方起電力の増大。 |
| | **$\text{SV}_1$ 電位** | **$< 0.2\text{ mV}$ ($2\text{ mm}$)** | S波の消失・減高。 |
| | **$\text{V}_1$ 波形パターン** | **$\text{qR}$ 型** | 重症右室肥大に極めて特異的（右房拡大・中隔偏位）。 |
| | **$\text{V}_1 \text{ VAT}$ (興奮時間)** | **$> 0.035\text{ 秒}$ ($35\text{ ms}$)** | 右室自由壁の肥厚による興奮到達遅延。 |
| **左側胸部 (V5/V6)** | **$\text{V}_5/\text{V}_6 \text{ R/S比}$** | **$\le 1.0$** | 左室側誘導でS波がR波を凌駕。 |
| | **$\text{SV}_5$ または $\text{SV}_6$** | **$\ge 0.7\text{ mV}$ ($7\text{ mm}$)** | 右後方への終末部引き戻しベクトル。 |
| **四肢誘導** | **平均QRS電気軸** | **$> +90^\circ$（特に $> +110^\circ$）** | 右軸偏位（RAD）。 |
| | **$\text{RaVR}$ 電位** | **$\ge 0.5\text{ mV}$ ($5\text{ mm}$)** | aVR誘導（$-150^\circ$）に向かうベクトルの増大。 |
| **ST-T変化** | **右室ストレイン** | **V1〜V3 のST低下 ＋ 陰性T波** | 右室収縮期圧過負荷（二次性再分極異常）。 |
| **心房波** | **肺性P波** | **II, III, aVF で P波高 $\ge 0.25\text{ mV}$** | 右房負荷の合併（[[02_心房負荷_右房負荷_左房負荷_両房負荷の心電図基準]]）。 |

> [!IMPORTANT]
> **不完全右脚ブロック（IRBBB）と右室肥大（RVH）の鑑別**
> - **IRBBB**: V1で $rsR'$ 型（ウサギの耳型）を呈し、QRS幅は $0.10 \sim 0.11\text{s}$。心房中隔欠損症（ASD）などの**右室容量過負荷**で頻見。
> - **純粋なRVH**: V1で単相性の高いR波（$R$ または $qR$ 型）を呈し、右軸偏位と右室ストレインを伴う。肺高血圧症などの**右室圧過負荷**で典型的。

## 3. 両室肥大（Biventricular Hypertrophy: BVH）の心電図基準

両室肥大では、左室の起電力（左後方）と右室の起電力（右前方）が**互いに電気的に相殺（Cancelling effect）**し合うため、心電図単独での診断感度は約 $30 \sim 50\%$ と低くなります。以下の特異的所見の組み合わせを見逃さないことが肝要です。

```mermaid
graph TD
    BVH["\"両室肥大 (BVH") の診断アプローチ"]
    BVH --> KW["\"① Katz-Wachtel現象 (中間胸部誘導")<br>"V2〜V4 で巨大等二相性QRS群<br>(R + S ≥ 5.0 mV / 50mm")"]
    BVH --> Comb1["\"② LVH基準 ＋ 右軸偏位 (> +90°")<br>"(左側誘導高電位 ＋ 肢誘導右偏")"]
    BVH --> Comb2["\"③ RVH基準 (V1 R/S>1") ＋ 左側胸部巨大R波<br>"(V1高R波 ＋ V5/V6高R波")"]
    BVH --> Comb3["\"④ 心房と心室の交差負荷<br>(左房負荷 ＋ 右室肥大 / 右房負荷 ＋ 左室肥大")"]
```

### (1) Katz-Wachtel現象（カッツ・ワハテル現象）
- **心電図特徴**: **胸部中間誘導（V2, V3, V4）において、巨大な等二相性（Equiphasic）QRS群** が出現する現象。
- **診断基準**: **$\text{R波の高さ} + \text{S波の深さ} \ge 5.0\text{ mV}$（$50\text{ mm}$ / 大マス10個分以上）**
- **臨床的背景**: 先天性心疾患（心室中隔欠損症 VSD、動脈管開存症 PDA）、複合弁膜症、両心室に著明な負荷がかかる病態で極めて特異的です。

$$\text{Katz-Wachtel Criteria: } \text{Amp}(\text{R}_{\text{V2-V4}}) + \text{Amp}(\text{S}_{\text{V2-V4}}) \ge 5.0\text{ mV} \ (50\text{ mm})$$

### (2) その他の両室肥大診断パターン一覧表

| パターン | 心電図所見の組み合わせ | メカニズム |
| :--- | :--- | :--- |
| **パターン A** | **左室肥大の電圧基準（Sokolow-Lyon $\ge 3.5\text{mV}$ 等）**<br>　$+$ **明瞭な右軸偏位（$\text{Axis} > +90^\circ$）** | 左室肥大による高電位と、右室肥大による電気軸の右方牽引。 |
| **パターン B** | **V1誘導で $\text{R}/\text{S} > 1.0$（RVH基準）**<br>　$+$ **V5/V6誘導で $\text{R} \ge 2.5\text{ mV}$（高電位）** | 右室前方起電力と左室側方起電力の双方が残存。 |
| **パターン C** | **左房負荷（僧帽性P波 / Morris指数陽性）**<br>　$+$ **右室肥大所見（V1高R波、右軸偏位）** | 僧帽弁狭窄症（MS）に伴う左房圧上昇 ＋ 反応性肺高血圧症による右室肥大。 |
| **パターン D** | **右房負荷（肺性P波）**<br>　$+$ **左室肥大所見（LVH基準陽性）** | 拡張型心筋症、虚血性心筋症、重症心不全の末期像。 |

## 4. 臨床・心電図検定での要点チェック

1. **急性肺塞栓症（APE）での一過性右室負荷**:
   - 突然発症の呼吸困難・ショック時、**急速な右軸偏位**、**S1Q3T3パターン（I誘導深いS波、III誘導Q波＋陰性T波）**、**V1〜V3のT波陰転化**が出現します（[[04_急性心膜炎_心筋炎_たこつぼ心筋症_肺塞栓_S1Q3T3]] 参照）。
2. **小児・新生児心電図の生理的右室優位**:
   - 乳幼児は胎児循環の名残で生理的右室優位（右軸偏位、V1高R波）が正常です。成人基準を機械的に当てはめないよう注意が必要です。
