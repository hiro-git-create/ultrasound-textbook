# 02 心房負荷 右房負荷・左房負荷・両房負荷の心電図基準

心房負荷（Atrial Enlargement / Overload）は、心房壁の肥大、心房腔の拡大、または心房内圧の上昇によって**P波の形態・電位（高さ）・幅（時間）・極性**が変形する病態です。左右の心房脱分極は時間差（右房先行 $\rightarrow$ 左房遅延）をもって進行するため、心房負荷の心電図変化は「高さの変化（右房）」と「幅・終末陰性波の変化（左房）」として明確に分離して現れます。

```mermaid
        L_LA["\"左房成分が遅延・拡大<br>(伝導遅延・後方起電力増大")"] --> L_Sum
    end
```

## 2. 右房負荷（Right Atrial Enlargement: RAE / 肺性P波）

右房肥大・拡大では、心房脱分極前半の起電力が増大し、左房成分と重なり合って上方に突出します。

```mermaid
graph LR
    subgraph RAE_Criteria["右房負荷の主要心電図基準"]
        II["\"肢誘導 (II, III, aVF")<br>"P波高 ≥ 0.25 mV (2.5 mm")<br>"尖鋭な立ち上がり (テント状")"]
        V1["\"V1, V2 誘導<br>初期陽性P波 ≥ 0.15 mV (1.5 mm")"]
        Duration["\"P波幅<br>正常範囲 (≤ 0.11 秒")"]
    end
```

### (1) 心電図診断基準（JCS / AHA）
1. **肢誘導（特に II, III, aVF）**: **P波の高さ $\ge 0.25\text{ mV}$（$2.5\text{ mm}$ / 2.5小マス以上）**
2. **右側胸部誘導（V1, V2）**: **P波初期陽性成分の高さ $\ge 0.15\text{ mV}$（$1.5\text{ mm}$）**
3. **P波幅**: **正常（$\le 0.11\text{ 秒}$）**（左房伝導は正常なため幅は広がらない）
4. **P波電気軸**: 右方シフト（$+75^\circ \sim +90^\circ$）

### (2) 主な原因疾患
- **慢性閉塞性肺疾患（COPD）・肺気腫・肺線維症**（肺性心: Cor Pulmonale）
- **肺動脈性肺高血圧症（PAH）**、**慢性血栓塞栓性肺高血圧症（CTEPH）**
- **先天性心疾患**: 肺動脈弁狭窄症（PS）、Ebstein奇形、心房中隔欠損症（ASD）、Fallot四徴症
- **三尖弁疾患**: 三尖弁閉鎖不全症（TR）、三尖弁狭窄症（TS）

---

## 3. 左房負荷（Left Atrial Enlargement: LAE / 僧帽性P波）

左房肥大・拡大では、左房脱分極の完了が遅延し、後方への起電力が増大します。

```mermaid
graph LR
    subgraph LAE_Criteria["左房負荷の主要心電図基準"]
        II_LAE["\"I, II 誘導<br>P波幅 ≥ 0.12 秒 (120 ms")<br>"ノッチ間隔 ≥ 0.04 秒 (二峰性")"]
        V1_LAE["\"V1 誘導: Morris指数陽性<br>終末陰性波 幅 ≥ 0.04s ＆ 深さ ≥ 1mm<br>(面積積 ≤ -0.04 mm·s")"]
    end
```

### (1) 心電図診断基準（JCS / AHA）
1. **肢誘導（I, II 誘導）**: **P波幅 $\ge 0.12\text{ 秒}$（$120\text{ ms}$ / 3小マス以上）**
2. **二峰性P波（僧帽性P波: P mitrale）**: P波の2つのピーク（頂点）間の距離が **$\ge 0.04\text{ 秒}$（$40\text{ ms}$ / 1小マス以上）**
3. **V1誘導 Morris指数（Morris Index / P terminal force in V1）陽性**:
   - V1終末部陰性波の「幅（秒）」$\times$「深さ（mm）」 $\le -0.04\text{ mm}\cdot\text{s}$
   - 実務的判定: **終末陰性波が「幅 $\ge 0.04\text{s}$（1小マス）」かつ「深さ $\ge 1.0\text{mm}$（1小マス）」**

$$\text{Morris Index} = \text{Duration}_{\text{negative}} (\text{s}) \times \text{Depth}_{\text{negative}} (\text{mm}) \le -0.04\text{ mm}\cdot\text{s}$$

```mermaid
graph TD
    Morris["V1誘導 Morris指数の判定"]
    Morris --> P_Pos["\"初期陽性成分 (右房脱分極: 前方")"]
    Morris --> P_Neg["\"終末陰性成分 (左房脱分極: 後方")<br>"深さ ≥ 1mm (0.1mV")<br>"幅 ≥ 0.04s (40ms")"]
    P_Neg --> Judge["\"🚨 Morris指数陽性 ➔ 左房負荷 (LAE")"]
```

### (2) 主な原因疾患
- **僧帽弁疾患**: 僧帽弁狭窄症（MS: 典型的な僧帽性P波）、僧帽弁閉鎖不全症（MR）
- **高血圧性心疾患**: 左室拡張不全（舒張期コンプライアンス低下による左房圧上昇）
- **大動脈弁疾患**: 大動脈弁狭窄症（AS）、大動脈弁閉鎖不全症（AR）
- **心筋症**: 肥大型心筋症（HCM）、拡張型心筋症（DCM）

## 4. 両房負荷（Biatrial Enlargement: BAE）の診断基準

左右両方の心房に負荷がかかっている場合、右房負荷の「高いP波」と左房負荷の「幅広い二峰性・Morris指数陽性」が同時に出現します。

```mermaid
graph TD
    BAE["\"両房負荷 (BAE") の診断"]
    BAE --> C1["パターン①<br>II誘導で P波高 ≥ 0.25mV かつ P波幅 ≥ 0.12s"]
    BAE --> C2["\"パターン②<br>II誘導で 肺性P波 (≥0.25mV") ＋ V1誘導で Morris指数陽性"]
    BAE --> C3["\"パターン③<br>V1誘導で 巨大二相性P波<br>(初期陽性 ≥0.15mV ＋ 終末陰性 ≥1mm/0.04s")"]
```

| 診断パターン | 心電図所見 |
| :--- | :--- |
| **基準 ①** | **II 誘導で P波高 $\ge 0.25\text{ mV}$（$2.5\text{ mm}$）** かつ **P波幅 $\ge 0.12\text{ 秒}$（$120\text{ ms}$）** |
| **基準 ②** | **肢誘導（II, III, aVF）で肺性P波（高P波）** を認め、同時に **V1誘導でMorris指数陽性（深い終末陰性波）** |
| **基準 ③** | **V1誘導で初期陽性波 $\ge 0.15\text{ mV}$** かつ **終末陰性波の深さ $\ge 1\text{ mm}$ かつ幅 $\ge 0.04\text{ s}$**（巨大二相性P波） |

- **主な原因疾患**: リウマチ性多弁膜症（MS ＋ TR等）、拘束型心筋症（アミロイドーシス等）、高度心不全。

## 5. 心房負荷の鑑別対照表とピットフォール

| 項目 | 正常 P波 | 右房負荷 (RAE: 肺性P) | 左房負荷 (LAE: 僧帽性P) | 両房負荷 (BAE) |
| :--- | :--- | :--- | :--- | :--- |
| **II誘導 高さ** | $\le 0.25\text{ mV}$ | **$\ge 0.25\text{ mV}$ (高尖)** | $\le 0.25\text{ mV}$ (通常) | **$\ge 0.25\text{ mV}$** |
| **II誘導 幅** | $\le 0.11\text{ s}$ | $\le 0.11\text{ s}$ (正常) | **$\ge 0.12\text{ s}$ (幅広)** | **$\ge 0.12\text{ s}$** |
| **II誘導 形態** | なだらかなドーム状 | 鋭利なテント状・ピラミッド状 | **二峰性（ノッチ間 $\ge 0.04\text{s}$）** | 二峰性または高尖幅広 |
| **V1誘導 形態** | 浅い二相性 | **初期陽性波 $\ge 0.15\text{ mV}$** | **終末陰性波 $\ge 1\text{mm} \times 0.04\text{s}$** | **巨大二相性P波** |
| **P波 電気軸** | $+30^\circ \sim +75^\circ$ | **右偏 ($+75^\circ \sim +90^\circ$)** | 正常または左偏 ($-30^\circ \sim +30^\circ$) | 不定 |

> [!WARNING]
> **心電図検定での頻出ピットフォール**
> 1. **洞性頻脈時のP波偽高電位**: 心拍数が $100\text{ bpm}$ を超えると、先行するT波や心房再分極波（Ta波）の落ち込みと重なり、正常心房でもII誘導のP波が $0.25\text{ mV}$ を超えることがあります。心拍数が落ち着いた状態で再評価が必要です。
> 2. **心房内伝導障害（IAB）との鑑別**: 左房腔の拡大がなくても、加齢や線維化でBachmann束の伝導が遅延するとP波幅が $\ge 0.12\text{s}$ に拡大します（[[01_P波_PQ時間_PR部分の成り立ちと計測]] 参照）。
