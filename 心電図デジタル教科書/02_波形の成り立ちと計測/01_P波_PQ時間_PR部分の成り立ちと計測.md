# 01 P波・PQ時間・PR部分の成り立ちと計測

P波およびPQ（PR）時間は、**心房の脱分極**および**心房から心室（房室結節・ヒス・プルキンエ系）への興奮伝導**を表す極めて重要な指標です。P波の極性・幅・高さ、そしてPQ時間の正確な計測により、調律の起源（洞調律か異所性か）、心房負荷、房室伝導ブロック、早期興奮症候群（WPW症候群）、さらには急性心膜炎の早期診断が可能です。

---

## 1. P波の電気生理学的成り立ち

P波は、洞結節で発生した興奮が左右の心房作業心筋を伝播・脱分極する際に生じる電位変化です。

```mermaid
graph TD
    SAN["\"洞結節 (SA node") 発火"] --> RA["\"右心房脱分極 (P波前半成分")<br>"ベクトル: 前・下・右方向\""]
    SAN -->|"Bachmann束 経由"| LA["\"左心房脱分極 (P波後半成分")<br>"ベクトル: 後・下・左方向\""]
    RA & LA --> Pwave["\"合成P波 (体表面心電図")<br>"全体ベクトル: 左前下方 (+60°")"]
```

- **右心房（RA）脱分極（前半 0.04〜0.06秒）**: 上大静脈開口部付近の洞結節から下方・前方・わずかに右方へ進行。
- **左心房（LA）脱分極（後半 0.04〜0.06秒）**: Bachmann束を介して伝播し、後方・左方・下方へ進行。
- **合成ベクトル**: 前額面では左下方（約 $+60^\circ$）を向き、水平面ではわずかに左後方を向きます。

---

## 2. 正常P波の基準値と洞調律の判定条件

標準12誘導心電図における正常P波の形態と計測基準値は以下の通りです。

```mermaid
graph LR
    subgraph PwaveNormal["正常P波の基準値"]
        W["\"幅 (Duration")<br>"≤ 0.11 秒 (110 ms")<br>"< 3小マス\""]
        H["\"高さ (Voltage")<br>"≤ 0.25 mV (2.5 mm")<br>"肢誘導 (II誘導")"]
        V1["\"V1誘導 形態<br>二相性 (+ / -")<br>"終末部深さ < 1mm\""]
    end
```

| 計測項目 | 正常基準値 | 計測方法・誘導 | 異常時の代表的病態 |
| :--- | :--- | :--- | :--- |
| **P波 幅 (時間)** | **$\le 0.11\text{ s}$ ($110\text{ ms}$)** | 最も幅広い誘導（通常 II または V1） | $\ge 0.12\text{ s}$: 左房負荷（[[02_心房負荷_右房負荷_左房負荷_両房負荷の心電図基準]]）、心房内伝導障害（IAB） |
| **P波 高さ (電位)** | **$\le 0.25\text{ mV}$ ($2.5\text{ mm}$)** | 肢誘導（特に II 誘導）で計測 | $>0.25\text{ mV}$: 右房負荷（肺性P波） |
| **胸部P波 高さ** | **$\le 0.15\text{ mV}$ ($1.5\text{ mm}$)** | V1, V2 誘導で計測 | $>0.15\text{ mV}$: 右房負荷 |
| **P波 極性** | **陽性 (+)**: I, II, aVF, V4〜V6<br>**陰性 (-)**: aVR<br>**二相性 ($\pm$)**: V1, III, aVL | 全12誘導で確認 | II, III, aVFで陰性: 低位心房調律・逆行性伝導<br>I誘導で陰性: 電極逆付け、右心症 |

> [!IMPORTANT]
> **「正常洞調律（Normal Sinus Rhythm: NSR）」の厳密な定義**
> 1. **P波が II, III, aVF で直立（陽性）**、かつ **aVR で陰性**であること。
> 2. P波に続いて一定のPQ時間をおいて **QRS群が 1:1 で追従** すること。
> 3. 心拍数が **50〜100 bpm**（洞結節の正常発火頻度）であること。

---

## 3. PQ（PR）時間とPR部分の計測と定義

```mermaid
graph LR
    subgraph WaveInterval["波形と間隔の定義"]
        Pstart["P波 開始点"] -->|"PQ (PR) 時間 (0.12〜0.20s)"| Qstart["\"QRS群 開始点 (QまたはR")"]
        Pend["P波 終末点"] -->|"PR 部分 (PR segment)"| Qstart
    end
```

- **PQ（PR）時間（PR Interval）**: P波の開始からQRS群の開始点（Q波があればQ波の始まり、なければR波の始まり）までの時間。
  - **正常値**: **$0.12 \sim 0.20\text{ 秒}$（$120 \sim 200\text{ ms}$ / 3〜5小マス）**
  - **生理的意義**: 洞結節から心房、房室結節、ヒス束、脚、プルキンエ線維を経て心室筋が脱分極を開始するまでの総伝導時間。大部分の遅延は**房室結節（AV node）**で生じます。
- **PR部分（PR Segment）**: P波の終わりからQRS群の開始点までの平坦な区間。
  - 心房の脱分極が完了し、興奮が房室結節・ヒス束を通過している期間に対応します。
  - 通常は等電位線（基線）上に位置します。

---

## 4. PQ（PR）時間延長の鑑別診断

$\text{PQ時間} > 0.20\text{ 秒}$（$200\text{ ms}$、大マス1個超）を認めた場合、**1度房室ブロック（First-degree AV block）**と診断します。

| 原因分類 | 具体的な病態・薬剤 | 機序と特徴 |
| :--- | :--- | :--- |
| **生理的・自律神経性** | ・高アスリート心臓<br>・迷走神経緊張（睡眠時、安静時） | 房室結節の不応期延長。運動やアトロピン投与で正常化。 |
| **薬剤性 (最頻出)** | ・$\beta$遮断薬（ビソプロロール等）<br>・Ca拮抗薬（ベラパミル、ジルチアゼム）<br>・ジギタリス（ジゴキシン）<br>・抗不整脈薬（Ia, Ic, III群） | 房室結節のL型Caチャネル抑制、交感神経抑制。 |
| **虚血性・心疾患** | ・急性下壁心筋梗塞（RCA閉塞）<br>・心筋炎（ウイルス性、膠原病）<br>・サルコイドーシス、アミロイドーシス | 房室結節動脈の虚血、炎症細胞浸潤・線維化。 |
| **変性・加齢** | ・Lenègre病、Lev病 | 刺激伝導系の特発性硬化・石灰化変性。 |

---

## 5. PQ（PR）時間短縮の鑑別診断

$\text{PQ時間} < 0.12\text{ 秒}$（$120\text{ ms}$、3小マス未満）を認めた場合の鑑別疾患です。

```mermaid
graph TD
    ShortPR["\"PQ時間短縮 (<0.12秒")"] --> CheckQRS{"QRS幅の拡大 / デルタ波はあるか？"}
    
    CheckQRS -- "あり (QRS ≥ 0.12s + デルタ波)" --> WPW["\"🫀 WPW症候群 (Wolff-Parkinson-White")<br>"副伝導路 (Kent束") 経由の早期興奮"]
    CheckQRS -- "なし (正常 QRS幅)" --> CheckP{"P波の極性・形態は？"}
    
    CheckP -- "II, III, aVFで陰性P波" --> Junctional["\"⚡ 房室接合部調律 / 低位心房調律<br>(逆行性伝導のため短縮")"]
    CheckP -- "正常洞性P波 (IIで陽性)" --> LGL["\"⏱️ LGL症候群 / 交感神経過緊張<br>(房室結節内の高速伝導")"]
```

1. **WPW症候群（Wolff-Parkinson-White Syndrome）**:
   - 副伝導路（Kent束）が房室結節の生理的遅延をバイパスして心室を早期興奮させる。
   - **短PQ（$<0.12\text{s}$） ＋ デルタ波（$\delta$波） ＋ Wide QRS（$\ge 0.12\text{s}$）** の3徴。
2. **房室接合部調律（Junctional Rhythm）**:
   - 房室結節近傍から逆行性に心房へ、順行性に心室へ伝導するため、P波が陰性化しPQが短縮（またはQRS直後にP波が出現）。
3. **高アドレナリン状態 / 洞性頻脈**:
   - 交感神経刺激により房室結節伝導が加速し、生理的にPQ時間が $0.10 \sim 0.12\text{s}$ へ短縮。

## 6. PR部分（PR segment）の偏位と臨床的意義

PR部分は通常、等電位線（TPセグメント）と同じ高さですが、特定の病態で偏位（上昇または低下）します。

```mermaid
graph LR
    subgraph PRDev["PR部分の偏位"]
        PRDep["\"PR低下 (PR depression")<br>"・急性心膜炎 (広範")<br>"・心房梗塞\""]
        PRAlev["\"PR上昇 (PR elevation")<br>"・aVR誘導での鏡面像<br>・心房梗塞\""]
    end
```

### (1) 急性心膜炎（Acute Pericarditis）
- **特徴的所見**: **広範な誘導（I, II, aVF, V2〜V6）でのPR部分の低下（PR depression）** と、**aVR誘導でのPR部分の上昇（PR elevation）**。
- **機序**: 心膜炎の炎症が心房心外膜筋層（Atrial epicardium）に波及し、心房再分極波（Ta波）が変調してPR部分を基線以下に引き下げる。
- **鑑別**: STEMIではPR偏位は稀であり、急性心膜炎と急性心筋梗塞の超初期鑑別に最も有用なサインです。

## 7. 心房内伝導障害（Interatrial Block: IAB）とBayés症候群

心房間の高速伝導路である **Bachmann束（前結節間路分枝）** の伝導遅延・ブロックにより生じる病態です。

- **部分的IAB（Partial IAB）**:
  - P波幅 $\ge 0.12\text{ 秒}$（$120\text{ ms}$）、P波の頂点が二峰性（Notched P波）。
- **高度IAB（Advanced IAB）**:
  - P波幅 $\ge 0.12\text{ 秒}$ かつ **下壁誘導（II, III, aVF）で二相性（$\pm$: 最初陽性、後半陰性）のP波**。
  - 左心房への興奮がBachmann束を通れず、房室結節部から冠静脈洞付近を経由して「下から上へ」逆行性に左房が脱分極するために生じます。

> [!TIP]
> **Bayés症候群（バイエス症候群）**
> 高度心房内伝導障害（Advanced IAB）に **発作性心房細動（AF）** および心房細動に伴う **心原性脳塞栓症** が高率に合併する臨床症候群です。健診や外来の洞調律心電図で高度IABを発見した場合、無症候性AFのスクリーニング（ホルター心電図等）が強く推奨されます。
