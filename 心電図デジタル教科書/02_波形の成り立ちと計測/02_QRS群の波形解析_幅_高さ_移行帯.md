# 02 QRS群の波形解析 幅・高さ・移行帯

QRS群は**心室作業心筋の脱分極（収縮のトリガー）**を表す心電図の中核波形です。QRS群の幅（時間）、高さ（電位）、胸部誘導における波形の変化（R波増高推移・移行帯）、および心室興奮時間（VAT）を精緻に解析することで、脚ブロック、心室肥大、心室性不整脈、心筋梗塞（壊死）、全身性疾患（アミロイドーシスや心嚢液貯留）の有無を即座に判断できます。

---

## 1. QRS群の構成波と命名規則

QRS波形は各偏位の方向と振幅（大きさ）によって大文字と小文字で厳密に書き分けられます。

```mermaid
graph LR
    subgraph WaveDefinition["QRS構成波の定義"]
        Q["\"Q (q") 波<br>"初期の『下向き』陰性波\""]
        R["\"R (r") 波<br>"最初の『上向き』陽性波\""]
        S["\"S (s") 波<br>"R波に続く『下向き』陰性波\""]
        Rprime["\"R' (r'") 波<br>"S波に続く2番目の『上向き』陽性波\""]
        QS["QS パターン<br>陽性波がなく全波が『下向き』"]
    end
```

- **大文字と小文字の基準**:
  - 振幅 $\ge 0.5\text{ mV}$（$5\text{ mm}$ 以上） $\rightarrow$ **大文字（Q, R, S）**
  - 振幅 $< 0.5\text{ mV}$（$5\text{ mm}$ 未満） $\rightarrow$ **小文字（q, r, s）**
- **代表的表記パターン**:
  - `qR`: 小さな初期陰性波に続く大きな陽性波（左側胸部誘導 V5, V6 の典型）
  - `rS`: 小さな初期陽性波に続く深い陰性波（右側胸部誘導 V1, V2 の典型）
  - `rsR'`: いわゆる「ウサギの耳（M型）」パターン（右脚ブロックの V1）
  - `QS`: 上向きのR波が全く存在しない下向き単相波（広範梗塞巣の壊死波形）

## 2. 心室脱分極の電気生理学的3相

```mermaid
sequenceDiagram
    autonumber
    participant LVSeptum as 心室中隔左室側
    participant FreeWall as 心室自由壁 (内膜→外膜)
    participant Base as 心室基底部・流出路

    LVSeptum->">FreeWall: ① 中隔脱分極 (左→右・前下方")<br>V1: 初期r波 / V6: 中隔q波
    FreeWall->">Base: ② 心室主部脱分極 (左室優位・左後下方")<br>V1: 深いS波 / V6: 高い主R波
    Base-->">Base: ③ 心室基底部脱分極 (上後方")<br>V1/V6: 終末部s波
```

1. **第1相（中隔脱分極: 0.01〜0.02秒）**:
   - 興奮は左脚から中隔左室側へ先行して入力し、**中隔を左から右、かつ前下方へ**伝播。
   - 右側誘導（V1）には向かってくるため「初期小r波」、左側誘導（I, aVL, V5, V6）からは遠ざかるため「初期小q波（中隔q波: septal q）」を形成。
2. **第2相（心室自由壁脱分極: 0.02〜0.06秒）**:
   - プルキンエ線維網から心室自由壁の心内膜側から心外膜側へ興奮。
   - 左室心筋重量は右室の約3倍あるため、電気ベクトルは圧倒的に**左後下方**へ向く。
   - 左側誘導（V5, V6）で「巨大なR波」、右側誘導（V1, V2）で「深いS波」を形成。
3. **第3相（心室基底部脱分極: 0.06〜0.08秒）**:
   - 心室中隔基底部および右室流出路（RVOT）が最後に脱分極。ベクトルは**上後方**へ向き、各誘導の「終末部s波」となる。

## 3. QRS幅（Duration）の計測と臨床的鑑別

QRS幅は、全12誘導の中で最も早く開始する点から最も遅く終了する点までの最大幅を計測します。

```mermaid
graph TD
    QRSwidth["QRS幅の評価"]
    QRSwidth --> NormalQRS["\"正常: 0.06〜0.10秒 (60〜100ms")<br>"1.5〜2.5小マス\""]
    QRSwidth --> Incomplete["\"不完全脚ブロック / 伝導遅延<br>0.10〜0.11秒 (100〜110ms")"]
    QRSwidth --> WideQRS["\"Wide QRS (異常拡大")<br>"≥ 0.12秒 (≥ 120ms")<br>"3小マス以上\""]
```

### Wide QRS（$\ge 0.12\text{ 秒}$）の鑑別診断
QRS幅が $0.12\text{ 秒}$（$120\text{ ms}$）以上に拡大している場合、興奮が特殊刺激伝導系を高速伝導できず、作業心筋間を遅延伝導していることを意味します。

| 鑑別疾患 | 心電図特徴 | 発生機序・鑑別点 |
| :--- | :--- | :--- |
| **完全右脚ブロック (CRBBB)** | V1 で **rsR' (M型)**、I・V6 で **幅広く浅いS波** | 右室への興奮が左室経由で遅延伝播（[[01_完全右脚ブロック_CRBBB_と不完全右脚ブロック_IRBBB]]） |
| **完全左脚ブロック (CLBBB)** | I・aVL・V5・V6 で **幅広ノッチ付きR波**、V1 で **深いQS/rS** | 心室中隔が右から左へ逆転興奮（[[02_完全左脚ブロック_CLBBB_と不完全左脚ブロック]]） |
| **心室期外収縮 (PVC) / 心室頻拍 (VT)** | 先行P波なし、著明なWide QRS（$\ge 0.14\text{s}$）、変形T波 | 心室筋内の異所性フォーカスから発生（[[01_心室期外収縮_PVC_Lown分類と重症度判定]], [[02_心室頻拍_VT_単形性_多形性_鑑別診断_Brugada基準]]） |
| **WPW症候群 (デルタ波)** | **短PQ ($<0.12\text{s}$)** ＋ **QRS立ち上がりの緩徐化（$\delta$波）** | 副伝導路（Kent束）による心室早期興奮（[[03_WPW症候群と副伝導路_Kent束局在診断]]） |
| **高カリウム血症 (重症)** | QRS全般のびまん性拡大、P波平坦化、テント状T波 | 静止膜電位脱分極によるNaチャネル広範不活性化（[[01_高カリウム血症_テント状T波から正弦波まで_低K血症]]） |
| **抗不整脈薬 (Ia/Ic群) 影響** | 心拍数依存性のQRS拡大（Use-dependence） | Naチャネル遮断作用による伝導速度低下（[[04_抗不整脈薬による心電図変化_低体温_Osborn波]]） |

## 4. 胸部誘導における波形推移（R Wave Progression）と移行帯

胸部誘導（V1〜V6）は心臓を水平面で囲むように配置されているため、正常心では右室側から左室側に向かって規則的な波形変化を示します。

```mermaid
graph LR
    V1["\"V1 (rS型")<br>"r < S\""] --> V2["\"V2 (rS型")<br>"r < S\""]
    V2 --> V3["\"V3 (RS型")<br>"R ≈ S\""]
    V3 --> V4["\"V4 (RS型")<br>"R > S\""]
    V4 --> V5["\"V5 (qR型")<br>"高いR波\""]
    V5 --> V6["\"V6 (qR型")<br>"qR型\""]
```

### (1) 移行帯（Transition Zone）の判定
- **定義**: R波とS波の振幅がほぼ等しくなる（$R/S \approx 1$）胸部誘導の位置。
- **正常位置**: **V3 または V4**（心室中隔の電気的位置に対応）。

### (2) 水平面回転（Horizontal Plane Rotation）
心臓の長軸まわりの回転により移行帯が偏位します。

```mermaid
graph TD
    Rotation["水平面回転の分類"]
    Rotation --> CCW["\"反時計方向回転 (Counter-clockwise")<br>"移行帯が V1〜V2 へ左方移動<br>原因: 正常亜型, 左室肥大\""]
    Rotation --> NormalPos["正常移行帯<br>V3〜V4"]
    Rotation --> CW["\"時計方向回転 (Clockwise")<br>"移行帯が V5〜V6 へ右方移動<br>原因: 右室負荷, 肺気腫, 正常亜型\""]
```

### (3) R波増高不良（Poor R Wave Progression: PRWP）
- **定義**: V1からV3にかけてR波が順調に増高せず、**V3誘導におけるR波の高さが $0.3\text{ mV}$（$3\text{ mm}$）未満**にとどまる状態。
- **臨床的鑑別**:
  1. **陳旧性前壁中隔心筋梗塞（OMI）**: 梗塞による起電力喪失。Q波や局所ST-T異常を伴う。
  2. **左室肥大（LVH）**: 右側胸部誘導で左室後壁の強い起電力によりS波が極端に深くなり、見かけ上r波が減高する。
  3. **左脚前枝ブロック（LAFB）**: 初期ベクトルが下方へ向くため、V1〜V3でr波が減高。
  4. **慢性閉塞性肺疾患（COPD）・肺気腫**: 横隔膜低位と肺過膨張による心臓の垂下・右室後方偏位。
  5. **胸部電極の高位肋間誤装着**: 第2・第3肋間に貼ると偽性PRWPとなる。

## 5. QRS電位（Voltage）の異常：低電位と高電位

### (1) 低電位（Low Voltage）の定義と鑑別疾患

```mermaid
graph TD
    LowV["低電位の判定基準"]
    LowV --> LimbLow["\"四肢低電位 (Limb Low Voltage")<br>"四肢全誘導 (I〜aVF") で<br>"最大QRS振幅 < 0.5 mV (5mm")"]
    LowV --> PrecordialLow["\"胸部低電位 (Precordial Low Voltage")<br>"胸部全誘導 (V1〜V6") で<br>"最大QRS振幅 < 1.0 mV (10mm")"]
    LowV --> TotalLow["全誘導低電位<br>四肢・胸部ともに基準合致"]
```

> [!IMPORTANT]
> **低電位を来す3大メカニズムと原因疾患**
> 1. **心臓を取り囲む絶縁体・液体の存在（電気伝導阻害）**:
>    - **心嚢液貯留・心タンポナーデ**（電気的交互脈: Electrical Alternans を伴う）
>    - **多量胸水**、**高度肥満**、**高度皮下浮腫**、**重症肺気腫（過膨張空気）**
> 2. **心筋細胞の脱落・置換（起電力自体の喪失）**:
>    - **心アミロイドーシス**（心エコーで心筋壁肥厚があるにもかかわらず心電図で低電位を呈する「肥厚と低電位の乖離」が極めて特異的）
>    - **広範陳旧性心筋梗塞**、**末期拡張型心筋症**
> 3. **代謝性・内分泌疾患**:
>    - **粘液水腫（重症甲状腺機能低下症）**: 洞徐脈＋低電位＋T波平坦化

### (2) 高電位（High Voltage）
- **判定**: Sokolow-Lyon基準（$SV_1 + RV_{5/6} \ge 3.5\text{ mV}$）など。
- **鑑別**: 左室肥大（LVH）、右室肥大（RVH）、若年健常男子・アスリート（胸壁の薄さと生理的心筋発達）。

## 6. 心室興奮時間（Ventricular Activation Time: VAT）

- **定義**: QRS群の開始点から **R波の頂点（ピーク）** までの時間（固有偏向時間: Intrinsicoid deflection time とも呼ばれる）。
- **生理的意義**: 興奮が心内膜下プルキンエ網から心外膜直下に到達するまでの時間を表す。
- **基準値**:
  - **右側胸部誘導（V1, V2）**: **$\le 0.03\text{ 秒}$（$30\text{ ms}$、3/4小マス）**
  - **左側胸部誘導（V5, V6）**: **$\le 0.05\text{ 秒}$（$50\text{ ms}$、1.25小マス）**
- **異常の意義**:
  - V5/V6 で $>0.05\text{s}$ $\rightarrow$ **左室肥大（LVH）**、**完全左脚ブロック（CLBBB）**
  - V1 で $>0.035\text{s}$ $\rightarrow$ **右室肥大（RVH）**、**完全右脚ブロック（CRBBB）**
