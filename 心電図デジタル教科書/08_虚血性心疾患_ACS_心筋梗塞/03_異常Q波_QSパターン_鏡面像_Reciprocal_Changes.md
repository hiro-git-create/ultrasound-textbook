# 異常Q波・QSパターン・鏡面像（Reciprocal Changes）と急性心筋梗塞の経時的推移

急性心筋梗塞（AMI）において、虚血心筋の壊死（Necrosis）に伴う起電力喪失は **異常Q波（Pathological Q wave）** や **QSパターン** を形成し、梗塞対向壁には **鏡面像（Reciprocal Changes: 鏡像変化）** が出現します。
急性期の超急性T波から慢性期の陳旧性心筋梗塞に至る一連の **経時的心電図推移（Evolution of ECG Changes）** を正確に把握することは、発症時期の推定や治療介入効果の判定に不可欠です。

---

## 1. 急性心筋梗塞の経時的心電図変化（Time Course of AMI）

心筋梗塞の発症から治癒期にかけて、心電図は4つの特徴的なステージを辿ります。

```mermaid
flowchart LR
    Phase1["\"① 超急性期 (数分〜数時間")<br/>巨大高尖T波 (Hyperacute T)<br/>ST上昇開始"] --> Phase2["\"② 急性期 (数時間〜数日")<br/>著明なST上昇 (Pardee波)<br/>R波減高・異常Q波出現"]
    Phase2 --> Phase3["\"③ 亜急性期 (数日〜数週")<br/>ST低下傾向・基線復帰<br/>冠性T波 (対称性深い陰性T)"]
    Phase3 --> Phase4["\"④ 慢性期/陳旧期 (数週〜恒久")<br/>異常Q波/QSパターンの固定<br/>T波の平低化・残存陰性T"]
```

| 病期 (Stage) | 経過時間 | 特徴的心電図所見 | 病態生理・心筋状態 |
| :--- | :--- | :--- | :--- |
| **① 超急性期<br>(Hyperacute phase)** | 発症数分〜数時間 | ・**巨大高尖T波（Hyperacute T wave）**<br>・軽微〜急速なST上昇開始 | 局所細胞内K+漏出による再分極不均一、心内膜下〜貫壁性虚血初期 |
| **② 急性期<br>(Acute phase)** | 数時間〜数日 | ・**ドーム状著明なST上昇（Pardee波）**<br>・**R波の減高**<br>・**異常Q波の出現・増大**<br>・**明瞭な鏡面像（Reciprocal ST低下）** | 全層性心筋虚血および不可逆的壊死の進行、損傷電流の発生 |
| **③ 亜急性期<br>(Subacute phase)** | 数日〜数週間 | ・ST上昇の低下（基線復帰へ向かう）<br>・**深い左右対称性の陰性T波（冠性T波 / PardeeのT波）**<br>・異常Q波の固定 | 壊死組織の線維化置換開始、周囲心筋の再分極遅延 |
| **④ 慢性期・陳旧期<br>(Chronic / OMI)** | 数週間〜恒久 | ・**異常Q波またはQSパターンの残存**<br>・ST部の基線復帰<br>・T波の平低化〜軽度陰性Tの残存 | 瘢痕化（Scarring）完了、起電力の永久欠損 |

## 2. 異常Q波とQSパターンの診断基準と発生機序

### 1) 発生機序：「電気的窓（Electrical Window）」現象
心室壁の全層が壊死すると、その領域の心筋は脱分極起電力を完全に失います。その結果、電極は壊死部をあたかも「窓」のように透過して、**対向する正常な反対側の壁が遠ざかるように脱分極するベクトル（陰性電位）** を直接記録するため、深いQ波（またはR波のないQS波）が形成されます。

```mermaid
flowchart TD
    Necrosis["全層性心筋壊死"] --> Loss["\"壊死領域の脱分極起電力の消失 (0 mV")"]
    Loss --> Window["『電気的窓』の形成"]
    Window --> Record["\"対側壁の脱分極ベクトル (遠ざかる電気") を直視記録"]
    Record --> QWave["初期陰性波 ➔ 異常Q波 / QSパターンの形成"]
```

### 2) 異常Q波（Pathological Q Wave）の診断基準
正常な中隔脱分極による「生理的Q波（Septal Q: 幅 < 0.04s, 深さ < R波の1/4）」と以下の基準で明確に鑑別します。

| 誘導 | 異常Q波の確定診断基準 |
| :--- | :--- |
| **V1, V2, V3 誘導** | **任意の深さのQ波・QSパターンの存在**（※正常ではV1-V3にQ波は存在しない） |
| **I, II, aVL, aVF, V4, V5, V6** | **Q波の幅（時間） ≥ 0.04 秒（40 ms = 1小マス幅）**<br>かつ/または<br>**Q波の深さ ≥ 同一誘導のR波振幅の 1/4（25% 以上）** |
| **aVR 誘導** | ※除外（正常心電図でも深いQS/Qr型を呈するため診断に用いない） |
| **III 誘導単独** | ※要注意（III誘導単独のQ波は健常者の横位心でも多小見られるため、**aVFやII誘導での異常Q波合併** を確認） |

## 3. 鏡面像（Reciprocal Changes / 鏡像変化）

急性ST上昇型心筋梗塞（STEMI）において、梗塞責任領域と空間的に反対側に位置する誘導に現れる **「鏡に映したようなST低下（Reciprocal ST depression）」** を指します。

```mermaid
flowchart LR
    A["\"梗塞部電極 (例: 下壁 II, III, aVF")"] -->|局所ST上昇| B["上向きの損傷電流ベクトル"]
    B -->|反対側電極から見ると遠ざかる| C["\"対向部電極 (例: 高位側壁 I, aVL")"]
    C -->|鏡面像として記録| D["\"著明な下向きST低下 (Reciprocal ST低下")"]
```

### 1) 梗塞部位とReciprocal変化の対照表

| 梗塞責任部位 | ST上昇誘導 (Primary) | 鏡面像 (Reciprocal ST低下誘導) | 臨床的意義 |
| :--- | :---: | :---: | :--- |
| **下壁梗塞 (Inferior)** | **II, III, aVF** | **I, aVL**（高位側壁） | 下壁STEMIの確定診断に極めて有用 |
| **前壁梗塞 (Anterior)** | **V1〜V4** | **II, III, aVF**（下壁） | 広範な前壁心筋虚血を示唆 |
| **高位側壁梗塞 (High Lateral)** | **I, aVL** | **II, III, aVF, V1-V2** | LCxまたはD1閉塞の鑑別に有用 |
| **真性後壁梗塞 (Posterior)** | **V7〜V9** | **V1, V2, V3** (ST低下+高いR波) | 前胸部でのミラー像（V1-V3 ST低下） |

### 2) 鏡面像の臨床的価値
1. **心膜炎（Acute Pericarditis）との決定的な鑑別点**:
   - 急性心膜炎では心膜全体の炎症により **広範な誘導でST上昇** が生じるが、**Reciprocal ST低下は認めない**（aVRおよびV1を除く）。
   - **「aVLや下壁誘導にReciprocal ST低下が存在する ➔ 100% 心筋梗塞（ACS）である」** と判定できます。
2. **早期診断と感度の向上**: ST上昇が軽微（1mm未満）な早期であっても、対向誘導でのReciprocal ST低下が明瞭に出現することが多く、早期覚知の鍵となります。

## 4. 異常Q波の偽陽性・鑑別を要する病態

虚血性心筋梗塞以外にも、以下の病態で異常Q波様波形（Pseudo-infarction pattern）が出現します。

| 非虚血性疾患 | 擬陽性Q波の出現誘導 | 鑑別メカニズム |
| :--- | :---: | :--- |
| **左脚ブロック (CLBBB)** | V1〜V3 (QS型) | 中隔脱分極方向が左➔右から右➔左へ逆転するため |
| **左室肥大 (LVH)** | V1〜V3 (QS/rS型) | 左室後壁の強い後方起電力による前胸部初期起電力のマスク |
| **肥大型心筋症 (HCM)** | I, aVL, V5, V6, 下壁 | 著明な非対称性心室中隔肥大による中隔起電力の巨大化（中隔Q波の深化） |
| **WPW症候群** | 下壁 (II, III, aVF) または 前壁 | 副伝導路を介する早期興奮デルタ波の極性による偽Q波 |
| **急性肺塞栓症 (PE)** | III, aVF (S1Q3T3型) | 急性右室負荷に伴う右室偏位と時計方向回転 |
| **気胸・重度肺気腫** | V1〜V4 (低電位・QS) | 肺内空気貯留による心臓偏位と電位伝播障害 |

## 5. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 洞調律 (Heart Rate: 78 bpm)
・QRS波所見: 
  - V1, V2, V3誘導にてR波が消失し、明瞭なQSパターン (異常Q波) を認める。
  - V4誘導にて幅 45 ms、深さ 4.0 mm の異常Q波 (深さ > R波の1/4) を形成。
・ST-T所見: 
  - V2〜V5誘導にてST部分はほぼ基線へ復帰し、左右対称性の深い冠性陰性T波 (Negative T: -5.0mm) を認める。
  - II, III, aVF誘導での明らかなST-T変化なし。

【総合判定】
亜急性期〜陳旧性前壁中隔心筋梗塞 (Subacute to Old Anteroseptal MI)

【推奨コメント】
左前下行枝領域の貫壁性心筋壊死および亜急性期変化を示唆します。心エコー図検査にて前壁中隔の壁運動異常(Asynergy/Akinesis)および左室収縮機能、左室瘤形成の有無を確認してください。
```
