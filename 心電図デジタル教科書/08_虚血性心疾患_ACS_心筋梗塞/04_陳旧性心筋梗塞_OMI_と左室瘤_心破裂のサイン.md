# 陳旧性心筋梗塞（OMI）・慢性期持続性ST上昇（左室瘤）と致死的機械的合併症（心破裂・中隔穿孔・乳頭筋断裂）

急性心筋梗塞の発症後、数ヶ月以上経過して心筋組織が線維性瘢痕（Scar）に置換された状態を **陳旧性心筋梗塞（Old Myocardial Infarction: OMI）** と呼びます。
慢性期における **異常Q波の残存** や **R波増高不良（Poor R-Wave Progression: PRWP）** の評価に加え、急性期を過ぎてもST上昇が持続する **左室瘤（Left Ventricular Aneurysm）** と急性再発の鑑別、ならびに急性期〜亜急性期に突発する致死的な **機械的合併症（Mechanical Complications: 心破裂、心室中隔穿孔、乳頭筋断裂）** の心電図・臨床サインを網羅します。

---

## 1. 陳旧性心筋梗塞（OMI）の心電図診断基準

```mermaid
flowchart TD
    OMI["\"陳旧性心筋梗塞 (OMI") の3大所見"] --> OMI1["① 固定化した異常Q波 / QSパターン"]
    OMI --> OMI2["\"② 胸部誘導のR波増高不良 (Poor R-Wave Progression: PRWP")"]
    OMI --> OMI3["\"③ 慢性期のT波変化 (平低T波 / 浅い陰性T波")"]
```

### 1) 局在別OMIの確定診断基準
- **前壁・中隔OMI**:
  - V1〜V3におけるQSパターンまたは異常Q波（幅 ≥ 0.04s）。
  - **Poor R-Wave Progression（PRWP）**: 通常V1からV4〜V5へ向かって漸増すべきR波が、V1〜V3で増高せず 3mm 未満（または $RV3 \le 3\text{mm}$ かつ $RV2 \le RV1$）にとどまる。
- **側壁・高位側壁OMI**:
  - I, aVL, V5, V6における異常Q波（幅 ≥ 0.04s かつ/または 深さ ≥ R波の1/4）。
- **下壁OMI**:
  - II, III, aVFにおける異常Q波。
  - ※注意: **III誘導単独のQ波は健常横位心でも出現** するため、aVF誘導（幅 ≥ 0.04s、深さ ≥ 0.5mV）やII誘導での異常Q波合併が必須。吸気時に深呼吸させても消失しない固定性Q波であることを確認。
- **後壁OMI**:
  - V1, V2誘導における高いR波（$R/S \ge 1.0$、R波時間 ≥ 0.04s）および直立陽性T波（後壁の電気的欠損による前胸部への偏位）。

## 2. 左室瘤（Left Ventricular Aneurysm）の心電図診断と急性STEMIとの鑑別

心筋梗塞後、広範な壊死心筋が菲薄化・線維化し、収縮期に外側へ奇異性に突出（Dyskinesia）する状態を **左室瘤** と呼びます（主に前壁心尖部に好発）。

```mermaid
flowchart TD
    Infarct["広範前壁梗塞の治癒期"] --> Thin["\"壊死壁の菲薄化・線維化 (Scar")"]
    Thin --> Bulge["\"収縮期の奇異性突出 (左室瘤: LV Aneurysm")"]
    Bulge --> Tension["梗塞境界部の持続的伸展・機械的ストレス"]
    Tension --> ChronicST["\"発症後2〜3週以上経過しても<br/>V1〜V4で持続するST上昇 (≥ 1mm")"]
```

### 1) 左室瘤の心電図診断基準
1. 急性心筋梗塞発症後、**2〜3週間以上（数ヶ月〜数年）経過しても前胸部誘導（V1-V4）でST上昇（≥ 1mm）が持続** している。
2. 同一誘導において明瞭な **異常Q波またはQSパターン** を伴う。

### 2) 左室瘤（慢性所見） vs 新規急性STEMI（再発）の鑑別法

胸痛を訴えて来院したOMI既往患者の持続性ST上昇が、「以前からの左室瘤」か「新規の急性STEMI」かを鑑別する基準です。

| 鑑別ポイント | 左室瘤 (慢性期所見) | 急性STEMI (新規発症・再発) |
| :--- | :--- | :--- |
| **過去の心電図との比較** | **過去の波形とST上昇度が完全に一致** | 以前と比べて新たにSTがさらに上昇 |
| **T波振幅 / QRS振幅比<br>($T/QRS$ 比 in V1-V4)** | **$T/QRS < 0.36$**（T波が低くQRSに対して目立たない） | **$T/QRS \ge 0.36$**（T波が高く尖鋭化） |
| **鏡面像 (Reciprocal ST低下)** | **認めない**（下壁誘導のST低下なし） | **認める**（下壁誘導 II, III, aVF で明瞭なST低下） |
| **経時的変化 (数時間後)** | 何時間経過しても波形変化なし | 時間経過とともにST・T波が刻々と変化 |
| **心筋トロポニン推移** | 陰性またはベースライン一定 | 急激な上昇（Dynamic rise and fall） |

## 3. 急性心筋梗塞の致死的機械的合併症（Mechanical Complications）

STEMI発症後 **数日〜1週間前後（心筋の融解・壊死が最も脆弱となる時期）** に突発する機械的破綻であり、致死率が極めて高い病態です。

```mermaid
flowchart TD
    AMI["\"急性心筋梗塞 (発症後3〜7日")"] --> Mech1["\"① 左室自由壁破裂 (Free Wall Rupture")"]
    AMI --> Mech2["\"② 心室中隔穿孔 (VSR / VSD")"]
    AMI --> Mech3["\"③ 乳頭筋断裂 (Papillary Muscle Rupture")"]
    
    Mech1 --> PEA["\"急性心タンポナーデ ➔ 電気的機械的解離 (PEA")・突然死"]
    Mech2 --> Shunt["左右短絡 ➔ 汎収縮期雑音・両心不全・ショック"]
    Mech3 --> AcuteMR["\"急性僧帽弁閉鎖不全 (急性MR") ➔ 急性肺水腫・ショック"]
```

### 1) 左室自由壁破裂（Free Wall Rupture）
- **病態**: 梗塞心筋の全層が破裂し、心嚢内へ急速に血液が流出。
- **臨床像**: 突発的な意識消失・心停止。**急性心タンポナーデ**。
- **心電図特徴**:
  - **電気的機械的解離（PEA: Pulseless Electrical Activity）** への急速な移行（心電図上は洞調律や徐脈波形が残存しているが脈拍触知不能）。
  - **突然の著明な徐脈（Sinus bradycardia / 接合部調律）**。
  - 低電位および **電気的交互脈（Electrical Alternans）**。
  - 一過性の新たなST再上昇。

### 2) 心室中隔穿孔（Ventricular Septal Rupture: VSR）
- **病態**: 中隔の貫壁性壊死に伴う穿孔（前壁梗塞での心尖部中隔、下壁梗塞での心基部中隔に好発）。
- **臨床像**: 胸骨左縁第4肋間に最強点を持つ **粗暴な汎収縮期雑音（Levine IV〜V度）** と急激な心原性ショック・右心不全。
- **心電図特徴**:
  - 新規の **完全右脚ブロック（CRBBB）** や **左脚前枝ブロック（LAFB）**、房室ブロックの突発。

### 3) 乳頭筋断裂（Papillary Muscle Rupture）
- **病態**: 僧帽弁乳頭筋の壊死・断裂（特に単一血流支配である後内側乳頭筋断裂が下壁梗塞で好発）。
- **臨床像**: 突発する **急性肺水腫（Flash pulmonary edema）**、低血圧。心尖部収縮期雑音（急性期は左房圧急上昇のため雑音が減弱・短縮することがあり注意）。
- **心電図特徴**: 下壁STEMIの所見に加え、急性左房負荷（P波増高・幅延長）や頻脈。

## 4. 機械的合併症の鑑別診断まとめ

| 合併症 | 好発時期 | 好発梗塞部位 | 聴診・理学所見 | 心電図サイン | 緊急処置 |
| :--- | :---: | :---: | :--- | :--- | :--- |
| **自由壁破裂** | 発症後 2〜7日 | 前壁 / 側壁 | 心音微弱、頸静脈怒張、ショック | **PEA、突然の徐脈、電気的交互脈** | 緊急心膜穿刺・緊急開胸手術 |
| **心室中隔穿孔 (VSR)** | 発症後 3〜5日 | 前壁中隔 / 下壁 | 胸骨左縁の粗暴な汎収縮期雑音 | **新規脚ブロック、両室負荷** | IABP/Impella、緊急パッチ閉鎖術 |
| **乳頭筋断裂** | 発症後 2〜7日 | 下壁 (RCA/LCx) | 心尖部収縮期雑音、ピンク色泡沫喀痰 | **下壁STEMI + 急性肺水腫所見** | IABP、緊急僧帽弁置換術(MVR) |

## 5. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 洞調律 (Heart Rate: 70 bpm)
・QRS波所見: 
  - V1〜V3誘導にてQSパターン (異常Q波) を認める。
  - V1〜V4誘導にてR波増高不良 (Poor R-Wave Progression: V3 R波 1.5mm)。
・ST-T所見: 
  - V1〜V4誘導にて 1.5〜2.0 mm のST上昇が持続 (基線復帰せず)。
  - T波振幅は低平化しており、T/QRS比は 0.22 (< 0.36)。
  - 下壁誘導 (II, III, aVF) に鏡面像ST低下を認めず。
・比較読影: 3ヶ月前の心電図と比較し、ST上昇度およびQRS形態に有意な変化なし。

【総合判定】
陳旧性前壁中隔心筋梗塞 (Old Anteroseptal MI) および 慢性期左室瘤形成疑い (Stable LV Aneurysm)

【推奨コメント】
慢性期の固定性変化と考えられます。急性虚血の新規出現は否定的ですが、左室瘤に伴う壁運動異常(Dyskinesia)・心内血栓形成の有無およびLVEF評価のため心エコー図検査を推奨します。
```
