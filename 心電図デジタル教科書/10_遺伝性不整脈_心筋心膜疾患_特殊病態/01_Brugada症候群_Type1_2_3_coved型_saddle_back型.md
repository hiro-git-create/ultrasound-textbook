# 🫀 Brugada症候群（Type 1 / 2 / 3・coved型・saddle-back型）

Brugada症候群（ブルガダ症候群）は、右側胸部誘導（$V_1 \sim V_3$）における特徴的なST上昇と、心室細動（VF）による夜間・安静時の突然死（ぽっくり病）を特徴とする遺伝性不整脈疾患です。

---

## 1. Brugada型心電図の分類と波形特徴

歴史的にはType 1〜Type 3の3種類に分類されていましたが、国際コンセンサス（2012年以降）では**Type 1（coved型）のみが確定診断に直結する診断的心電図**と定義され、Type 2とType 3はsaddle-back型として包括的に扱われます。

```
【Type 1: coved型（確定診断的）】
       ▲ J点 ≥ 2mm
      / \
     /   \___
    /        \ (陰性T波)
---'          \___________

【Type 2: saddle-back型（疑い・要精査）】
       ▲ J点 ≥ 2mm
      / \     /\ (陽性/二峰性T波)
     /   \___/  \
    /   (ST≥1mm) \________
---'
```

### 波形分類比較表

| 分類 | ST形態 | J点上昇高 | ST部挙上高 | T波の極性 | 臨床的意義 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Type 1 (coved型)** | 下向き凸のドーム状（弓状） | $\ge 2.0\,\text{mm}\ (0.2\,\text{mV})$ | 漸減し陰性T波へ移行 | **陰性T波**（逆転） | **Brugada症候群の診断波形**（自然出現または薬物誘発） |
| **Type 2 (saddle-back型)** | 馬の背状（鞍状） | $\ge 2.0\,\text{mm}\ (0.2\,\text{mV})$ | 谷部ST $\ge 1.0\,\text{mm}$ | **陽性または二峰性T波** | 疑診（高位肋間記録や誘発試験でType 1化するか評価） |
| **Type 3 (saddle-back型)** | 馬の背状 / ドーム状 | $\ge 2.0\,\text{mm}\ (0.2\,\text{mV})$ | 谷部ST $< 1.0\,\text{mm}$ | 陽性T波 | 疑診（Type 2より平坦、経過観察・再検） |

> [!IMPORTANT]
> **心電図検定・臨床の超重要ポイント**
> - **Type 1波形（coved型）が1誘導でも記録された場合のみ**、Brugada型心電図と確定できます（自然出現、発熱時、またはNaチャネル遮断薬負荷後）。
> - Saddle-back型（Type 2/3）単独では確定診断とはならず、「Brugada型心電図疑い」として高位肋間記録や負荷試験の適応を検討します。

---

## 2. 高位肋間記録（High-intercostal ECG recording）

Brugada波形は、**右室流出路（RVOT: Right Ventricular Outflow Tract）** の直上に位置する誘導で最も顕著に現れます。標準の第4肋間記録では検出できず、第2肋間・第3肋間に電極を上方移動することでType 1波形が明瞭化することが多々あります。

```mermaid
graph TD
    A["\"標準12誘導心電図<br/>(第4肋間 V1-V2")"] --> B{"波形判定"}
    B -->|"Type 1 (coved型) 記録"| C["Type 1 Brugada心電図確定"]
    B -->|"Type 2/3 (saddle-back型) または 境界域ST上昇"| D["\"高位肋間心電図を施行<br/>(第2肋間・第3肋間 V1-V2")"]
    D -->|"Type 1化 陽性"| C
    D -->|"変化なし / saddle-back持続"| E["\"必要に応じ薬物誘発試験<br/>(ピルジカイニド/フレカイニド")"]
```

### 電極配置の手順
1. **第2肋間**: 胸骨右縁（$V_1$相当）、胸骨左縁（$V_2$相当）
2. **第3肋間**: 胸骨右縁（$V_1$相当）、胸骨左縁（$V_2$相当）
3. **第4肋間**: 通常の標準記録位置

> [!TIP]
> 健診や救急外来で「右側胸部誘導の軽度ST上昇」や「不完全右脚ブロック様波形」を見た場合、必ず**第2・第3肋間の高位肋間心電図を追加記録**することが推奨されます。

## 3. 発生機序・遺伝学的背景

### 分子病態
- **責任遺伝子**: **$SCN5A$変異**（電位依存性Naチャネル $\text{Na}_{\text{v}}1.5$ の機能喪失型変異）が約20〜30%に同定される。
- **電気生理学的機序**:
  1. **再分極異常説（Repolarization disorder）**: 心外膜側の過分極性一過性外向きカリウム電流（$I_{\text{to}}$）が心内膜側より優位な右室流出路において、Naチャネル機能低下により活動電位第1相のノッチが深くなり、心外膜側と心内膜側の電位勾配（Transmural voltage gradient）が生じてST上昇とPhase 2 Reentry（心室細動の引き金）が発生。
  2. **脱分極異常説（Depolarization disorder）**: 右室流出路心外膜側の微小線維化・局所伝導遅延が原因とする説。

---

## 4. 誘発因子と生活上の注意点

Brugada症候群の心電図変化や不整脈イベントは、以下の要因で顕性化・増悪します。

1. **発熱（Fever）**: 高体温によりNaチャネルの不活化が加速する。**発熱時は直ちに解熱薬（アセトアミノフェン等）を服用**させる。
2. **迷走神経緊張（Vagal tone）**: 夜間睡眠時、食後安静時、飲酒後に心室細動が多く発症する。
3. **薬剤性誘発**:
   - **クラスIc抗不整脈薬**: ピルジカイニド（サンリズム）、フレカイニド（タンボコール）
   - **クラスIa抗不整脈薬**: アジマリン、プロカインアミド
   - **向精神薬**: 三環系抗うつ薬、リチウム
   - **麻酔薬**: プロポフォール
4. **過度の飲酒・大食**: 副交感神経反射を亢進させる。

## 5. 診断基準と上海スコアシステム（Shanghai Score）

Brugada症候群の診断には、心電図所見に加えて臨床症状、家族歴、遺伝子検査を統合した**上海スコアリングシステム（Shanghai Score System）** が国際的に汎用されます。

### 上海スコアリングシステム（3.5点以上で診断確定）

| カテゴリ | 項目 | 点数 |
| :--- | :--- | :--- |
| **① 心電図所見**（最高3.5点） | 自然出現したType 1波形（第4肋間または高位肋間） | 3.5 |
| | 発熱時のみに出現したType 1波形 | 3.0 |
| | Naチャネル遮断薬で誘発されたType 1波形 | 2.0 |
| | Type 2/3 saddle-back波形 | 0.5 |
| **② 臨床症状**（最高3.0点） | 心肺停止蘇生後 / 心室細動（VF） / 多形性心室頻拍（pVT） | 3.0 |
| | 原因不明の失神（心原性が疑われるもの） | 2.0 |
| | 夜間苦悶様呼吸（Agonal respiration） | 1.5 |
| **③ 家族歴**（最高2.0点） | 45歳未満の一親等の原因不明突然死 / SADS | 1.0 |
| | 一親等に確定診断されたBrugada症候群患者 | 1.0 |
| **④ 遺伝子検査**（0.5点） | $SCN5A$ 病原性変異同定 | 0.5 |

> **スコア判定**:
> - **$\ge 3.5$ 点**: Brugada症候群 確定（Probable / Definite）
> - **$2.0 \sim 3.0$ 点**: 疑診（Possible）
> - **$< 2.0$ 点**: 否定的（Non-diagnostic）

## 6. 鑑別診断

1. **不完全右脚ブロック（IRBBB）**: $V_1$ で $rSr'$ パターンを呈するが、$r'$ の下行脚が基線まで戻り、ST上昇を伴わない。
2. **急性前壁心筋梗塞（STEMI）**: 広範なST上昇、対側誘導（下壁 II, III, aVF）のReciprocal ST低下、胸痛症状、心筋逸脱酵素の上昇。
3. **早期再分極症候群（ERS）**: J点上昇とノッチを認めるが、主に下壁・側壁誘導（II, III, aVF, $V_4 \sim V_6$）に好発。
4. **不整脈原性右室心筋症（ARVC）**: $V_1 \sim V_3$ の陰性T波、イプシロン波、局所伝導遅延。[[03_不整脈原性右室心筋症_ARVC_イプシロン波_短縮QT]]参照。
5. **漏斗胸（Pectus excavatum）**: 胸郭変形による電極位置異常で偽性saddle-back様ST上昇を来す。

## 7. リスク層別化と治療方針

```mermaid
graph TD
    A["Brugada症候群（Type 1波形保有者）"] --> B{"臨床症状・既往歴"}
    B -->|"心停止蘇生後 / VF既往"| C["\"二次予防: ICD植込み (クラスI")"]
    B -->|"心原性失神の既往あり"| D["\"一次予防: ICD植込み (クラスIIa")"]
    B -->|"無症候性 (健診発見等)"| E{"心電図自然出現 & 家族歴"}
    E -->|"高リスク群 (自然Type 1 + 突然死家族歴)"| F["\"EPS (電気生理学的検査") 検討<br/>または慎重な経過観察"]
    E -->|"低リスク群"| G["\"生活指導 (発熱時早期解熱・禁忌薬回避")"]
```

### 治療オプション
- **植込み型除細動器（ICD）**: 突然死予防における唯一のエビデンスを持つ第一選択治療。[[04_ICD_CRT_CRT_D_皮下植込み型S_ICDの心電図評価]]参照。
- **薬物治療**:
  - **キニジン（硫酸キニジン）**: $I_{\text{to}}$ 遮断作用によりST上昇を抑制し、VFストーム（電気的嵐）の抑制に有効。
  - **イソプロテレノール**: $\beta$ 受容体刺激により $I_{\text{Ca,L}}$ を増強し、急性期VFストームを鎮静化。
- **カテーテルアブレーション**: 右室流出路心外膜側の異常遅延電位領域を高周波焼灼し、VF再発を抑制。

## 8. 心電図所見の記載例

```text
【心電図所見】
洞調律 62bpm。
V1・V2誘導においてJ点から連続する2.5mmの下向き凸型ST上昇とそれに続く陰性T波（coved型ST上昇）を認める。
第3肋間高位肋間記録においても明瞭なcoved型波形が確認される。

【診断】
Brugada型心電図（Type 1 coved型）

【推奨事項】
失神歴・突然死家族歴の問診、発熱時の迅速な解熱指導、Brugada禁忌薬リストの確認、循環器専門医（不整脈専門医）への精査紹介を推奨。
```
