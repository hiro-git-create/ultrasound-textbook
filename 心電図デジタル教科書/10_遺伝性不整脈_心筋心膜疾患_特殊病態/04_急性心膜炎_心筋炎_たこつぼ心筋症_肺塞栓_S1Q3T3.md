# 🫀 急性心膜炎・心筋炎・たこつぼ心筋症・急性肺塞栓（S1Q3T3）

胸痛や呼吸困難、ショックで救急搬送される患者において、急性心筋梗塞（STEMI）と酷似したST-T変化を呈する4大重要病態（**急性心膜炎・急性心筋炎・たこつぼ心筋症・急性肺塞栓症**）の心電図鑑別ポイントを徹底解説します。

---

## 1. 急性心膜炎（Acute Pericarditis）

急性心膜炎では、心外膜直下の炎症に伴う傷害電流により、**単一冠動脈領域にとどまらない広範な誘導**でST-T変化とPR部分の変化を来します。

```
【急性心膜炎の波形特徴】
           ▲ R
          / \     __/\ (上向き凹のST上昇 Concave upward)
   ______/   \___/    \_____
   (PR低下)
```

### 特徴的心電図所見
1. **広範な上向き凹（Concave upward）のST上昇**: aVRと$V_1$を除くほぼ全誘導（I, II, III, aVF, aVL, $V_2 \sim V_6$）で出現。
2. **PR部分の低下（PR depression）**: 心房心外膜の炎症を反映（II, aVF, $V_4 \sim V_6$ 等で明瞭）。
3. **aVR誘導における鏡面像（Reciprocal ST低下 & PR上昇）**: aVRでST低下とPR上昇（**Spodickサイン**：基線が右肩下がりに傾斜）を認める。
4. **対側性ST低下（鏡面像）の欠如**: aVR/$V_1$以外の誘導間にReciprocal ST低下を認めない。
5. **異常Q波を形成しない**。

### 心膜炎の4段階の経時的変化（Stages of Pericarditis）

| 病期 | 心電図所見 |
| :--- | :--- |
| **Stage 1（急性期: 数時間〜数日）** | 広範な上向き凹ST上昇 ＋ PR部分の低下（aVRでPR上昇・ST低下） |
| **Stage 2（亜急性期: 数日〜1週）** | ST部・PR部が基線に復帰、T波が平低化 |
| **Stage 3（回復期: 数週）** | 広範な誘導でT波が左右対称性に陰転化（陰性T波） |
| **Stage 4（慢性期: 数週〜数ヶ月）** | T波が正常化し完全回復（一部で陰性T波が残存） |

## 2. たこつぼ心筋症（Takotsubo Cardiomyopathy: TTS）

強い精神的・身体的ストレスを契機に、左室心尖部の広範な収縮不全（バルーニング）を来す病態です。急性冠症候群（前壁STEMI）との鑑別が最重要課題となります。

```
【たこつぼ心筋症の心電図推移】
【急性期】 広範な胸部ST上昇（-aVR ST上昇）
【亜急性期】 巨大陰性T波（Giant negative T）＋ 著明なQT延長
       ▲ R
      / \
  ---'   \________
                  \            /--- (著明なQT延長)
                   \__________/
                   (巨大陰性T波)
```

### たこつぼ心筋症の心電図特徴
1. **広範な胸部ST上昇**: $V_2 \sim V_6$ および肢誘導（I, II, aVL）でST上昇。
2. **$V_1$ 誘導のST上昇の欠如**: 前壁STEMIでは$V_1$が上昇しやすいが、たこつぼでは$V_1$の上昇は稀。
3. **$-aVR$ 誘導のST上昇（aVRのST低下）**: 心尖部全体の虚血を反映。
4. **亜急性期の巨大陰性T波（Giant negative T wave）と著明なQT延長**: 発症24〜48時間後から急速に出現し、TdPのリスクとなる。
5. **一過性の異常Q波**: 形成されても退院時には消失・改善することが多い。

---

## 3. 急性心筋炎（Acute Myocarditis）

心筋細胞の広範な変性・壊死により、極めて多彩で重篤な心電図変化を呈します。

### 心筋炎の要注意サイン
- **びまん性ST上昇 / 平低T波 / 陰性T波**: 心膜炎類似のST上昇から虚血類似の陰性T波まで多彩。
- **伝導障害**: 新規出現の脚ブロック（特に左脚ブロック CLBBB）、左脚前枝ブロック、1度〜3度房室ブロック。
- **四肢誘導の低電位（Low voltage）**: 心筋浮腫や心嚢液貯留を反映。
- **重症心室性不整脈**: 多源性PVC、持続性VT、心室細動（VF）。

> [!CAUTION]
> **劇症型心筋炎の警戒サイン**
> 発熱・感冒様症状の後に「QRS幅の急激な拡大（$\ge 120\,\text{ms}$）」や「高度房室ブロック」「著明な低電位」が出現した場合は、数時間以内に心原性ショックへ進行する**劇症型心筋炎（Fulminant Myocarditis）** を強く疑い、直ちにECMO（PCPS）等の補助循環準備を行います。

## 4. 急性肺血栓塞栓症（APE: Acute Pulmonary Embolism）

肺動脈の急激な閉塞により急性右室過負荷・肺高血圧（Acute cor pulmonale）を来し、特徴的な右心負荷パターンが出現します。

```
【McGinn-White S1Q3T3 パターン】
【I誘導】        【III誘導】
      ▲ R             _/\_ 基線
     / \                 \  / (Q波 ≥1mm)
    /   \     /---        \/   \ (陰性T波)
---'     \___/                  \________
         (深いS波)
```

### 肺塞栓症の代表的心電図所見

| 所見名 | 詳細心電図特徴 | 臨床的機序 |
| :--- | :--- | :--- |
| **洞性頻拍**（最頻出） | 心拍数 $> 100\,\text{bpm}$（約50%以上に出現） | 低酸素血症・心拍出量低下に対する交感神経代償 |
| **$S_I Q_{III} T_{III}$ パターン**<br/>（McGinn-White） | **I誘導の深いS波**（$>1.5\,\text{mm}$）<br/>**III誘導のQ波**（$>1.0\,\text{mm}$）<br/>**III誘導の陰性T波** | 急性右室拡大に伴う心臓の時計方向回転と電気軸右偏 |
| **右側胸部陰性T波**<br/>（Right ventricular strain） | **$V_1 \sim V_4$ の対称性陰性T波**<br/>（下壁誘導 II, III, aVF にも波及） | 急性右室圧負荷による心内膜下虚血・ひずみ |
| **右脚ブロック（RBBB）** | 新規出現の不完全 / 完全右脚ブロック | 右室伝導遅延 |
| **右軸偏位 / 時計方向回転** | 電気軸 $> +90^\circ$、移行帯の左方移動（$V_5 \sim V_6$） | 右室拡大による解剖学的偏位 |

## 5. STEMI vs 心膜炎 vs たこつぼ vs 肺塞栓 鑑別マトリックス

| 鑑別項目 | 急性前壁STEMI | 急性心膜炎 | たこつぼ心筋症 | 急性肺塞栓症 |
| :--- | :--- | :--- | :--- | :--- |
| **ST上昇形態** | **上向き凸（Convex upward）**<br/>または直線状 | **上向き凹（Concave upward）**<br/>ドーム状 | 上向き凸〜平坦 | 通常なし（$V_1 \sim V_3$で軽度上昇あり） |
| **ST上昇誘導** | LAD灌流領域（$V_1 \sim V_4$, I, aVL） | **広範（aVR/V1を除く全誘導）** | 広範胸部（$V_2 \sim V_6$, I, aVL） | なし（aVRで軽度上昇あり） |
| **$V_1$ 誘導のST** | **著明に上昇** | 通常基線または軽度低下 | **上昇しない（等電位/正常）** | 正常〜軽度上昇 |
| **PR低下** | なし | **広範に陽性（Spodick sign）** | なし | なし |
| **鏡面像（Reciprocal）**| **明確に存在（II, III, aVF低下）**| **なし**（aVR以外） | なし | なし |
| **異常Q波** | **早期に出現・永続化** | 出現しない | 一過性に出現（後に消失） | $S_I Q_{III} T_{III}$（IIIのみ） |
| **T波変化** | 早期からT波陰転化 | ST正常化後に陰転化 | **亜急性期に巨大陰性T波** | **$V_1 \sim V_4$ 陰性T波（Strain）** |
| **QTc時間** | 正常〜軽度延長 | 正常 | **著明に延長（$\ge 500\,\text{ms}$）** | 正常 |

## 7. 心電図所見の記載例

```text
【心電図所見】
洞性頻拍 108bpm。
I誘導に明瞭なS波（深さ 2.5mm）、III誘導に病的なQ波および左右対称の陰性T波（S1Q3T3パターン）を認める。
V1〜V3誘導において左右非対称の陰性T波（右室ひずみパターン）を認め、移行帯はV5に偏位（時計方向回転）。
明らかなST上昇やPR低下は認めず。

【診断】
1. 洞性頻拍
2. S1Q3T3パターンおよび右心負荷所見（右室ひずみ）

【推奨事項】
急性肺血栓塞栓症（APE）を強く疑う所見。至急血中D-dimer測定、心臓超音波検査（右室拡大・D-shape・McConnell徴候の確認）、造影CT施行および呼吸循環動態のモニタリング管理を推奨。
```
