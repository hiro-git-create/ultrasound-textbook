# ⚡ 先天性・後天性QT延長症候群（LQTS / LQT1・LQT2・LQT3 / TdP）

QT延長症候群（Long QT Syndrome: LQTS）は、心室筋細胞の再分極時間が異常に延長することにより、特徴的な多形性心室頻拍である**トルサード・ド・ポアンツ（Torsades de Pointes: TdP）** を誘発し、失神や心臓突然死を来す病態群です。

---

## 1. QTc時間の計測と診断基準

QT時間は心拍数に依存して変動するため、**Bazettの補正計算式（$\text{QTc} = \text{QT} / \sqrt{\text{RR}}$）** または **Fridericia式（$\text{QTc} = \text{QT} / \sqrt[3]{\text{RR}}$）** を用いて補正します。

$$ \text{QTc (Bazett)} = \frac{\text{QT (sec)}}{\sqrt{\text{RR (sec)}}} $$

### QTc正常値と延長のカットオフ

| 性別 | 正常値 | 境界域 | QT延長（病的） |
| :--- | :--- | :--- | :--- |
| **男性** | $\le 430\,\text{ms}$ | $430 \sim 450\,\text{ms}$ | **$> 450\,\text{ms}$**（$\ge 480\,\text{ms}$で高リスク） |
| **女性** | $\le 450\,\text{ms}$ | $450 \sim 460\,\text{ms}$ | **$> 460\,\text{ms}$**（$\ge 480\,\text{ms}$で高リスク） |

> [!WARNING]
> - **$\text{QTc} \ge 500\,\text{ms}$** は、先天性・後天性を問わず**TdP・心室細動発症の極めて高いリスク指標**（赤信号）です。
> - 頻脈時や徐脈時ではBazett式の誤差が大きくなるため、心拍数が60bpm未満または100bpm以上の場合は**Fridericia式**を併用して評価します。

---

## 2. 先天性LQTSの三大遺伝子型と心電図形態

先天性LQTSの約90%は、LQT1、LQT2、LQT3の3つのタイプで占められます。心電図上の**T波形態**と**発症トリガー**が明確に異なります。

```
【LQT1: 幅広T波 (Broad-based T)】
       ▲ R
      / \        ______ (幅広いT波)
     /   \______/      \_____
----'

【LQT2: 二峰性・ノッチT波 (Notched / Bifid T)】
       ▲ R
      / \         /\  /\ (ノッチ/2峰)
     /   \_______/  \/  \____
----'

【LQT3: 遅延出現T波 (Late-onset peaked T)】
       ▲ R
      / \             /\ (鋭いT波が遅れて出現)
     /   \___________/  \____
----'    (長いST部分)
```

### 三大遺伝子型の特徴対比表

| 病型 | 責任遺伝子 | イオンチャネル異常 | T波の特徴 | 主な発症トリガー | 第一選択薬・治療 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **LQT1**<br/>（約45%） | **$KCNQ1$**<br/>$(KvLQT1)$ | $I_{\text{Ks}}$ カリウム電流減少<br/>（遅延整流Kチャネル遅延成分） | **幅が広く均一なT波**<br/>（Broad-based T wave） | **運動（特に水泳・競泳）**<br/>身体的労作・緊張 | **$\beta$遮断薬（プロプラノロール/ナドロール）が著効** |
| **LQT2**<br/>（約40%） | **$KCNH2$**<br/>$(hERG)$ | $I_{\text{Kr}}$ カリウム電流減少<br/>（遅延整流Kチャネル急速成分） | **低振幅・二峰性・ノッチT波**<br/>（Notched / Bifid T wave） | **聴覚刺激（目覚まし時計・電話音）**<br/>驚愕・情動ストレス・産褥期 | **$\beta$遮断薬**<br/>**カリウム補正（K保持薬/Spironolactone）** |
| **LQT3**<br/>（約5〜10%） | **$SCN5A$** | $I_{\text{Na-L}}$ ナトリウム遅延電流増加<br/>（Naチャネル機能獲得） | **長い等電位STと遅れて立ち上がる鋭いT波**<br/>（Late-onset peaked T wave） | **睡眠時・安静時・夜間**<br/>徐脈時に発症 | **Naチャネル遮断薬（メキシレチン）**<br/>$\beta$遮断薬、ペースメーカ/ICD |

## 3. 先天性LQTSの診断スコア（Schwartz Score）

臨床所見、心電図所見、家族歴から算出する**Schwartzスコアリングシステム**（2011年改訂版）で判定します。

| 評価項目 | 詳細基準 | 点数 |
| :--- | :--- | :--- |
| **心電図所見** | QTc $\ge 480\,\text{ms}$ | 3.0 |
| | QTc $460 \sim 470\,\text{ms}$ | 2.0 |
| | QTc $450\,\text{ms}$（男性） | 1.0 |
| | エルゴメーター運動負荷回復4分後 QTc $\ge 480\,\text{ms}$ | 1.0 |
| | Torsades de Pointes（TdP）の出現 | 2.0 |
| | T波交代現象（T-wave alternans） | 1.0 |
| | 3誘導以上でノッチを伴う二峰性T波 | 1.0 |
| | 年齢相応の安静時心拍数低下（低心拍数） | 0.5 |
| **病歴・症状** | 運動誘発性の失神 | 2.0 |
| | 感情・安静時の失神 | 1.0 |
| | 先天性感音難聴（Jervell-Lange-Nielsen症候群） | 0.5 |
| **家族歴** | 一親等に確定診断されたLQTS患者がいる | 1.0 |
| | 30歳未満の一親等の原因不明突然死 | 0.5 |

> **スコア判定基準**:
> - **$\ge 3.5$ 点**: LQTSの確率が極めて高い（High probability）
> - **$1.5 \sim 3.0$ 点**: LQTSの中等度疑い（Intermediate probability）
> - **$\le 1.0$ 点**: LQTSの可能性は低い（Low probability）

## 4. 後天性QT延長症候群（Acquired LQTS）の原因

後天性LQTSは、薬剤や電解質異常などによって二次的に再分極が遅延する病態です。潜在的な遺伝素因が背景に存在することも少なくありません。

```mermaid
graph TD
    A["後天性QT延長の主な原因"] --> B["\"電解質異常<br/>(低K血症, 低Mg血症, 低Ca血症")"]
    A --> C["\"QT延長誘発薬剤<br/>(抗不整脈薬, 抗菌薬, 向精神薬など")"]
    A --> D["\"重症徐脈<br/>(完全房室ブロック, 洞不全症候群")"]
    A --> E["\"心疾患・中枢神経疾患<br/>(急性心筋梗塞, たこつぼ心筋症, クモ膜下出血")"]
```

### 代表的なQT延長誘発薬剤

| 薬剤分類 | 代表的な一般名（商品名） |
| :--- | :--- |
| **クラスIa抗不整脈薬** | ジソピラミド、プロカインアミド、キニジン |
| **クラスIII抗不整脈薬** | アミオダロン、ソタロール、ニフェカラント |
| **抗菌薬・抗真菌薬** | マクロライド系（クラリスロマイシン、アジスロマイシン）、ニューキノロン系（レボフロキサシン、モキシフロキサシン）、アゾール系抗真菌薬 |
| **向精神薬・抗うつ薬** | ハロペリドール、クロルプロマジン、エスシタロプラム、三環系抗うつ薬 |
| **消化器用薬・制吐薬** | ドンペリドン、メトクロプラミド |

## 5. Torsades de Pointes（TdP）の発生機序と波形

TdPは、QRS波の極性と振幅が基線を中心に周期的にねじれるように変化する（Twisting around the isoelectric line）特徴的な多形性心室頻拍です。

```
【TdP波形（基線を中心に極性がねじれる）】
     /\      /\    /\                                /\      /\
    /  \    /  \  /  \    /\    /\    /  \    /  \  /  \    /  \
---'----\--'----\-'---\--'--\--'--\--/----\--/----\-'----\--'----\---
         \/      \/    \/    \/    \/      \/             \/
```

### 発生の電気生理学的メカニズム
1. **活動電位持続時間（APD）の延長**: 再分極カリウム電流の低下または遅延Na/Ca電流の増加。
2. **早期後脱分極（EAD: Early Afterdepolarization）**: APD延長によりL型Caチャネルが再活性化され、第2相〜第3相で過剰な脱分極が発生。
3. **トリガーとShort-Long-Short sequence**:
   - PVC出現（Short） $\to$ 代償休止期（Long: 徐脈でさらにQT延長） $\to$ 次の洞性拍動のT波頂点付近でEADによるPVCがトリガー（Short）となりTdPが発症。

## 6. 緊急対応・治療アルゴリズム

```mermaid
graph TD
    A["\"Torsades de Pointes (TdP") 発症"] --> B{"血行動態の評価"}
    B -->|"不安定 / 心停止 / VF移行"| C["\"直ちに非同期除細動 (DCショック: 200J")"]
    B -->|"安定 / 自己停止を繰り返す"| D["\"硫酸マグネシウム 1〜2g 緩徐静注<br/>(血清Mg正常でも有効")"]
    D --> E["\"原因薬剤の即時中止 & 電解質補正<br/>(目標: K ≥ 4.5 mEq/L, Mg ≥ 2.0 mg/dL")"]
    E --> F{"徐脈依存性TdPの持続?"}
    F -->|"徐脈あり"| G["\"一時的ペーシング (Overdrive pacing 90-110bpm")<br/>または イソプロテレノール持続点滴"]
    F -->|"先天性LQTS (LQT1/2)"| H["\"β遮断薬投与<br/>(イソプロテレノールは禁忌!")"]
```

> [!IMPORTANT]
> **先天性LQTS vs 後天性LQTSの緊急治療の違い**
> - **後天性徐脈依存性TdP**: 心拍数を上げるために**イソプロテレノール**や**オーバードライブペーシング**が有効。
> - **先天性LQTS（LQT1・LQT2）**: 交感神経刺激が発作を引き起こすため、**イソプロテレノールは絶対禁忌**であり、**$\beta$遮断薬**を使用します。

## 7. 心電図所見の記載例

```text
【心電図所見】
洞調律 58bpm。
QT時間 540ms、QTc(Bazett) 530msと著明なQT延長を認める。
V2〜V4誘導においてT波の終末部に明瞭なノッチ（二峰性T波）が観察される。
先行する心室期外収縮の休止期後に多形性心室頻拍（TdP）の短い連発を認める。

【診断】
1. 著明なQT延長症候群（LQT2型疑い）
2. 臨床的Torsades de Pointes（TdP）

【対応・推奨】
直ちに硫酸マグネシウム静注準備および心電図モニター監視下での救急管理。原因薬剤の精査・中止、血清電解質（K, Mg, Ca）の至急測定と補正、不整脈専門医への緊急コンサルト。
```
