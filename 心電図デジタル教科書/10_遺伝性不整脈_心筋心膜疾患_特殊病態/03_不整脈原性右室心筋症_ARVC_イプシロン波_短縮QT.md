# 🫀 不整脈原性右室心筋症（ARVC）と短縮QT症候群（SQTS）

不整脈原性右室心筋症（ARVC: Arrhythmogenic Right Ventricular Cardiomyopathy）および短縮QT症候群（SQTS）は、特徴的な脱分極・再分極異常波形を呈し、致死性不整脈や心臓突然死の原因となる重要な遺伝性心筋・不整脈疾患です。

---

## 1. 不整脈原性右室心筋症（ARVC）の疾患概要

ARVCは、右室（進行例では左室も含む）の心筋細胞が**線維脂肪組織（Fibrofatty tissue）に置換**される進行性の遺伝性心筋疾患です。
- **遺伝学的背景**: デスモソーム（細胞接着斑）関連遺伝子（$PKP2$, $DSP$, $DSG2$, $DSC2$ など）の変異。
- **臨床症状**: 労作時や運動時の動悸・失神、持続性心室頻拍（VT）、心室細動（VF）。

---

## 2. ARVCの心電図診断基準（2010年 改訂タスクフォース基準）

ARVCの診断では、心電図における**脱分極異常**、**再分極異常**、**心室性不整脈形態**が重要な大基準・小基準に位置づけられています。

```
【イプシロン波 (Epsilon wave) の形態】
       ▲ R
      / \
     /   \   _/\ (QRS終末部の低振幅ノッチ = イプシロン波)
----'     \/'   \_____
                      \ (V1-V3 陰性T波)
                       \_______
```

### 心電図所見の大基準と小基準

| 区分 | 大基準（Major Criteria） | 小基準（Minor Criteria） |
| :--- | :--- | :--- |
| **① 脱分極伝導異常** | **イプシロン波（Epsilon wave）**<br/>右側胸部誘導（$V_1 \sim V_3$）のQRS終末部とST開始部の間に存在する明瞭な低振幅電位ノッチ | **局所右室伝導遅延**<br/>右脚ブロック非存在下で、$V_1 \sim V_3$ の終末部活性化遅延（Terminal activation duration: TAD $\ge 55\,\text{ms}$：S波最下点から基線復帰までの時間）<br/>または 加算平均心電図（SAECG）で心室遅延電位（LP）陽性 |
| **② 再分極異常** | **右側胸部誘導の陰性T波**<br/>14歳以上・右脚ブロック非存在下で、$V_1 \sim V_3$（またはそれ以上 $V_4$ 等）の陰性T波 | 14歳以上・右脚ブロック非存在下で、$V_1, V_2$ のみの陰性T波<br/>または 右脚ブロック合併下で $V_1 \sim V_4$ の陰性T波 |
| **③ 心室性不整脈** | **右室起源の持続性 / 非持続性VT**<br/>左脚ブロック（LBBB）パターン ＋ **上方軸**（II, III, aVFで陰性QRS） | **左脚ブロック（LBBB）パターン ＋ 下方軸**（右室流出路起源）のVT<br/>または 24時間ホルターで **PVC $> 500$個/日** |

> [!IMPORTANT]
> **イプシロン波の判読のコツ**
> - イプシロン波は右室の線維化部位を伝導する微小な遅延電位が体表面に現れたものです。
> - $V_1 \sim V_3$ 誘導において、QRSの下降脚の終わり（S波の直後）に「小さなピョコンとしたコブ（ノッチ）」として観察されます。
> - 振幅が小さいため、標準感度（10mm/mV）では見落としやすく、感度を2倍（20mm/mV）に拡大すると同定しやすくなります。

## 3. ARVC診断アルゴリズム（総合判定）

改訂タスクフォース基準では、心電図所見、心エコー/心臓MRI（右室拡大・局所壁運動異常）、心筋生検（線維脂肪置換）、家族歴・遺伝子変異を組み合わせて確定診断を行います。


## 4. 短縮QT症候群（SQTS: Short QT Syndrome）

短縮QT症候群は、心室再分極時間が著明に短縮し、心房細動（AF）、心室細動（VF）、心臓突然死を惹起する稀なチャネル病です。

```
【短縮QT症候群の波形特徴】
       ▲ R
      / \   /\ (極めて短いSTと尖鋭な左右対称T波)
     /   \_/  \_____
----'
    |← QT ≤ 330ms →|
```

### SQTSの心電図特徴と診断基準

1. **著明なQT短縮**:
   - **$\text{QTc} \le 330\,\text{ms}$**: 単独でSQTSの確定診断。
   - **$\text{QTc} \le 360\,\text{ms}$**: かつ以下のいずれかを有する場合に診断。
     - 心停止蘇生後 / VF・多形性VTの既往
     - 40歳未満の突然死家族歴
     - $KCNH2$ ($SQT1$), $KCNQ1$ ($SQT2$), $KCNJ2$ ($SQT3$) などの機能獲得型変異同定
2. **ST部分の短縮〜消失**: QRSの直後から直ちにT波が立ち上がる。
3. **高峻で狭小な対称性T波**: テント状T波に類似（高カリウム血症との鑑別が必要）。
4. **心房細動の合併**: 心房の不応期も短縮するため、若年性発作性心房細動を高頻度に合併する。

### 高カリウム血症 vs 短縮QT症候群の鑑別

| 鑑別項目 | 短縮QT症候群（SQTS） | 高カリウム血症 |
| :--- | :--- | :--- |
| **血清カリウム値** | 正常（$3.5 \sim 5.0\,\text{mEq/L}$） | **高値（$\ge 5.5\,\text{mEq/L}$）** |
| **P波** | 正常に存在（AF合併時は消失） | 平低化 $\to$ 消失 |
| **QRS幅** | 正常（狭い） | **拡大（幅広いQRS）** |
| **QTc時間** | **著明に短縮（$\le 330 \sim 360\,\text{ms}$）** | 正常〜軽度短縮 |

## 5. 治療方針

### ARVCの管理
- **運動制限**: 激しい競技スポーツや高強度運動は右室負荷を増大させ病勢を悪化させるため**厳格に禁止**。
- **薬物治療**: $\beta$遮断薬（PVC/VT抑制）、アミオダロン。
- **ICD植込み**: 心停止蘇生後、持続性VT、高度右室機能低下例に対する突然死予防。

### SQTSの管理
- **ICD植込み**: 突然死予防の第一選択。ただし、T波が高峻でQTが短いため、**T波オーバセンシング（TWOS）による不適切作動**に厳重なプログラミング配慮が必要。
- **キニジン（硫酸キニジン）**: カリウム電流（$I_{\text{Kr}}$, $I_{\text{Ks}}$, $I_{\text{to}}$）を遮断して有効にQT時間を延長させる唯一の特効薬。

## 6. 心電図所見の記載例

```text
【心電図所見】
洞調律 70bpm。
V1〜V3誘導においてQRS終末部に明瞭な低振幅電位ノッチ（イプシロン波）を認める。
また、V1〜V4誘導において左右非対称の陰性T波を認める。
完全右脚ブロックは認めず、V1におけるTerminal Activation Durationは65msと遅延している。

【診断】
不整脈原性右室心筋症（ARVC）疑い所見（イプシロン波 ＋ 右側胸部陰性T波）

【推奨事項】
高強度運動の中止を指示。心筋症精査目的で心臓超音波検査、心臓MRI、加算平均心電図（SAECG）、24時間ホルター心電図の施行および不整脈専門医への精査紹介を推奨。
```
