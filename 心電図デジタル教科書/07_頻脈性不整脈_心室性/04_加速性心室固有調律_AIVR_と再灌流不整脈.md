# 加速性心室固有調律（AIVR）：心電図特徴・発生機序と再灌流不整脈の臨床的意義

加速性心室固有調律（Accelerated Idioventricular Rhythm: **AIVR** / 促進心室固有調律）は、ヒス束分岐部以下の心室興奮フォーカスから発生する調律で、心拍数が **50〜100（または110）bpm** の範囲にある心室性不整脈です。
通常の心室固有調律（Ventricular Escape Rhythm: < 40 bpm）より速く、心室頻拍（VT: > 100〜120 bpm）より遅いことから、通称 **"Slow VT"** とも呼ばれます。急性心筋梗塞（STEMI）に対するカテーテル治療（PCI）や血栓溶解療法による閉塞冠動脈再開通に伴う **再灌流不整脈（Reperfusion Arrhythmia）** の代表的サインとして極めて重要です。

---

## 1. AIVRの発生機序と病態生理

```mermaid
flowchart TD
    A["冠動脈閉塞・虚血部位"] -->|カテーテル治療 (PCI) / 血栓溶解| B["\"血流再開・再灌流 (Reperfusion")"]
    B --> C["細胞内Ca2+過負荷 & フリーラジカル産生"]
    C --> D["\"心室プルキンエ線維・虚血境界部の<br/>異常自動能亢進 (Enhanced Automaticity")"]
    D --> E["\"洞結節レートをわずかに上回る<br/>心室調律 (50-100 bpm") の出現 ➔ AIVR"]
```

### 1) 発生メカニズム
- **異常自動能の亢進（Enhanced Automaticity）**: 虚血組織の再灌流時に生じるカルシウム過負荷や酸素ラジカルによって、心室プルキンエ線維の自動能が一時的に亢進し、洞結節の固有心拍数（60〜70 bpm前後）をわずかに上回ることで調律の主導権を奪います。
- **等頻度性房室解離（Isochronous AV Dissociation）**: 洞結節のレートとAIVRのレートが非常に近いため、心房と心室がほぼ同じ心拍数で独立して興奮し、P波がQRSの前後にゆっくりと出入りする現象（房室解離）が高頻度に観察されます。

### 2) 出現する主な臨床病態
1. **急性心筋梗塞（STEMI）の再灌流時**: カテーテル治療（バルーン拡張・ステント留置）成功直後に好発。**再灌流成功の良好な指標**。
2. **ジギタリス中毒（Digitalis Toxicity）**: 遅延後脱分極（DAD）に基づく自動能亢進。
3. **電解質異常（高K血症・低K血症）や心筋炎**。
4. **開胸心臓手術後や重度低酸素状態からの回復期**。
5. **健常者・若年アスリートの迷走神経緊張時**（洞徐脈時に一時的に心室自動能が勝る）。

## 2. 心電図波形の特徴と診断基準

```mermaid
flowchart LR
    A["\"心拍数 50〜100 bpm (規則的")"] --> D["AIVRの診断"]
    B["\"幅広い変形QRS (≥ 0.12s")"] --> D
    C["\"徐々に始まり徐々に終わる<br/>(Warm-up / Cool-down現象")"] --> D
    E["\"高頻度な融合収縮 (Fusion Beat")"] --> D
```

| 診断項目 | 心電図所見・特徴 |
| :--- | :--- |
| **心拍数 (HR)** | **50〜100 bpm**（時に110 bpmまで）。洞調律と同等かやや速い。 |
| **QRS形態** | **QRS幅拡大（≥ 0.12秒 = 120ms）**。単形性で変形している。 |
| **開始・停止様式** | **漸増・漸減（Warm-up & Cool-down）**: 突然開始・突然停止するリエントリー性VTと異なり、心室レートが徐々に速くなって洞調律を追い抜き、徐々に遅くなって洞調律にバトンタッチする。 |
| **房室関係** | **房室解離（AV dissociation）** が高頻度。逆行性心房伝導（1:1 VA伝導）を伴うこともある。 |
| **融合収縮・捕捉拍** | 洞調律とAIVRの交代期に、**融合収縮（Fusion beat）** や **心室捕捉拍（Capture beat）** が極めて高頻度に出現する。 |

## 3. 心室調律のスペクトラム比較（固有調律 vs AIVR vs VT）

| 項目 | 心室固有補充調律<br>(Ventricular Escape) | 加速性心室固有調律<br>(AIVR) | 心室頻拍<br>(VT) |
| :--- | :---: | :---: | :---: |
| **心拍数 (Rate)** | **< 40 bpm** (20〜40) | **50〜100 bpm** | **> 100〜120 bpm** (120〜250) |
| **発生機序** | 正常自動能（受動的補充） | 異常自動能亢進（能動的） | リエントリー（最多）/ トリガード |
| **出現の契機** | 高度房室ブロック、洞停止 | 再灌流、ジギタリス、迷走神経緊張 | 心筋梗塞後瘢痕、急性虚血、心筋症 |
| **血行動態** | 徐脈により低下（ペーシング要） | **ほぼ安定（維持される）** | 不安定・ショック（緊急治療要） |
| **治療方針** | アトロピン、一時ペーシング | **原則として治療不要（経過観察）** | 抗不整脈薬、同期下除細動 |

> [!CAUTION]
> **AIVRに対する抗不整脈薬投与の危険性**
> AIVRを通常の心室頻拍（VT）と誤認して、リドカインやアミオダロンなどの **Na/Kチャネル遮断薬を安易に静注して心室自動能を抑制してはなりません**。洞結節機能が一時的に抑制されている状態でAIVRを止めてしまうと、代わりの補充調律が出現せず **心静止（Asystole）や高度徐脈性ショック** を引き起こす危険があります。

## 4. 臨床マネジメントと治療戦略

```mermaid
flowchart TD
    Detect["\"心電図上でAIVR (HR 50-100, Wide QRS") を検出"] --> Assessment{"血行動態・自覚症状の評価"}
    
    Assessment -- "血行動態安定 (血圧正常・無症状)" --> Reassure["\"原則として無治療・厳重監視<br/>(自然消失を待つ")"]
    Reassure --> Success["虚血再灌流成功のサインとして評価"]
    
    Assessment -- "血行動態不安定 (心拍出量低下・低血圧)" --> Brady{"\"心房収縮の欠如 (房室非同期") による低血圧"}
    Brady --> Treat["\"洞調律レートを加速させる治療<br/>① アトロピン静注 (0.5mg")<br/>② 心房オーバードライブペーシング"]
```

1. **原則は経過観察（Observation）**:
   - AIVRの大部分は数分〜数時間以内に自然消失する一過性の良性不整脈です。血圧が保たれていれば特別な薬物介入は行いません。
2. **心房キック喪失による血圧低下時の対応**:
   - 房室解離により心房収縮による心室拡張末期容量の充満（Atrial kick）が失われ、軽度の血圧低下を認める場合は、**アトロピン（0.5mg静注）** を投与して洞結節レートを加速させ、洞調律による心室興奮を回復させます。
3. **カテ室での再灌流マーカー**:
   - AMIのPCI中にAIVRが出現した際は、責任病変のTIMI 3 flow再開通が達成された有力な臨床的証拠となります。

## 5. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・調律: 心拍数 75 bpm、幅広い変形QRS波 (QRS幅: 135 ms) が規則的に持続。
・波形推移: 洞性拍から緩徐に移行 (Warm-up現象) し、移行部に明瞭な融合収縮 (Fusion beat) を認める。
・房室関係: QRS波と解離した洞性P波を認め、等頻度性房室解離を形成。
・調律判定: 心室レートが50〜100 bpmの範囲にあり、加速性心室固有調律 (AIVR) の基準を満たす。
・ST-T所見: 責任領域 (下壁誘導 II, III, aVF) におけるST上昇の急速な改善傾向を認める。

【総合判定】
加速性心室固有調律 (Accelerated Idioventricular Rhythm: AIVR) / 再灌流不整脈

【対応・推奨】
急性心筋梗塞PCI後の再灌流成功に伴う良性不整脈と判断。血圧・血行動態は安定しており抗不整脈薬の投与は行わず、モニター監視下で経過観察とします。
```
