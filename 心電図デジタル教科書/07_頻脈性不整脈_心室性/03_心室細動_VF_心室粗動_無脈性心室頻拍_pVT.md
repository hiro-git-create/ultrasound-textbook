# 心室細動（VF）・心室粗動・無脈性心室頻拍（pVT）：心電図所見とACLS蘇生プロトコル

心室細動（Ventricular Fibrillation: **VF**）、心室粗動（Ventricular Flutter: **VFL**）、および無脈性心室頻拍（Pulseless Ventricular Tachycardia: **pVT**）は、有効な心拍出量が瞬時にゼロとなる **心停止（Cardiac Arrest）** を引き起こす最も緊急度の高い致死性心室性不整脈です。心室筋が無秩序・高速に興奮し、発症から数秒で意識消失、数分で不可逆的な脳虚血障害をきたすため、波形の即時認識と **非同期下電気的除細動（Defibrillation）** を主軸とする一次・二次救命処置（BLS / ACLS）が必須となります。

---

## 1. 致死性心室性不整脈の病態と心電図特徴

```mermaid
flowchart LR
    A["\"多小波リエントリー (Multiple Wavelet")"] --> B["心室筋の無秩序・高速興奮"]
    B --> C["心室ポンプ機能の完全破綻"]
    C --> D["\"心拍出量 = 0 (脈拍消失")"]
    D --> E["数秒で意識消失 ➔ 迅速除細動が唯一の救命手段"]
```

### 1) 心室細動（VF: Ventricular Fibrillation）
- **心電図特徴**: P波、QRS波、ST-T波の区別が完全に消失し、不規則で無秩序な基線の動揺波形が連続する。
- **粗大心室細動（Coarse VF）**: 波形の振幅が **> 0.2 mV（2小マス以上）**。発症直後に多く、心筋のエネルギー状態が保たれており除細動の成功率が高い。
- **微細心室細動（Fine VF）**: 波形の振幅が **≤ 0.2 mV**。心筋の虚血・アシドーシスが進行した末期像であり、心静止（Asystole）との鑑別が重要（2誘導以上で確認し、CPRを継続して心筋灌流圧を高めることでCoarse VFへ移行させる）。

### 2) 心室粗動（VFL: Ventricular Flutter）
- **心電図特徴**: 心拍数 **250〜350 bpm** の極めて高速で規則的な **正弦波様波形（Sine wave appearance）**。
- QRS波とT波が完全に融合し、等電位線（基線）が存在しない。
- 血液拍出は不能であり、数秒〜数十秒以内に速やかにVFへ移行する。

### 3) 無脈性心室頻拍（pVT: Pulseless VT）
- **心電図特徴**: 心電図上は単形性または多形性の心室頻拍（VT）波形を呈するが、大動脈弁開口や末梢動脈拍動が完全に消失している状態。
- ACLSプロトコル上、**VFと全く同一のアルゴリズム（ショック適応リズム）** として扱われる。

## 2. 波形比較表

| 疾患・病態 | 心拍数 (bpm) | QRS形態 | 基線・等電位線 | 脈拍・血行動態 | ACLS分類 |
| :--- | :---: | :--- | :---: | :---: | :---: |
| **粗大心室細動 (Coarse VF)** | 計測不能 | 不規則・無秩序（振幅 >0.2mV） | なし | 触知不能（心停止） | **ショック適応リズム** |
| **微細心室細動 (Fine VF)** | 計測不能 | 微細・不規則（振幅 ≤0.2mV） | なし | 触知不能（心停止） | **ショック適応リズム** |
| **心室粗動 (VFL)** | 250〜350 | 規則的正弦波（鋸歯状・ジグザグ） | なし | 触知不能（心停止） | **ショック適応リズム** |
| **無脈性心室頻拍 (pVT)** | 120〜250 | 幅広い均一/不均一なQRS | 消失/僅存 | 触知不能（心停止） | **ショック適応リズム** |
| **心静止 (Asystole)** | 0 | 直線（平坦線） | 平坦 | 触知不能（心停止） | 非ショック適応リズム |

> [!WARNING]
> **アーチファクトとVFの鑑別（Toothbrush Tachycardiaなど）**
> 電動歯ブラシの使用、パーキンソン病の振戦、電極リードの接触不良・揺れによって、モニター上にVFやVTに酷似した波形（アーチファクト）が描出されることがあります。
> **「波形を見る前に、まず患者の意識と頸動脈拍動を確認する」** ことが絶対原則です（意識清明・会話可能な患者のVF波形は100%アーチファクトです）。

## 3. ACLS（二次心肺蘇生）プロトコルにおける治療手順

```mermaid
flowchart TD
    CA["\"心停止の確認 (無反応・無呼吸・脈拍なし")"] --> BLS["\"CPR開始 (胸骨圧迫 100-120回/分") + 酸素投与/モニター装着"]
    BLS --> Rhythm{"\"リズムチェック (除細動器装着")"}
    
    Rhythm -- "VF / pVT (ショック適応)" --> Shock1["\"第1回 電気的除細動 (2相性 150-200J / 1相性 360J")"]
    Shock1 --> CPR1["\"直ちにCPR再開 (2分間") ※脈拍確認せず圧迫優先"]
    
    CPR1 --> Rhythm2{"リズムチェック"}
    Rhythm2 -- "VF/pVT持続" --> Shock2["第2回 電気的除細動"]
    Shock2 --> CPR2["\"直ちにCPR再開 (2分間") + アドレナリン 1mg静注 (3-5分毎)"]
    
    CPR2 --> Rhythm3{"リズムチェック"}
    Rhythm3 -- "VF/pVT持続 (難治性VF)" --> Shock3["第3回 電気的除細動"]
    Shock3 --> CPR3["\"直ちにCPR再開 (2分間") + 抗不整脈薬投与<br/>(アミオダロン 300mg または リドカイン 1.0-1.5mg/kg)"]
```

> [!IMPORTANT]
> **非同期除細動（Defibrillation）の原則**
> - VF/pVTではQRS波が識別不能、または同期不能であるため、**必ず「非同期（Defib）モード」** で放電します（同期スイッチをONのままにすると、R波を認識できず放電ボタンを押しても通電されません）。
> - ショック直後は心筋が一時的に気絶状態（Stunning）となるため、**ショック後すぐに脈拍や心電図を確認せず、直ちに胸骨圧迫からCPRを再開** します。

## 4. 致死性不整脈の背景原因（5H5Tの鑑別）

VF/pVTを停止させ自己心拍再開（ROSC）を得た後、および難治性VFの持続時には、以下の可逆的原因（5H5T）を迅速に検索・是正します。

| 5H (生理学的異常) | 心電図・臨床所見 | 是正処置 |
| :--- | :--- | :--- |
| **Hypoxia (低酸素血症)** | 洞性徐脈からのPEA/VF、SpO2低下 | 気道確保・高濃度酸素・気管挿管 |
| **Hypovolemia (循環血液量減少)** | 頻脈、狭いQRS、血圧低下、脱水・出血 | 急速輸液・輸血・止血 |
| **Hydrogen ion (アシドーシス)** | 低電位、幅広いQRS、呼吸不全 | 十分な換気、重炭酸ナトリウム考慮 |
| **Hypo-/Hyperkalemia (電解質異常)** | [[01_高カリウム血症_テント状T波から正弦波まで_低K血症|テント状T波/Sine wave]] / U波 | グルコン酸Ca、GI療法、K補正 |
| **Hypothermia (低体温症)** | [[04_抗不整脈薬による心電図変化_低体温_Osborn波|Osborn J波]]、徐脈、微細振戦 | 能動的復温（体外循環、加温輸液） |

| 5T (解剖学的・中毒性病因) | 心電図・臨床所見 | 是正処置 |
| :--- | :--- | :--- |
| **Tension pneumothorax (緊張性気胸)** | 呼吸音消失、気管偏位、頸静脈怒張 | 直ちに胸腔穿刺・脱気・胸腔ドレナージ |
| **Tamponade (心タンポナーデ)** | 電気的交互脈（Electrical Alternans）、低血圧 | 緊急心膜穿刺（Pericardiocentesis） |
| **Toxins (薬物・中毒)** | [[03_ジギタリス効果とジギタリス中毒_盆状ST低下|ジギタリス]]、TCA、[[04_抗不整脈薬による心電図変化_低体温_Osborn波|抗不整脈薬]] | 特異的中和薬、重炭酸ナトリウム |
| **Thrombosis (肺血栓塞栓症)** | S1Q3T3、急性右室負荷、低酸素 | 血栓溶解療法、血栓回収術 |
| **Thrombosis (冠動脈: 急性心筋梗塞)** | [[01_ST上昇型心筋梗塞_STEMI_責任冠動脈枝の同定と誘導局在|ST上昇]]、異常Q波、Reciprocal変化 | 緊急冠動脈造影（CAG）およびPCI |

## 5. 自己心拍再開後ケア（Post-Cardiac Arrest Care）と二次予防

1. **目標体温管理（TTM: Targeted Temperature Management）**: 意識障害が遷延する患者に対し、32〜36℃の一定目標体温を最低24時間維持し脳保護を図る。
2. **緊急カテーテル治療（PCI）**: 心電図でST上昇を認める例、または心原性心停止が強く疑われる例では直ちに緊急CAG/PCIを施行。
3. **二次予防**:
   - 虚血や電解質異常など一過性・可逆的原因がない器質的心疾患に伴うVF/pVT生還者には、**植込み型除細動器（ICD）** のクラスI適応。
   - 遺伝性不整脈（Brugada症候群、QT延長症候群、ARVC等）の精査。
