# 心室期外収縮（PVC）：Lown分類と重症度判定・起源推定

心室期外収縮（Premature Ventricular Contraction: **PVC** / Ventricular Premature Complex: **VPC**）は、ヒス束分岐部より下位の心室興奮伝導系または心室固有心筋から、予定された洞性興奮よりも早期に発生する異所性興奮です。日常臨床や心電図検定で極めて高頻度に遭遇する基本不整脈であり、良性の特発性PVCから致死的不整脈（[[02_心室頻拍_VT_単形性_多形性_鑑別診断_Brugada基準|心室頻拍(VT)]]・[[03_心室細動_VF_心室粗動_無脈性心室頻拍_pVT|心室細動(VF)]]）の引き金となる悪性PVCまで、適切なリスク層別化と起源部位の同定が求められます。

---

## 1. 心電図波形の特徴と診断基準

心室期外収縮の基本的心電図特徴は以下の通りです。

```mermaid
flowchart LR
    A["心室内の異所性フォーカス起因"] --> B["刺激伝導系を介さない心室筋伝播"]
    B --> C["\"幅広い変形QRS (QRS ≥ 0.12s")"]
    B --> D["\"二次性ST-T変化 (QRS主波と反対方向")"]
    B --> E["先行P波の欠如"]
    B --> F["完全代償性休止期の形成"]
```

### 1) 診断の3大徴候
1. **先行するP波が存在しない**: 心室筋内で自発的に発生するため、心房脱分極（P波）が先行しません（逆行性P波がQRS後方やST部分に見られることはあります）。
2. **QRS波の幅が広く変形している（QRS時間 ≥ 0.12秒 = 120ms）**: 特殊刺激伝導系（ヒス束-プルキンエ線維）を高速で順行伝播せず、固有心筋間をゆっくりと伝播するため脱分極時間が延長します。
3. **二次性ST-T変化（Secondary ST-T change）**: QRS主波の向きとST部分・T波の極性が反対（Discordant: QRSが上向きならST低下・陰性T波、QRSが下向きならST上昇・陽性T波）になります。

### 2) 休止期（Pause）のパターン
- **完全代償性休止期（Compensatory Pause）**: 洞結節の自律的歩調取り周期がPVCの逆行伝導によってリセット（再分極相のリセット）されないため、PVCを挟む前後の洞性P-P間隔の合計が、通常の洞性P-P間隔のちょうど2倍（$(P_1-P_2) + (P_2-P_3) = 2 \times PP$）になります。※上室期外収縮（PAC）では洞結節がリセットされるため「非代償性休止期（不完全代償性休止期）」となります。
- **間入性心室期外収縮（Interpolated PVC）**: 徐脈時に、洞性興奮のリズムをまったく乱すことなく、2つの連続する正常洞性QRSの間に挟み込まれるように出現するPVCです。直後の洞性P波のPR時間が軽度延長することがあります。

## 2. 出現形式と連結期（Coupling Interval）

| 出現パターン | 心電図定義 | 臨床的意義 |
| :--- | :--- | :--- |
| **単発（Isolated）** | 孤立して1拍のみ出現 | 最も一般的。健常者でも高頻度に認める。 |
| **二段脈（Bigeminy）** | 正常洞性拍 ➔ PVC ➔ 正常洞性拍 ➔ PVC が連続 | 自律神経アンバランス、ジギタリス中毒、電解質異常を考慮。 |
| **三段脈（Trigeminy）** | 正常 ➔ 正常 ➔ PVC または 正常 ➔ PVC ➔ PVC | 二段脈と同様、誘因の検索が必要。 |
| **四段脈（Quadrigeminy）** | 正常3拍ごとに1拍のPVCが出現 | 比較的安定した出現様式。 |
| **二連発（Couplet / Pair）** | PVCが連続して2拍出現 | 非持続性心室頻拍への移行リスクに注意。 |
| **三連発以上（Triplet / Short Run）** | PVCが連続して3拍以上出現（心拍数>100bpm） | [[02_心室頻拍_VT_単形性_多形性_鑑別診断_Brugada基準|非持続性心室頻拍(NSVT)]] と定義される。 |

> [!WARNING]
> **R-on-T 現象（R-on-T Phenomenon）**
> 先行する洞性拍のT波の頂点付近（**心室脆弱期: Vulnerable period**）にPVCのQRS波が重なって出現する現象です。心室筋の再分極の不均一性が最大となる時期に脱分極が加わるため、局所リエントリーが容易に誘発され、致死的な[[03_心室細動_VF_心室粗動_無脈性心室頻拍_pVT|心室細動(VF)]] や多形性VT（TdP）へ移行する極めて危険なサインです。

## 3. Lown分類（Lown Grading System）

B. Lownら（1971年）によって提唱された心室期外収縮の重症度分類です。急性心筋梗塞（AMI）の急性期モニタリングにおけるVF移行リスクの層別化として開発されました。

| Grade | 心電図所見・出現特徴 | 臨床的重症度評価 |
| :---: | :--- | :--- |
| **0** | PVCを認めない | 正常 |
| **1** | 散発性単源性PVC（**< 30個 / 時間** または < 1個 / 分） | 低リスク・良性 |
| **2** | 頻発性単源性PVC（**≥ 30個 / 時間** または ≥ 1個 / 分） | 中等度リスク |
| **3** | **多源性（Multiform / Multifocal）PVC**（同一誘導でQRS波形が複数存在） | 心筋障害・不均一性の反映（高リスク） |
| **4A** | **2連発（Couplets）** | 心室頻拍への進展注意 |
| **4B** | **3連発以上の連発（Short runs / NSVT）** | 高度催不整脈リスク（極めて高リスク） |
| **5** | **R-on-T 現象（R-on-T Phenomenon）** | 最重症・VF誘発の最高危険群 |

> [!NOTE]
> **現代臨床におけるLown分類の解釈と限界**
> Lown分類は急性心筋梗塞期におけるモニタリング指標として確立されたため、**「基礎心疾患を持たない健常者の特発性PVC」に対してLown Grade 2や3だからといって直ちに生命予後不良を意味するわけではありません**。
> 現代の臨床評価では、Lown分類の数字のみに依存せず、**「器質的心疾患（虚血・心不全・心筋症・LVEF低下）の有無」** および **「24時間総心拍数に対するPVC出現率（PVC burden: 通常 >10〜15% でPVC誘発性心筋症のリスク）」** を総合して重症度を判断します。

## 4. 12誘導心電図による起源部位の推定（Localization）

12誘導心電図のQRS波形パターンから、PVCの発生起源（右室系 vs 左室系、流出路 vs 心尖部）を精密に推定できます。

```mermaid
flowchart TD
    Start["12誘導心電図のPVC波形"] --> Q1{"V1誘導の極性"}
    Q1 -- "QS型 / rS型 (左脚ブロック様)" --> RV["\"右室系起源 (RV/中隔")"]
    Q1 -- "R型 / Rs型 / qR型 (右脚ブロック様)" --> LV["\"左室系起源 (LV")"]
    
    RV --> Q2{"\"下方誘導 (II, III, aVF") の極性"}
    Q2 -- "高電位の陽性R波 (下方軸)" --> RVOT["\"右室流出路 (RVOT") 起源"]
    Q2 -- "陰性QS/rS波 (上方軸)" --> RVApex["右室心尖部 / 下壁起源"]
    
    LV --> Q3{"電気軸"}
    Q3 -- "左軸偏位 (-30°〜-90°)" --> PostFascicle["左室後乳頭筋 / 左脚後枝領域"]
    Q3 -- "右軸偏位 (+90°〜+180°)" --> AntFascicle["左室前乳頭筋 / 左脚前枝領域"]
```

### 1) 右室流出路（RVOT）起源（最も頻度の高い特発性PVC）
- **V1誘導**: **左脚ブロック型（LBBB pattern）**（QS型またはrS型）。
- **肢誘導（II, III, aVF）**: **著明な高電位R波（下方軸: Inferior axis）**。
- **I, aVL誘導**: QS型または深いS波。
- **胸部誘導の移行帯（Transition zone）**: 通常 V3〜V4（V3より手前でR波が優位になる場合は大動脈弁洞冠尖 RCC/LCC 起源を考慮）。
- **特徴**: 若年・女性に多く、器質的心疾患を伴わない良性不整脈（アデノシン・β遮断薬感受性）。

### 2) 左室中隔・プルキンエ線維起源（Fascicular PVC）
- **V1誘導**: **右脚ブロック型（RBBB pattern）**（rsR'型または単相性R波）。
- **QRS幅**: 固有心筋起源に比べて比較的狭い（0.11〜0.13秒程度）。
- **左脚後枝領域起源**: 左軸偏位（II, III, aVFで陰性）。
- **左脚前枝領域起源**: 右軸偏位（II, III, aVFで陽性）。

## 5. リスク層別化と治療方針フローチャート

```mermaid
flowchart TD
    PVC["\"心室期外収縮 (PVC") の検出"] --> Step1["\"器質的心疾患の評価 (心エコー / 冠動脈評価 / MRI")"]
    
    Step1 -->|器質的心疾患なし (特発性)| Idiopathic{"症状 / PVC burden"}
    Idiopathic -->|無症状 かつ Burden < 10%| Obs["\"無治療・経過観察 (生活習慣是正")"]
    Idiopathic -->|有症状 または Burden ≥ 10-15%| TreatIdio["\"薬物療法 (β遮断薬") または カテーテルアブレーション"]
    
    Step1 -->|器質的心疾患あり (OMI/DCM/HCM/心不全)| Structural{"\"心機能・リスク評価 (LVEF / NSVT / R-on-T")"}
    Structural -->|LVEF ≤ 35% または 多形性/短連発| HighRisk["\"高リスク: β遮断薬 + 植込み型除細動器(ICD")検討"]
    Structural -->|LVEF > 35% かつ 散発性| LowRisk["\"基礎疾患の治療 (ACE-I/ARB/β遮断薬") + 厳重経過観察"]
```

> [!TIP]
> **PVC誘発性心筋症（PVC-induced Cardiomyopathy）**
> 特発性PVCであっても、総心拍数に対する出現割合が **15〜20%以上（ホルター心電図で1日15,000〜20,000発以上）** 存在し長期間持続すると、心室同期不全により進行性の左室拡大およびLVEF低下をきたすことがあります。この場合、カテーテルアブレーションによってPVCを根絶することで、心機能が劇的に正常化（Reversible）することが知られています。

## 6. 電子カルテ記載用レポートテンプレート

```text
【心電図所見】
・基本調律: 洞調律 (HR: 72 bpm)
・不整脈所見: 単源性心室期外収縮 (PVC) を散発的に認める (二段脈/連発なし)。
・PVC波形特徴: V1誘導でQS型(LBBB様)、II・III・aVF誘導で高電位R波(下方軸)。移行帯はV3-V4。
・重症度評価: Lown Grade 1 (RVOT起源の特発性PVCを示唆)。
・ST-T変化: 洞性拍において有意なST-T変化なし。

【総合判定】
単源性心室期外収縮 (RVOT起源疑い、Lown Grade 1)

【推奨コメント】
自覚症状(動悸・胸部不快感)の有無を確認。器質的心疾患が疑われない場合は経過観察可能ですが、有症状時や頻発時は24時間ホルター心電図および心エコー図検査による精査を推奨します。
```
