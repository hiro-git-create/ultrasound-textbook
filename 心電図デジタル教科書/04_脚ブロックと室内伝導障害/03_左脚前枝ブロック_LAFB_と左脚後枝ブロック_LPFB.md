# 03 左脚前枝ブロック (LAFB) と左脚後枝ブロック (LPFB)

左脚はヒス束から分岐した後、解剖学的に**左脚前枝（Left Anterior Fascicle）**と**左脚後枝（Left Posterior Fascicle）**の2本の主要な分枝（Fascicle）に分かれます。このいずれか一方が単独で伝導途絶をきたした病態を「分枝ブロック（Fascicular Block）」または「半ブロック（Hemiblock）」と呼びます。

---

## 1. 解剖学的特徴と血流支配の比較

```mermaid
graph TD
    His["\"ヒス束 (Bundle of His")"] --> LBB["\"左脚本幹 (Left Bundle Branch")"]
    
    LBB --> LAF["\"左脚前枝 (Left Anterior Fascicle")<br>"・細長く単一の束<br>・左室前壁〜心尖部〜前乳頭筋へ走行<br>・単一血流: LAD (前下行枝中隔枝")"]
    LBB --> LPF["\"左脚後枝 (Left Posterior Fascicle")<br>"・太く短い扇状の束<br>・左室後下壁〜後乳頭筋へ走行<br>・二重血流: LAD後中隔枝 + RCA/LCx\""]
    
    LAF -.->|障害されやすい (高頻度)| LAFB["\"左脚前枝ブロック (LAFB")"]
    LPF -.->|極めて障害されにくい (稀)| LPFB["\"左脚後枝ブロック (LPFB")"]
```

| 項目 | 左脚前枝 (Left Anterior Fascicle) | 左脚後枝 (Left Posterior Fascicle) |
| :--- | :--- | :--- |
| **解剖学的形態** | 細長く、脆弱な単一の線維束 | 太く短く、扇状に広がる強固な線維網 |
| **走行経路** | 左室流出道・前壁・前乳頭筋 | 左室流入道・後下壁・後乳頭筋 |
| **冠動脈血流支配** | **左前下行枝（LAD）の前中隔枝のみ**（単一支配） | **LAD後中隔枝 ＋ 右冠動脈（RCA）/ 回旋枝（LCx）**（二重支配） |
| **ブロックの頻度** | **極めて高頻度**（単独でも高血圧・加齢等で多発） | **極めて稀**（広範な心筋障害がないと生じない） |
| **電気軸への影響** | **著明な左軸偏位 ($-45^\circ \sim -90^\circ$)** | **著明な右軸偏位 ($+90^\circ \sim +180^\circ$)** |

## 2. 左脚前枝ブロック（LAFB）の心電図診断

```mermaid
graph TD
    LAFB_Mech["左脚前枝ブロックの興奮伝播"]
    LAFB_Mech --> Step1["\"① 正常な左脚後枝から後下壁が早期脱分極<br>(下向き・右向きの初期起電力: II/III/aVFに微小r波、I/aVLに微小q波")"]
    Step1 --> Step2["\"② 遅延した前壁・側壁へ興奮が上向きに伝播<br>(左上方へ向かう巨大な主興奮ベクトル: I/aVLに高いR波、II/III/aVFに深いS波")"]
    Step2 --> Result["\"結果: 著明な左軸偏位 (-45°〜-90°")"]
```

### LAFBの確定診断基準
1. **著明な左軸偏位**: 前額面電気軸が **$-45^\circ \sim -90^\circ$**（II, III, aVF誘導の主波が深い陰性S波）。
2. **側壁誘導（I, aVL）**: **qRパターン**（小さなq波と高いR波）。aVL誘導におけるピーク時間（VAT）$\ge 0.045$ 秒。
3. **下壁誘導（II, III, aVF）**: **rSパターン**（小さなr波と深く幅広いS波、S波の深さは III > II）。
4. **QRS幅**: **正常範囲内（$< 0.12$ 秒、通常は $0.08 \sim 0.10$ 秒）**。
5. **除外項目**: 著明な左軸偏位をきたす他の原因（下壁心筋梗塞、左室肥大単独、肺気腫等）がないこと。

> [!WARNING]
> **LAFBにおける心電図誤診ピットフォール**
> 1. **前壁中隔の r波減高（Poor R Wave Progression: PRWP）**:
>    - LAFBでは初期起電力が下方に向かうため、V1〜V3でr波が小さくなりやすく、前壁心筋梗塞と誤認されやすい。
> 2. **下壁心筋梗塞（OMI）との鑑別**:
>    - 下壁誘導（II, III, aVF）の「rSパターン」の初期微小r波を見落とすと「QSパターン（下壁梗塞）」と誤読してしまうため、高感度記録で微小r波を確認する。

## 3. 左脚後枝ブロック（LPFB）の心電図診断

```mermaid
graph TD
    LPFB_Mech["左脚後枝ブロックの興奮伝播"]
    LPFB_Mech --> Step1["\"① 正常な左脚前枝から前側壁が早期脱分極<br>(左上方へ向かう初期起電力: I/aVLに微小r波、II/III/aVFに微小q波")"]
    Step1 --> Step2["\"② 遅延した後下壁へ興奮が右下方へ向かって伝播<br>(右下方へ向かう巨大な主興奮ベクトル: II/III/aVFに高いR波、I/aVLに深いS波")"]
    Step2 --> Result["\"結果: 著明な右軸偏位 (+90°〜+180°")"]
```

### LPFBの確定診断基準
1. **著明な右軸偏位**: 前額面電気軸が **$+90^\circ \sim +180^\circ$（特に $+120^\circ$ 以上）**。
2. **側壁誘導（I, aVL）**: **rSパターン**（小さなr波と深いS波）。
3. **下壁誘導（II, III, aVF）**: **qRパターン**（小さなq波と高いR波、R波の高さは III > II）。
4. **QRS幅**: **正常範囲内（$< 0.12$ 秒）**。
5. **必須条件（除外診断）**: **右室肥大（RVH）、広範側壁心筋梗塞、慢性肺疾患、若年やせ型の生理的右軸偏位がないこと**。

> [!CAUTION]
> **LPFBは「完全な除外診断」である！**
> 左脚後枝は極めて太く二重血行支配を持つため、単独でLPFBをきたすことは極めて稀です。右軸偏位を認めた場合、まず**肺高血圧症・右室肥大・急性肺塞栓症・側壁心筋梗塞**を徹底的に除外した上で初めてLPFBと診断します。

## 4. LAFB vs LPFB 徹底比較対比表

| 項目 | 左脚前枝ブロック (LAFB) | 左脚後枝ブロック (LPFB) |
| :--- | :--- | :--- |
| **電気軸** | **著明な左軸偏位 ($-45^\circ \sim -90^\circ$)** | **著明な右軸偏位 ($+90^\circ \sim +180^\circ$)** |
| **I, aVL 誘導** | **qR パターン** (微小q + 高いR) | **rS パターン** (微小r + 深いS) |
| **II, III, aVF 誘導** | **rS パターン** (微小r + 深いS, S波: III > II) | **qR パターン** (微小q + 高いR, R波: III > II) |
| **QRS幅** | $< 0.12$ 秒 (正常〜軽度延長) | $< 0.12$ 秒 (正常〜軽度延長) |
| **V1〜V3 誘導** | Poor R progression（r波減高）を呈しやすい | 特異的変化なし（正常rS） |
| **好発原因** | 加齢、高血圧、前壁心筋梗塞、弁膜症 | 広範心筋梗塞、心筋症、高度線維化病変 |
| **合併頻度** | **完全右脚ブロック（CRBBB）との合併が多い** | 稀だがCRBBBと合併すると完全房室ブロック高リスク |

## 5. レポート記載例

### 左脚前枝ブロック（LAFB）の標準レポート
```text
【心電図所見】
洞調律 64bpm、前額面電気軸 -58° (著明な左軸偏位)。
QRS幅 92ms。
I, aVL誘導にて qR パターン (aVL VAT 48ms)、II, III, aVF誘導にて rS パターン (S_III > S_II) を認める。
胸部誘導において明らかな異常Q波やST-T変化は認めず。

【診断】
左脚前枝ブロック (Left Anterior Fascicular Block: LAFB)
【コメント】
単独のLAFB所見です。高血圧性心疾患や加齢性変化でしばしば認められます。自覚症状・基礎心疾患の有無を確認してください。
```

### 左脚後枝ブロック（LPFB）のレポート
```text
【心電図所見】
洞調律 76bpm、前額面電気軸 +125° (右軸偏位)。
QRS幅 96ms。
I, aVL誘導にて rS パターン、II, III, aVF誘導にて qR パターン (R_III > R_II) を認める。
心エコー上、右室拡大・肺高血圧・側壁梗塞等の器質的所見は除外済み。

【診断】
左脚後枝ブロック (Left Posterior Fascicular Block: LPFB)
【コメント】
器質的心疾患および肺疾患の除外に基づくLPFBの診断です。刺激伝導系の広範な障害を示唆するため、完全房室ブロックへの進展に留意し経過観察を推奨します。
```
