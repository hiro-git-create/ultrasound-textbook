# 小児特有疾患の評価（川崎病冠動脈病変・PPHN・重症先天性心疾患）

本ページでは、小児心エコー検査において特に緊急性・重要性が高い**川崎病における冠動脈病変（CAL）のZ-score評価**、**新生児遷延性肺高血圧症（PPHN）**、および**重症先天性心疾患（Critical CHD）のスクリーニング**について解説します。

---

## 1. 川崎病（Kawasaki Disease）と冠動脈病変の Z-score 評価

川崎病の心エコー評価では、急性期から遠隔期にかけて**冠動脈障害（CAL: Coronary Artery Lesion）の早期発見とZ-scoreによる重症度分類**が最重要課題です。

### 1. 冠動脈の標準描出法と計測部位
- **胸骨傍短軸断面 (大動脈弁レベル)**:
  - **#5 左主幹部 (LMT)**: 大動脈弁輪の1〜2時方向から分岐する幹部。
  - **#6 左前下行枝 (LAD)** と **#11 左回旋枝 (LCx)** の分岐部。
  - **#1 右冠動脈 (RCA) 近位部**: 大動脈弁輪の10〜11時方向から起始する血管。
- **計測の鉄則**:
  - 超音波ビームに対して血管壁が垂直になる画像ズームで撮影。
  - 血管内腔の内膜から対側内膜（**trailing-edge to leading-edge**）までを最小〜最大径で計測。

### 2. 日本小児循環器学会 ガイドライン準拠 Z-score 重症度分類

体表面積（BSA）補正した Z-score（布施式/RAISE Study等）に基づき、以下のように分類・管理されます。

| 分類 | Z-score 定義 / 絶対径 | 臨床病態と管理 |
| :--- | :--- | :--- |
| **正常 (No involvement)** | **Z-score $< 2.0$** | 冠動脈径は正常範囲。 |
| **軽度拡大 (Dilation)** | **$2.0 \le \text{Z-score} < 2.5$** | 境界領域の拡大。 |
| **小冠動脈瘤 (Small Aneurysm)** | **$2.5 \le \text{Z-score} < 5.0$**<br>(かつ 絶対径 $< 4\text{mm}$) | 明らかな瘤形成。アスピリン等の抗血小板療法。 |
| **中等大冠動脈瘤 (Medium Aneurysm)** | **$5.0 \le \text{Z-score} < 10.0$**<br>(かつ 絶対径 $< 8\text{mm}$) | 高度な瘤形成。抗血小板・抗凝固療法の併用考慮。 |
| **巨大冠動脈瘤 (Giant Aneurysm)** | **$\text{Z-score} \ge 10.0$**<br>(または 絶対径 $\ge 8\text{mm}$) | **最重症。血栓形成・血栓性閉塞・心筋梗塞のリスクが極めて高。厳重な凝固管理**。 |

### 3. 川崎病におけるその他の観察項目
- **心筋炎 (Myocarditis)**: びまん性壁運動低下、LVEF低下。
- **心膜液貯留 (Pericardial Effusion)**: 急性期の炎症性液貯留。
- **弁膜症**: 僧帽弁逆流（MR）や大動脈弁逆流（AR）の併発。

## 2. 新生児遷延性肺高血圧症 (PPHN) のエコー評価

新生児期に肺血管抵抗（PVR）が低下せず、**著しい肺高血圧と右-左シャント（Right-to-Left Shunt）による重症チアノーゼ**を引き起こす病態です。

### 心エコー診断の3大チェックポイント
1. **心室中隔の収縮期平坦化 (D-shaped LV)**:
   - 右室高圧により、胸骨傍短軸断面で心室中隔が左室側に押し込まれ、左室腔が「D」の字型に変形する。
2. **動脈管 (PDA)・心房中隔 (PFO/ASD) での右-左シャント**:
   - カラー/パルスドプラにて、PDAまたはPFOを介して**右房/右室/肺動脈から大動脈/左房へ血流が流れる右-左シャント（R-to-L Shunt）**を証明する。
3. **TR Vmax による右室圧推定**:
   - 三尖弁逆流（TR）の最高血流速度 $V_{max}$ より、右室収縮期圧（RVSP $\approx 4 V_{max}^2 + \text{RAP}$）を算出し、大動脈圧（体血圧）と比較する（右室圧 $\ge$ 体血圧 で高圧）。

## 3. 重症先天性心疾患 (Critical CHD) のスクリーニング

出生直後〜新生児期に迅速な診断と動脈管開存維持（PGE1製剤投与）が必要となる4大重症疾患のエコー特徴です。

```
┌─────────────────────────────────────────────────────────────┐
│                 重症先天性心疾患 (Critical CHD)             │
├──────────────────────────────┬──────────────────────────────┤
│ 1. 左心発育不全症候群 (HLHS) │ 大動脈弁/僧帽弁閉鎖、左室極小, PDA依存 │
│ 2. 完全大血管転位 (d-TGA)    │ 大動脈がRVから、肺動脈がLVから起始   │
│ 3. 総肺静脈還流異常 (TAPVR)  │ 4本肺静脈がLAに還流せず右房/SVC等へ  │
│ 4. 重症大動脈縮窄 (CoAo)     │ 大動脈弓峡部狭窄、PDA閉鎖でショック  │
└──────────────────────────────┴──────────────────────────────┘
```

| 疾患名 | 心エコーの主要所見 | 緊急臨床アクション |
| :--- | :--- | :--- |
| **HLHS** (左心発育不全症候群) | **左室・上行大動脈が極小（低形成）**。右室が全身血流を駆動。PDA必須。 | PGE1持続投与。BAS（心房中隔裂開術）検討。 |
| **d-TGA** (完全大血管転位) | **大動脈が右室から前方に起始、肺動脈が左室から後方に起始**。大血管平行走行。 | PGE1持続投与。緊急BASによる心房レベルシャント確保。 |
| **TAPVR** (総肺静脈還流異常) | **左房背側に共通肺静脈幹（CPVV）が存在**し、左房に直接還流しない。 | 肺静脈狭窄を伴う場合は**超緊急手術適応**。 |
| **CoAo** (大動脈縮窄症) | 胸骨上窩で**大動脈弓峡部に周径性狭窄・Ductal cut**。下行大動脈舒張期拡張血流。 | PGE1投与にてPDAを開大させ下半身血流確保。 |

## 4. 臨床で役立つ3秒まとめ

| チェック項目 | 臨床アクション |
| :--- | :--- |
| **川崎病を見たら** | 主幹部(#5), LAD(#6), LCx(#11), RCA(#1) を必ず描出し、**Z-score を算出して Z ≥ 2.5 で瘤と判定**。 |
| **新生児のチアノーゼ** | 短軸で **D-shaped LV** を見逃さず、PDA/PFOのシャント方向（右-左シャント）をカラーで即確認。 |
| **大血管の平行走行** | 通常ねじれて交差する大動脈と肺動脈が平行に出ていたら **大血管転位 (TGA)** を疑う。 |
