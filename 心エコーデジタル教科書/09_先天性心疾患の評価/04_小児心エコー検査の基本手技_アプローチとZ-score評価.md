# 小児心エコー検査の基本手技・セグメント診断法と Z-score 評価

本ページでは、小児心エコー検査における**成人と異なる生理・解剖学的アプローチ**、解剖構造を系統的に同定する**順序立てたセグメント診断法（Sequential Segmental Analysis）**、小児固有の標準描出断面、および体格補正指標である**Z-score（ゼットスコア）の原理と臨床活用法**について詳細に解説します。

---

## 1. 小児心エコー検査の基本原則と準備

### 1. 検査環境と患者管理（鎮静と安全）
- **環境整備**: 室温の維持（特に新生児・乳幼児では低体温防止のため保温が必須）、静かな環境とビデオ・おもちゃ等によるなだめ。
- **鎮静管理**: 乳幼児で自発運動が著しく検査困難な場合、主治医管理のもとトリクロホスナトリウム（トリクロリール）やクロラール水和物等の鎮静薬を使用。**呼吸状態・SpO2モニターの常時監視**が必須。
- **プローブ選択**: 小児では高周波プローブ（7.5 MHz〜12 MHz）を使用し、高い空間分解能と高フレームレート（> 60 fps）を確保する。

---

## 2. 順序立てたセグメント診断法 (Sequential Segmental Analysis)

複雑先天性心疾患（CHD）の誤診断を防ぐため、**「心臓の空間的位置関係に惑わされず、各腔腸・血管の構造的特徴に基づき順序立てて同定する」**体系的診断アプローチです。

```
【セグメント診断の5つのステップ】

 1. 内臓-心房位 (Visceroatrial Situs) の判定
    ├── Solitus (正常位) / Inversus (逆位) / Ambiguus (無脾・多脾症候群)
    │
 2. 房室接続 (Atrioventricular Connection) と 房室弁 の同定
    ├── D-loop (正常) / L-loop (逆位)
    │
 3. 心室位 (Ventricular Loop) と 心室構造 の同定
    ├── 右室 (RV: 粗大肉柱・調節帯) vs 左室 (LV: 平滑肉柱・2本乳頭筋)
    │
 4. 心室大血管接続 (Ventriculoarterial Connection) の同定
    ├── Concordant (正常接続) / Discordant (大血管転位 TGA) / Double Outlet (両大室出)
    │
 5. 大血管位 (Great Arteries) と 関連構造 の確認
    └── 大動脈弓の走行 (左側 / 右側)・動脈管 (PDA)・静脈還流 (TAPVR/PAPVR)
```

### 心房・心室の解剖学的同定ポイント
- **右房 (RA)**: 広い三角形の心耳、Eustachian弁、櫛状筋。下大静脈（IVC）が直接還流する。
- **左房 (LA)**: 狭い指状（サギのくちばし状）の心耳。4本の肺静脈が還流する。
- **右室 (RV)**: **粗大な壁肉柱**、**調節帯（Moderator band）**、中隔付着の三尖弁。
- **左室 (LV)**: **滑らかな中隔壁**、**2本の遊離乳頭筋**、僧帽弁（僧帽弁輪と大動脈弁輪の解剖学的連続性）。

## 3. 小児固有の標準描出断面

成人と異なり、小児では**肋骨下断面 (Subcostal)** と **胸骨上窩断面 (Suprasternal)** が極めて重要なアプローチウィンドウとなります。

| 描出断面 | 主な観察構造と診断項目 | 臨床的意義 |
| :--- | :--- | :--- |
| **肋骨下断面 (Subcostal View)** | 心房中隔 (ASD)、心室中隔 (VSD)、IVC還流、内臓位 | 乳幼児で音響窓が広く、心房中隔の欠損やシャント血流をドプラ・2Dで最も直交して正確に観察可能。 |
| **胸骨上窩断面 (Suprasternal View)** | 大動脈弓 (Aortic Arch)、大動脈縮窄 (CoAo)、動脈管 (PDA) | 大動脈弓の走行（左側/右側弓）、CoAoの狭窄部流速（Ductal cut）、PDAの連続性シャントの確認。 |
| **高縦隔断面 (High Sternal View)** | 肺動脈分岐部 (RPA/LPA)、上大静脈 (SVC)、TAPVR | 左右肺動脈枝の形態・径の計測、総肺静脈還流異常（TAPVR）の垂直静脈流速評価。 |
| **胸骨傍断面 (Parasternal View)** | 冠動脈 (LCA/RCA)、LVOT/RVOT、VSD | 川崎病における冠動脈内径の描出、流出路狭窄の評価。 |

## 4. Z-score（ゼットスコア）による体格補正計測

### 1. なぜ小児では絶対値ではなく Z-score なのか？
- 小児は新生児（体重 2〜3 kg）から学童期・思春期（体重 50 kg 以上）まで**体格差が極めて大きい**ため、成人のような「大動脈弁輪径 > 20 mm」といった固定カットオフ値は使用できません。
- **Z-score** は、**「健常小児の体表面積（BSA）に対する平均値からの標準偏差（SD）がどれだけ離れているか」**を表す数値です。

$$\text{Z-score} = \frac{\text{計測値} - \text{平均値 (BSA依存)}}{\text{標準偏差 (SD)}}$$

### 2. Z-score の判定基準と臨床的解釈

| Z-score 数値 | 臨床的解釈 | 臨床的アクション・意義 |
| :---: | :--- | :--- |
| **$-2.0 \sim +2.0$** | **正常範囲 (Normal)** | 平均値の ±2SD 以内（健常児の95%が含まれる） |
| **$+2.0 \sim +2.5$** | **軽度拡大 (Mild Dilation)** | 境界域。経過観察を考慮。 |
| **$+2.5 \sim +5.0$** | **中等度拡大 / 小瘤** | 川崎病では**小冠動脈瘤 (Small Aneurysm)** と定義 |
| **$+5.0 \sim +10.0$** | **高度拡大 / 中等大瘤** | 川崎病では**中等大冠動脈瘤 (Medium Aneurysm)** |
| **$\ge +10.0$ (または absolute $>8\text{mm}$)** | **巨大瘤 (Giant Aneurysm)** | **極めて高リスク。血栓形成・心筋梗塞の絶対的注意** |

## 5. 臨床で役立つ小児心エコーの3秒まとめ

| チェック項目 | 観察ポイント |
| :--- | :--- |
| **1. 解剖の基本** | 空間の位置ではなく、**内臓位 ➔ 房室接続 ➔ 心室大血管接続** のセグメント順序で診断する。 |
| **2. 音響窓** | 探触子を当てたらまず **肋骨下断面 (Subcostal)** から入り、ASD・中隔・IVCをクリアに確認する。 |
| **3. 計測の鉄則** | 構造物（弁輪径、冠動脈、大動脈径）を計測したら、**必ず BSA に応じた Z-score に換算して評価する**。 |
