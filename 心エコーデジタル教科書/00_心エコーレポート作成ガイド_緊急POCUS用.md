# 緊急心エコー (POCUS / FATE) 標準レポート ＆ 作成ガイド (1分速攻型)

本ページは、救急外来・ICU・当直帯でのショック・呼吸困難・胸痛患者に対し、**1分で入力・完了できる速攻型 POCUS (Point-of-Care Ultrasound) レポートテンプレート**です。（**FATE / FOCUS プロトコル** に完全準拠）

## 📋 緊急心エコー (POCUS) 入力テンプレート (1分完成型)

```text
================================================================================
                    緊急心超音波検査報告書 (POCUS / FATE Report)
================================================================================
【患者情報 ＆ 検査目的】
ID: [           ] 氏名: [           ] 年齢: [   ]歳 性別: [男/女]  HR: [   ] bpm  BP: [   /   ]
検査適応: [ ショック鑑別 / 心停止 / 心肺停止(ROSC後) / 呼吸困難 / 胸痛 / 外傷(FAST) ]

--------------------------------------------------------------------------------
【ショック鑑別 5大緊急チェック項目】

1. 心タンポナーデ (Pericardial Tamponade)
   [ 陰性 ] 心嚢液なし・わずか
   [ 陽性 ] Echo-free space [    ] mm ＋ 右房/右室収縮期虚脱 (RA/RV collapse) あり ➔ 超緊急!

2. 急性右心負荷 / 肺塞栓症 (Acute RV Strain / PE)
   [ 陰性 ] 右室正常サイズ (RV/LV比 < 0.6)
   [ 陽性 ] 右室拡大 (RV/LV比 ≥ 1.0) ＋ 心室中隔 D-shaped LV ＋ McConnellサイン ➔ 急性PE疑い!

3. 左室収縮不全 (Severe LV Dysfunction)
   [ 正常〜軽度低下 ] 視覚的 EF (Eyeball EF) ≥ 45%
   [ 重度低下 ] 視覚的 EF < 30% (びまん性壁運動高度低下) ➔ 心臓原性ショック疑い

4. 脱水・有効循環血流量 (Intravascular Volume / IVC)
   [ 虚脱/脱水 ] IVC径 < 15 mm ＋ 吸気性完全虚脱 (>50%) ➔ 低容量性/出血性ショック
   [ 充盈/うっ血 ] IVC径 > 21 mm ＋ 虚脱障害 (<50%) ➔ 心原性/静脈うっ血

5. 急性大動脈解離 (Aortic Dissection)
   [ 陰性 ] 上行大動脈径正常、フラップなし
   [ 陽性 ] 上行大動脈拡大 ＋ 内膜フラップ (Intimal Flap) ＋ 急性AR ➔ Stanford A型解離!

--------------------------------------------------------------------------------
【総合緊急判定 (POCUS Conclusion)】
[ 判定 ]: [ 正常範囲 / 心タンポナーデ / 急性右心負荷(PE疑い) / 心原性ショック / 低容量性ショック / 大動脈解離疑い ]
[ 推奨 ]: [ 心臓血管外科緊急コンサルト / 心臓カテーテル検査 / 造影CT検査 / 液量負荷 / 降圧・消炎 ]
================================================================================
```
