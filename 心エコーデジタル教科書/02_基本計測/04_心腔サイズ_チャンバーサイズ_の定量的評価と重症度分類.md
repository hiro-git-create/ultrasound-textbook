# 心腔サイズ（チャンバーサイズ）の定量的評価と拡大重症度分類

日常臨床において、左室や右室・心房の大きさ（チャンバーサイズ）を「見た目（Eyeballing / 視覚的印象）」だけで判定すると、**検者の熟練度や体格・心腔の視覚的錯覚による誤認・ブレ**が生じます。

米国心エコー図学会（ASE）および欧州心臓病画像学会（EACVI）の国際ガイドラインでは、**4大心腔（LV, LA, RV, RA）すべての拡大重症度（軽度・中等度・高度拡大）が性別・体表面積（BSA）別に定量数値基準**として厳密に定められています。

---

## 1. なぜ「見た目の判断（Eyeballing）」だけでは危険なのか？

1. **心腔の立体形状による錯覚**:
   - 右室（RV）は三日月型をしているため、描出角度が少し傾くだけで拡大して見えたり（偽の右室拡大）、逆に正常に見えたりします。
2. **体格（BSA）の影響**:
   - 痩せ型の患者では絶対値が正常でも体格比で拡大していたり、逆に体格の大きなスポーツ選手では絶対値が大きくても正常範囲内であったりします。
3. **定量化のメリット**:
   - 経時的変化（治療効果や弁膜症の進行）をミリ単位・mL単位で客観的にトラッキングできます。

---

## 2. 4大心腔（チャンバー）の定量評価基準と拡大重症度分類

### ■ 1. 左室 (Left Ventricle: LV) の拡大重症度分類

左室の拡大は**「拡張末期内径 (LVDd)」**および**「2D Biplane Simpson法による拡張末期容積係数 (LVEDVi)」**で評価します。

#### ① 左室拡張末期径 (LVDd: mm) の重症度分類

| 性別 | 正常範囲 (Normal) | 軽度拡大 (Mild) | 中等度拡大 (Moderate) | 高度拡大 (Severe) |
| :---: | :---: | :---: | :---: | :---: |
| **男性** | **42 〜 58 mm** | **59 〜 63 mm** | **64 〜 68 mm** | **$\ge 69\text{ mm}$** |
| **女性** | **38 〜 52 mm** | **53 〜 56 mm** | **57 〜 61 mm** | **$\ge 62\text{ mm}$** |

#### ② 左室拡張末期容積係数 (LVEDVi: mL/m²) の重症度分類 ★より正確

| 性別 | 正常範囲 (Normal) | 軽度拡大 (Mild) | 中等度拡大 (Moderate) | 高度拡大 (Severe) |
| :---: | :---: | :---: | :---: | :---: |
| **男性** | **35 〜 74 mL/m²** | **75 〜 89 mL/m²** | **90 〜 100 mL/m²** | **$\ge 101\text{ mL/m}^2$** |
| **女性** | **29 〜 61 mL/m²** | **62 〜 70 mL/m²** | **71 〜 80 mL/m²** | **$\ge 81\text{ mL/m}^2$** |

---

### ■ 2. 左房 (Left Atrium: LA) の拡大重症度分類

> [!IMPORTANT]
> **左房は1次元の「前後径 (LAD)」で見ると誤認する**
> 左房は前後方向に胸郭で挟まれているため、拡大する際は左右・上下方向に偏って拡大します。そのため、前後径（LAD）が正常に見えても**左房容積係数 (LAVI)** では高度拡大しているケースが多発します。必ず **LAVI** で評価してください。

#### 左房容積係数 (LAVI: mL/m²) の重症度分類 (男女共通)

| 拡大区分 | LAVI 基準値 | 臨床的背景・リスク |
| :--- | :---: | :--- |
| **正常 (Normal)** | **$\le 34.0\text{ mL/m}^2$** | 正常な左房圧・構造 |
| **軽度拡大 (Mildly Enlarged)** | **$35.0 \sim 41.0\text{ mL/m}^2$** | 初期拡張能障害、軽度MR |
| **中等度拡大 (Moderately Enlarged)** | **$42.0 \sim 48.0\text{ mL/m}^2$** | 持続的な左房圧負荷、心房細動 (AF) リスク上昇 |
| **高度拡大 (Severely Enlarged)** | **$> 48.0\text{ mL/m}^2$** | **重症拡張障害、慢性AF、心不全再入院の高リスク** |

---

### ■ 3. 右室 (Right Ventricle: RV) の拡大重症度分類

右室は視覚的印象（Eyeballing）で最も誤認しやすいため、**「右室強調4腔像 (RV-focused A4C)」における基部径 (RV Base)** および **RV / LV 径比** で客観評価します。

#### ① 右室基部径 (RV Basal Diameter: mm) の重症度分類

| 区分                   |      RV 基部径 (RV Base)      | 右室 / 左室 (RV/LV) 径比 | 視覚的特徴・中隔動態                                       |
| :------------------- | :------------------------: | :----------------: | :----------------------------------------------- |
| **正常 (Normal)**      |   **$\le 41\text{ mm}$**   |    **$< 0.6$**     | 右室は左室より明らかに小さく、心尖部は左室が形成。                        |
| **軽度拡大 (Mild)**      | **$42 \sim 47\text{ mm}$** | **$0.6 \sim 0.9$** | 右室が拡大するが、心尖部は依然として左室が形成。                         |
| **中等度拡大 (Moderate)** | **$48 \sim 51\text{ mm}$** | **$\approx 1.0$**  | **右室と左室の大きさが同等**に見える。                            |
| **高度拡大 (Severe)**    |   **$\ge 52\text{ mm}$**   |    **$> 1.0$**     | **右室が左室より巨大化し、心尖部を右室が形成**。心室中隔が平坦化（D-shaped LV）。 |

---

### ■ 4. 右房 (Right Atrium: RA) の拡大重症度分類

右房は心尖部4腔像 (AP4) の収縮末期において**「右房最大面積 (RA Area)」**で評価します。

#### 右房最大面積 (RA Area: cm²) の重症度分類 (男女共通)

| 拡大区分 | RA 面積 (RA Area) | 臨床的意義 |
| :--- | :---: | :--- |
| **正常 (Normal)** | **$\le 18.0\text{ cm}^2$** | 正常な右房サイズ |
| **軽度拡大 (Mild)** | **$19.0 \sim 24.0\text{ cm}^2$** | 三尖弁逆流 (TR) 軽度、右房圧軽度上昇 |
| **中等度拡大 (Moderate)** | **$25.0 \sim 30.0\text{ cm}^2$** | 重症TR、肺高血圧症 (PH) の進行 |
| **高度拡大 (Severe)** | **$> 30.0\text{ cm}^2$** | **最重症右心不全、右房内血栓・不整脈ハイリスク** |

---

## 3. 小児科におけるチャンバーサイズ（心腔サイズ）重症度基準

小児科では体格差（新生児〜思春期）が非常に大きいため、「LVDd 55 mm以上」のような固定値は一切使用できません。
代わりに**体表面積（BSA）で補正した Z-score（ゼットスコア）による拡大重症度分類**が国際標準（ASE 2024 Pediatric Guidelines）として採用されています。

### ■ 小児心腔サイズ (LV, LA, RV, RA) の Z-score 重症度分類基準

| 拡大区分 | Z-score 範囲 | 臨床的意義・心腔状態 |
| :--- | :---: | :--- |
| **高度低形成 (Severely Small)** | **$\text{Z-score} < -4.0$** | 心腔が極小（HLHSや単心室等での低形成） |
| **軽度〜中等度低形成** | **$-4.0 \le \text{Z-score} < -2.0$** | 体格に対して明らかに小さい心腔 |
| **正常範囲 (Normal)** | **$-2.0 \le \text{Z-score} \le +2.0$** | **標準偏差 ±2SD 以内（同体格小児の95%が含まれる）** |
| **軽度拡大 (Mild Dilation)** | **$+2.0 < \text{Z-score} \le +3.0$** | 体格標準よりやや大きい心腔 |
| **中等度拡大 (Moderate Dilation)** | **$+3.0 < \text{Z-score} \le +4.0$** | シャント疾患（VSD/PDA/ASD等）による明確な心拡大 |
| **高度拡大 (Severe Dilation)** | **$\text{Z-score} > +4.0$** | **最重症。著明な容量負荷・心不全・弁逆流を伴う心腔拡大** |

---

## 4. 臨床で迷った時の3秒チェックリスト

```
【チャンバーサイズ評価の標準ステップ】

 1. 左室 (LV): LVDd (男>58, 女>52) だけでなく、LVEDVi (男>74, 女>61) を確認。
 2. 左房 (LA): 見た目のLADではなく、必ず Simpson法で LAVI (>34) を算出。
 3. 右室 (RV): RV-focused A4C で基部径 (>41mm) と RV/LV 比 (>1.0 で重症) を計測。
 4. 右房 (RA): 4腔像で RA Area (>18cm²) をトレース。
```

> [!TIP]
> **見た目（Eyeballing）との併用**
> スクリーニング時には見た目の直感も有用ですが、レポート作成や電子カルテ記載時には**必ず上記ガイドラインの定量的数値と拡大グレード（軽度/中等度/高度拡大）をセットで明記する**ことが推奨されます。
