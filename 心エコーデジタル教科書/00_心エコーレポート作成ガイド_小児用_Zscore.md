## 2. 小児 Z-score 判定値クイックガイド

### ■ 冠動脈 Z-score 分類 (川崎病 JCSガイドライン)
- **Z < +2.0**: 正常 (Normal)
- **+2.0 ≤ Z < +2.5**: 軽度拡大 (Dilation)
- **+2.5 ≤ Z < +5.0**: **小冠動脈瘤 (Small Aneurysm)** (かつ絶対径 $<4\text{mm}$)
- **+5.0 ≤ Z < +10.0**: **中等大冠動脈瘤 (Medium Aneurysm)** (かつ絶対径 $<8\text{mm}$)
- **Z ≥ +10.0**: **巨大冠動脈瘤 (Giant Aneurysm)** (または絶対径 $\ge 8\text{mm}$)

### ■ チャンバーサイズ Z-score 分類 (ASE 2024)
- **Z < -4.0**: 高度低形成 (HLHSなど)
- **-2.0 ≤ Z ≤ +2.0**: **正常範囲 (Normal)**
- **+2.0 < Z ≤ +3.0**: 軽度拡大 (Mild)
- **+3.0 < Z ≤ +4.0**: 中等度拡大 (Moderate)
- **Z > +4.0**: **高度拡大 (Severe)**
